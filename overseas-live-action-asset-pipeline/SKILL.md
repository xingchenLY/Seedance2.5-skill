# 资产自动化流程

技能对外名称固定为“资产自动化流程”。Codex 和剧梦仅为图片生成环节的流程名称；后续导入、切换或更新不修改技能名称。

## 共用前期：先整理表格

读取 [共用资产整理与存储流程](references/shared-workflow.md)。调用时先明确国内／海外模式，正文分析、资产清单、完整提示词、表格排序合并、排版检查及本地保存使用同一流程，不在这些阶段询问 Codex／剧梦。

默认只整理并保存 Excel，不生成图片，也不询问出图流程。需要图片时，先完成并保存资产表，再进入下方出图环节。用户明确只要提示词或只要图片时保留原输出限制；仅图片任务不强加 Excel，但仍在开始出图前选择流程。提前明确的流程选择可记录，不能据此跳过共用整理工作。

## 中间分流：图片生成

只有准备生成已选的人物原照、人物三视图、场景或道具图片时，才询问：“资产表已整理完成，本次图片生成使用 Codex 还是剧梦（待导入）？”仅图片任务相应说明正在进入出图阶段。用户已经明确选择则沿用；未选时等待选择，不自动默认。

| 图片生成流程 | 入口 |
| --- | --- |
| Codex | [Codex 图片生成](references/codex-workflow.md)，沿用原来的出图方式 |
| 剧梦 | [剧梦图片生成入口](references/jumeng-workflow.md)，内容暂空，待用户导入 |

选择写入 asset_workflow：codex／jumeng；它只控制新图片生成。表格整理时允许省略，国内／海外和题材均为共用设置。剧梦尚未导入时只暂停新出图，不阻塞资产表制作、保存或交付，不补写生成步骤、不调用剧梦视频技能、不自动切回 Codex。

## 共用后期：沿用原存储流程

无论图片由哪个流程生成，返回后均接回 [原运行与保存规则](references/runtime.md)：绑定真实源图、返回即保存待审副本、逐图检查、正式归档、命名、去重、失败恢复及交付均沿用原方式。人物／场景／道具目录、图片版本策略和表格原路径覆盖规则不变。

出图流程切换不重做表格、不删除旧图片，也不把已有图片说成新流程生成。已有在途请求继续接收，已返回图片继续检查和存储；新图片按当前所选流程生成，记录真实来源。后续只导入剧梦的图片生成步骤，将结果接回共用存储即可。

修改／分析技能、索取既有模板或安装包不启动资产生产，不要求选择出图流程。
