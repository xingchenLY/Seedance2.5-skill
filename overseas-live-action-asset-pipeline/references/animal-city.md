# 拟人动物都市动画题材：形象、空间、光影与材质

**先选国内／海外模式：** 本页原模板保留为海外原样版本。国内同样采用此处物种、动画比例、材质和光影设计方法，但场景道具使用 [国内模板](domestic-mode.md#国内拟人动物都市动画) 的国内环境与中文文字规则；原有场景道具“无可辨文字”不适用于已指定的必要中文。动物角色不套亚洲人脸，真人角色才执行国内亚洲面貌设定。

本题材以《疯狂动物城》（Zootopia，2016）的官方成片画面、概念图和制作资料为分析基础，将可复用的设计方法转成资产提示词。读取后只应用本次所选类别；不是自动制作原片角色、复制城市或启动整套生图的指令。

## 启用与既有规则的关系

- 用户明确要求“疯狂动物城风格”“拟人动物都市动画”等，或正文明确采用穿衣、直立、参与城市社会的拟人动物世界时启用。真人剧里出现宠物、野生动物或动物装饰不触发；只有某些资产采用此题材时仅覆盖这些资产，不自行把全剧人类变成动物。纯分析或技能维护无需剧本，不启动出图。
- 保持原有技能名称、请求字段、资产 ID 与类别；拟人动物居民仍归“人物”，不是“道具”。沿用正文取证、所选范围、张数、服装／状态去重、图片依赖、逐图保存与返修上限。风格选择写入现有 `preflight.continuity`，不添加脚本不支持的请求字段。
- 本题材以本页模板替换对应资产模板中的“真人摄影、演员选角、人类肤色骨相、人体黄金比例、无动漫／无游戏建模感”等不相容措辞，目标是电影级三维动画成片。保留画幅、命名、完整服装、无标识、空场景、表格排序合并及本地保存要求；不要将两套风格句子叠在同一提示词里。
- 物种和毛色不套用真人族裔偏好，不强制匹配真人脸或给动物判断族裔；用户人物参考在适用且已查看时可借服装、配色与气质，不把真人脸贴到动物头部。原创动物以物种结构、毛色分区和稳定辨识点复核；含真人、真人面貌参考或明确真人指向的部分仍执行相应原创与肖像风险规则。不编造名人相似度或全球商用许可。
- 按人类社会年龄设定的拟人角色，保留既有外观年龄映射一次：正文 30–40 岁对应 25–30 岁，41–50 岁对应 31–35 岁，提示词确定一个社会年龄并辅以相符的成年气质；不改剧情年龄或代际。正文给出动物自然年龄时按物种与剧情生命阶段理解，不机械当成人类儿童年龄或触发上述映射；未明数字时用正文支持的幼年、青年成年、成熟或年长阶段，不凭毛色测精确年龄。
- 默认资产设计围绕本次剧本的角色、职业和地点展开；原片中的兔警官、狐狸搭档和地名只作分析例，不自动导入本剧。用户明确点名原片资产时按其实际请求处理，不把风格分析当成素材授权结论。

## 分析依据与可复用特点

查阅日期：2026-10-15。以下区分官方资料、画面观察和本技能的美术设计建议。

| 维度 | 分析结论 | 转为资产设计时的重点 |
| --- | --- | --- |
| 动物形象 | 官方制作资料强调：拟人化服装与表演仍保留动物特征；官网办公场景中，兔与狐的耳形、口鼻长度、面颊轮廓和眼睑表情均不同。 | 先锁定物种轮廓与体型，再设计眼睑、口角、姿态和服装；避免所有物种共用人脸或同一头身比。 |
| 场景风格 | 官方资料将城市定义为多气候、多尺度环境；官网街口概念图把动物身体差异与城市用品放在一起组织。 | 门洞、柜台、座椅、交通和手持物按使用者尺度设计，保持可居住、可通行的空间逻辑。 |
| 光影色调 | 官网冰雪城区概念图可见青蓝环境与暖窗灯；沙漠城区概念图呈暖红橙大气和局部亮色灯光。概念图是色彩与形状参考，不等于每场成片固定滤镜。 | 按城区、时间和剧情选择色彩关系，室内再受窗向、材料与实景灯影响；避免全片统一橙青或一律高饱和。 |
| 材质风格 | 官方毛发论文讨论纤维多重散射、粗糙度与可控外观；角色保持概括造型，同时需要可信的毛发和服装细节。 | 用毛流、毛长、粗糙度和反射差异区分表面，保留动画轮廓；不把动物做成塑料玩具、布偶服或野生动物照片。 |

## 动物形象设计

在现有连续性记录中为每个角色固定：物种、直立体型与相对身高、头身关系、口鼻长度、耳／角形状、眼睛与眼睑、毛色或皮肤色及花纹分区、各部位毛长、尾形、爪／蹄结构、服装及必要配饰。正文未规定的部分可设计，但前后状态保持一致；两三个可见记忆点优先来自这些形态，不任意加剧情伤疤。象、河马等稀疏毛物种按裸露皮肤和少量毛发设计，不强加绒毛；本次正文另含爬行动物时按其实际鳞片与结构替换毛发条款，不将其说成首部电影的物种分析。

| 形态方向 | 可用设计重点 | 常见偏差 |
| --- | --- | --- |
| 兔、鼠等长耳或小体型角色 | 区分耳长与耳根、口鼻厚度、门牙是否可见、短密绒毛；用轮廓和衣服剪裁表达年龄与职业。 | 一律大眼幼态、耳朵裁断、仅换毛色就当不同角色。 |
| 狐、犬、狼等长口鼻角色 | 保留吻部长度、耳尖形状、面颊毛流、鼻部与胡须；肩背体型及尾形各有差别。 | 动物鼻子贴在人脸上；所有犬科都复制同一狡黠笑容。 |
| 牛、鹿、羊等有蹄角色 | 设计角与耳的空间关系、蹄部或既定拟人手部、颈肩结构；羊毛与短毛分开处理。 | 通用人手人脚、角长在错误位置、毛发覆盖眼睛或衣领穿模。 |
| 熊、大型猫科等厚实体型 | 通过胸肩、腹部、颈部和四肢重量组织大轮廓，毛色／斑纹保留稳定分区。 | 把大型物种统一缩成纤细人形，或将所有大体型都当凶恶反派。 |
| 水獭等水边生活角色 | 可采用贴伏短毛、适配的体型和尾部轮廓；是否湿润由剧情决定。 | 因物种而自动全身滴水，把鼻部小高光扩成全身塑料反光。 |
| 象、河马等稀疏毛角色 | 保留鼻、耳、厚重体块和皮肤褶皱的物种差异，纹理按动画尺度概括。 | 给全身长出绒毛，或将皮肤做成无层次的硬塑料。 |

物种不决定性格、阶级或善恶，职业与行为来自正文。服装需要适配耳角、脖颈、尾根、爪蹄和既定动作；裁缝式结构可以夸张但应能穿着，不强迫所有物种穿同一种人类鞋。头顶毛簇与身体毛发分开描述，不默认给动物加真人假发。

角色图默认 9:16 半身正面，耳朵、角和口鼻完整入画；未显示的尾部、下装和足部只作文字设定，不声称半身照已展示。群像沿用 4:3，逐个描述物种、服装和站位，保留相对体型，不把不同物种强行等高；只有同一角色的三视图要求等高。

## 场景体系、光影和色彩

先确定这间房或街段服务的物种与尺度，再选择城区和功能。共享建筑可按实际需求安排大小入口、不同高度操作面和连通路线，私人房间则以主人尺度为主；不要求每个房间都放齐所有尺寸。核心功能和至少两项可见空间区别继续按 [空间区分与防重复](visual-specs.md#空间区分与防重复) 执行。

| 场景方向 | 形状与陈设建议 | 光影与配色建议 |
| --- | --- | --- |
| 都市中心／交通与商业街段 | 现代建筑、清楚的街道层级、适配不同体型的门口与公共设施；轮廓适度概括。 | 白天可用温暖日光与偏冷天空补光，主体色块清晰、远处降低对比；夜晚由已设灯具建立局部色彩。 |
| 寒冷城区 | 建筑体块和防寒结构明确，积雪、冰棱等只在已确定环境与状态下出现；室内具保温感。 | 冷青蓝环境中用小范围琥珀暖窗或壁灯建立生活感；雪、冰与涂漆墙面有不同反射。 |
| 干燥／沙漠城区 | 可用遮阳构件、石材、灰泥、通风空间及适配环境的植被，不把所有建筑变成沙堡。 | 日间赭石、沙金和克制的冷色阴影；黄昏或夜景按既定时间设计，霓虹仅用于有该设施的地点。 |
| 湿润／雨林城区 | 分层植被、适配坡地或高差的建筑和走道，门窗通路仍可辨。 | 绿青环境反射配局部暖光，枝叶投影打破大平面；仅在湿度与气氛设定合理时加入轻微体积光。 |
| 小体型居民街区 | 从居民视角看是完整生活空间，门窗、家具和用品按其尺度设计；确需表现外部大尺度设施时再加入对照。 | 保留街巷的正常纵深与清楚光向，不默认移轴、玩具陈列或建筑沙盘效果。 |
| 公共办公室／住宅室内 | 物种适配的座椅、柜台、收纳和必要生活装饰；不要只在普通人类房间贴动物图案。 | 采用有来源的窗光和实景灯，反射补光保留结构，棉麻、木材与金属分区清楚。 |

以上不是新建资产清单；只设计正文或用户选择的空间。选定某城区不自动增加雨雪、昼夜版本或未出现的设备。时段推断与天气规则沿用原流程；参考图的视角、文字和群众不自动带入资产。

场景保持 16:9 全景、自然透视。空场景中不出现人类、拟人动物居民、普通动物、身体局部、人物影子或角色反射，也不以动物肖像画、海报、屏幕补入角色；保留必要陈设和环境植物。相邻房间参考已有合格图延伸共享结构、物种尺度、材料和光照关系，同时保留各自功能布局。昼夜版保持房间与主要陈设位置不变。

沿用 [场景影视光影](scene-lighting.md) 的“光源位置—方向—光质—明暗冷暖—介质／材质反应”写法：

- 常态生活可采用较明亮的中间调、柔和环境补光和清楚的冷暖分区；不是所有画面必须高调。
- 悬疑或危险场景可降低背景亮度、增加局部硬光和明暗对照，仍保留关键空间结构；不因三维动画题材取消剧情情绪。
- 毛发边缘可用克制轮廓光，浅色毛发保留层次；场景体积光、焦散、斑驳光只在来源和介质成立时使用。
- 将主色、辅助色和少量视觉重点分开，避免每块材质同饱和、同亮度；情绪色只作用于本场，不永久改变角色毛色或道具固有色。

## 材质风格的提示词写法

| 材质 | 写出可见结果 | 控制偏差 |
| --- | --- | --- |
| 毛发 | 固定毛长分区和生长方向，短密底绒与适量长毛形成自然轮廓；光在毛束间散射，亮部柔润、阴影有层次。 | 不要求全身一样长，不用几根粗毛代替覆盖，不做毛绒玩具接缝。 |
| 稀疏毛与裸露皮肤 | 按物种保留疏毛、厚皮褶皱及局部细纹，控制粗糙度与透光，轮廓仍概括清楚。 | 不把所有动物做成毛球，也不将厚皮表现成半透明果冻。 |
| 眼睛、鼻与耳内薄皮 | 眼睑包裹眼球，适量角膜反光；鼻部有限湿润高光；耳内仅有克制透光感。 | 不把整张脸做成玻璃或果冻，不用人类皮肤孔洞覆盖有毛区域。 |
| 棉麻、针织与制服 | 缝线和织纹适配角色尺度，折痕与受力合理；衣领、袖口及尾部开口干净，毛发不穿布。 | 不把布料做成金属反射或把毛发与衣服融成一种表面。 |
| 木材、石材、灰泥 | 大形简练，表面有适度纹理、粗糙度变化与局部使用痕迹，边角符合设计语言。 | 不全城统一光滑塑料，也不以过度脏污追求照片写实。 |
| 金属、玻璃、橡胶 | 金属定向高光、玻璃受控反射与透明度、橡胶柔哑表面各自清楚。 | 不让全部表面同亮、同粗糙度，不把所有边缘变成发光描边。 |

“物理可信材质”“多重散射”“各向异性毛发高光”等用于表达目标外观，不声称图片工具实际使用了指定渲染器、算法或精确参数；不把样片的毛发数量、软件名、渲染耗时当作提示词质量保证。

## 逐项检查与交付

- 生成前把世界风格、物种、固定毛色／尺度、服装结构、城区与材质方案放入既有四项 preflight；图像工具收到的是完整提示词与适用的实际参考图。只做提示词或表格时同样写完整方案，不为验证模板额外出图。
- 角色检查物种特征、眼口表情、耳角与爪蹄结构、稳定毛色、服装适配及有无穿模；群像检查人数、逐个身份和相对体型。原照的 `single_person` 在此表示“画面仅一名拟人角色”，由实际观察判断，不能因其是动物就填 false 或当成多人照。
- 同次执行 [跨角色外貌校验](character-distinction.md)，用动物头部结构和固定面部花纹对照项目内其它角色；同物种角色撞脸也不通过，不使用真人族裔或人脸身份识别。
- 场景检查使用者尺度、建筑连接、不同房间的功能区别、空场景、必要陈设和光照连续性；道具检查功能、尺度与材质，手机另查正背面和壳体。技术比例检查通过不代表这些项目已通过。
- 视觉结论写入 `checked.note`；不符时记录具体物种、结构或风格问题并沿用已有质量返修上限，不做名人识别、族裔判定或精确年龄鉴定。真人风险规则只用于有对应自然人要素的部分，不能把纯动物原创设计说成已完成人脸比对或取得 IP 授权。
- 动物角色沿用“人物资产”表和人物文件夹；场景／道具沿用各自类别。题材与光影、材质描述写在原有完整提示词列，不加题材工作表或新列；人物三视图仍不入表。排序合并、表格就绪即保存与后续覆盖、待审落盘与正式归档规则全部沿用。
