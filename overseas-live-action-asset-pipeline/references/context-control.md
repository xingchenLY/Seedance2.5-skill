# 上下文与输出开销控制

资产生产启动时读取一次，同任务沿用。以下是读取和输出预算，不是模型硬性 token 上限，也不保证具体速度或额度；用户要求完整解释时正常提供。不能为节省上下文跳过正文依据、图片审核、引用核对或保存验证，不改变资产范围与并发规则。

## 按阶段读取

- 首次只读入口、请求规则和当前阶段引用；确定地域、题材、平台后只读相应分支。不要一次读取整个技能目录、所有题材、全部历史对话或旧安装包。文件未变且规则仍在上下文中时不重复读取；用户说明技能已修改或实际文件变更时只补读受影响部分。
- 正文在首次分析时完整覆盖所选范围，长剧本按集／场拆读并建立有原文行号的索引。生成阶段只取当前资产的证据、完整提示词、关联图与必要规则，不每张重读整部剧本或全表。需要跨集证据时定向补读，不能用摘要替代尚未核对的正文。
- 运行环境、模板样式、参考图索引定位一次后复用；只查看当前确实需要的参考图，不每轮加载 34 张素材。已通过图片在文件和设计未变时复用审核记录，不反复打开同图作同项审核；新图、返修图和变更引用仍须实际查看。

## 单次输出预算

- 常规文本工具输出目标不超过约 4,000 字符（可控制时 max_output_tokens 约 1,500）；诊断日志尾部目标不超过 2,000 字符。按行号、资产 ID、类别、动作或关键词筛选，先摘要后定向展开。超过预算的必要内容分块读取，不能直接截掉当前任务需要的证据、路径、句柄或错误信息。
- 前台用 `next --actions generate retry_generation --limit 5 --no-summary` 查询可提交项，按 [双队列流程](result-recovery.md) 轮查平台结果并及时下载；后台领取待审文件实际查看。用 `next --actions inspect save deliver --limit 5 --no-summary` 核对后处理，前台统一落账。两类查询独立，不要求后处理清空才查生成。摘要保留队列数量、工作者状态与文件位置；limit 不是总并发上限，轮换游标避免漏项。仅当前提交项加载完整提示词，后台只接收单项必要信息与引用，不复制完整 state 或历史。
- 完整工具响应、逐次日志及历史记录留在工作区；对话只回传资产 ID、attempt_id、真实句柄／路径、状态和本次变化。禁止向对话打印图片 base64、二进制、完整网页源码或重复完整提示词；提交给生成工具的实际提示词仍必须完整。
- 浏览器只获取当前操作所需状态、目标控件和必要截图，不反复回传全项目历史。沿用有效项目／剧集／分镜标识，但页面导航、弹窗变化或提交前仍须核对当前目标；不缓存失效元素或猜选择器。每次图片审核查看对应成品，不为压缩输出用无法辨认的缩略图代替检查。

## 精简进度摘要与恢复

- request、索引、plan、state 及平台任务映射是完整记录，不写入聊天代替落盘。继续使用原流程即时记录每次提交句柄和结果，不能延迟到摘要更新时才记录在途任务。
- 在本次工作区维护 `run-summary.md`，目标不超过约 1,500 中文字；每完成约 5 个资产、切换类别／阶段、发生阻塞或准备恢复时更新，有实质变更才写。内容仅含：当前用户要求与停止点、地域／平台／项目、文件位置及 state revision、阶段与完成数量、当前分镜及满额等待情况、下一步、阻塞和完整在途映射文件位置。不要复制全量提示词、原文或已完成历史。
- 摘要是导航，不是新的事实来源；不得直接给 state 增加不受支持字段。在途任务无论多少都完整记录在原状态／平台映射中，摘要只写数量与索引位置，不为限长删任务、失败次数或引用关系。
- 恢复时先读摘要和当前请求，再读取 state 的必要条目及平台在途记录，核对 revision、真实文件、目标项目／分镜与任务状态后继续；过期或矛盾摘要以真实记录和用户最新要求为准。不要重新建表、重传图或重提交已在途／已合格任务。没有摘要时从已有状态重建，不从头重跑。

## 等待与交付

- 无变化状态按平台反馈约 15–30 秒回查，长任务可退避至约 60 秒；提交期间每最多 2 次提交或到期就回查。发现成图及时下载交给后台审核，前台继续独立生成，不等待审核反馈。审核工作者完成当前单图后再领下一张。用户消息、失败或依赖解锁及时处理，不高频空查或重复输出。
- 有实际进展、失败、依赖解锁或保存问题时才报告变化，避免每次轮询重复整份名单。剧梦当前分镜满 5 个仍原地等待空位，不因节省轮询或上下文转到别的分镜补交；其他已在途任务继续运行。
- 收尾做一次完整数量、未完成项、文件与平台保存核对；对话给结果、实际路径和剩余问题，完整日志保留本地。不会因上下文预算而缩减必需资产或提前宣称完成。
