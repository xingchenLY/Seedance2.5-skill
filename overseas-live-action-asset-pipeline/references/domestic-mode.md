# 国内模式：亚洲人物与中文场景道具

仅在用户已选择 region_mode=domestic 时使用。本页覆盖原模板中非亚洲人物审美、排除中式环境及场景道具全面禁字的条款；海外模式使用 [语种与地区选角](character-casting.md) 和海外模板，不应用本页。提示词本来就以中文书写，本次新增要求还包括成图中实际可见的场景与道具文字。

## 共同规则与优先级

- 真人角色采用原创东亚人物面貌，最终提示词明确写“选角人种／族裔设定：东亚虚构角色”，覆盖男女主、配角、群演和群像。按正文时代、身份及国内影视审美分别设计脸型、眉眼、鼻唇、肤色和发型，保留人物差异；不把所有亚洲人物写成同一张脸，不以名人作仿脸目标。不从参考照片识别或鉴定真实族裔；验收核对确定的可见五官设定，而非计算“亚洲概率”。
- 角色参考库仍可借用气质、发型、穿搭、配色和材质，但不得将库中海外面孔或“避免亚洲面孔”的句子带入国内提示词。无适合的面部参考时用具体文字原创设计。用户明确保留的特殊角色设定按本次要求处理，有实质冲突只澄清该项，不擅改剧情。
- 场景和道具适配正文中的国内时代、用途及生活环境。现代住宅、医院、办公楼等按真实功能设计，不把国内风格统一处理成古建筑、红灯笼、龙纹或红金配色。保留原来的空场景、空间差异、关联延伸、必要陈设及专业光影规则。
- 场景与道具需要展示的招牌、门牌、导视、包装、文件、票据、标签、按键及屏幕界面使用中文，默认简体；用户明确要求繁体时按其要求。数字、日期及必要单位可保留，不用英文单词代替中文标签。无需文字的物件保持无字，不为了国内模式硬加招牌或标签。
- 先确定需要出现的字句与位置，在完整提示词中逐字用引号列明，例如“急诊”“出口”“会议室”“联系人”“消息”。原文明确内容优先；美术补充使用简洁、与功能一致的中文，不虚构改变剧情的合同、消息或金额。长段正文只在剧情需要且可读范围合理时保留，不以乱码或假字充当中文。
- “允许必要中文”不等于允许品牌：保留去品牌logo、商标、品牌识别性图案、水印及无关说明文字的要求。国内场景／道具提示词不能同时出现“无任何文字／无可辨文字”和明确的中文标牌要求；改为“仅出现指定中文及必要数字，无其他文字”。
- 人物定妆照及人物三视图继续无文字标签；动物、人类、空场景等主体数量规则不因中文文字而改变。需要画面内文字的场景道具才采用上述例外。
- 年龄映射、原创检查、服装状态、画幅、手机正背面与身份手机壳、表格五列和排序合并全部沿用。默认仅制作并保存表格，四类图片仍独立选择，三视图仍不入表，后续表格覆盖原文件。
- 国内／海外是设计模式，不能代替实际发行地区和素材授权范围。人物仍按原风险初筛机制记录来源与用途；国内任务按实际使用地区核查，不自动套用“全球海外已审查”，不预先保证不侵权。

## 国内真人角色模板

将方括号替换为本项确定内容后再交付。剧情年龄按 [年龄规则](visual-specs.md#人物年龄范围) 映射一次，最终提示词只填确定外观年龄。

~~~text
真人写实风格，电影级国内影视角色定妆照，原创虚构角色，选角人种／族裔设定：东亚；符合[时代、人物身份及本剧气质]。
仅一名[角色名]，[确定外观年龄]，[身份与剧情状态]，[具体身高和体型]。9:16竖版，半身正面，双肩正对镜头，眼睛直视镜头，头顶和双肩完整入画，脸部清晰对焦。
面部固定为[脸型、眉眼关系、鼻唇轮廓、颧骨下颌、眼睛颜色和自然肤色]，具有[两三个稳定辨识点]；原创五官组合，不模仿名人或明星。
通过[至少两组明确的脸型或五官结构差异]与本剧其它角色区分，不能复用同一面孔仅更换服装或发型；同一角色派生图则保持自己的基准面容。
发型为[发色、长度、分缝和造型状态]。穿[内外层、下装、鞋履和必要配饰]，明确[颜色、材质、剪裁和必要磨损状态]，女性胸前完整遮挡；未入画的下装与鞋履仅为后续全身设计设定。
气质与表情为[明确状态]。背景为[一个确定的代表性虚化环境或统一背景]；[主光方向和光质]，适度补光保留面部层次，真实皮肤、发丝和织物质感，无过度磨皮。
无额外人物、文字标签、品牌logo、水印、插画或动漫质感。
~~~

群像改为4:3，明确人数、逐人外貌与服装，不能只限定主角。换装／状态图和三视图沿用同一角色已确认的亚洲面貌设计，不重新选脸。

群像还须使用 [群像逐人防撞脸](character-distinction.md#群像照的逐人防撞脸) 和 [群像提示词段](visual-specs.md#人物提示词填写)，逐人明确面部结构差异，所有主体面部清晰；图内不同人物与项目基准都要实际对照，无名群演也纳入。同为东亚面貌、同制服不允许复制同脸，任一人物未通过则整图不通过。

生成前设计和成图后审核均执行 [不同角色外貌区分](character-distinction.md)，逐张对照本项目可用基准图，撞脸不通过；不以同为东亚设定或使用同一 A 形象模板省略校验。

## 国内场景模板

国内风格与中文规则保持；内部机位、入口清楚入画和无畸变要求共用 [场景布局与机位规则](scene-layout-camera.md)，不叠加其中仅限海外的中式风格排除项。

~~~text
[本项目确定的真人电影写实或三维动画成片风格]，国内[时代与环境类型]的场景资产，16:9横版，全景，自然透视，清楚展示[地点—具体空间]。
本场时段为[明确或根据剧情合理推断的时段]，环境条件为[有依据的天气与季节]，空间功能为[用途]。
结构为[层高、门窗位置、入口及连接方向]，墙地面使用[材质与配色]；[核心家具及位置]，保留[必要装饰、灯具、植物和生活陈设]，留出可使用的通路。
室内机位设于[房间内部可站立的侧区或斜角]，朝向[入口所在区域与核心功能区]，不在门口、门槛或外侧走廊向内拍摄；真实主要入口清楚位于画面[中景或后景的确定位置]，门洞边界与地面通路可辨，不遮挡、不裁断，不新造门洞。开放式空间展示实际连通开口；室外删除这条室内机位段。
自然直线透视，合理消失方向与近大远小，墙门窗及家具尺度准确；无鱼眼、桶形／枕形畸变、边缘拉伸、弯墙、错位门洞、变形家具、悬浮或穿模。
通过[两项具体的结构或功能布局区别]与同地点其他空间区分。[有参考时写出需延续的建筑细节、材质、尺度及可见衔接关系。]
画面内必要文字采用简体中文：[文字承载物、准确位置及引号中的确切中文字句]。字形清楚、笔画完整、方向正确，字句与空间功能一致，仅出现指定中文及必要数字，无无关外语、假字或乱码。
[光源及位置]从[方向]照亮[区域]，采用[软硬光质与影调]；[主辅色关系]，[有条件依据的丁达尔效应、斑驳光或材质反射等具体可见效果]，暗部保留[关键结构]，不同材质粗糙度与高光有明确差异。
空场景，无人类、拟人动物居民、普通动物、身体局部、人物影子、人物反射或角色图像；无品牌logo、水印、无关说明标签或拍摄器材，不清空必要陈设，不以复制其他房间画面替代本空间。
~~~

没有必要标牌或文字时，将整条文字段替换为“本空间无须出现可读文字”，不填写假想中文牌匾。

## 国内独立道具模板

~~~text
[本项目确定的真人产品摄影或三维动画材质风格]，国内[时代与使用语境]的独立道具资产，[确定的9:16竖版或16:9横版]，不透明浅灰纯色背景。
仅展示[具体道具或不可分组合]，完整全貌、居中、边缘清楚，属于[角色身份或用途]，尺寸、结构和操作方式符合[使用者]。
固定形状为[外形]，颜色为[颜色]，由[材料及分区]组成，具有[关键结构]，状态为[正文要求的开合、磨损或损坏状态]。
需要呈现的文字为简体中文：[包装／标签／文件／界面上的位置与确切中文字句]；必要数字为[有依据的数字及对应中文字段]，字形清楚、方向正确，内容与剧情用途一致，仅出现指定文字，无无关外语、假字或乱码。
柔和均匀照明，体现[材料]的纹理、粗糙度与反射差异，结构清晰，高光不遮挡关键文字和部件。

~~~

无需文字时删除文字及数字设定，改为“本物件无文字或标识”。不把每个无字物件都改成中文包装商品。

~~~text
[本项目确定的真人产品摄影或三维动画材质风格]，16:9横版，不透明浅灰纯色背景，完整展示同一部手机的正面和背面。
左侧为严格正面，右侧为严格背面，两面竖直摆正、等高同比例、上下对齐，间隔清楚。正面完整展示屏幕和壳体包边，背面完整展示同一壳体及镜头开孔。
手机属于[角色名及身份]，配备[具体颜色、材质、纹理及结构]的原创无品牌手机壳，设计符合[职业、气质和使用习惯]，机身尺寸、按键、接口、镜头及壳体开孔两面一致。

~~~

屏幕关闭时删除亮屏文字要求；有剧情信息时使用准确的中文，不因旧模板“无可辨文字”而清空。

## 国内拟人动物都市动画

地域模式与题材独立：国内模式可以是真人，也可以是拟人动物都市动画。后者读取 [动物题材](animal-city.md) 的物种、比例、毛色、毛流、材质、尺度和光影规则，海外原模板保持原样。

- 动物居民继续是动物，不套亚洲人脸、不贴真人面孔、不做动物族裔识别。角色使用国内身份语境及服饰气质，仍按物种适配耳角、颈部、尾根与爪蹄；如果该作品确有真人角色，真人才执行亚洲人物面貌要求。
- 动物角色定妆图采用原动物模板，把身份、服装、生活环境填成国内设定；原有物种结构、9:16半身、毛发材质及无文字定妆要求不变。
- 场景使用本页国内场景模板，风格确定为电影级三维拟人动物都市动画，并补充主要使用者物种、相对体型与门窗家具的尺度适配。保留国内城市生活逻辑和必要中文导视，不能只在海外场景上替换一个字牌。
- 道具／手机使用本页对应模板，风格确定为三维动画材质，补充物种操作与握持尺度。中文文字、同一手机正背面及身份手机壳同时落实。
- 三视图仍使用原动物三视图规格，引用当前模式的合格角色原照，保持物种、毛色、服装和比例。真人三视图同样引用国内角色原照；两者都不加中文视图标签、不写入人物资产表。

## 校验与记录

在现有 preflight.continuity 中记录 region_mode=domestic、具体面貌设计或动物设定、中文内容与位置；exclusions 不得误禁用本项必要中文。仅表格／提示词时完成文字设计与冲突检查，不为验证模板额外出图。

图片开启后，实际查看中文是否正确、清楚、有无漏字、错字、镜像、乱码或英文残留；同时核对角色的具体外貌设计及场景道具的国内用途。中文不符用 checked.approved=false、code=domestic_text_mismatch，并在 note 写清实际可见问题，沿用原质量失败上限；不以尺寸、文件哈希或未经执行的OCR冒充文字验收。面貌只检查约定的可见设计，仍用现有原创设计检查，不声称识别族裔。

实际完整提示词进入资产表原列，不新增模式列或审查列。切换国内／海外后先核对并更新完整设计计划、重新 init；旧模式成图不自动记为新模式合格图，模式内换装与空间连续性仍按原规则维持。
