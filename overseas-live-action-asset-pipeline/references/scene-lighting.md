# 场景资产的影视光影

本页光源、明暗、材质反应和连续性方法也适用于 [拟人动物都市动画场景](animal-city.md#场景体系光影和色彩)；已启用该题材时保留三维动画造型与物种尺度，按该页城区配色建议组织光照，不混入真人摄影风格或画面中的动物居民。

仅在设计或检查场景资产时读取一次，适用于仅提示词、表格和图片模式。每条场景提示词都要写出具体光照方案；下列术语按本场条件选用，不是每张图必须叠加的特效清单。人物面部布光术语（伦勃朗光、蝴蝶光、眼神光等）不套入无人场景；本文件不改变人物、道具和三视图规则。

## 写入提示词的方法

首次生成前按 [场景时间推断](visual-specs.md#场景时间推断) 确定基准图时段；同空间后续仅改剧情时间按 [时间复用规则](visual-specs.md#同场景时间复用) 继续用原图，不另做换光图。需要首次出图的空间，再依据空间功能、建筑开口、既有灯具、材质和剧情氛围组织光线。采用“专业术语＋可见结果”，将选定内容融入完整中文提示词：

> 光源依据与位置 → 入射方向 → 光质软硬 → 明暗关系与冷暖 → 空气或材质反应（适用时） → 需要保留的空间细节。

- **先有光源，再有风格。** 写清窗光、天光、门洞借光、壁灯或其它符合时代与空间的光源，从哪一处照向哪一区域，以及阴影、光斑落在哪里。光源可在画外，但必须与建筑关系相容；拍摄灯架、柔光箱、反光板等不作为场景陈设入画。
- **基础布光必写，特殊现象按需选用。** 先完成合理的主光、环境补光和影调，再选择能表达本场的少量效果；普通房间可以只用柔和窗光与反射补光。不要仅写“电影级光影”“高级感”或裸列术语，也不把整张术语表复制进提示词。
- **氛围服务可用资产。** 保持既有 16:9 全景、自然透视和无人规格，交代本图必要的结构、主要家具、空间动线及装饰；入口按 [布局与机位规则](scene-layout-camera.md) 决定是否展示，画外光源与画外入口不因光影设计强行入画；允许符合剧情的局部深暗，不用大面积死黑、过曝或浓雾掩盖需要展示的结构。不为展示云隙光而改成大全景或航拍。
- **效果遵从条件。** 沿用原文明确天气；不为光效新增雨雪、积水、云层或室外浓雾。轻微室内尘埃或薄雾仅在环境合理、无明确洁净要求且不改变剧情状态时作为美术补充，不默认每张都有。条件不足时改用清晰投影、材质高光等可实现的描述；时间仍无法确定时使用中性漫射光或合理固定照明，不凭效果反推日出、落日或夜晚。
- **一条提示词给出确定方案。** 写出本图实际采用的光源、方向和效果，删除备选风格、术语解释及填写指令；软硬光与明暗反差分别描述，不把高调等同于过曝、低调等同于欠曝。可写“低调环境中的局部柔光”，但不同时要求整幅画面高调与低调。

## 海外真人的灯具开关状态

本节仅补充海外真人场景的首次设计、提示词编写及本次已授权的出图／返修；国内与拟人动物沿用原分支。**时段、灯具是否存在、灯具是否开启分别确定，保留灯具陈设不等于把它点亮。**

- **日间默认。** 住宅等空间自然采光充足、无剧情或实际功能需求时，以日光、天光和已有墙地面的反射照明，吊灯、壁灯、台灯、落地灯、灯带等已有普通照明及装饰灯默认关闭，灯具本体照常保留。室外日景的普通路灯、庭院灯和景观灯也不无故点亮；指示、信号等有明确功能的光源按用途判断，不套装饰灯规则。
- **允许开启的依据。** 用户／正文明确要求，或无窗、进深和遮挡造成自然采光不足，或当前营业、医疗、工作照明等实际功能确实需要时，才开启对应灯具。依据可以来自正文或已确定空间的合理美术设计，不新增逐项确认；不能仅凭“这是办公室／医院”、阴天、追求冷暖对比或高级感就把所有灯打开。夜间也按使用状态选光源，不自动全开。
- **先定状态再写效果。** 在已有 `preflight.continuity` 简记灯组位置、开／关及开启依据，完整提示词明确哪些开启、哪些关闭；无灯具时省略。关闭灯具不产生灯泡自发光、由内部光源造成的灯罩透亮、灯下光池或相应人工照明投影；日光照到灯具造成的反光、外部透光可以保留。开灯方案写清作用区域，其余灯保持关闭；不为说明状态新增灯具或把画外灯强行纳入构图，不新增表格列或 schema 字段。
- **清除诱导冲突。** 日间默认关灯时，删除暗示这些灯开启的“暖色壁灯光池、灯带氛围光、灯泡柔晕”等句子。环境补光优先用合理天光与反射光表达，不一律解释为场内灯点亮；冷暖层次可以来自已有材质及有依据的自然光，不为效果更改既定颜色、天气或时段。指定灯光例外时改写关闭句，避免同一灯同时开／关。
- **引用与复用。** 风格参考或另一房间中的亮灯状态不自动继承；新空间按自己的采光、用途及基准时段确定。已有同空间合格图仍按时间复用规则原样使用，不因后续白天场次或本规则升级批量关灯重绘，也不将表格或描述改成与原图不符的“已关灯”。用户明确要求修改或原图本身不符合其提交设计时，才按原范围和返修规则处理。

海外真人日间采光充足的光影段，在窗光与反射描述后明确写成例如：“保留已有吊灯与台灯，均处于关闭状态，灯泡不自发光，灯罩无内部照明，周围无由这些灯产生的光池；允许日光在灯具表面的自然反射。”只列本场实际存在的灯具。有必要开灯时改写为已确定的位置、开启范围及其余关闭状态，不照搬全关句。

## 场景适用术语与条件

### 空间散射与投影

| 术语 | 选用条件及落地写法 |
| --- | --- |
| 丁达尔效应（Tyndall Effect） | 描述微粒散射使光路可见；场景提示词具体写“窗光经少量悬浮微粒散射形成可见光束”，交代介质、方向和强弱，不把任何发亮都称作丁达尔效应。 |
| 体积光（Volumetric Lighting） | 空气中有合理的散射介质时，写出光束在空间中的宽度、层次和衰减；例如“高窗斜射的体积光穿过稀薄尘雾，远端逐渐减弱”。 |
| 光束／光柱（Light Shafts） | 定向光经开口进入且光路可见时使用；例如“窄天窗投下单束光柱，落在中央石地面”。清洁空气中的窗格投影不必另加可见光柱。 |
| 曙暮光线／云隙光（Crepuscular Rays） | 已有天色、云层与阳光条件支持时，描述云隙间明暗相间的光束；避免把室内窗光统一叫“耶稣光”，也不无依据补造云层。 |
| 焦散（Caustics） | 已有水面、弧面玻璃等能聚光的介质时，写“池底出现由水面折射汇聚的亮纹”或“玻璃器皿在桌面投下细小焦散光斑”；不为此新增水景或独立剧情道具。 |
| 图案投影（Gobo Projection） | 以本场窗格、百叶、栏杆等合理遮挡解释投影形状和落点；“百叶窗条纹斜落在侧墙与地面”。不把片场投影设备画进资产。 |
| 斑驳光（Dappled Light） | 已有枝叶等不规则遮挡时，“树冠过滤的阳光在石阶形成疏密不均的光斑”；不在无树空间凭空制造树影。 |

### 光质与空间塑形

| 术语 | 选用条件及落地写法 |
| --- | --- |
| 硬光（Hard Light） | 阴影边缘清晰，适合突出投影和表面起伏；写明定向来源与受光面。 |
| 柔光（Soft Light） | 阴影边缘过渡宽缓；例如“大面积窗侧柔光照亮沙发会客区，靠垫与墙面阴影自然过渡”。 |
| 掠射光（Raking Light） | 光线接近沿表面掠过，突出纹理；“低角度光线擦过石墙，显出接缝与凹凸”。 |
| 反射补光（Bounce Fill） | 用已有浅色墙面、顶棚等合理反射补亮暗部，保留材质；反射面的颜色可影响补光色彩。 |
| 负补光（Negative Fill） | 减少环境反射，让局部阴影更集中；最终画面写出柱侧、墙角等暗部位置与深度，不凭术语添加黑布或遮光旗。 |
| 书页式柔光（Book Light） | 可用于表达先反射再柔化形成的宽广柔光质感，需有合理画外布光动机；重点写空间中的柔和覆盖与阴影过渡，不让器材入画。 |
| 有动机布光（Motivated Lighting） | 光向、颜色和亮度受窗、灯具等场内或画外合理光源支撑；例如“右侧壁灯在墙面形成暖色光池”。 |
| 画内实景灯（Practical Light） | 壁灯、台灯、吊灯等属于环境陈设的可见光源；符合时代、功能和既定位置，避免所有灯具无理由同时点亮。海外真人先按上节确定开关状态，关闭的灯具只作陈设，不因选择此术语而点亮。 |
| 侧逆光与轮廓光（Back-Side / Rim Light） | 用于门框、家具或植物等实物边缘分离；说明后侧来源，保留物体表面与空间信息，不引入人物剪影。 |
| 镜面高光（Specular Highlight） | 表达金属、玻璃、抛光木面等的方向性反射；控制宽度与亮度，避免把哑光墙面、布料全部变成镜面。 |

### 影调与成像效果

| 术语 | 选用条件及落地写法 |
| --- | --- |
| 高调照明（High-Key Lighting） | 明亮调子占主导、阴影通常较轻；适合本场明快氛围，白墙、窗边和浅色家具仍有层次。 |
| 低调照明（Low-Key Lighting） | 暗调占主导，用局部光突出视觉重点；交代本图需要可见的结构、通路和陈设，不用整体压黑替代布光。 |
| 明暗对照法（Chiaroscuro） | 以鲜明明暗分区塑造体积和视觉重心；写清哪面墙、哪组家具受光，哪些区域退入阴影。 |
| 冷暖光对比（Warm–Cool Contrast） | 分别指定冷暖来源与作用区域，例如偏冷窗外环境光与已有依据开启的暖色壁灯；不默认所有夜晚都是强蓝色月光，海外真人不得为了冷暖对比推翻已确定的关灯状态。 |
| 高光柔晕（Highlight Bloom / Diffusion Glow） | 灯具或高亮边缘周围轻微扩散，保留纹理；不把整间房做成失焦或乳白雾。 |
| 胶片光晕（Halation） | 需要胶片成像质感时，限定于极亮边缘的克制晕染；与空气中的体积光、一般柔晕分开描述，不固定套用浓重红边。 |

## 同地点光照连续性

- 首张基准图确定时段、主光来源、开口与灯具位置、入射关系、基础冷暖及主要光斑。把会影响后续空间的条件写入现有 `preflight.continuity`；区分原文明示、剧情推断和美术补充，不新增必填字段、单独报表或光影资产任务。
- 延伸相邻空间时，以已查看的关联图和建筑位置为依据继承同一时段、外部光照及共享门洞的借光关系；本房间按自己的窗向、遮挡、进深和灯具形成局部差异。机位转向后依据实际空间转换画面方向，不能机械复制“左侧来光”，也不要求朝向不同的房间具有相同光斑。
- 同一空间仅时间或相应照明变化直接复用基准图，不触发换光生图。已选且确有必要的非时间状态或视角版本保留未变化的窗户、灯具和光源关系。生成不同的相邻空间时，关联图若为不同时段，只继承适用结构，按新空间首次确定的基准时段设计照明；不能借此为原空间补生昼夜图。
- 不用改变光色或明暗冒充不同房间的布局差异，继续执行 [空间区分与防重复](visual-specs.md#空间区分与防重复)。仅为尝试另一种光效，不自动增加资产行、图片张数或参考图生成任务。

## 场景模板中的光影段落

以下是可替换的结构，提交前填成确定的自然语言，不保留方括号或分支。海外真人还须将本页确定的灯具开关状态合入同一段，即使已有“白天／窗光”也不能省略适用的关灯描述；夜间或必要开灯例外写成实际方案。其余模式沿用原模板：

~~~text
[已确定时段下的具体光源]从[门窗或灯具位置]向[空间区域]照射，形成[硬光或柔光及可见阴影边缘]；[合理的反射光或环境光]保留[所需暗部结构]。整体采用[本场影调]，[各光源的冷暖与作用区域]。[条件成立时才添加的散射、投影或材质高光及落点]，保留[本图必要的可见结构、家具、装饰和动线]的可辨细节；不为展示光源或入口扩大取景。
~~~

下列仅示范光影段落，须与目标资产的完整场景提示词合并，替换为本场已确定的结构和条件，不照搬示例地点、时段或灯具：

- **住宅客厅／白天，普通清洁环境：** 大面积窗光从会客区窗侧柔和照入，浅色墙面提供反射补光，沙发和靠垫阴影过渡自然；整体明亮而有层次，木质茶几保留克制的镜面高光，主要家具与必要通路清楚可辨。不附加雾效。
- **旧建筑大厅／午后，允许轻微尘埃：** 午后定向窗光从高窗斜射至中央石地面，少量悬浮微粒散射形成可见体积光；掠射光显出立柱与石墙接缝，侧廊处于较暗调子，仍可辨认画面中的固定陈设和必要通行空间。
- **办公走廊／夜间：** 既有壁灯在墙面形成间隔分布的暖色光池，尽端窗洞引入微弱偏冷环境光，整体采用低调照明和局部明暗对照；门框获得克制的侧逆光，地面与本图需展示的房间入口保留辨识度，不添加人物或人形影子。
- **室内泳池／白天，正文已有水池：** 侧窗日光照入水面，在池底形成随水面起伏弯曲的焦散亮纹；池沿瓷砖高光清晰而受控，墙面由环境反射光补亮，保持池边必要通道清楚可辨，入口按本图用途决定展示。

## 出图检查与表格同步

每张新图或实际修改后的图按 [时间与光影专项校验](scene-layout-camera.md#时间与光影专项校验) 检查确定时段与实际表现，并记录可见依据及不可判读部分。检查随既有单图审核完成，不另加一轮生成或保存前等待：核对光源和开口关系、投影方向、软硬过渡、目标影调、材质反应，以及选用效果的可见结果；对照关联图时同时检查共享光照关系。实际观察写入 `checked.note`，画外或未展示的部分注明未验证，不声称测得照度、色温或准确光比。

明显反向来光、无来源光束、不合条件的焦散、雾光遮蔽关键布局、必要细节严重过曝或死黑，以及与同时间关联图冲突的光照，应说明具体问题并按已有质量流程返修。仅修正受影响资产，先更新 state 中的完整提示词，保留有效建筑与参考关系；沿用同项本轮生成与质量失败合并累计六次上限，不为术语数量不足判失败。

仅提示词／表格模式也采用上述具体光影段落，但不声称完成了图像验收。光影描述随 state 中完整最终提示词进入场景表原有“文生图提示词参考”列，不单独建光影列，不写术语解释、来源链接、设备操作或审核日志；遵守原表保存和覆盖规则。
