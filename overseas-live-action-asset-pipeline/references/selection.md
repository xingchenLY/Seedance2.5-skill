# 指定角色、场景或道具

点名具体资产时采用指定模式，支持单项、多项及跨类；只写类别仍按类别执行。默认值及可选保存统一见 [请求字段](request-options.md)。人物形象继续只从剧本正文分析，不参考人物小传。点名角色或版本本身不启用出图；未明确要图片时只整理对应表格。图片范围另用 image_types 选择，不改变已确定的表格范围。

半身定妆照默认范围例外：用户选择生成而未限定角色时，按当前表格全部独立人物，每人只选一个基础版本并写 count=1；明确版本条件优先。总表不删行，详见 [剧梦流程](jumeng-workflow.md)。

## 精确筛选

selected_assets 可混用名称字符串和结构化对象：

~~~json
{
  "人物": [{"name": "艾玛", "outfit": "红裙", "state": "干净", "count": 1}],
  "场景": [{"name": "医院", "space": "急诊室", "time": "白天", "count": 1}],
  "道具": [{"name": "银色钥匙", "state": "完好", "count": 2}]
}
~~~

- 每项必须有 name；人物支持 outfit/state，场景支持 space/time/state，道具支持 state，三类均支持 count。不适用字段、空条件及非正整数张数报错。
- 从正文归一别名及版本，再用 [正文索引](content-index.md) 匹配。名称或已核对别名须唯一对应同类别资产，版本条件采用归一文字精确比较。用户描述与内部标准描述同义时由代理按正文统一，不能静默删除未匹配条件。
- 场景 name 表示地点、space 表示空间；“医院-急诊室”拆为这两个字段，不扩大为所有房间。同名多个候选、名称不存在、条件不符或集数交集为空时合并澄清，不用近似角色代替。
- 未限定版本时取所选名称在本次范围内确需的全部版本；count 省略为每个匹配版本一张。count 是该条选择的原照／场景／道具总张数，不含三视图。小于版本数时按正文首次出现取前 N 个；大于版本数时额外张数为首个匹配版本的独立候选，不编造服装或场景版本。执行前简述选中版本与张数，不另设确认关卡。
- 手机默认按 [手机道具规则](visual-specs.md#手机道具正背面与手机壳) 在一张 16:9 图片中同时展示正面和背面，`count=1` 即一张完整双视图，不自动增加第二张；它仍是道具，不受人物三视图开关或表格排除规则影响。明确另定构图时采用用户要求，并保持约定张数。
- 重叠选择合并同一版本，张数取各条对该版本需求的最大值，不重复相加；同一筛选条件给出不同 count 视为冲突。需要逐版本控制张数时分别填写条件。
- 最终提示词、表格、图片及依赖均采用匹配结果。可阅读关联剧情，但不生成未选资产；纯声音或仅被提及的人物不自动加人像。

## 三视图与引用

所有范围的三视图均默认关闭；明确要求时，用 image_types 的“三视图”开启，并可用 turnaround_characters 限定角色。本次新生成原照先通过比例与视觉检查并确认单人；有主路径须归档成功，无路径须已交付且源图可读。只选择三视图、不选择人物原照时，按 [已有原照引用](progress.md#仅生成三视图时的已有原照) 复用合格图片，缺失时说明需要哪张原照，不自动补生。

每张所选原照只派生自己的三视图。多人照跳过，人数不明先检查，不选人或裁切拆分。多个候选原照且启用三视图时，每张候选分别对应一张三视图，计数分开说明；未启用时不加占位或失败项。

~~~text
$overseas-live-action-asset-pipeline
图片生成流程：Codex
模式：海外
剧本：本次提供的剧本
指定角色：艾玛，只要红裙，1 张
指定场景：医院急诊室，白天，1 张
指定道具：银色钥匙，完好状态，1 张
输出类型：只要图片
~~~

无主路径时直接交付。增加“需要三视图：艾玛”只增加艾玛三视图；增加本次主路径即可归档。示例名称不是实际资产。
