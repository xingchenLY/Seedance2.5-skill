# 按语种与地区固定虚构角色选角

用户要求根据语种和地区规定人物人种。本页将“人种”作为本剧虚构角色的族裔／血统设计字段，不是对参考图真人的身份判断，也不表示某国居民只有一种族裔。与纯文字 [人物提示词库](character-genres.md) 配合使用；男女主、配角、群演、群像逐人执行，不能只约束主角。

## 确定顺序

1. 本次用户对具体角色的明确设定优先，其次正文必须保留的角色族裔／血统设定。保持剧情身份，不因语言、姓名或职业覆盖它。
2. 无明确角色设定时，以本次用户指定的制作地区或正文明确故事地区确定区域，再用正文主要对白语种选择该地区的影视质感。发行地区不自动替换已有故事与角色身份；配音／翻译语种变化不重新选角。
3. 只有语种、没有明确地区时，沿用既有缺省：英语→美国／加拿大的北美影视方向，西班牙语→西班牙，葡萄牙语→葡萄牙。它们是本技能的美术默认，不是语种对应族裔的事实。明确英国、拉美、巴西等地区时用对应行，不再被语种默认覆盖。
4. 按下表先选一条地区规则，再为每个角色确定一个唯一的选角句。表中未覆盖、地域信息互相矛盾，或多语种无法确定主要地区时，只询问缺失的地区／选角方向；不在最终提示词列多个备选、不随机混合血统。

## 地区选角前缀

这些是为本项目提供稳定结果的默认美术方案，可由明确剧情或用户指令覆盖。一个项目可以有正文规定的多族裔角色，但每个人的设定须先固定；不为追求差异随机改换族裔。

## 组装和固定

- 完整人物提示词 = **已解析为唯一值的地区选角前缀 + 一套 M 编号外貌／发型片段 + 当前角色已确定的单个外观年龄、身体和服装 + 本次定妆照或三视图规格 + 原创约束**。M 编号片段本身不是可直接提交的完整稿，不单独发送；它们跨地区复用，所以不为每种地区复制 33 份相同衣服描述。
- 在每个角色最终稿中显式写“选角人种／族裔设定：……”；不能只写“海外”“北美演员感”“非亚洲”或留下“按地区决定”等占位语。不要把国籍、语言、文化与人种当同义词。复合血统仅在明确设计时写一个确定组合，不使用“白人／拉丁／混血均可”。
- 可见面貌仍须确定：脸型比例、眉眼间距和形状、鼻梁鼻尖、唇形、颧骨下颌、肤色与自然皮肤细节、发色发型、两到三个辨识点。不同族裔选角需要适配文字库时，把有冲突的肤色／发色等替换成该角色明确设计，不把旧句和新句并列，也不把族裔写成唯一外貌特征。
- `preflight.continuity` 记录实际语种、故事／制作地区及依据、唯一选角句、A 形象／C 服装编号、具体五官和改动。既有字段即可，不新增 Excel 列。最终完整稿同时保存到 plan/state 和资产表；网页、Dreama CLI、Codex 使用相同设计。检查实际 tool_prompt 保留选角句，CLI 引用组装不能删掉它。
- 本次首次合格定妆照确立后，换装、状态及三视图沿用同一选角与可见面容，不能换模型、换通道或换衣服就重新选族裔。前图有用户指出的形象偏差时先修基准照，再处理受影响派生图。
- 审核前核对文字中的选角字段是否落实、有没有冲突与遗漏；出图后实际核对脸型、眉眼、鼻唇、肤色、发型等设计。按可见设计偏差返修，不从图像鉴定族裔，不输出人种概率或“族裔识别通过”。只有文字一致不等于图像合格。
- 精灵、人鱼等采用明确的虚构物种；仅人形部分沿用项目的选角美术设定，不能把物种与现实人种混为一谈。M04 巨龙及拟人动物不套人类族裔前缀。

示例（原创设计示例，不是参考图身份结论）：“北美影视风格的原创虚构男性角色；选角人种／族裔设定：欧洲血统白人。外观年龄 27 岁，纤长脸型、蓝灰眼睛、直鼻、清楚唇线、浅色自然皮肤，深棕松散短卷发，额前少量碎发……”其中年龄须在实际任务按原年龄规则重新确定；不会因为示例固定为 27 岁。
