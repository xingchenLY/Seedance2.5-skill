# 海外真人场景提示词

仅在 `region_mode=overseas` 且本项为真人写实场景时读取一次，适用于场景表格、提示词及已启用的生图；国内、拟人动物、人物和独立道具不应用。本页细化 [场景模板](visual-specs.md#场景模板与陈设) 的空间、构图、光影和材质段，不增加资产、生成批次或审批环节。既有地区设定、16:9、无人、入口按需展示、绑定与排除、家具数量、时间复用及返修规则继续优先。

## 先区分参考的用途

- 有实际参考时先查看，区分可见事实、合理推断和本次美术设计；未显示的区域不声称已经核验。只用文字资料时直接设计，不假装提取了图像特征，也不为启动制作强制搜图或生成风格样张。
- 从风格参考提取可迁移的明暗组织、主辅色、材质响应及细节密度；单张图的门位、家具排列、天气和光斑不自动成为项目通用规则。不能从外观猜定真实摄影机、镜头型号、胶片或 LUT。
- 项目共同风格、特定时段或空间才成立的效果、本房间固定结构分别记录。延伸相邻房间时沿用合格基准的共享结构和建筑语言，本房间仍按自身功能布局；纯风格参考不得覆盖已确定的门窗、尺度、连接和绑定清单。参考中的人物、临时道具、文字、标识不随风格搬入。

项目方向沿用 [海外项目美术](overseas-art-direction.md)，只在原 `preflight.body_basis` 记录依据，在 `continuity` 记录本项固定结构及参考职责；机位沿用 `framing`，排除项沿用 `exclusions`。没有新依据不重做全项目风格分析。

## 将设计编译为具体场景段落

按以下顺序填写确定内容，替换共用模板中对应的设计段，合并成一条可独立执行的中文提示词；不把下列编写指令、表格或整页规则发给生成器。已经保留的约束只写一次，不在共用模板末尾再堆一套相同要求。

| 段落 | 写入最终提示词的内容 |
| --- | --- |
| 地点与美术定位 | 具体国家／地区、年代、建筑用途、居住或经营条件及当前空间。用实际建筑形制、家具廓形和表面材料表达生活环境；不把欧美等同于豪宅、古堡、全金色或统一冷色，正文设定在其它海外地区时按实际地区设计。 |
| 固定结构与主要陈设 | 本图可见的墙地关系、开口、核心家具位置、相对尺度及必要通路；选用门窗凹入、板件边缘厚度、家具支撑、接地和遮挡关系表现体积。结构先成立，再加表面纹理；不为厚重感加粗所有墙体或家具。数量及物件是否允许入景先按原绑定规则决定。 |
| 内部机位与视觉层次 | 写实际可站立的内部位置、朝向和主要功能区，以功能家具或建筑关系作为视觉中心，用已有陈设形成辅助层次，其余区域降低对比和纹理密度。近中远层次只在空间容纳时使用，不硬加前景物件、不拉长房间；保留必要动作区域及通路，不清空应有家具。 |
| 光源到受光面的关系 | 先按 [灯具开关状态](scene-lighting.md#海外真人的灯具开关状态) 区分保留的灯具与实际开启的光源，写明适用的开启／关闭状态，再写主光位置、方向、光质与明暗冷暖；按实际条件描述开口／遮挡、空气介质、受光面、投影、反弹光及反射。只保留本场成立的环节，不强凑每种光效。交代关键落点和亮暗过渡，避免仅写术语名称。 |
| 色彩、材质与细节 | 写主要颜色分别由墙面、家具、织物或灯光中的什么承载，再写关键可见表面的光泽、粗糙程度、纹理方向和使用状态。主要结构与陈设清楚，非关键区域保持自然、安静；远处纹理按观察尺度简化，不要求整图同等微观细节。 |
| 必须保留与排除 | 合并原模板的画幅、无人、海外无中文、指定必要文字、绑定数量、相邻关系、空间区分及本项易发错误。删去重复质感词、被替代方案和失败历史，只保留当前有效约束；不能为压缩删掉必要规格或以“同上”代替设计。 |

室内构图继续执行 [布局与机位](scene-layout-camera.md)：真实布局优先，入口仅按本图用途展示，允许画外时不详细描述画外门，也不借“前中后景”“纵深”要求把门塞回画面。全景服务于主要功能区，不改为超广角全屋展示、2.35:1 电影条幅或带黑边画面。室外改写为实际地面机位和道路、建筑、地形关系，不套室内站位。必要结构、数量及区分点不能靠强虚化、遮挡或暗部隐藏。

## 光影和材质的因果约束

沿用 [影视光影术语与条件](scene-lighting.md)，只补充本项需要的可见表现：

- **光线有来处和落点。** 开口光被墙体、家具遮断后不能无缘无故继续形成同一光斑；阴影软硬随光源尺度和距离合理变化。多光源允许不同方向的投影，以各自来源解释，不强制所有影子同向。光源可以画外，不为交代光源增加窗、门或可见灯具。
- **反射由视角和表面共同决定。** 抛光石材、玻璃、金属可出现强弱不同的反射，高光位置符合表面朝向和当前视角；不机械地让每盏灯正下方都有镜像。哑光木材、织物不统一变成镜面，拉丝金属以方向性反光表现，不全部铬化。
- **空气效果有条件。** 空气透视不等于可见光束；丁达尔效应或体积光需要合理散射介质，介质分布与来源相容，光不能穿透实体墙。无依据不加雾、灰尘、雨水或湿地反光，也不把远处统一染蓝。需要清晰空气时可直接不用这些效果。
- **曝光保护必要信息。** 有依据的低调光可保留暗部层次，不必把所有角落提亮；高光柔和滚降不等于全图泛白或光晕。让本图必须展示的结构、家具及绑定物件可读，避免死黑、过曝、浓雾或夸张 HDR 把缺陷藏住。色彩分离来自物体和光照关系，不靠统一滤镜改掉已定颜色。
- **细节服从尺度和使用状态。** 木纹顺着构件、石材接缝服从分区，接触阴影体现落地；磨损、褪色只在有依据的接触、受晒或使用区域出现。不是每个表面都做旧，也不是每块材质都无瑕光滑；禁止用全图锐化、重复微纹理或颗粒堆砌替代真实结构。

例如，已确定的“当代美国普通住宅、日间客厅、清晰空气”可以把泛泛的“欧美高级电影光、超精细纹理”改为：

> 内部侧向平视会客区，沙发与茶几关系清楚，已有边柜作为次要层次，墙面保持低对比。既定侧窗的柔和日光照向沙发扶手与茶几，地面反弹光轻微抬起家具下侧，必要结构保留暗部细节。自然采光充足，场内已有灯具保留且保持关闭，灯泡不自发光，灯罩无内部照明，周围无灯具产生的光池，允许日光在灯具表面的自然反射。浅色涂料墙、哑光木桌与亚麻沙发形成克制的材质区分；木纹顺着桌板，织物纹理按全景尺度自然呈现，桌脚接地清楚，玻璃高光受控。空气通透，无可见光束。

这只是写法示例，须有相应布局、窗与陈设依据才采用，不作为每个海外房间的固定方案；不向无窗夜景补窗，也不复制示例家具。

## 合并到原审核与返修

实际成图在原单图审核中同时看：空间承重、遮挡与接地是否可信；光源到受光面和投影／反射是否相容；材质是否可区分；必要区域能否看清；参考风格是否覆盖了原布局或带入排除物。记录到已有 `checked.note`，沿用几何、光影、材质、内容等现有错误分类，不新增打分表或独立排队。没有成图时只检查设计和提示词，不声称已验证视觉质量；不能凭提示词数值宣称测得真实焦距或物理精度。

发现问题先定位成因，重写冲突段并清除旧句，保留正确的结构和设计；同一提示词包含本次需要修正的所有已知缺陷，不为“单变量测试”额外拆成付费批次。大范围几何、布局、光照或风格错误按 [返修方式](repair-policy.md) 重新生成，不把问题图作为底图或参考；基础正确的局部小问题按原规则引用稳定底图，只调整本次目标及其必要阴影／反射。首次加最多 5 次返修、即时下载、后台审核及存储流程不变。
