# Codex 图片生成流程

这是原有的图片生成方式，只在共用资产表已整理、核对并保存且用户已选择图片类别后进入；用户明确仅图片时沿用原输出限制。asset_workflow=codex 才提交新的图片生成；国内／海外及题材沿用共用阶段的选择。

1. 使用当前 imagegen 技能和内置图片工具，将 state 中完整提示词、实际可读参考图传入。工具不可用时说明限制，不自行切换付费 API/CLI 或其他模型。
2. 按 [运行队列](runtime.md#连续队列) 与 [进度助手](progress.md) 完成逐图 preflight、依赖检查、唯一 attempt_id、generating 记录和工具提交。允许时先最多 2 个在途，稳定后最多 4 个；已有任务按原句柄接收，不因等待超时重复出图。阶段内返修可以 init --partial 更新必要设计，但不能用分批出图绕过首次表格整理。
3. 人物换装、状态、三视图及相邻空间图引用已确认的基准图，遵守单人、比例、连续性和失败预算。仅生成明确启用的图片类别，不为三视图自动补生未选原照。
4. 工具返回时立即将真实源路径、资产 ID、attempt_id 交回共用 receive_asset.py；有主路径即按原规则保存待审副本，再检查、正式归档和交付。保存、命名、目录、去重、图片版本及表格覆盖规则都使用 [共用流程](shared-workflow.md)，此分支不另设存储逻辑。

只输出原生图片和必要状态，不重复打印 base64 或完整工具响应。后续表格内容变化按共用规则及时覆盖原文件，未变内容复用。
