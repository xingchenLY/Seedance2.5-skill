# 人物原创设计与出图复核

用户要求人物避免明星仿脸。对单人原照、换装／状态图、群像中可见的人脸及已启用三视图执行本规则；先做原创外貌设计，再对实际生成图逐张复核。纯提示词／表格任务只检查文字设计，不声称已检查图片。

判断肖像侵权风险时，同时执行 [肖像及形象权风险初筛](portrait-rights-risk.md)。原创设计检查与法律风险初筛分别记录：前者核对图像是否落实设定，后者核对来源、授权、使用语境及法域。用户要求全球海外发行，不能将本页检查通过解释为全球不侵权。

## 校验范围

这是原创设计落实情况的检查，不是名人身份识别。可以描述脸型、眉眼、鼻唇、下颌、发型等可见特征并与本次原创设定核对；不根据人脸猜测姓名、不匹配明星名单，也不通过反向搜脸、名人人脸库或人脸向量检索判断“像哪位明星”。素材身份不明时仍按一般造型参考使用，不要求用户先确认图片人物身份。

通过表示实际可见特征符合原创角色设计，不表示已经排除与所有名人的相似性。不得虚构撞脸相似度、检索结果或“全球名人排查通过”的保证。用户提出具体撞脸反馈时将该版列为待修，采用反馈中描述的外貌问题调整，不自行确认所提姓名与图片人脸的对应关系。

“与名人人脸相似度不超过 70%”不能作为本技能已实现的验收阈值：本技能不执行人脸与名人身份的比对或量化评分，不返回相似度百分比，也不写“低于 70%，通过”。不能把服装、色彩、构图或整图像素的相似程度冒称为人脸相似度。遇到该要求时说明不能执行这一部分，继续可执行的原创设计与可见特征复核。

## 生成前

- 外貌设计与实际提交的提示词不使用明星姓名、明星绰号、“某演员同款脸”“某演员年轻版”或影视角色的演员面容作模仿目标；正面和负面提示词都不列明星名单。剧本角色名仍按正文保留，不能把角色姓名自动解释成演员长相。
- 男女主继续贴近用户参考的题材、整体气质、发型和穿搭审美，年龄感服从本次生成外观年龄，同时为本剧独立组合脸型比例、眉眼关系、鼻唇轮廓与下颌形状，写明两到三个稳定、可见的原创辨识点。不得以“贴近参考”为由要求照搬整张参考脸；不以不同发色、衣服或背景代替面部设计。正文明确的体型及外貌特征仍须保留，正文年龄按 [人物年龄范围](visual-specs.md#人物年龄范围) 映射后用于外观设计。
- 用户明确说明某参考是明星时，仅借用服装、发型或摄影风格，不将该图用作锁脸参考。身份未知的参考也只按可见造型元素提取设计；不用识别人脸作为筛选素材的前提。若工具无法将造型参考与锁脸作用区分开，首张角色图改用具体文字设定；后续换装及三视图使用本次通过复核的角色基准照。
- 在完整人物提示词中加入简短约束：“原创虚构角色，面部特征按本次独立设定呈现，不模仿名人或明星的面容。”这是生成目标，不能代替出图检查。
- 复用现有 `preflight.continuity` 记录原创五官组合、辨识点和参考用途，在 `preflight.exclusions` 记录不采用明星面容模仿。无需增加表格列或单独交付检查报告。

## 出图后

1. 实际查看当前尝试的源图及清晰面部细节，核对脸型、眉眼比例、鼻唇和下颌是否落实文字设计，原创辨识点是否可见。不能只凭提示词或几何检查结果批准。
   同时按 [人物年龄范围](visual-specs.md#人物年龄范围) 核对正文年龄至外观年龄的映射及生成图的大致年龄感；映射允许的 30–35 岁外观不得按旧禁用规则退回。不能从人脸证明精确年龄或将年龄感复核当作明星相似度检查。
2. 换装／状态图核对本次已通过基准照的可见特征是否保持；真人三视图通过左侧未打码的清晰面部特写核对基准面容；右侧全身图按模板遮挡可见面部，只核对可见发型、头部轮廓、体型、服装与打码范围，不声称核对了被遮住的五官。右侧按要求打码本身不是失败原因；左侧特写被额外打码或无法核对必要面部特征时仍须返修。群像分别检查可辨面孔，不能只检查主角后就批准全组。
3. 原创面部设定未落实、沿用用户已指出的仿脸方案，或脸部过小／遮挡使必要特征无法检查时，不批准该版。描述具体缺失或需调整的特征，不猜测明星姓名。按既有质量失败流程返修；不可把“未能校验”写成“无撞脸”。
4. 在现有 `checked.note` 中写本次实际观察及原创设计复核结论。合格后才进入归档／交付及后续基准图引用。通过结论只覆盖已检查的设定与图像特征，不宣称名人身份排除。

记录示例仅说明格式，必须替换为实际所见：“原创设计复核通过：窄椭圆脸、平直眉与略宽眼距、圆钝鼻尖已落实，脸部可辨；服装、人数与构图符合计划。此结论不涉及名人身份匹配。”

## 返修与连续性

使用 `checked` 的 `approved=false`、`code=originality_design_mismatch` 或 `code=face_details_uncheckable`，在 `note` 写实际原因。若用户反馈撞脸，记录反馈来源为用户意见，不写成模型识别结论。先更新 state 中完整提示词与参考用途，再按已授权流程返修；调整脸型、眉眼、鼻唇、下颌等面部结构的组合，保持已确定的生成外观年龄、剧情身份气质和服装要求，不把映射后的年龄改回正文年龄。

不使用不合格面容继续锁脸。必要时重新生成该角色基准照；基准照变化后按既有引用依赖规则处理受影响的换装和三视图。每张返修图重新查看并记录结论，遵守同项质量阶段连续六次失败即暂停的既有上限，不无限重试。`image_check.py` 只检查文件与几何规格，不提供明星识别或原创性自动鉴定。
