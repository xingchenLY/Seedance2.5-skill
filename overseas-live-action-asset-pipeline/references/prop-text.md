# 道具文字：按用途与内容分别处理

适用于独立道具、手机／其它屏幕、文件票据、包装标签，以及按 [绑定条件](visual-specs.md#场景与道具绑定) 允许画入场景的同一道具可见文字；文字规则不构成额外绑定道具的理由。国内／海外、真人／拟人动物和所有生图通道共用。取代道具“一律模糊／只许色块／一律禁姓名金额编号”的旧要求，不自动放开品牌、无关文字或其它类别的视图标签。

## 哪些清晰，哪些处理

| 内容类别 | 处理方式 |
| --- | --- |
| 剧情或道具用途需要，内容已确定且不涉及敏感或不允许展示的信息 | 清晰呈现，例如通用按钮／功能标签、文件标题、指定剧情短句、虚构角色姓名及剧情必要的日期、金额、数量、单位和道具编号；不因含数字或姓名就一律模糊 |
| 不需要读出的内容或正文未给出的非关键细节 | 优先留白或简化版式，不随意补长段文字、假字或乱码；不能把剧情必须读出的关键字句放进此类 |
| 涉及真实个人敏感资料、有效账号／支付信息、密码令牌、可用凭证，或明确不允许展示的内容 | 仅对相关字段遮挡、删除或用不指向真实个人／账户的虚构内容替换；保留其余可公开信息、道具结构和清晰度，不整张模糊。来源或公开范围不明且影响判断时，只核对该字段，不擅自公开 |

品牌 logo、型号标识、品牌专属图案、应用品牌及水印仍按原去品牌规则排除；不能把这些包装成“必要文字”自动放行。普通通用词、数字、剧情内的虚构名称不因属于文字就视作品牌。

## 地域与语言

- **海外道具成图不能出现中文。** 需要清晰显示的内容使用本项目已确定、符合故事地域的语言，不一律改成英语，也不使用聊天语言。检查标签、正文、屏幕、编号前缀、单位说明、边角及反射中的中文残留，不允许中外文混排。
- 剧本或工作表是中文时，先转换为确定的目标语言，角色名沿用项目外文名映射；保留剧情含义与已确定日期、金额和编号，不擅自换币种、改金额或增加剧情。目标语言无法从既有项目设定确定时先补齐文字方案，不能把中文直接送进成图或随意猜造关键文本。
- 国内沿用指定中文，默认简体，用户指定时用繁体，必要数字和单位保留。无须文字的物件仍可无字。海外“无中文”限制针对成图内容，不要求把中文提示词、资产表或文件名改成外文。

## 提示词与同物连续性

1. 在现有 `preflight.body_basis` 记录哪些信息来自正文、哪些属于虚构美术补充；`continuity` 记录最终语言、逐字文本、所在面／区域、保持或变化的字段，以及需要局部处理的字段。`exclusions` 只排除非指定文字、敏感字段和品牌，海外另排除中文，不再与清晰文字要求同时写“无任何文字／数字”。不新增表格列或请求字段。
2. 在完整提示词中逐项写“位置＋准确字句＋清晰可读要求”，用引号标出最终成图文本。海外的引号内必须是已确定的目标语言；不得保留“填入内容”等占位说明，也不把中文分析说明画到道具上。按原图尺寸安排可读字号、字距和版面，关键文字不被反光、裁切或手部遮住。
3. 长文只保留剧情确实需要且能读清的范围，不自动编造合同条款、诊断、转账信息或正文未给出的证据。必要标题、姓名、金额等不能为了省事改成模糊色块；非关键段落可采用留白／简化排版，不能以假字冒充可读正文。
4. 同一道具在独立图、场景关联图和不同状态中的文字版本保持一致；只有剧情明确内容改变时才更新。手机需要显示消息／按钮时按此规则做无品牌界面，不强制变回黑屏或纯色块；不需要亮屏时继续原关闭屏幕默认。文字允许显示不取消正背面、手机壳和去品牌要求。

通用文字段（提交前替换为确定的内容，删除不适用句子）：

~~~text
本图仅显示已经确定的必要文字，语言为本项目的目标语言，在指定位置逐字显示约定的准确字句，字形端正、内容完整、清晰可读。其它无用文字区域留白或简化，不生成随机假字、乱码或额外说明。敏感字段仅在指定局部遮挡或使用已确定的虚构替代，保留其余内容及物件清晰度。无品牌标识或水印；海外图无中文，国内图采用指定中文。
~~~

## 成图审核

实际查看各个必要文字区域，逐字核对语言、内容、位置、清晰度、数字及上下文；海外还要检查有无中文残留。OCR 如可用只作辅助，不能代替实际看图，也不宣称执行了没有使用的识别工具。

- 必要文字缺失、被整块模糊、错字／乱码、数字错误或镜像，用 `approved=false, code=prop_text_mismatch`；国内已有 `domestic_text_mismatch` 可沿用，不重复计数。
- 海外出现中文或使用了错误的目标语言，用 `code=prop_text_language_mismatch`；未按要求处理敏感字段用 `code=prop_text_sensitive_content`。品牌问题继续按原规格处理，保留物件本身和允许的文字。
- 在现有 `checked.note` 记录实际问题区域和改正目标，不把真实秘密原值复制进审核日志。修正提示词后返修当前资产，重新核对文字及整件物体，合格后才归档／入库。与结构、重复和质量检查在同次审图完成，同次问题只算一次，仍沿用最多 5 次返修；不修改其它人物及三视图的无文字标签规则。
