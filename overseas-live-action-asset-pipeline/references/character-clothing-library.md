# 服装库：风格、廓形与使用场合

按服装风格、廓形和场合独立归类，共 31 套 C 模板。可与任意符合剧情和身体条件的 A 形象组合，不限定同号搭配、不绑定原角色面孔。每组可供常服／专用服判断，不自动代表职业、财富或剧情事实。

选择顺序：正文明确衣服 → 主要常服复用 → 身份与重要场合专用服 → 材质配色和细节。按 [服装规则](character-wardrobe.md) 和 [组合规则](character-genres.md) 使用，不因更换库结构增加资产数量。儿童使用适龄完整童装；成人衣服只可借配色或材质再重新裁剪，不直接套给儿童。女性胸前完整遮挡。

每项补齐内外层、下装、鞋履、配饰及状态；原片段未出现的部分是本剧美术补充，不能宣称原素材已展示。C10/C22/C23/C29/C33/C34 等被裙摆遮挡或原仅半身的鞋履／下装按剧情补齐。腕表、首饰、礼帽、发饰属于可调整配饰；武器、手包、轮椅等独立剧情道具不自动进入服装。M24 的轮椅只按正文另行使用，不推断病因。

真实鱼尾、膜翼、尖耳和皮肤鳞片不是衣服；C01 仅是上衣，C18 是鳞纹礼裙，不会自动获得鱼尾。M03、M17 原文没有确定的可拆服装，不虚构 C03／C17 或把无衣状态当通用穿搭；有需要按剧情另选合适上衣。
