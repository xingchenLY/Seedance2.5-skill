# 人物形象库：面貌、妆发与身体结构

按可见脸型、五官、妆发及物种结构归类，共 33 套 A 模板。气质标签是造型方向，不证明性格、职业、善恶或族裔。服装从 [独立服装库](character-clothing-library.md) 另选；组合方法见 [总入口](character-genres.md)。

片段中的成年／少年／儿童只表示原造型方向，最终年龄按正文及既有映射确定，不把儿童脸套成人；地区选角由角色设定决定。肤色、眼色、发色适配该设计，不从素材识别真人族裔。面部纹理服从最终外观年龄。先选一套结构，再按 [角色区分规则](character-distinction.md) 做具体差异；固定后的同一角色不因换衣换脸。

尖耳、膜翼、鱼尾、鳞片及爪属于身体结构，只用于正文支持的物种。普通人借海洋气质时删去非人结构，明确补成人类身体设计，不能当成原图已有信息。M04 巨龙仍见 [生物附录](character-genres/epic-creature.md)。
