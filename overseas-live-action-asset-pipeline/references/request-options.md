# 请求字段与默认值

此处是默认规则的唯一说明表；各阶段读取 `scripts/input_check.py` 返回的归一结果，不再各自推导开关。代理把自然语言写入内部 request.json，用户无需填写 JSON。未明确要求图片时直接整理、检查并保存 Excel，不询问是否出图，不把“制作资产”“整理人物”自动解释成出图。

## 表格完成后的出图流程选择

asset_workflow 仅选择图片生成方式，Codex/codex/Codex流程 归一为 codex，剧梦/剧梦流程/jumeng 归一为 jumeng。整理提示词和资产表时允许省略、null 或空白，返回 null，不自动补为 Codex；明确未知值或同时选择两种仍报错。

先完成共用正文分析、完整提示词、资产表整理和本地保存；需要出图且未明确选择时，再询问 Codex／剧梦。默认仅表格或仅提示词不询问。明确仅图片时不强加表格，在出图前选择即可。

选择剧梦不阻塞表格、索引、检查或保存；当前只保留其出图入口，新生成须等待导入。两条出图流程的地区、题材、资产范围及后续存储共用。input_check 的 ready_for_generation 只表示正文与已导入的出图选择具备条件；调用者仍须先完成所选表格和逐图检查，不以该值证明 Excel 已保存。

## 必选地域模式

每个新的资产任务先选择国内或海外，未选时等待用户回答，不从正文语言或旧任务推断；本次已明确选择则直接使用，同次续跑不重复问。技能编辑／模板说明不属于资产生产，不需要填写 request。

| region_mode | 规则 |
| --- | --- |
| domestic／国内／国内模式 | 亚洲真人原创面貌，国内时代与用途，场景道具的必要可见文字使用中文；读取 [国内模板](domestic-mode.md) |
| overseas／海外／海外模式 | 原海外模板及审美、排除项保持不变 |

不允许省略、null、空白、任意自动值或同时选择两种。该字段独立于 output_mode、image_types 和题材，不会自动开启图片。正文索引仍以原始剧本为依据，模式选择不改写剧情或引文。旧 request 缺少模式也须补上本次明确选择，不能自动升级为海外。

## 输出类型

| output_mode | 含义 | generate_images | generate_workbook 默认值 |
| --- | --- | --- | --- |
| workbook（默认） | 只要表格 | false | true，不可同时关闭表格 |
| assets | 表格及所选图片 | 由 image_types 决定 | true；可明确关闭 |
| images | 只要所选图片 | true | false，不可同时开启表格 |
| prompts | 只要提示词 | false | false，不可同时开启表格 |

省略 output_mode 且未选图片时按 workbook；省略模式但明确选择非空 image_types 时按 assets，仍保留表格。用户明确“只要图片”才用 images；“只要提示词”用 prompts。“只要表格”须同时清空旧图片选择，不能只改变 generate_workbook 后沿用旧出图任务。显式 assets/images 却未填写 image_types 时，兼容解释为本次资产范围内的原照、场景和道具图片，三视图仍关闭；代理新建请求应始终写出已选择的 image_types，避免歧义。

prompts 在对话交付完整提示词，不创建资产归档目录。workbook 仅导出并检查 Excel；所有模式的人物资产表均不收录三视图行或提示词，即使已启用三视图任务也不加入表格。

## 四项图片选择

`image_types` 接受以下名称组成的数组，四项分别可选；`[]` 明确全部关闭。未选择的类别只整理表格／提示词，不启动图片工具、重试、保存或等待队列。表格包含哪些资产仍由 asset_types、selected_assets 和 episodes 决定；不能把 image_types 当作表格筛选器。

| 选择 | 内容 |
| --- | --- |
| 人物 | 单人原照、已选服装／状态图及群像；不自动包含三视图 |
| 三视图 | 已选单人角色的三视图；不自动包含原照 |
| 场景 | 所选场景及空间／时间版本 |
| 道具 | 所选道具；手机正背面属于同一道具图 |

可表达为“只给表格”“表格加人物和场景图片”“只生成道具图”“用已有原照，只生成三视图”。只有泛称“要图片”时按所选资产范围开启人物／场景／道具，三视图仍须明确选择；“全部四类图片，含三视图”才选四项。用户之后补选类别时，只处理新启用或确需修改的图片，复用已有合格成果。

只选三视图时先复用合格单人原照，或按 [已有原照引用](progress.md#仅生成三视图时的已有原照) 绑定用户指定图片。没有可用原照就说明具体缺项，保持该三视图等待，不自动开启人物图片；表格和其它独立图片继续。

## 范围与路径

| 字段 | 规则 |
| --- | --- |
| asset_workflow | 仅出图前选择 codex／jumeng；整理表格允许省略或 null，无自动默认；剧梦只暂停新出图 |
| region_mode | 必选国内/domestic 或海外/overseas，无默认；先选择后制作，当前任务续跑沿用 |
| script_path / script_text | 必须且只能选一个；文件用可读取、非空的绝对路径，正文用非空文本。链接先取得正文，附件先定位真实文件 |
| selected_assets | 点名资产的非空类别字典，支持名称及版本条件，见 [指定资产](selection.md)；未点名时省略或 null |
| asset_types | 人物、场景、道具的一个或多个；点名时从名单推导，显式类别必须一致；非点名省略默认三类 |
| episodes | 省略、null、空白、空数组或全部均取 all，不询问是否全部；支持正整数、整数数组及 1-3,5。须匹配正文标题，不清楚或越界不扩大范围 |
| output_root | 本次绝对目录。仅表格可省略，省略时保存到本次本地工作区；全量／按类别且开启图片时必填；点名图片可省略、不追问、不代填；prompts 无须目录。显式无效路径仍报错 |
| generate_workbook | 布尔值或生成／不生成、是／否、需要／不需要、yes/no；省略、null、空白采用上表。不对任意字符串强制转真假 |
| image_types | 四项图片选择，见上表；可选一个或多个，空数组全部关闭。必须属于本次资产范围，三视图要求范围内含人物；workbook/prompts 不允许非空图片选择 |
| generate_turnarounds | 兼容开关，默认 false；image_types 包含三视图时归一为 true。与 image_types 显式选择冲突时报错，不静默扩大范围。workbook/prompts 可用旧开关设计三视图提示词但不出图，三视图仍不入表 |
| turnaround_characters | 可选的已选角色名称数组，支持正文核对的别名；提供即启用对应三视图，与 false 或显式未选三视图的 image_types 冲突。无名单且启用时覆盖本次所选单人角色 |
| min_short_side | 图片短边最低实际像素，默认 512，可按用户明确的分辨率要求调整为正整数；不代表生成工具保证该尺寸 |
| content_index | 完成正文分析后加入索引绝对路径；初次格式校验可缺省，开始资产生产前须存在且匹配当前剧本 |

缺少 output_root 返回 null、save_assets=false；有路径且需要图片时 save_assets=true。`save_assets` 控制图片归档，不阻止默认资产表保存：没有主路径时在本次本地工作区保存真实 Excel 并提供实际路径和链接，不建立图片分类目录；有主路径则将表格保存到其根目录。表格按 [总表交付](workbook.md) 在整理并核对完成后立即保存，不等图片全部生成；后续更新覆盖原表格原路径。请求、索引、提示词计划及进度属于工具工作区记录，不是交付用资产表。

只提供兼容三视图开关／角色名单且省略 output_mode、image_types 时，按“表格加三视图”处理，不开启原照。归一结果中的 generate_images 表示是否选了任一图片类别；resolved_assets 的 generate_image 决定各项能否出图。generate_turnarounds 可能只表示兼容文字设计，不能独立用作调用图片工具的依据。

未选地域模式时先完成选择；缺失剧本、必需路径或明确冲突时一次合并指出；缺失路径不阻塞点名资产。明确的空名单、通配符、未知类别和无效集数均报错。只凭文件可读不能开始生产：初次校验返回 content_validated=false、ready_for_generation=false；[正文索引](content-index.md) 的 prepare.py index 会完成内容校验，无须再单独重复运行 input_check.py --require-content。

~~~json
{
  "asset_workflow": "codex",
  "region_mode": "overseas",
  "script_path": "本次剧本绝对路径",
  "selected_assets": {"人物": [{"name": "艾玛", "outfit": "红裙", "count": 1}]},
  "output_mode": "images",
  "image_types": ["人物"]
}
~~~

此例只生成艾玛红裙原照一张，无归档、表格或三视图。示例值必须替换为真实输入。用户只补路径时归档已有合格图；只改表格开关时仅处理表格；只加三视图时复用原照，不重新设计已通过的图片。

已明确地域模式后，默认完整资产表只需有效剧本；不填写图片选择。要保留完整表格并只开启人物与场景图片，可用：

~~~json
{
  "asset_workflow": "codex",
  "region_mode": "overseas",
  "script_path": "本次剧本绝对路径",
  "output_root": "本次交付绝对目录",
  "image_types": ["人物", "场景"]
}
~~~

此例三类资产仍全部入表，道具图和人物三视图关闭。
