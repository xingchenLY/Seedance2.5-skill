# 请求字段与默认值

此处是默认规则的唯一说明表；各阶段读取 `scripts/input_check.py` 返回的归一结果，不再各自推导开关。代理把自然语言写入内部 request.json，用户无需填写 JSON。未明确要求图片时直接整理、检查并保存 Excel，不询问是否出图，“生成资产／资产生成／生成图片”属于出图请求；“整理资产／分析人物”仍仅整理。

## 表格完成后的出图流程选择

asset_workflow 仅选择图片生成方式，Codex/codex/Codex流程 归一为 codex，剧梦/剧梦流程/jumeng 归一为 jumeng。整理提示词和资产表时允许省略、null 或空白，返回 null，不自动补为 Codex；明确未知值或同时选择两种仍报错。

先完成所选表格；需要出图且未明确选择平台时默认 jumeng，不询问 Codex／剧梦二选一。明确 Codex 时沿用。仅表格或提示词保持 null，不打开平台；明确仅图片不强加表格。

选择剧梦不阻塞表格、索引、检查或保存；选择后必须提供 jumeng_project_name，再按 [剧梦流程](jumeng-workflow.md) 准备浏览器、项目与资产剧集；按剧梦完整流程继续人物、三视图、群像、场景及道具。缺项目名只阻止平台准备，不阻塞共用表格或已有图片后处理。两条出图流程的地区、题材、资产范围及后续存储共用。input_check 的 ready_for_generation 只表示正文与已导入的出图选择具备条件；调用者仍须先完成所选表格和逐图检查，不以该值证明 Excel 已保存。

jumeng_project_required 表示剧梦图片任务缺少项目名，应询问后再操作网页；ready_for_jumeng_setup 表示已具备项目准备的输入，jumeng_episode_names 按已解析、启用图片的实际类别给出人物资产／场景资产／道具资产（含三视图时归人物资产）。这些是归一结果，不是用户必须手填字段；不代表页面或剧集已创建。ready_for_generation 对 Codex 或项目名齐备的剧梦图片请求开放，逐项仍受正文、提示词、参考依赖和审核门槛约束。

## 必选地域模式

每个新的资产任务先选择国内或海外，未选时等待用户回答，不从正文语言或旧任务推断；本次已明确选择则直接使用，同次续跑不重复问。技能编辑／模板说明不属于资产生产，不需要填写 request。

| region_mode | 规则 |
| --- | --- |
| domestic／国内／国内模式 | 亚洲真人原创面貌，国内时代与用途，场景道具的必要可见文字使用中文；读取 [国内模板](domestic-mode.md) |
| overseas／海外／海外模式 | 原海外模板及审美、排除项保持不变 |

不允许省略、null、空白、任意自动值或同时选择两种。该字段独立于 output_mode、image_types 和题材，不会自动开启图片。正文索引仍以原始剧本为依据，模式选择不改写剧情或引文。旧 request 缺少模式也须补上本次明确选择，不能自动升级为海外。

## 输出类型

| output_mode | 含义 | generate_images | generate_workbook 默认值 |
| --- | --- | --- | --- |
| workbook（默认） | 只要表格 | false | true，不可同时关闭表格 |
| assets | 表格及所选图片 | 由 image_types 决定 | true；可明确关闭 |
| images | 只要所选图片 | true | false，不可同时开启表格 |
| prompts | 只要提示词 | false | false，不可同时开启表格 |

省略 output_mode 且未选图片时按 workbook；省略模式但明确选择非空 image_types 时按 assets，仍保留表格。用户明确“只要图片”才用 images；“只要提示词”用 prompts。“只要表格”须同时清空旧图片选择，不能只改变 generate_workbook 后沿用旧出图任务。显式 assets/images 却未填写 image_types 时，兼容解释为本次资产范围内的原照、场景和道具图片，底层兼容接口不自行推断人物身份或扩展三视图；代理新建请求必须先按下方自然语言默认范围明确 image_types 与 selected_assets，不能把兼容默认当作用户默认。

prompts 在对话交付完整提示词，不创建资产归档目录。workbook 仅导出并检查 Excel；所有模式的人物资产表均不收录三视图行或提示词，即使已启用三视图任务也不加入表格。

## 四项图片选择

`image_types` 接受以下名称组成的数组，四项分别可选；`[]` 明确全部关闭。未选择的类别只整理表格／提示词，不启动图片工具、重试、保存或等待队列。表格包含哪些资产仍由 asset_types、selected_assets 和 episodes 决定；不能把 image_types 当作表格筛选器。

| 选择 | 内容 |
| --- | --- |
| 人物 | 单人原照、已选服装／状态图及群像；不自动包含三视图 |
| 三视图 | 已选单人角色的三视图；不自动包含原照 |
| 场景 | 所选场景及空间／时间版本 |
| 道具 | 所选道具；手机正背面属于同一道具图 |

可表达为“只给表格”“表格加人物和场景图片”“只生成道具图”“用已有原照，只生成三视图”。泛称“生成人物资产”默认人物及三视图；泛称“生成资产”按所选类别处理，其中人物遵从下方角色排除规则。明确“只生成定妆照”只选人物；“全部四类图片，含三视图”选四项。用户之后补选类别时，只处理新启用或确需修改的图片，复用已有合格成果。

只选三视图时先复用合格单人原照，或按 [已有原照引用](progress.md#仅生成三视图时的已有原照) 绑定用户指定图片。没有可用原照就说明具体缺项，保持该三视图等待，不自动开启人物图片；表格和其它独立图片继续。

## 范围与路径

| 字段 | 规则 |
| --- | --- |
| asset_workflow | 图片任务缺省为 jumeng，明确 Codex 优先；仅表格允许 null；剧梦须用户指定项目名 |
| jumeng_project_name | 剧梦图片模式进入平台前必填，用户指定的非空单行项目名；同任务沿用，不从剧名／目录推断；仅表格、仅提示词和 Codex 不要求 |
| region_mode | 必选国内/domestic 或海外/overseas，无默认；先选择后制作，当前任务续跑沿用 |
| script_path / script_text | 必须且只能选一个；文件用可读取、非空的绝对路径，正文用非空文本。链接先取得正文，附件先定位真实文件 |
| selected_assets | 点名资产的非空类别字典，支持名称及版本条件，见 [指定资产](selection.md)；未点名时省略或 null |
| asset_types | 人物、场景、道具的一个或多个；点名时从名单推导，显式类别必须一致；非点名省略默认三类 |
| episodes | 省略、null、空白、空数组或全部均取 all，不询问是否全部；支持正整数、整数数组及 1-3,5。须匹配正文标题，不清楚或越界不扩大范围 |
| output_root | 本次绝对目录。仅表格可省略，该字段只用于图片归档，Excel 由 workbook_output_dir 独立确定；全量／按类别且开启图片时必填；点名图片可省略、不追问、不代填；prompts 无须目录。显式无效路径仍报错 |
| workbook_output_dir | 可选的 Excel 专用绝对保存目录；未填默认原始 script_path 所在文件夹，纯正文无文件路径时使用本次工作区。用户明确统一交付目录时将该目录同时填入本字段及 output_root；不能仅凭图片目录推断 Excel 目录 |
| generate_workbook | 布尔值或生成／不生成、是／否、需要／不需要、yes/no；省略、null、空白采用上表。不对任意字符串强制转真假 |
| image_types | 四项图片选择，见上表；可选一个或多个，空数组全部关闭。必须属于本次资产范围，三视图要求范围内含人物；workbook/prompts 不允许非空图片选择 |
| generate_turnarounds | 兼容开关，默认 false；image_types 包含三视图时归一为 true。与 image_types 显式选择冲突时报错，不静默扩大范围。workbook/prompts 可用旧开关设计三视图提示词但不出图，三视图仍不入表 |
| turnaround_characters | 可选的已选角色名称数组，支持正文核对的别名；提供即启用对应三视图，与 false 或显式未选三视图的 image_types 冲突。无名单且启用时覆盖本次所选单人角色 |
| min_short_side | 图片短边最低实际像素，默认 512，可按用户明确的分辨率要求调整为正整数；不代表生成工具保证该尺寸 |
| content_index | 完成正文分析后加入索引绝对路径；初次格式校验可缺省，开始资产生产前须存在且匹配当前剧本 |

缺少 output_root 返回 null、save_assets=false；有路径且需要图片时 save_assets=true。`save_assets` 控制图片归档，不阻止默认资产表保存：没有明确 Excel／统一交付目录时，默认在原始剧本文件的父目录保存真实 Excel；没有本地剧本文件路径才使用本次本地工作区。明确指定 Excel 路径优先；用户明确统一交付目录时将同一目录填入 workbook_output_dir 和 output_root；仅给图片 output_root 不改变 Excel 的默认位置。返回 workbook_output_dir 作为表格默认目录（纯文本在请求阶段为 null，由 workbook_data.py 使用 state 工作区），不将该默认值回填 output_root，不因此开启图片归档。提供实际路径和链接，不建立图片分类目录。表格按 [总表交付](workbook.md) 在整理并核对完成后立即保存，不等图片全部生成；后续更新覆盖原表格原路径。请求、索引、提示词计划及进度属于工具工作区记录，不是交付用资产表。

只提供兼容三视图开关／角色名单且省略 output_mode、image_types 时，按“表格加三视图”处理，不开启原照。归一结果中的 generate_images 表示是否选了任一图片类别；resolved_assets 的 generate_image 决定各项能否出图。generate_turnarounds 可能只表示兼容文字设计，不能独立用作调用图片工具的依据。

未选地域模式时先完成选择；缺失剧本、必需路径或明确冲突时一次合并指出；缺失路径不阻塞点名资产。明确的空名单、通配符、未知类别和无效集数均报错。只凭文件可读不能开始生产：初次校验返回 content_validated=false、ready_for_generation=false；[正文索引](content-index.md) 的 prepare.py index 会完成内容校验，无须再单独重复运行 input_check.py --require-content。

~~~json
{
  "asset_workflow": "codex",
  "region_mode": "overseas",
  "script_path": "本次剧本绝对路径",
  "selected_assets": {"人物": [{"name": "艾玛", "outfit": "红裙", "count": 1}]},
  "output_mode": "images",
  "image_types": ["人物"]
}
~~~

此例只生成艾玛红裙原照一张，无归档、表格或三视图。示例值必须替换为真实输入。用户只补路径时归档已有合格图；只改表格开关时仅处理表格；只加三视图时复用原照，不重新设计已通过的图片。

已明确地域模式后，默认完整资产表只需有效剧本；不填写图片选择。要保留完整表格并只开启人物与场景图片，可用：

~~~json
{
  "asset_workflow": "codex",
  "region_mode": "overseas",
  "script_path": "本次剧本绝对路径",
  "output_root": "本次交付绝对目录",
  "image_types": ["人物", "场景"]
}
~~~

此例三类资产仍全部入表，道具图和人物三视图关闭。

## 人物图片的自然语言默认范围

此处在代理把自然语言转成 request.json 时执行，适用于 Codex 和剧梦；脚本不从姓名、性别或排序猜叙事身份。

- 未点名的“生成人物资产”或生成资产中包含人物：依据正文及已确认角色定位，排除男主、女主、男反、女反，其余独立人物每人一张基础半身定妆照和对应三视图，写 `image_types=["人物","三视图"]`。男反／女反指明确承担对应反派定位者，不把所有有冲突的人都排除；定位不明时先查正文，仍不明则只询问有歧义的角色，其余继续。
- 用户点名、要求包含主角／反派或明确“全部人物一个不漏”时覆盖默认排除；不能因排除规则跳过用户点名的人。只要定妆照则不做三视图；只要三视图则复用合格原照，不擅自开启原照生成。明确换装、状态及张数优先。
- 从表格按归一身份去重，默认每个角色一个基础／干净日常状态。默认三视图只对这一基础照派生，不扩大到表格全部服装伤情；用户要求“所有三视图”才覆盖其已选必要版本。群像不拆人、不做三视图。
- 将已确认纳入的角色及基础 outfit/state、count=1 显式写入图片请求的 selected_assets；三视图名单与之对齐。保留完整资产总表，不删除被默认跳过的角色行；用独立图片请求／状态与表格请求分离。
- 简述纳入、跳过名单及依据，不为无歧义默认项追加确认。已有合格成品复用，每角色基础定妆照一张足够；通过审核并归档即开始该角色三视图，不等待其他人物全部完成。
- 场景、道具未指定数量或条目时默认选中类别全部；“前N张”取表格顺序前N个图资产，包含状态变体。人物跳过规则不影响场景和道具。
