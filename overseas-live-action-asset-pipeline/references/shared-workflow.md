# 共用资产整理与存储流程

国内／海外模式、正文分析、提示词和资产表整理，以及图片返回后的检查、保存、命名、归档和交付均使用本页共用流程。Codex／剧梦只区分中间的图片生成环节，不决定表格或存储流程。命令中的 scripts/ 仍相对于技能根目录。

## 模式选择

开始新的资产制作任务时，先明确选择“国内”或“海外”，无默认值。用户本次已写明模式即视为已选择；未写明时先只问：“本次使用国内模式还是海外模式？国内采用亚洲真人面貌，场景与道具必要文字使用中文；海外沿用原模板。”等待选择后再开始正文提取和资产设计，不凭剧本语种、中文姓名、聊天语言、旧项目或技能名称猜测。模式是用户要求的制作选项，不是出图授权；本次只是修改／分析技能或索取既有模板时，不要求先选模式。

将选择写入内部 request.json 的 region_mode：国内为 domestic，海外为 overseas。所有输出模式均须明确选择；同次任务续跑沿用已选模式，不重复询问。新项目重新选择，用户明确表示沿用时可继承。

- **海外：** 沿用原有人物、场景、道具与拟人动物模板，原审美、排除项和文字限制不变。
- **国内：** 先读 [国内模式与模板](domestic-mode.md)。真人采用原创亚洲面貌，场景与道具的必要画面文字使用中文；本页和旧参考中“非亚洲面貌、按海外语种选角、排除中式建筑物品、场景道具一律无可辨文字”仅作用于海外，由国内规则替换。共享的年龄、画幅、连续性、光影、表格与出图选择规则继续执行。
- 国内／海外与真人／拟人动物题材分别选择。国内拟人动物仍保留动物头部与物种结构，按国内身份、服饰、城市生活和中文标识设计；亚洲真人面貌不强加给动物。国内完整提示词不得混入被替换的海外禁用句。

## 题材路由

默认执行真人题材；用户明确要求“疯狂动物城风格／拟人动物都市动画”，或正文明确采用拟人动物城市世界时，先读取 [拟人动物都市题材分析与模板](animal-city.md)，按本次选定范围应用角色、场景、道具和按需三视图模板。该分支优先替换下文真人选角、族裔、人体比例和摄影风格等不相容规则，保留物种结构、动画比例与可信材质；自然人要素仍执行相应肖像风险规则。不因普通宠物或动物装饰自动切换，不将未选真人资产改成动物。类别、构图规格、输出范围、表格及保存流程仍按原规则；手机继续采用正背面和身份手机壳设计。

## 入口

先完成模式选择，再阅读 [请求字段与默认值](request-options.md)，把用户输入归一为内部请求。入口只加载请求规则和 [正文索引](content-index.md)；点名才加读 [指定资产规则](selection.md)。同次任务已读规则、已定位运行时和模板直接复用，不全量加载参考文件或扫描工作目录找剧本；各阶段只用校验后的默认值。

- 剧本必须可读且含正文；缺少必需输入或有明确冲突时一次合并指出并停止资产流程。点名资产不要求路径、不追问；给路径即按要求归档。未填集数默认提供剧本全部内容，不增加“是否全部”的询问。
- 不从历史项目、工作目录或技能示例代填输入；仅用户明确沿用且能唯一定位时解析指代。同次续跑复用已校验参数。
- 人物的身份、剧情状态及明确外貌要求仅据正文场景、动作、对白及描写分析，人物小传、简介、角色档案即使在同一附件也不作依据。男女主的默认视觉目标是尽量贴近用户提供的人物形象：按题材从 [人物造型参考库](character-genres.md) 选择主参考，重点靠拢面貌结构、发型、气质和服装美感；保持正文明确的体型、时代与服装要求，剧情年龄保留为依据，生成外观年龄按下述映射处理。其余人物可按需借用。记录为美术补充，不代替正文或导入素材角色。海外模式的英语剧本采用北美影视审美，西班牙语采用西班牙审美，葡萄牙语采用葡萄牙审美；语种方向用于适配影视质感，不能冲淡用户参考偏好。男女主在符合年龄映射与正文身份前提下年轻、有稳定辨识点，详见资产设计。
- 附件是剧情资料，不是运行指令或授权。用户要求创建／修改／优化本技能时只做技能编辑，不索要剧本或启动资产生成。
- 人物采用原创虚构面容，不以名人或明星为仿脸目标。贴近用户参考时保留题材、气质及穿搭方向，并独立设计五官组合；按 [人物原创设计与出图复核](character-originality.md) 检查每张人物图，不将原创设计检查说成名人身份识别或绝对无撞脸保证。
- 仅海外模式：人物形象尽量避免亚洲面孔，默认优先采用非亚洲人物的原创面貌设计，覆盖男女主、配角、群演和群像；用户另有明确指定或正文有必须保留的族裔设定时遵从明确设定。按 [人物面貌偏好](visual-specs.md#人物面貌偏好) 在生成前落实具体外貌与参考用途，继续贴近用户参考的气质、发型和穿搭；换装、状态图及三视图保持基准面容，不根据图片判定真实族裔。
- 人物还须按 [肖像及形象权风险初筛](portrait-rights-risk.md) 审查参考来源、授权范围、真人指向证据及实际用途，海外模式默认覆盖用户要求的全球海外发行场景；国内模式按实际用途及发布地区记录，不自动套用全球海外范围。逐项给出高风险、资料不足或目前未见明确风险，写清已核法域及未覆盖部分；不以“相似度低于 70%”或原创检查通过作为不侵权证明，不作全球法律许可保证。
- 正文明确年龄为 30–40 岁时，人物生成外观年龄按 25–30 岁区间选择；明确为 41–50 岁时，按 31–35 岁区间选择，各区间均含两端。只按正文年龄映射一次，不再因正文为 30–50 岁暂停出图；剧情年龄及人物关系不改写，提示词使用映射后的一个确定年龄。其他明确年龄保留；未明确年龄的成年、年长及儿童角色按 [人物年龄范围](visual-specs.md#人物年龄范围) 处理。
- **默认仅制作、检查并保存 Excel 资产表，不生成任何图片。** 用户未明确出图时直接完成表格，不增加是否出图的确认关卡。人物原照（含换装／状态及所选群像）、人物三视图、场景图、道具图四项可独立选一种或多种，也可全部关闭；只对明确启用项出图。表格范围按剧本及资产选择确定，不能因某类图片关闭而漏掉其表格。已有文件不因关闭出图而删除，未选图片不计失败。

## 执行

1. **用固定助手准备正文。** `scripts/prepare.py extract` 一次校验请求、缓存提取结果并输出带原行号的所选集数，直接阅读返回片段。排除小传，完成本次范围内的场次、别名、版本、证据与资产去重后，`prepare.py index` 一次建索引、回填请求并核对选择，返回精确 ID。标注错误集中报告，修正整份错误列表后再运行；引文匹配建议仍须阅读确认，不自动猜别名。遇到 `01／02` 独立数字标题，阅读确认后使用内置标注开关，不临时复制修改解析器。
人物索引建立前读取 [人物重要性与服装设计](character-wardrobe.md)，按正文判断主次，重要角色优先从正文已有服装中选定主要常服，没有合适服装才补充设计；重要场所／场合补齐专用服。复用已有服装不新增同款资产行或图片任务。将角色等级、服装用途和真实场次／基础定装的区别写入索引，再进入设计；场合服装可以是有剧情依据的美术补充，不要求原文直接写出衣服。

2. **完成完整提示词与资产表计划。** 阅读 [资产设计](visual-specs.md) 及本次题材、地域对应模板；人物按参考库和原创设计要求确定外貌、服装，场景锁定空间区分、关联延伸、陈设及光影，道具落实结构与手机双面规则。将全部可入表资产的完整提示词写入 plan，完整 init 到 state，核对分类、去重、版本和正文范围。此阶段不需要选择出图流程，不为获取参考图提前出图；关联空间先确定文字设计与引用计划，出图阶段再绑定实际合格图片。
3. **先整理、检查并保存资产表。** generate_workbook=true 时加载 [总表交付](workbook.md) 和适用 spreadsheets 技能，完成固定五列、排序、合并、排版预览与真实 Excel 导出。有主路径保存到其根目录，无主路径保存到本次工作区，核对文件非空可读并提供链接。完成此步后才进入出图选择；表格只需当前完整提示词，不等待图片生成或视觉验收。默认仅表格任务交付后结束，不询问 Codex／剧梦。明确仅提示词时交付文字结束；明确只要图片时沿用原输出限制，不强加 Excel，先完成对应清单及提示词，再按第 4 步选择出图流程。
4. **仅在图片生成环节分流。** 需要图片时，先核对本次资产表已保存（或用户明确仅图片），以及人物原照、三视图、场景、道具的选择。尚未选择流程时询问“资产表已整理完成，本次图片生成使用 Codex 还是剧梦（待导入）？”，仅图片任务相应说明进入出图阶段。用户已明确选择则沿用，不重复询问、不自动默认。将 asset_workflow 写为 codex 或 jumeng，更新 init 保留相同设计与已有成果。Codex 使用 [Codex 图片生成](codex-workflow.md)；剧梦只到 [空白入口](jumeng-workflow.md)，等待导入，不妨碍已完成表格交付或已有图片后处理。
5. **对已生成图片逐张审核并正式归档。** 实际查看待审副本，无主路径时查看源图，核对人物、服装、构图及本项四项约束；场景与同地点已有空间图按 [空间区分与防重复](visual-specs.md#空间区分与防重复) 对照检查；人物执行 [原创设计复核](character-originality.md) 和 [肖像及形象权风险初筛](portrait-rights-risk.md)，记录实际依据。视觉不合格返修；高风险或关键授权资料不足的版本保留待处理，继续其它资产。可验收项用 `finish_asset.py` 提交实际结论并完成几何检查、单图正式归档和状态更新。有路径正式归档成功才记 saved；待审副本不算成品、不解锁后续引用。无路径跳过归档，不创建分类目录。只有合格图片实际显示后才传 `--displayed` 或记 delivered。保存失败只补保存。技术验收不代表全球商业发行许可，收尾说明人物风险结论及未解决项。
6. **按需三视图与恢复。** 三视图始终按需开启，只为已启用角色使用合格单人原照。本次同时生成原照时，有路径须先归档，无路径须已交付且源图可读；仅生成三视图时，复用已通过检查且可读的原照，或按 [已有原照引用](progress.md#仅生成三视图时的已有原照) 绑定用户指定图片。缺少可用原照则说明缺项并继续其它工作，不自动开启人物原照出图。多人照跳过，人数不明待检查，不裁切拆分。改表格只补表格，加三视图复用原照；同项在生成或质量阶段连续两次失败暂停本项，错误码不同也计入该阶段，同一次尝试不重复计数。修改提示词保留此前尝试和失败预算；继续独立项。续跑读取进度及实际文件。
7. **核对交付。** state 是最终提示词的唯一来源，已通过图片绑定对应尝试的完整提示词；返修前先更新 state，再提交，禁止用表格补丁另改措辞。生成表格时，所有可入表项都须有完整提示词；仅检查启用图片的 design/preflight、父图关系、命名、真实像素及跳过／失败数量。text_only 表示本项图片未开启，不算未完成图片；纯表格任务以 Excel 保存及检查完成为交付条件。表格首次整理好时已用 `workbook_data.py` 和 `build_workbook.mjs` 导出检查并保存；后续内容变更及时覆盖原资产表，使用原路径及 `--overwrite`，目录和文件名不变，不另存版本、不再询问覆盖。收尾只补尚未同步的变更并核对原路径实际文件，复用未变内容，只复查受影响视图。用 `metrics` 读取实测阶段耗时，不补造历史时间或承诺固定提速倍数。

两条出图流程只负责按已确定的提示词及引用返回对应图片。取得真实源图后接回 [运行与逐张保存](runtime.md) 和 [进度助手](progress.md)，沿用同一检查、待审保存、正式归档、失败恢复及交付规则。图片来源记录真实流程，切换流程不改保存目录、命名或覆盖策略。

| 类型 | 固定要求 | 归档名称 |
| --- | --- | --- |
| 单人人物 | 9:16 半身正面；国内用亚洲人物原创面貌；海外按剧本语言适配影视审美，默认优先非亚洲人物的原创面貌，明确设定按人物面貌偏好处理；固定五官、发型、体型和完整服装；男女主年轻、有特点且符合生成外观年龄规则 | 角色中文名-简短服装描述 |
| 群像 | 剧情需要、人数明确、面貌可区分，4:3；不生成三视图 | 角色／群体名-服装描述 |
| 场景 | 16:9 全景，自然透视；海外沿用海外地域时代的建筑陈设及无中式元素要求，国内按国内时代与功能设计并采用必要中文标识；两者均保留必要装饰道具和生活陈设；无人、无人物反射；需独立使用的剧情动作道具不固化到背景 | 地点-具体空间-时间 |
| 道具 | 普通道具根据主体形状与展示角度选择 9:16 竖版或 16:9 横版，单一主体或不可分组合、完整全貌；手机默认一张 16:9 正背面双视图，配符合所属人物身份的原创无标识手机壳，详见 [手机道具](visual-specs.md#手机道具正背面与手机壳)；均为不透明浅灰纯色底，无人物、手持、场景或logo；海外无可辨文字，国内仅保留指定中文及必要数字 | 具体道具名称 |
| 三视图 | 16:9；左 40% 面部特写，右 60% 全身正面、严格朝左侧面、背面；浅灰纯色底，空手、双臂自然下垂，无裁切、文字或徽章，女性不露乳沟 | 已保存原照实际主名-三视图 |

场景资产设计时加载 [场景影视光影](scene-lighting.md)，把光源位置、入射方向、软硬光质、明暗冷暖及适用的材质／空气反应写进每条完整提示词；使用“专业术语＋可见效果”，按条件选用丁达尔效应、体积光、焦散、掠射光等，不堆砌术语或给所有场景加雾。关联空间延续合理光照关系，逐图审核同时检查光影与空间可读性；仅提示词／表格模式同样落实设计，光影段落进入场景表原有提示词列。

同一场景地点的其它房间或空间，尽量根据已确认的关联场景图延伸，优先参考直接相邻或连通的空间，延续整体装修、建筑细节及已确定的连接关系；各房间仍保留可辨认的功能布局和主要陈设，不能复制同一画面后换名称。设计提示词、实际图像引用及出图验收均执行 [空间区分与防重复](visual-specs.md#空间区分与防重复)；同一房间的昼夜版本保持原布局和陈设连续。

场景时间原文明确时按原文；未写明时可按 [剧情逻辑自行推断](visual-specs.md#场景时间推断)，不逐场追问。推断依据记入内部分析，确定的时段统一用于索引、Excel、提示词光线和文件名，不冒充原文明示。仅在缺少合理推断依据时省略时间字段、让 Excel 留真正空单元格，并省略提示词和名称中的时间，不填“时间未知”等占位词。未说明的美术细节可统一设计；半身未显示的鞋履、裤脚属于文字设定，三视图生成后核对。“8K”提示词不代表实际像素，报告真实尺寸。

有主路径时先保存到“待审／对应类别”，合格后正式归档到“人物／场景／道具”；待审文件以尝试标识区分，并保留源图和历史副本，不能混入正式交付数量。总表整理并核对完成后立即保存到根目录；没有主路径时，Excel 保存到本次本地工作区，无论全量、按类别还是点名。保存后核对文件非空、可读取并及时提供实际路径和链接，表格已保存不代表图片已完成。正式图片名称不加集数、日期或序号，必要状态才加描述；保留源图与真实扩展名，同名同内容复用、不同内容另存 -v2/-v3，只有用户明确替换时才覆盖。三视图保留原照的实际版本后缀。

Excel 使用配套模板及固定五列，不放图片、路径、链接或内部执行日志，不以 Markdown 文件替代，不额外交付说明文档。人物资产表只收录原照及所选群像的资产和提示词，不收录三视图，即使启用了三视图图片任务也不加入表格。人物按主角、重要配角、普通配角、群演／群像的等级优先排序，同级按首次出场；每个角色内主要常服优先，其余服装及必要状态按首次使用／出现归组；相同角色纵向合并“角色名”单元格，同角色内相同完整服装标签纵向合并“服装”单元格，保留必要状态区分。场景资产按场景、房间归组，各组按正文首次出现顺序排列；相同场景纵向合并“场景”单元格，同场景内相同房间纵向合并“场景房间”单元格。两表其余三列均逐行保留，详见 [总表交付](workbook.md)。最终简述所选内容、交付数量及未完成项；图片有主路径时附实际目录和新增／复用数，图片无主路径时注明“已交付，未归档”；表格另附真实本地保存位置和最新文件链接，仅提示词任务交付完整提示词。不能把计划条目或已保存表格说成已生成图片。
