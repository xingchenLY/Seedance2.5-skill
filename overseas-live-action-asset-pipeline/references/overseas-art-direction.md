# 海外真人资产的项目美术与提示词

仅在本次请求已明确 `region_mode=overseas`，且当前资产采用真人写实题材时读取和应用。适用于人物、群像、三视图、场景及道具的文字设计和已开启的图片审核。国内模式与拟人动物都市动画不加载、不套用本页；海外不等于欧美，正文明确其他地区时使用其实际时代与生活语境，不强改成欧美。

本页补充设计方法，不替换 [视觉规格](visual-specs.md)、[地区选角](character-casting.md)、[服装规则](character-wardrobe.md) 和 [场景光影](scene-lighting.md)。同任务读取一次；依现有输入、正文和已批准设计自主补齐美术细节，仅按原规则询问真正缺失的必要信息，不新增必填美术参数、逐项问答或逐图确认。默认只整理表格，不因需要风格基准而提前出图。

## 项目共同方向

首次设计时从所选正文确定故事地区、年代、题材与场合，建立简短且可见的共同方向：写实程度、主辅色关系、服装剪裁、建筑家具语言及主要材质。区分正文事实与美术补充；发行或配音语种变化不重设故事地点和选角。已有本项目合格设计优先沿用，不因升级本页重做旧资产。

- 风格词必须落实为可见设计。例如克制的商务感可以由服装剪裁、有限配饰、家具轮廓和受控反光体现，不能只写“高级欧美电影感”。有多个参考方向时选与正文相符的主方向，少量补充相容元素，不逐条堆片名或互相冲突的风格。
- 共同方向统一审美，不统一所有人的脸、衣服、房间布局或颜色。允许不同家庭、职业和生活条件形成有依据的差异；角色社会地位不决定固定脸型、善恶或族裔。
- 色彩以本场已有物体与合理光源为基础，组织主要中性色和少量强调色；不强制“欧美全冷色”“富人全金色”。同色皮肤、衣服与家具依明度、材质和反光区分，不为区分而擅改正文颜色。
- 以演员定妆所需的清晰真人质感为常用起点：皮肤自然、妆造适度、身份和服装可辨。仅在当前资产规格允许时使用克制成像效果，不自动添加抓拍噪点、手抖、浓雾、颗粒或磨皮滤镜。

项目共同方向只决定一次，按需将适用于本项的确定内容写入已有 `preflight.continuity`，依据与美术补充写入 `body_basis`，不要给每件资产复制整份策划。续跑从当前 plan/state 与合格基准恢复，不重做全项目选风格；不新增 schema 字段、Excel 列或独立交付报告。

## 人物的结构、妆发与成像分层

继续从 [形象库 A](character-appearance-library.md) 与 [服装库 C](character-clothing-library.md) 独立组合，A 是面貌起点、C 是服装起点；旧 M 编号仅溯源，不重新绑定成脸与衣服的固定套装。不引入外部脸型库或职业决定脸型的分类。

1. **固定身份结构。** 在已有脸型、眉眼鼻唇设计中，按辨识需要补清眉骨与眼窝关系、颧骨位置、下颌与下巴形态，配合原有体型和辨识点。采用可观察的相对描述，不用毫米级痣点、精确比例或模板编号保证不撞脸。服从正文、外观年龄映射和 [角色区分](character-distinction.md)，不为了差异强加伤疤、纹身、残障或更改族裔设计。
2. **单独确定妆发造型。** 写明实际需要的眉部修饰、眼妆、唇色及质地、双颊妆感和发型整理程度；不要求每个人全妆。气质由结构、妆发、服装与允许的表情共同表达，不把温柔、冷艳、权威绑定为某一种骨相。已确立面貌后，用户仅调整气质或妆容时先改对应层，不顺带重塑脸型；正文要求的剪发、妆容或状态变化按原版本规则处理。
3. **确定成像质感。** 皮肤保留自然明暗转折和符合外观年龄的细微纹理，控制额鼻、颧部等区域的反光，避免全脸统一蜡质高光或涂抹。精致不等于没有皮肤纹理，真实也不要求增加粗糙、皱纹或污渍。细节服从景别：清晰面部区可写皮肤与唇纹，全身区优先轮廓、比例和服装，不堆微观毛孔。

人物仍按现有画幅、背景、正面半身与中性清晰要求设计。三视图左侧清晰特写用于身份细节，右侧全身按原规则打码；不得借“面部细节”要求恢复右侧被遮挡五官，也不改为无头身体、3:4 肖像或新增头部资产。群像每人保持独立结构，清晰度与逐人防撞脸优先于氛围效果。

## 材质写成表面在光线下的表现

先选本项真正可见、会影响辨识的主要材质，再写其表面状态、光照响应及必要接触关系。不同材质有区别，不靠全图“8K、超精细、真实”替代设计。下面是写法方向，不是默认添加的物件、瑕疵或布光方案：

| 材质 | 可采用的可见描述 |
| --- | --- |
| 羊毛、棉、针织 | 合理的低光泽，近处织纹随衣褶和结构转向，缝线与领口清楚；不把织纹变成平贴印花 |
| 缎面、丝质 | 高光随褶皱形成连续变化，亮部保留布料体积，避免统一塑料反光 |
| 皮革 | 纹理尺度、厚度和边缘结构符合物件，表面光泽与使用状态相符；不默认龟裂、油亮或做旧 |
| 木材与石材 | 纹理方向、板件接缝或石材分区服从结构，哑光与抛光区域分别体现，不把纹理铺到无关表面 |
| 金属与玻璃 | 按表面处理表现集中或宽缓高光，玻璃反射保留必要透视与可读信息；不把全部金属做成铬镜面 |

正文明确颜色、结构、新旧或干湿状态优先。划痕、指纹、褪色等仅在有依据或合理且不改变剧情状态的美术补充中使用；不为“生活感”给新品做旧、给衣服加污渍。光源沿用本项既定设计，接触阴影、反射与物体落点相容，不为展示材质新增灯具、雨水、道具或场景版本。

人物优先看清面部与必要服装；场景优先看清入口、布局、主要家具及允许绑定的物件；独立道具优先完整结构、必要文字和关键部件。可以减少无关纹理的抢眼程度，但不以强虚化、失焦、死黑或不完整轮廓隐藏必须展示的内容。道具和三视图继续用既定浅灰纯色底，不继承场景的戏剧化布光。

## 固定内容与本次变化

在已有 `preflight.continuity` 中简洁说明“固定什么、本次改什么、为什么”，不另建变量表或增加试验批次。无变化依据的既定设计继续保持；低风险且未明确的美术细节可按正文自主补齐，不把所有未知都变成确认关卡。

| 使用情况 | 保持 | 本次变化的依据 |
| --- | --- | --- |
| 人物换装或状态 | 自己已审核基准的面貌、体型及未变化特征 | 正文、用户指定或既有场合服装规则支持的衣服、妆发和必要状态 |
| 同地点相邻空间 | 地区年代、建筑连接和适用的材质语言 | 当前房间的功能、真实结构、家具和陈设；不同房间有可见区别 |
| 道具状态版本 | 物件身份、核心形态、尺度及未变化部件 | 剧情所需开合、损坏、内容或显示状态；同款不冒充不同物件 |

时间光照仍按 [同场景时间复用](visual-specs.md#同场景时间复用) 执行，不因本页增加昼夜或换光图。参考图只继承本次允许的职责：身份、服装、相邻空间或材质风格；实际引用必须可用且符合原规则，工具无法隔离另一角色面容时用文字描述服装或风格。延续 [绑定条件](visual-specs.md#场景与道具绑定)，美术搭配不能把临时道具固定进可复用场景。

## 题材方向按正文选用

以下仅是可组合的美术方向；优先服从实际国家、年代、角色生活条件和已知空间用途。使用其中一个相关片段即可，不整表注入，也不据此扩展资产清单。

| 题材语境 | 可考虑的设计方法 | 避免机械套用 |
| --- | --- | --- |
| 当代商业爱情 | 通过衣服剪裁、局部配饰、当代家具廓形及克制的木石金属组合区分身份 | 所有角色穿西装、所有空间豪宅化、全金色或统一冷光 |
| 小镇与家庭情感 | 根据当地住宅、职业与活动选择生活家具和日常面料，用合理状态体现使用感 | 为生活感一律破旧、乡村化或添加乡土装饰 |
| 悬疑与犯罪 | 用空间层次、受控明暗和关键材质建立紧张感，保持资产结构可读 | 自动补枪械、纹身、血迹、雨夜或压黑入口 |
| 现代超自然 | 保留现代生活基础，只加入正文支持的物种、时代遗留或超自然结构 | 题材名自动触发古堡、符文、尖牙、霓虹或游戏材质 |

## 提交前与成图审核

融入现有单项 preflight 和后台审图，不增加串行审批、候选图、独立试拍或新的审核轮次：

- **组装完整提示词。** 从本资产设计展开地区时代、身份或空间结构、当前服装／物件状态、固定视图、必要光影材质及适用排除项。只取本页相关段，不发送 A/C 编号、表格填空指令、分类说明、审核日志或读不到的内部引用；继续使用完整中文提示词，海外画面内文字仍按项目目标语言处理且无中文。
- **去重和消除冲突。** 每条保留当前设计中独有的可见事实，删去旧角色、旧房间、旧颜色和被替代状态。合并重复质感词和禁用句；不能为压缩删掉唯一身份、完整服装、画幅、遮码要求、必要文字、引用或绑定／排除约束。必要无品牌、无人场景和海外无中文等限制仍保留，不套“全部禁用词删除”。
- **确认可独立执行。** 生成器应仅凭完整提示词及实际输入的参考图理解本项，不依赖“同上”“像之前一样”。局部调整时按 [返修方式](repair-policy.md) 排除本次修改目标及其必要阴影反射后，再限定其他内容保持。
- **先身份与结构，再风格。** 实际查看面貌／物件／空间不变量及本次有意变化，然后核对已确定的材质、妆造、色彩、曝光和清晰度；有意变化不误判漂移。只按正文、已确定设计和可见缺陷判定，不因个人偏爱另一种风格、少写术语或无法量出毫米值而返修；不得声称测得真实焦距、色温、材质参数或人种概率。
- **随原记录处理。** 观察写入现有 `checked.note`，不新增主观分数、工作表或重复审核。缺陷仍用现有错误分类和返修预算；严重问题改完整提示词重新生成，正确的局部小问题按原规则引用稳定底图。仅表格／提示词完成设计检查即可，不能声称已验图。

各生成通道使用同一设计；生成与后台审核并行、及时下载、正式归档、表格原路径覆盖及图片版本保护沿用原流程。本页不新增后台阻塞或自动生成权限，不安装外部技能、模型或接口。
