# 人物肖像及形象权风险初筛

**地域模式说明：** 下文全球海外发行范围保留给海外模式。国内模式沿用来源、授权、用途和不作保证的初筛方法，按本次真实发布地区核查适用规则，不将国内设计模式自动等同于全球海外发行。具体法律判断仍须检索当地当前官方资料，模板模式不是法律许可。

用户要求判断生成形象是否存在肖像侵权风险，发行范围为海外所有地区。本流程给出有依据、可追溯的风险初筛，不承诺全球不侵权，也不代替发行地区律师的法律审核。覆盖所有自然人的形象，不能只检查明星；没有具体成图或授权资料时，仅说明待核验事项，不能预先批准。

## 全球发行范围

- 将本次用途记为全球海外发行；核对实际发布、投放、经营及相关权利人的地区。不要把剧本语种等同于发行国家。
- 同时记录已核查和未覆盖的法域。下方来源不覆盖全球、全美各州或所有欧盟成员。每次作具体法律判断时检索当地最新官方规则和适用例外，不把本页查阅日期当永久有效结论。
- 用户选择全球发行后不反复追问同一范围；先核对来源、授权及使用事实。尚未完成逐地法律审核不妨碍独立原创资产制作和内部审阅，但不得写成“全球可商用已通过”。明确权利争议或关键授权缺失的具体资产按下表处理。

## 先查事实，再看成图

1. **来源及生成链路：** 核对实际输入图片、提示词、引用关系和本次成图。区分自主文字设计、用户自有素材、有授权的真人素材、来源不明图片、明确借用特定真人的素材。用户上传、图片公开可见、AI生成、已装进技能包，都不等于已取得肖像或素材使用授权。没有凭据时记录未知，不推定合法或侵权。
2. **授权及范围：** 存在真人形象使用线索时，查已提供的同意或授权，确认授权方有相应权限，以及是否覆盖本次 AI 合成／改编、短剧、宣传投放、媒介、期限、地域及必要的转授权。核对全球发行是否超出地域限制。照片／素材著作权许可与被摄者形象许可分开记录，不可相互替代。已有材料能确认的内容不重复询问，缺项集中一次说明。
3. **具体真人指向：** 依据用户提供的身份说明、来源元数据、生成指令、角色与宣传文案、权利人通知等非人脸识别证据，判断是否存在借用特定真人、冒充本人或暗示代言的线索。可检查图中姓名、签名及上下文，但不凭面孔识别姓名，不进行名人人脸检索、身份匹配或相似度评分。仅凭图片无法确认真人指向时记“未能确认”，不能反推“无侵权”。
4. **使用语境：** 区分内部审阅、虚构短剧正文、封面海报、付费广告、商品代言等实际用途；查看是否把真人指向与虚假经历、负面剧情或代言关系绑定。只审查已提供材料，缺少宣传稿时不能声称已检查。商业媒介不自动等于侵权，艺术表达也不自动免责，具体例外按当地规则另核。
5. **成图与设计：** 实际查看每张人物图，继续执行 [原创设计检查](character-originality.md) 和 [年龄范围](visual-specs.md#人物年龄范围)，核对可见特征、文字及原创设计是否落实。这不提供身份识别；原创检查通过、换发型、换年龄、换服装或标注“AI生成”均不能单独证明不侵权。

## 每项结论及处理

以下是本技能的制作风险分类，不是法院判定标准；法律认定须结合适用法域和具体事实。

| 初筛结论 | 事实依据 | 下一步 |
| --- | --- | --- |
| 高风险 | 已有明确借用特定真人、冒充／代言、超范围使用或权利人异议的证据，相关授权或适用例外未获支持 | 暂不用于商业发布；保留记录，取消该候选的本次成品交付，选择有依据的授权方案或独立原创替代设计；争议交当地律师复核 |
| 资料不足，待核验 | 输入涉及真人素材或借用线索，但来源、许可、用途或权利范围缺少关键资料 | 指明缺项及影响，不假定已授权；暂停把该版本作为已审核成品交付，继续其它资产或不依赖该素材的原创设计 |
| 目前未见明确风险 | 已核对的来源、生成记录、许可及使用语境未发现明确问题 | 可继续制作并交付初筛结论，同时写清已核资料、未覆盖法域及判断局限；不得承诺全球不侵权 |

不能用“与名人相似度低于 70%”判定安全。本技能不计算该类分数，下方所列规则也未给出通用的 70% 免责线。授权问题不能靠改几个五官或反复重生成自动解决。用户报告撞脸时先按反馈标记待核验，核查来源与用途并可返修，不自行确认图片就是所指真人。

## 接入现有资产流程

- 生成前在已有 `preflight.continuity`／`exclusions` 记录参考用途及已知授权限制；不把合同、路径或风险报告写入人物资产表，不新增表格列。
- 生成后记录“初筛结论；来源／授权依据；使用范围；已核法域与遗漏；下一步”。可验收项写入当前尝试的 `checked.note`，待处理项留在工作区内部审查记录中，不新增助手字段。区分用户陈述、已读取凭据、实际观察和法律推断，来源及查阅日期留在内部记录；敏感授权文件不外发。
- 高风险或关键资料不足时，不以 `approved=true` 记为审核通过，不调用 `finish_asset.py` 当作可交付成品归档；允许通过 `receive_asset.py` 先保存内部待审副本，明确标注待审核，保留内部源图并继续其它项。待审保存不表示通过本项审查或可发布。授权待核不冒记成图片质量失败，不自动消耗生成重试次数。已有文件不擅自删除或撤回外部发布。
- 视觉不合格沿用质量返修规则；改用独立原创面容后更新 state 及依赖图，再复核来源链路。法域覆盖不全须保留在结论中；技术上的 `approved` 不代表取得法律许可或全球商业发行批准。
- 收尾简述各人物的风险结论与未解决项；同来源、同授权和同用途的系列图片复用已核材料，仍逐张核对成图。用途、发行范围、授权期限或基准图改变时重查受影响项，不额外交付未要求的长篇法律报告。

| 法域示例 | 与本流程有关的规则 |
| --- | --- |
| 美国加利福尼亚州 | 《民法典》3344 涉及未经同意在商品或广告等情形使用他人姓名、照片或形象，并含可识别性及例外规则；不能直接套用于全美各州。[官方条文](https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=CIV&sectionNum=3344.) |
| 西班牙 | Ley Orgánica 1/1982 第 2、7、8 条涉及同意、形象使用及例外；广告／商业使用须结合保护范围审查。[BOE 法规入口](https://www.boe.es/buscar/act.php?id=BOE-A-1982-11196) |
| 葡萄牙 | 《民法典》第 79 条规定肖像展示、复制及商业使用的同意原则，并设例外和名誉保护限制。[官方法规入口](https://diariodarepublica.pt/dr/legislacao-consolidada/decreto-lei/1966-34509075-49761975) |

其余国家／地区及相关隐私、数据保护、诽谤、数字替身、未成年人或死者形象等问题，按具体素材与发行情况扩展核查；未查到的内容列为未覆盖，不虚构全球完成清单。
