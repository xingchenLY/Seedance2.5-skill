# 人物形象与服装组合库

文字库分为 [人物形象库 A](character-appearance-library.md)（33 套）和 [服装库 C](character-clothing-library.md)（31 套），按形象特点和服装风格分别分类，允许跨原题材自由组合。另保留 [M04 巨龙](character-genres/epic-creature.md)。仅保存文字，无旧参考图片；[旧 M 编号索引](character-material-index.md) 用于溯源，不再是一套脸加一套衣服的固定搭配。

## 根据剧本独立组合

1. 从正文确定角色身份、物种、地域、时代、年龄阶段、体型和出场场合。按 [地区选角](character-casting.md) 固定创作设定；年龄沿用原映射，不能由库中“成年”代替具体年龄。
2. 从 A 库选择一套面貌／妆发基础，结合剧本气质调整可见特征。职业、正反派或社会地位不决定固定脸型；不同角色使用相同 A 时仍须按 [角色区分](character-distinction.md) 独立设计至少两组面部结构差异。男女主优先贴近原参考文字的整体审美，不复制整张脸。
3. 独立从 C 库选择衣服，正文合适衣服优先，不要求与 A 同号或同题材。按 [服装规则](character-wardrobe.md) 确定主要常服与必要场合服；没有合适模板就按同样字段新设计，不为了用库强换剧情衣着。
4. 组合前检查地域与时代、实际身份和活动、年龄、身体轮廓、物种及动作条件。现代脸型／发型方向可适配古装，但现代腕表、拉链牛仔、领带等须与世界观相符；尖耳、鱼尾、膜翼不能作为普通衣服移植。保留正文体型，服装调整裁剪适配身体，不为适配衣服把人物改瘦。国内／海外及拟人动物使用各自现行规则。
5. 一个角色固定 A 的最终面部设计，可根据真实场次搭配多个 C。换装和状态用自己的已审核基准图，保持同一面容；不同角色可用相同 C，但不能长成同一人。不将 A×C 的所有排列生成资产，只建立剧本和用户范围需要的组合。
6. 在现有 preflight.continuity 记录“形象来源 A 编号＋角色化后的五官／妆发＋服装来源 C 编号＋本剧调整”，body_basis 区分正文和美术补充。旧 M 仅为溯源，不新增请求字段、表格列或共享 state 字段；完整描述写回原提示词列、plan/state，表格修改覆盖原路径。
7. 最终提示词顺序为：地域选角与最终年龄 → 本角色面貌／身体／妆发 → 本场完整服装与必要状态 → 当前视图规格 → 原创及角色区分约束。工具收到展开后的完整文字，不能只发送 A/C 编号、“同上”或未填占位符；模板和冲突句只保留适用的一份。
8. 成图同时核对人物面貌、跨角色差异、衣服适配及同角色连续性，通过后才归档和用于派生。拆库不触发重生旧图、不改变默认只出表格、图片选择、三视图不入表、并发或存储流程。

## 组合示例

- A07 的纤长脸与松散短卷发，可配 C09 三件套作为正式商务造型，也可配 C07 针织常服；剧情、体型和角色区分检查通过后使用，服装不改变面容。
- A20 的长椭圆脸与侧分波浪发，可配 C23 婚礼服或 C20 都市通勤装；是否有婚礼服由正文场合决定，不为展示模板自动新增。
- A26 的雀斑与浅金侧辫可配 C27 日常花卉牛仔，也可配 C26 田园棉麻；时代不符时调整发饰与衣服，原题材不绑定面孔。

旧题材目录只保留 A/C 来源导航；运行时按上述两库选择，避免再次读取整套混合造型。
