# 道具去重与出图对照校验

国内／海外、真人／拟人动物，以及 Codex／剧梦网页／CLI 共用。生成前核对是否重复建档，图片返回后实际核对是否误用同一造型或状态；同一道具的必要版本仍保持同一物件。仅表格／提示词任务执行文字去重与设计，不因此出图，不声称已做图像检查。

## 先判断是不是同一件物品

- 根据正文用途、所属与流转、出现场次和外观证据归一道具别名。同一物件被转交、借用、偷取或跨集出现，不因为持有人、名称或场次变化就生成另一件；不能只按“某人的手机”判断是新手机。不同物件也不能仅因同名就合并。
- 相同物件、相同必要状态、相同输出要求已有合格资产时复用其记录，合并场次与别名，不重复建表、生成、下载或平台入库。发现表格重复先修正文索引及原表，保留来源映射；已在途或结果不明的任务先对账，不重复提交，也不直接删除原图或历史记录。数据重复不记成图像质量失败，不靠重生解决。
- 开／合、完整／破损、空／装有内容等剧情确需的状态保留为同一物件的不同版本；手机正背面仍是一张双视图资产。状态、视图和独立物件不能互相混作去重依据。用户明确数量、不同候选或多件组合时保留授权范围，不因同名擅自减少张数；相同图片不能冒充用户要求的不同候选。
- 两件不同道具需要可辨区分时，设计适合剧情的轮廓、关键结构、材质分区、纹样或使用痕迹，写出具体可见差异，不只换名字、背景、角度或光线。正文明确的同款、成套、标准件或外观相同的仿制品按剧情保留，记录“有依据的同款／相似”，不为了去重擅改关键结构、添加编号或破坏情节；两件物品的身份记录仍分别保留。
- 在现有 `preflight.body_basis` 记录物件归属／流转及状态依据，`continuity` 写固定结构、需要变化的部分、易混淆道具的区分点和参考用途。尺寸和外观未写明的补充属于美术设计；文字／标识按 [文字分类规则](prop-text.md) 确定可读内容与局部处理字段，海外不得出现中文。文字差别可用于剧情身份／版本对照，但不能在需要结构区别时仅换标签冒充不同造型。场景布景用品不因此自动变成独立道具任务。

## 成图后逐项核对

1. 先按原流程落盘待审，再实际打开当前成图。对照自己的设计和适用基准图，检查完整边界、轮廓、结构、材质、比例、配件及状态；再与项目内同类、容易混淆且已有可用图片的其它道具比较。首件没有其它成图时如实记录，后续新增相关道具补齐对照。
2. 需要区分的不同物件出现相同主体造型、套用了另一物件，或仅靠镜像、裁切、视角、背景／光线改变来冒充差异，不通过。仅名称、文件路径或文件哈希不同不能证明是不同造型；同款剧情例外按已记录依据检查，不把合理连续性判为重复。
3. 同一物件的派生状态应保留结构不变量：例如手机的机身及壳体、戒指的戒托与宝石结构、容器的造型与连接关系；只改变正文要求的状态。破损版仍完好、开盖版仍闭合等预定变化未落实时不通过；为制造差异而改变整件物品身份也不通过。
4. 手机及其它明确启用的多视图／不可分组合逐视图、逐必要部件检查。手机左正右背不能是同一个正面或镜像重复，两个视图必须属于同一机身和壳体，尺寸、开孔和按键按真实翻转对应。不可分组合不得缺失关键部件，也不能把应不同的部件错误复制；不把本规则扩展为所有道具都自动生成多视图。
5. 必要辨识部位被反光、阴影、裁切、模糊或遮挡到无法核验时，不批准；调整显示方式后重查，不能把“看不清”当“没有重复”。本项与原有材质、无品牌、文字和几何审核在同次查看中完成，不另加一轮全量审图。

## 失败与恢复

在现有 `checked.note` 记录本物件／状态、实际对照资产及基准版本、可见区分点、应保留结构与状态变化的结论。详细清单放工作区，不增加资产表列、请求字段或共享 state 不支持的字段。

| 实际问题 | checked 的 code |
| --- | --- |
| 需要区分的不同道具误用同一造型或重复图 | prop_not_distinct |
| 同一物件派生图改变了固定结构或变成另一物件 | prop_identity_mismatch |
| 所需开合、内容物或损坏等状态没有落实 | prop_state_mismatch |
| 正背面重复、视图不一致或组合部件错误 | prop_view_mismatch |
| 必要部位不可辨，无法完成核验 | prop_details_uncheckable |

- 不合格以 `approved=false` 记录实际原因，多个问题合并到同一尝试，不按部件或视图重复累加质量失败。首次加最多 5 次返修；到上限暂停该项，继续其它独立项。未通过只保留待审，不正式归档、平台入库或解锁派生。
- 按 [返修方式](repair-policy.md) 判断：主体造型、身份或正背面结构等严重错误须调整完整提示词重新生成，不引用问题图；基础正确的孤立局部缺陷才可局部修改。保留正确设计要求，更新完整提示词及原表路径。返修图重新查看整件物品及所有必要视图，确认没有引入新错误。下载／保存失败仍只恢复对应操作，不触发生图返修。
- 并发审核把道具基准资产 ID、attempt、文件哈希、设计版本和对照范围记在已有工作区编排记录。批准前若新增或更换了相关易混淆道具基准，只补查这些变化；生成队列仍继续，不等待全部道具完成才检查。文件与设计未变的已有对照可复用，收尾只补遗漏，不反复下载或全项目重查。
- 文件哈希用于校验文件与复用记录，不等于道具外观相似度。保存脚本不会自动判断重复造型；必须由实际查看图片的审核者给出结论，不虚构相似度百分比或自动识别结果。
