# 站位与视频穿帮校验

`站位与视频穿帮校验`默认关闭，统一控制关联前段、独立分镜和链末段。关闭时全部跳过主动视觉、穿帮及衔接验收，不生成检查联系表，不因未检查或缺少视觉能力阻塞关联后段；不能换名保留“最低限度衔接验收”、首尾帧对照或局部抽查。用户可以关闭关联前段的这项检查，不能以本技能规则拒绝。具体关闭与旧记录更新按[主技能第4节](../SKILL.md#4-关联分镜顺序生成与站位复用)。开启时按本文件检查全部成片，并在本次已授权范围内执行定向修复及限额内重生成；用户仍明确保留的单独视觉检查只执行指定范围。

关联后段仍须等待全部直接前置的当前选用版本生成完成、归档，并通过文件及实际参数校验，所需站位／音色依据就绪。关闭时记录“文件与参数通过，全段视觉检查按设置跳过”，不能记“视觉通过”。以下全段检查方法仅在开启开关或用户明确要求全段检查时适用；按需取站位帧、核实音色区间或复核已知问题，只查看对应必要范围，不扩大为全片扫描。关闭开关不清除技术待核、素材缺项及已知未解决的实质问题。单独检查或发现问题均不自动授权追加付费重生成、恢复停止任务。

## 检查依据与方法

- 核对集号、分镜、实际选用版本、完整提示词及相邻已通过的成片。剧本决定事件，正确场景图决定已展示空间，已通过成片约束衔接状态；错误参考不能反过来成为正确标准。
- 优先复用[本地检查工具](performance.md#本地技术检查)输出的全时长分页联系表定位镜头和变化，再检查每个镜头、切点及关键动作，不重复生成相同版本初筛图。每秒1帧只作初筛，不能证明两帧之间无穿帮；视觉结论复用还须提示词、前置版本和验收要求均未变。
- 出入门、转身、交接、落座、人物走位、持物变更及疑点处，查看实际可见的动作和切点两侧；切镜允许省略有动作依据的中间过程，不要求每次移动都完整入镜。可加密至每0.25–0.5秒一帧，必要时播放对应视频；结合切前动作仍无法确定衔接关系时标为待核，不写“检查通过”。
- 联系表可能缩小、裁边、相邻格错认。判断复制人、额外肢体或穿模前，打开原始单帧和相邻帧复核，不把两格中的同一人误当同框重复，也不把合法镜面反射当复制人。
- 检查覆盖开场、段内转场和结尾，以及已生成前段的结尾到本段开场。后段尚未生成时，不把它的开场画面对照作为前段放行条件；这段实际衔接在后段成片后检查。**片尾站位正确不能替代整段动作和空间检查。** 说明真实检查方式，不把抽帧说成逐帧播放或完整音画验收。

## 有动作承接的切镜站位变化

- 前面成片已有对应的转身、起身、走向目标、出入场或其他动作铺垫，切后站位合理承接其目标与方向、人物及关键动作关系仍成立时，属于正常剪辑，不算穿帮。适用于段内切镜和跨分镜剪接；不要求完整展示被剪辑省略的每一步走位，也不要求切后位置等同切前最后一帧。
- 判断依据是切前实际画面中的动作及切后状态；提示词只能辅助理解，不能用未在成片建立的动作补造衔接。换机位造成的画面左右、远近变化也不自动等于人物实际互换，应结合固定场景参照和动作方向判断。
- 例如前镜人物已起身走向门口，切到后镜人物位于门边或门外，且出入方向及剧情关系一致，可以通过，不因省略部分行走判为瞬移。无动作依据、无法由合理剪辑解释的换位，或与已建立动作方向、人物关系冲突时，才按实质问题检查；仅发生切镜不能豁免这些矛盾。
- 记录切前动作、切后站位和承接理由，其余必要检查通过后正常放行，不为此重生成、追问或阻塞后段。站位参考采用切后已确认的实际状态，不继续沿用已不适用的切前旧图。先前仅因这类合理变化受阻的结果可复核解除阻塞，已有费用和次数照实保留。

## 严重程度判定与放行

按剧情、关键动作和前后衔接的影响判断严重程度，不按道具体积或单帧视觉差异大小判断。本节用于成片验收，不免除生成前人物素材、可选素材本地查找、文件及实际参数检查。

| 类型 | 判断与示例 | 处理 |
| --- | --- | --- |
| 轻微道具瑕疵 | 杯子花纹、普通装饰细节或背景小摆件轻微偏移等；不改变剧情信息、关键动作、持物归属、关键道具数量／状态或后续衔接。 | 记录时间点、瑕疵和放行理由；其余必要检查通过后，记“通过，含已放行轻微道具瑕疵”。不为此重生成、增加修复额度询问或暂停关联后段。 |
| 重大站位／空间错误 | 无对应动作依据且无法由合理剪辑或机位转换解释的人物瞬移／换位，或门内外颠倒、出门变进门、人物分组错位、朝向／通行路径矛盾，导致动作或人物关系不成立；先排除上节允许的动作承接。 | 必须定位并修订站位、机位、出入方向、动作过程或错误参考；按主技能已有授权、预算和次数执行修复，重新检查通过后才验收并放行关联后段。不能仅改文字就把未修正成片记为通过。 |
| 其他实质错误 | 关键证物或手机消失、交接归属错误、关键道具数量／状态变化，以及身份替换、明显复制人等；即使道具体积小也影响剧情。 | 不适用轻微道具放行，按原有实质问题修复流程处理。 |
| 影响待核 | 尚不能确认差异是否改变关键动作、站位或衔接。 | 结合原始帧、相邻镜头和实际动作复核；仍无法确认时记待核，不凭“小道具”直接放行。 |

只有轻微道具瑕疵时，开启穿帮校验也不自动重做。先前仅因此阻塞的成片，经核对满足轻微条件且其余必要检查通过后，可以撤销该阻塞；已发生的费用与次数仍如实保留。重大站位问题即使在校验关闭时被发现，也须进入修订流程；未获修复生成授权时按主技能准备具体方案，不擅自追加生成或把错误成片放行。

## 必须核对的关系

| 方面 | 判断内容 |
| --- | --- |
| 人物站位 | 人数、身份、相对位置、前后距离、身体朝向、视线与家长／孩子等分组有连续依据；转身和走位可由切前动作与切后状态合理承接，不要求全过程可见或切前切后位置不变。 |
| 出入空间 | 角色起点、终点、门槛内外、摄影机所在一侧及移动方向有连贯依据。有出门动作铺垫可切到门外；无剧情或动作依据的出入方向反转、空间矛盾仍须处理。 |
| 动作与道具 | 牵手、持物人、左右手、物体数量、交接前后归属、门扇开合、落座与起身有连续依据。 |
| 场景连续性 | 门窗和固定陈设位置、场景日夜、光向、段内空间转换与场景图和剧情一致；换机位不是搬动实体。 |
| 生成异常 | 明显复制／消失人物、身份替换、额外肢体、穿模或物体突变；区分特写裁切、正常遮挡及原文允许的离场。 |

不是每一镜都要看见所有在场人物。单帧缺人可能只是画框外或遮挡；用前后镜头判断场内关系。无法确认完整站位的帧不能单独作为全员站位依据，但不因此自动判整段穿帮。

## 剧情内文字不触发拦截或重生成

- 按[主技能的剧情内文字规则](../SKILL.md#剧情内文字默认放行)，剧情需要的道具文字和屏幕界面直接放行；有字、文字可辨识、纸面或来电界面未遮挡均不作为穿帮、待核或询问事项，不据此修改成片、追加生成或消耗修复额度。
- 旧提示词含“无任何文字／无 UI”时按主技能明确剧情例外，不将模板限制作为扣费修复依据。若先前仅因此阻塞，记录放行依据，在其余必要检查通过后继续；即使此前已达到修复上限，也不再为这类文字询问增加次数或重做。已提交的任务不擅自取消或重复提交，待结果返回后按调整后的范围检查。
- 人物站位、出入门、持物及其他实质剧情连续性错误继续按本文件处理，不能用文字豁免跳过这些检查。

## 有效站位图与复用

1. 优先用接近衔接点、与下一段状态相符的真实帧。片尾是特写时可用较早同框；需要两张参考时各自明确用途。
2. 检查朝向、持物、关系与动作阶段后保存，记录真实源视频版本及时间点；不补画，不用无关空间或错误帧。
3. 前段生成或当前设置要求的检查期间可预填后段和整理候选站位图，禁止提交关联后段。前段当前选用版本完成必需检查后，可确认旧图仍适用并复用；关闭时不以全段视觉检查作为条件，只核对实际采用的帧及判断其适用性所需的局部范围。省略重复取帧不免除生成、归档和文件／参数检查的等待。前段改变后段初态使旧图无效时，选取可靠新状态图；有动作承接的正常切镜站位变化也按切后实际状态更新，不为维持旧图而重做视频。
4. 人物站位或关键动作关系错误的图立即停用，并检查未提交后段是否继承了这张图；只有已放行的轻微道具瑕疵、站位及关键关系仍正确时，不因此停用有效参考。新版本取代旧图时核对实际缩略图／版本，必要时上传可区分的新版本名称，不能只覆盖本地同名文件后就认为平台旧图也更新了。
5. 前段后来被判有影响衔接的穿帮或选用版本变化时，按下一节处理未提交、生成中和已完成后段；不只更新尚未提交的分镜。无关且仍正确的段落保留。

## 后段依赖失效与重新验收

- 每次提交前，记录后段采用的源图／视频版本、实际时间点、全部直接前置及其当前版本在当前设置下的检查依据；关闭时如实记录全段视觉已跳过，不能仅因缺少视觉通过记录阻塞。本节处理前段已通过后又改版、恢复旧任务时发现过早提交，或历史后段已完成等情况，不授权新的关联分镜并行提交。
- 前段出现影响衔接的问题或改选新版本时，沿已记录依赖标记受影响后段待复核。未提交的依赖段暂停提交；生成中的任务不擅自取消或重复提交，待实际结果返回。已完成的视频保留原文件和版本记录，暂停作为最终验收成片交付。
- 前段修复并按当前设置重新完成检查、选定可用版本后，才可放行尚未提交的关联后段。对历史已生成后段，开启校验时对照前段实际结尾、后段实际开场及受影响的动作、人物、道具和空间关系重新验收；关闭时只更新版本与素材依据、核对实际使用的站位参考及已知问题影响范围，不因改版主动检查全片。旧图仍适用且没有已知未解决的实质问题时保留后段，只更新实际完成的检查记录，不因源版本号变化就重生成。确无关联依赖的后续段落通过自身预检后可直接生成，无须等待这条关联链修复或重新验收；只暂停受影响的依赖段。
- 确认后段有需修正的实质衔接错误时，记录时间点、证据及具体修订；仅有符合上表的轻微道具瑕疵时记录放行，不触发后段重做。开启校验且后段属于本次已授权生成范围时，可在后段自己的剩余上限及用户预算内修复；因上游改版触发的重生成与后段自身穿帮修复共用同一累计次数，不重置、不借用前段额度。超限、未授权历史成片或用户停止时不提交，保留待处理状态。单独检查请求仍不构成重生成授权。
- 每次后段修复按主技能第5节复查，人物素材未齐备仍不得生成。修复后按当前设置检查：开启时检查全段及新的衔接，关闭时完成文件／参数检查并核实已知错误及受影响的衔接范围，不扩展为全段视觉检查；用户单独要求的范围照常执行。若又发现影响更后段的问题，按相同规则传递待复核状态。上游必需检查仍未通过时，依赖链不能提前宣布全部验收完成。

## 定位、修订、重生成

1. 先排除有动作承接的正常切镜站位变化，按严重程度放行轻微道具瑕疵、排除剧情内文字豁免，再记录需修正的实质穿帮时间区间、画面、正确关系和证据帧。区分提示词歧义、错误素材引用和模型执行偏差，不凭感觉反复增添泛化负面词。
2. 在原稿中修正必要字段。例如出梯反转，应写清摄影机固定在轿厢内后侧、人物先转向门口，再以背影远离摄影机跨门槛进入大堂；同时保留台词及现场声音连续。不能只写“不要穿帮”，也不能直接删除出梯事件。
3. 有前文导演调用时按[导演技能衔接](director-handoff.md)用同一技能修订。没有时，只修复已有提示词内的机位、朝向和连续动作；缺少整段提示词仍须提示用户。
4. 保存修订版，核对原台词、发声顺序、身份、剧情、场景名称和时长未被误改；调整错误图／引用并确认平台正文回显。再执行主技能第5节完整预检。
5. 开启校验且在本次授权生成范围内，直接提交修复重生成，简短报告问题、改动、参数、可见费用及当前次数，不再次要求批准同一范围。未授权历史成片、变更剧情或超出用户预算仍需相应授权。
6. 新结果始终完成文件及实际参数检查；开启校验时重新检查全段及原错误区间，注意修复时引入的新问题。关闭时如已另获定向修复授权，只核实原错误及受影响的衔接范围，不默认扩大为全段视觉检查；用户另有明确检查范围则遵从。必需检查完成且已知实质错误解决后，才把新结果作为选用视频或新的衔接参考，并放行下一关联分镜；即使仍用旧有效图也须等待。历史已提交／已完成后段按依赖规则处理。旧版保留备份／历史，不永久删除。

## 次数、停止与结论

- 默认每个分镜最多自动追加2次穿帮修复生成。计数包含换提示词、换站位图及上游改版导致该分镜重做等修复尝试，断点恢复不清零；确认平台接受的修复尝试即计数，失败不返还次数，也不因此自动重试。提交状态不明时保留待核尝试和预算预留，查清历史再决定，不重复提交。用户给更低上限或预算时遵从；上限0只检查与准备修订。
- 达到上限仍有实质问题，停止该分镜及受其影响的后段，给出准确问题、最新修订和已用次数，再询问增加次数或调整方案。可以继续不依赖它的已授权工作。
- 生成失败、被取消、用户停止、账户／权限问题不属于“成功成片有穿帮”，不能用此自动重做规则绕过主技能停止要求。
- 风格不够喜欢、非关键微小表演差异不自动判为需扣费重生成的穿帮；聚焦人物、动作、空间及剧情连续性的可见错误。
- 交付写清检查范围、方式、已放行的轻微道具瑕疵及理由、实质问题的修复结果和未解决项；已放行瑕疵不再列为阻塞或待修复。未听检时不宣称对白、背景音乐或口型同步已经验收。
