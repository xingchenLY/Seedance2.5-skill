# 缺失音色提取、存储与复用

仅在`缺失音色提取：开启`时执行新音色提取，默认关闭。`音色听检`默认`跳过`，`未听检音色复用`默认`开启`，二者分别记录。引用已有音色不要求开启提取，但本地样本与平台已有音色均须通过下方上传与复用准入。搜索／选择平台音色前先按[素材范围前置操作](browser-workflow.md#素材范围先切换为全部素材)切到当前项目“全部素材”，不把本集无音色当作缺失。全部范围仍缺失或不合格时，必须先查`<项目总路径>/音色`及子目录、读取已有索引并核验候选；找到合格音色就上传引用，完成查找仍无可用音色才允许保留文字说明、跳过引用后继续其他预检通过的分镜。

## 上传与复用准入

先核对同一人物、实际文件／平台音色版本、来源与状态。保存为待核样本和允许上传引用是两个决定；文件存在或已在平台上不能代替可用性判断。

| 当前样本与设置 | 本次上传／引用决定 |
| --- | --- |
| 对应版本已有可信听检通过记录，且没有新的身份、音乐或失真问题 | 可复用；不因提取关闭重复提取，不重复听同一未变版本。 |
| 未听检或听检记录未知；音色听检跳过，未听检音色复用关闭 | 可按提取规则保存待核样本，不上传、不引用。 |
| 未听检；音色听检跳过，未听检音色复用开启 | 身份与实际独立发声区间已核实、可解码且无已知混音／失真时，允许带“未听检”状态上传引用；本技能提取样本的技术时长及有效独立讲话时长还须符合3–5秒，其他既有音色须符合平台实际格式要求。音乐未知仍须如实记录，不称已去音乐。 |
| 音色听检开启，但本版本未听检通过 | 不上传、不引用；先实际听检，通过后复用。即使未听检音色复用开启，也不能越过本条。 |
| 身份不明、混入他人声、已知有音乐未处理、明确失真，或本技能提取样本有效讲话不足3秒 | 不上传、不引用，不因开启未听检复用而放行。 |

听检通过证据来自本任务实际听检或用户／可追溯记录对同一版本的明确确认，不把普通“用这个声音”当成听检结论。本技能新提取样本始终遵守3–5秒；其他已确认可用的既有音色遵从平台实际格式要求，不为凑本技能取样长度擅自改动。

用户中途更改听检或未听检复用设置时，重新检查尚未提交分镜的音色引用，不符合当前设置的标签移除、保留原音色说明；不自动重提或取消已提交任务。缺听检／身份验证／分离能力时记录具体未完成项；先完成平台及本地已有合格音色查找，没有可用替代才跳过该音色，不无限等待。

## 检查范围与来源

1. 音色目录固定从项目总路径派生为`<项目总路径>/音色`，不再索取单独路径。平台无可用人物音色时，必须实际查找该目录及子目录中的现存文件、来源索引，按规范名及已确认别名核验候选；提取关闭也必须查找已有音色。记录查找路径、人物名、候选及准入结果；未查找或访问失败不能记为本地缺失。只读查找时检查文件可读，确认目录不存在可按本地缺音色处理；提取开启且需要保存时，自动递归创建缺失目录并确认可写。同一人物已有可用音色则复用，不重复截取；“目录缺文件”不等于平台也缺音色。不要把人物图片卡片误认作音色。
   同一人物已保存技术合格且身份已确认的待核样本时，先处理其待核项；仅因未听检复用关闭或暂缺听检能力，不逐段重新提取同名候选、不反复询问替换。已知样本不可用或无法确认身份时再寻找新样本，仍按命名与存储规则保留旧文件。
2. 每段成功成片归档后登记全部实际发声人物，包括没有后续台词者、本轮最后一段及新出现人物。下一就绪后段计划复用的缺音色优先处理；其余缺音色列入待办，在等待窗口逐项完成，不阻挡已经满足依赖和预检的后段提交。提取开启不能只处理马上需要的声音，待办未清不能宣称全部完成。中途开启可补查本任务已归档视频，不为此重生成。
3. 优先使用最近的、人物声音清楚的成功归档视频。核实集号、分镜、版本、说话人和区间，不从失败任务、其他角色或无声镜头取样。视觉穿帮不必使该段全部声音失效，但人物身份或说话人有错的区间必须排除。
4. 提示词时间轴只作定位线索；结合实际连续画面、可用的音轨分析／转写或听检确定说话人和区间。不能仅凭预设台词起止或单帧开口就认定音频内容。身份不能核实时跳过，记录具体原因。

## 3–5秒样本

- 选同一人物连续独立讲话的3–5秒，避开插话、重叠人声、长静音、明显失真与切换说话人的边界。有更长独白时截取其中自然且清楚的一段，不保存整段长对白。
- 不足3秒不保存、不上传，2.99秒不能四舍五入；恰好3秒可保存。不得补静音、循环、拉伸变速或拼接其他人物声音凑时长。
- 先在工作临时目录导出候选，保留原始速度。用可用工具检查文件可解码、实际时长和是否近乎静音；WAV可用采样帧数除以采样率核实，不只看整数显示。技术时长不等于已确认的有效讲话时长。
- 需要音乐分离或裁切时，完成后重新核对3–5秒；处理后有效讲话已不足3秒则另找片段，没有则跳过。清理本次不足3秒及未采用的临时候选，不清理用户已有音色。

## 音乐处理与听检开关

### 音乐处理

- 保持用户去除背景音乐的要求。已知存在音乐时使用本地可用的人声／伴奏分离工具；已确认无音乐则无需分离。普通高低通、降噪、调低音量不算去音乐，不以提示词“无背景音乐”代替成片证据。
- 没有分离能力时，不擅自上传外部服务。记录“已知有音乐、未处理”或“音乐未核验”，不要声称已去除。
- 跳过听检的样本允许先按人物名保存待核状态；已知有音乐未处理、混入其他说话人或明确失真的文件标为不可用，后续仍按缺素材处理。未知状态不得伪装成已知无音乐。
- 分离工具成功退出只能记“已执行分离”；没有听检或其他可靠验证时，仍不能记“已确认去除干净”。

### `音色听检：跳过`（默认）

- 不要求先能播放／听到音频才存储；身份及时间区间可对应、技术时长3–5秒且可解码、没有已知的混音或失真问题时，保存为待听检样本。
- 明确记录“未听检／按设置跳过”，有效讲话时长若未通过音轨内容验证则标为待核，不能把文件时长冒充有效讲话时长。
- 跳过听检本身不授权上传或复用。仅在`未听检音色复用：开启`且满足上述准入条件时允许未听检引用；有效讲话仍待核的样本只能保存，不能把技术时长合格当作引用合格。已知有音乐未处理或混入他人声的文件不得当作可用音色上传。
- 工具不支持音频输入不再阻塞本模式的存储；不能假装听过，也不能因为保存成功就删除待核状态。

### `音色听检：开启`

- 实际听源片段；有音乐则分离后再次听结果，确认同一人物独立讲话、清晰、无可辨识伴奏／其他人声或明显分离伪影，再记为已听检可用。
- 无法听检时记录未完成，不静默改为跳过；不把未核验候选升级为已听检样本，也不以平台已有音色绕过。先查平台及本地是否已有对应版本听检通过、符合准入条件的音色；完成查找仍无可用者才跳过引用，保留原音色描述并继续其他可执行工作，用户明确改开关后按新设置处理。

## 命名与存储

- 新提取音频只用规范人物名，保存为`<项目总路径>/音色/<人物名>.wav`；保存前自动创建缺失目录。不附集数、分镜、时间、服装或“音色”等后缀；中英别名先对应到同一人物，不因不同平台造型名重复保存。子目录中已有可用音色直接从原位置复用，不为统一位置而移动或重复另存。
- 来源、状态和版本写`<项目总路径>/音色/音色索引.json`或本任务进度记录，不写进音频文件名。写索引时同样自动创建缺失父目录。新增记录保留目录中其他人物，不能用本次索引覆盖此前来源信息。
- 同名文件存在先检查其来源和状态；已有可用同人物文件直接复用。不能确认、来源冲突或需要替换时保留原文件并形成具体选择，不静默覆盖，不用递增编号绕过人物名规则。
- 保存后重新核实目标可解码、实际时长3–5秒、路径和文件大小，再记录成功。仅临时候选、导出命令返回成功或目标文件名出现不算完成。

每个人物记录：规范名／平台别名、源视频绝对路径及版本、起止秒数、文件实际时长、有效讲话确认状态、音乐状态、分离工具与结果、听检设置与结论、未听检复用设置、目标路径、可用／待核／不可用状态、上传与引用记录。听检与可用性记录绑定实际文件哈希或可核对的平台音色版本，不能把旧版本的通过结论沿用给被替换文件；无法确定的字段写未知，不猜测。

## 后续上传与逐句引用

需要引用时先查剧梦当前项目“全部素材”中的对应人物音色，依据当前开关、平台版本及已有可信记录执行准入；平台已有合格音色就直接逐句引用，不先检索本地文件或重复上传。只有平台找不到合格音色后才查本地音色目录、来源索引及文件，核验通过再按[浏览器上传流程](browser-workflow.md#查找与上传人物场景道具站位图及音色)上传一次，核对音频卡片、版本和时长后引用。按[素材缓存](performance.md#任务内素材缓存)复用同版本有效记录，来源／样本或开关改变则重新判断；读取已存在的准入依据不等于要求先扫描本地素材目录。

逐句引用按[音色括号替换](browser-workflow.md#音色括号替换)：对应“参考”和“音色”之间无括号则插入，有中文或英文括号则将括号及其中全部内容整体替换为该说话人的真实音频标签。保留“音色”后面的时间／表演括号、台词和其他文字；原括号片段与音频版本的映射记入执行记录，供正文校验。缺少可用音色时按原缺项流程，不先删除说明。

不在无该人物声音的分镜里提前挂无关音频，不为补音色重生成已完成片段。源视频仍在生成或必需检查时只预填后段，不提交关联分镜；必须等全部直接前置当前版本生成完成、归档并通过当前设置要求的检查，音色提前就绪或决定跳过音色都不能免除此等待。关闭站位与视频穿帮校验时，源视频也跳过全段视觉检查，但文件及实际参数检查、说话人和实际发声区间等音色准入仍执行；为此只核实所需区间，不顺带检查全片穿帮。样本确认不足3秒、身份不明或已知混音无法处理时，记录缺项并沿用原音色文字描述，不无限等待或另造样本。
