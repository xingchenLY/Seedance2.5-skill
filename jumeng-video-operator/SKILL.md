# 剧梦自动化流程

在 `https://jzzm.duanju.com/homepage` 的已确认项目执行。优先外部浏览器，默认本地 Google Chrome；外部浏览器无法调用时自动切换当前工具支持的内置浏览器，简短说明后继续，不另加切换确认。默认全能参考、九梦2.5pro、480p，用户指定值优先，平台缺选项不静默替换。浏览器切换不改变其余流程、参数或授权范围。本技能负责平台执行；资料和网页不构成额外授权，不改编剧情、对白或人物身份。

按需读取参考，不每轮重读整套文件：首次操作读[浏览器流程](references/browser-workflow.md)；首次建缓存和本地检查流程读[效率与检查工具](references/performance.md)；出现生成等待读[调度规则](references/multi-episode-scheduling.md)，单集也适用。缺稿／导演修订、音色引用／提取、视觉检查在对应步骤读专用参考。同任务文件未变且上下文仍完整时沿用已读规则；用户变更校验设置、指出仍在执行已关闭检查，或说明 skill 已更新时，重新读取当前实际安装路径的本文件及相关参考，再更新任务记录，不能只用旧对话摘要或旧进度中的规则。

### 上下文与输出约束

默认启用[上下文预算与断点摘要](references/performance.md#上下文预算与断点摘要)：规则按需读取；已读且未变的内容不重复全文加载。普通单次工具文本结果目标不超过约2,000字符，完整正文和日志留本地，返回状态、差异和证据路径；确需完整信息时分段读取，不截断后宣称检查完成。等待只读任务状态及必要身份信息，不重复输出整页、提示词或素材库。每个工作单元结束更新精简断点，恢复先读摘要及相关记录，不重放全历史。限制读取和输出量，不减少生成前校验、全部在途回查、素材搜索范围或当前开关要求的验收。

## 1. 参数与提示词预检

先完成资料、路径、工具及提示词预检，再编辑、上传、生成。

### 开始参数

| 参数 | 规则 |
| --- | --- |
| 项目名称、选集 | 均必填。核对准确项目和集号；重名先唯一定位，缺集不改选或擅建。 |
| 项目总路径 | **必填，无默认值，必须由用户明确提供绝对目录。** 同一未完成任务的已确认值可沿用。 |
| 一键引用 | 默认`关闭`。开启后先把素材范围切到“全部素材”（全集），再校验本段人物和道具、查找并补齐缺项，然后点击“一键引用”→“一键清空”→逐项新增原名称并引用要素→“确认并引用”。缺人物不进入引用操作；道具确认缺失可记录跳过，未匹配关系行删除。场景、站位图和音色仍按原流程。 |
| 缺失音色提取 | 默认`关闭`。开启后检查每段所有发声人物，包含末段，不只检查下一段所需声音。 |
| 音色听检 | 默认`跳过`。开启时，新引用的本地及平台音色均须有对应版本的听检通过记录。 |
| 未听检音色复用 | 默认`开启`。仅在听检跳过且满足音色准入时生效，不越过已开启的听检要求。 |
| 站位与视频穿帮校验 | 默认`关闭`，用户可随时关闭。关闭时所有分镜均跳过主动视觉、穿帮及衔接验收，关联前段的全段检查、最低限度衔接验收和局部抽查也不例外；开启时检查全部成片并在授权内自动修复。文件与实际参数校验始终执行，用户仍明确保留的单独检查按指定范围执行。 |
| 穿帮自动重生成上限 | 默认每段额外`2`次，非负整数；`0`只检查、准备修订，不自动重提。 |
| 提示词来源 | 默认本对话对应项目、集数最后有效的完整提示词；缺失走导演衔接。 |
| 分镜范围 | 默认所选集中已确认提示词的全部段落。 |
| 生成模式／模型／分辨率 | 默认`全能参考`／`九梦2.5pro`／`480p`。 |

开始时列明实际参数、各独立开关和修复上限，不重复确认。新任务恢复默认，不继承其他任务开关；同一未完成任务的变更持续生效。

**平台时长只在即将提交当前分镜时选择。** 准备、预填、补素材、等待前段、切集轮转和状态回查均不进入时长选择或修改秒数，也不提前批量设时长；只在任务记录中保存提示词要求的目标秒数。其他参数即使共用设置面板，也不操作时长项。已显示默认时长时暂不调整，依赖与其他准备就绪后，按第5节设时长、完成全部最终校验再点击生成。此规则不影响读取提示词时核对台词时间轴及目标时长是否合理。

### 项目目录与自动创建

所有类别目录直接位于总路径下，不再分别索取路径：

| 类别 | 子目录 | 用途 |
| --- | --- | --- |
| 视频 | `素材` | 唯一正式成片路径为`素材/<至少两位集号>/<集号>-<分镜号>.mp4`，如`素材/01/1-1.mp4`；文件名数字不补零，仅一层集号目录。项目总目录不另存一份视频。 |
| 人物 | `人物` | 递归查找人物身份与造型素材。 |
| 场景 | `场景` | 递归查找空间与日夜变体。 |
| 道具 | `道具` | 递归查找外观与剧情用途对应素材。 |
| 人物站位 | `人物站位` | 递归查找有效旧图；新帧保存为`<集号>-<分镜号>.png`。 |
| 音色 | `音色` | 递归查找样本及索引；新增保存为`<规范人物名>.wav`。 |

解析绝对路径并用路径连接派生目录，不重复追加项目名／集号。首次生成前创建实际需要的输出目录和父目录，验证可写；每次保存前再次确保存在。只读查找缺目录可记录缺失，不靠创建空目录冒充素材、不强建本次不用的目录。有效绝对路径尚不存在不算缺参。权限问题按真实限制处理，不另存其他项目或下载目录，不移动旧目录或清理其他文件。

### 工具能力预检

首次付费提交前实际确认能力；同环境有效记录可复用，工具失效或启用新功能时补查。

- 必需：支持当前选用浏览器的 UI 操作、下载定位、实际视频参数读取、完整解码、SHA-256 和归档。外部浏览器无法调用时先按浏览器流程尝试内置浏览器，再判断所需能力是否缺失。`ffprobe`可读元数据不等于完整解码。能力仍缺失先解决，不提交受影响任务。
- 仅开启站位与视频穿帮校验，或用户单独要求全段视觉检查时，才要求覆盖全段的取帧／查看能力。关闭且没有单独要求时，关联前段也不要求全段视觉能力，不因此阻塞生成。用户要求局部检查、按需保存或复用站位帧、核实音色区间时，只需对应范围的取帧／查看能力，不扩展为全段穿帮检查；实际所需能力不足则记录对应事项待核。
- 提取音色需导出、解码和精确时长检查；听检、去音乐按需确认能力。缺能力记录未完成，按第3节先找已有合格音色，无可用者才跳过；不改开关、购买服务或上传外部处理平台。

优先用[本地技术检查](references/performance.md#本地技术检查)中的随附脚本；它不代替视觉、说话人或听检判断。

### 确认对应集数的完整提示词

1. 读取最新完整正文、段号、明确时长、场景、人物、道具及每处台词／VO／OS，记录来源版本。摘要、文件名、剧本原文和其他集提示词不算就绪。逐集核对，不混集混版；时间轴矛盾、台词缺失或时长超限先解决，不临时裁台词。
2. 缺失时按[导演衔接](references/director-handoff.md)复用本对话此前实际调用、适用于当前项目的同一导演技能；资料齐备就补齐保存后继续。无调用记录、技能不可用或资料不全说明缺项，不自行选陌生导演、不从零代写或直接填剧本生成。
3. 建立段号、平台分镜、提示词版本、素材和依赖映射。同一连续场景、承接人物／动作／道具／空间状态或使用前段成片、站位、音色均属关联，包括跨集。**仅计划复用前段视频音色也是硬依赖，必须等来源视频生成并检查通过。** 不以音色可跳过而提前提交；按实际衔接而非编号相邻判断。独立段通过自身预检可先提交。

### 剧情内文字默认放行

剧情必要的短信、定位、来电界面、合同、收据、备忘录、招牌等文字及载体默认允许，不因可辨识、未遮挡而询问、拦截、遮字或重生成。旧稿“无任何文字／无 UI”冲突时，本地另存修订为“允许剧情必要的道具文字与屏幕界面；禁止额外字幕、水印、LOGO及无关片头片尾文字”，保留原版与剧情。同步平台仍先完成第2节历史检查，只改已授权编辑范围；传给导演同样明确此例外。用户对具体文字的新要求优先，实质连续性错误不在豁免内。

### 预检不通过时

**总路径缺失、空白、占位符、非绝对目录或有未解决冲突时，请用户补充有效值后才编辑平台、上传、生成和保存。** 不从项目名、工作目录、下载目录、旧分类路径或其他任务推断；平台已有素材也不能免填。等待时可做与路径无关的资料检查。

只问真实缺项，填回已确认参数，非默认设置一并列明。简短调用格式：

```text
$jumeng-video-operator
项目名称：<准确项目名>
选集：<集号或列表>
项目总路径：<必填绝对目录>
一键引用：关闭
```

无可复用导演时说明：“未找到第X集完整提示词，本对话没有可复用的导演技能调用记录。请先调用导演技能生成，或提供完整提示词文件。”满足导演衔接条件的缺稿先补齐。

## 2. 平台定位与已有结果

按[浏览器流程](references/browser-workflow.md)优先使用外部浏览器的受支持 UI 接口，无法调用时改用受支持的内置浏览器；读取所选工具的初始化、上传及下载说明，仅采用受支持原生 UI 时读 computer-use。切换后重新核对账户、项目、集号、保存状态及在途任务，沿用本任务参数与进度，不重复提交。两类浏览器均不可用时说明具体缺失；不编造 API 或读取隐藏状态。每组动作后观察当前页面；纯回查只读任务身份、版本和状态，编辑／提交才核对正文、引用及参数，不跨切页沿用失效句柄。

编辑前检查目标分镜及历史，确认可编辑范围后同步稿件与引用。缺分镜按已确认提示词段数顺序创建，不凑数量。生成中或提交状态不明先查历史，不重复提交。

### 已有视频的覆盖确认

- 任务开始前已有成功视频：列明项目、集号、分镜、版本，询问保留或覆盖；空卡片不证明无历史。未决定或明确保留时不改正文、引用和选用结果。普通“生成整集”不含覆盖授权。
- 可保留已有仅生成缺失、覆盖重生成或指定范围。确需确认时说明本节要求并链接本文件；已有明确覆盖／修复授权不重复问。覆盖不包含删除历史；保留版不适合衔接时报告具体冲突。
- 本次授权范围内开启穿帮校验后的限额内修复直接执行。关闭时，重大站位等实质错误先记录、准备修订并暂停关联链；已有修复授权则执行，否则一次确认具体范围。轻微道具瑕疵不触发修复。失败、取消、停止不纳入自动修复授权。

## 3. 素材与音色引用

**搜索或选择素材前，先按[素材范围前置操作](references/browser-workflow.md#素材范围先切换为全部素材)把“本集素材”或单集筛选切为“全部素材”（用户所称全集素材），读回已生效后再查类别及准确名称。** 这是当前项目内的素材范围，不改变正在编辑的集数或分镜；人物、场景、道具、站位图、音色及一键引用的要素选择均适用。在“本集素材”下查不到不能判定平台缺失，也不能据此重复上传或跳过。

**提示词内资产的`@`引用优先直接使用剧梦平台现有素材。** 在当前项目“全部素材”中按名称／已确认别名和类别查找，核对身份／造型、空间／日夜、道具用途、站位来源或音色准入；找到合格素材就直接引用，不先扫本地、不要求再找到同名本地文件，也不重复上传。本规则同样适用于一键引用中的人物／道具要素。

只有平台全部范围查找完成、仍找不到合格可用素材时，才递归检索本项目对应本地目录，核验后上传引用；记录平台查找范围、名称及缺失／不可用依据。搜索未完成、范围不明或加载失败不能当作平台缺失。按[任务内素材缓存](references/performance.md#任务内素材缓存)复用仍有效的查找与核验结果，但本地缓存命中不改变平台优先顺序。同名歧义不选首个、不跨项目盲搜。场景名沿用用户图名，平台简称只做映射。

- **任何出镜人物素材缺失、身份／造型错误或真实引用缺失，都禁止该分镜生成，包括无台词人物。** 先查`人物`及子目录、看图核验并上传引用；仍缺记录人物、集号、分镜及已查路径，可继续其他就绪独立段。不用文字或别的人物替代、不删人物绕过。全段仅发声不出镜者不要求形象素材。
- **场景、道具、音色先完成对应本地目录及子目录查找，无可用者才跳过。** 音色还读索引，提取关闭也需查已有样本。找到可用者必须用；缺目录、查无匹配或候选均不可用时记录路径、名称、核验和未采用原因，保留文字与完整对白、清除空标签，不再问能否跳过。查找失败／权限不足不等于缺失，未完成时暂停受影响提交。
- `一键引用：开启`时先按[一键引用流程](references/one-click-reference.md)处理人物和道具，生成并读回平台已生效的真实引用；关闭时按[真实引用流程](references/browser-workflow.md)逐项建立`@`标签。场景、站位图和音色仍使用原流程，纯文本、未应用的关系行或“请选择”都不算引用完成。音色读[上传与复用准入](references/voice-extraction.md#上传与复用准入)，每处台词／VO／OS逐句放在对应说话人的“参考”和“音色”之间；若二者之间有括号，按[音色括号替换](references/browser-workflow.md#音色括号替换)用真实音频标签整体替换括号及其中内容，无括号则按原规则插入。不冒用别人声音。独立旁白仅按已有提示词及用户约定处理。
- 错误站位图立即停用并移除未提交后段引用，不凑流程引用或凭空补画。缺图按第4节处理，不能解除人物要求或关联等待。编辑只做已授权稿件填入、导演补全或定向修复。

### 一键引用开关

这是本技能的任务参数，不要求平台另有同名开关。开启后，**先确认素材范围为“全部素材”，再校验本段所有出镜人物和需引用道具是否缺失，完成平台查找、必要的本地查找及上传补齐，再点击“一键引用”**。人物仍缺或查找未完成时不进入该分镜的一键引用；道具确认无可用素材后记录跳过，可继续其他就绪关系。

进入界面后的第一项编辑动作仍为“一键清空”；清空自动分析关系后，逐项新增引用关系、输入提示词原名称、选择要素。素材绑定完成且关系核对无误后，**点击“确认并引用”**，再读回生效引用和保存状态。未匹配行删除，保留正文及缺项记录；若绑定时才发现素材失效，返回素材校验补齐后再继续，不以删除人物关系解除阻塞。入口或确认按钮缺失、结果不明时记录未完成；关闭则沿用原`@`流程。

### 缺失音色提取与存储

提取开启时按[音色参考](references/voice-extraction.md)处理每段所有缺音色的发声人物，包括末段；已有合格样本复用。新样本须实际同人连续独立讲话3–5秒，不补静音、循环、拉伸凑长；存派生音色目录，来源及状态写索引。

为刚解锁后段计划复用的音色，先完成来源验收和样本准入再提交；客观无合格样本时按音色参考记录跳过，不能为抢先提交主动取消依赖。暂不影响就绪后段的其他音色提取可入待办，在等待窗口完成；不遗漏人物或提前宣布全部完成。提取关闭不新提取，不额外生成视频取样。听检、未听检复用、音乐处理分别如实记录，不把保存成功说成可用／听检通过。

## 4. 关联分镜顺序生成与站位复用

**关联后段必须等待所有直接前置的当前选用版本生成完成、归档，并通过文件及实际参数校验。** `站位与视频穿帮校验：开启`时，还须通过全段视觉和相关衔接检查；`关闭`时，关联前段同样跳过主动视觉、穿帮及衔接验收，不把“尚未做视觉检查”作为后段阻塞条件。用户仍明确保留的单独检查按指定范围完成。

**关联顺序等待不等于视觉验收。** 关闭后不得以“最低限度衔接验收”“直接前置必要验收”“首尾帧检查”等名称继续要求视觉检查，也不得声称本技能的这项视觉规则“不能关闭”。用户说“关闭关联后段的直接前置成片最低限度衔接验收”时，立即关闭该范围的视觉检查并更新待办，不要求再确认或等待某次检查做完才生效。已有旧规则、摘要或进度中的“关联前段检查不可关闭”失效。只需保留本节技术与素材条件；按需看实际采用的站位参考或核实音色区间，是具体素材准入，不单独新增前段与后段的画面对照验收。

本技能及参考中的“前段检查通过／验收通过／前段通过”，均指完成当前开关及用户明确要求的检查；关闭时可记录“文件与参数通过，全段视觉检查按设置跳过”，不能写成“视觉通过”。技术待核、已知未解决的实质错误、修复中、生成中或失败／取消／停止仍阻塞对应链。平台成功或旧图不能代替必需的文件检查；所需站位／音色依据仍须就绪。检查由执行过程完成，不加未要求的人工逐段确认。

等待时仅预填后段、整理素材及已就绪引用，确认保存。通过后按第5节预检；只复用同一未变视频、提示词、关联依据与验收要求的有效检查记录。换版本撤销旧放行，按当前设置重查；已提交／完成后段按[依赖失效与重新验收](references/continuity-review.md#后段依赖失效与重新验收)处理，关闭时不因换版自动安排全段视觉检查。

中途关闭开关时，停止为该范围的主动视觉／衔接验收发起新取帧或观看，移除仅因尚未执行视觉检查或缺少该能力而挂起的待办／阻塞；已有工具操作返回后只收取结果，不继续展开该检查。具体素材准入和已知问题复核仍按下文及各自参考执行。保留技术、素材及已发现实质问题的记录，不为排查“可能有问题”主动恢复视觉检查。中途开启时，未提交后段所依赖的前段须补足当前所需视觉检查；不自动取消或重生成已提交任务。单独检查按用户最新明确范围执行：明确要求关闭的范围内，旧的单独检查要求也取消；未被取消且仍明确保留的其他范围继续执行。

站位图引用也先查剧梦当前项目“全部素材”中的已有可用参考，结合来源版本、时间点、画面和后段需求核对；平台没有合格站位图后才查本项目`人物站位`及子目录，仍无可用图时按下列条件取新帧或记录跳过。平台已有有效图不要求重复寻找同名本地文件或重新上传，仍不得免除关联前段等待。关闭全段视觉检查时，仅查看实际采用的站位帧及判断其适用性所需的局部范围，不顺带扫描全片：

- 前段通过后，旧图中人物组成、位置、朝向、持物及关键道具关系仍适用，可复用并记理由。
- 状态变化使旧图失效，从已通过成片选可靠新帧；只用真实帧，不凭空补图。
- 模糊、遮挡、矛盾图不用，可找同段稍早仍有效帧。仍无可靠图、完整文字明确人物关系且无冲突，可记录跳过图；关联前段仍须通过。
- 无剧情状态或前段产物依赖可独立提交；仅换地点、跳时、跳过音色／站位图不自动独立。

### 等待与多集轮转

按[调度规则](references/multi-episode-scheduling.md)回查当前集**全部**本任务在途分镜（含提交状态不明）及待检队列，列表覆盖全部时统一读状态，仅遗漏／异常开详情。优先当前集可处理成片，再处理其他已选集结果；前段通过后允许一次刚解锁后段的优先提交，随后恢复结果队列。只在预算、容量和完整预检允许时提交。

多集等待推进后续集一个完整可保存小单元，通常30秒、最迟60秒到安全保存点返回；完成更早则提前返回。每处理一个后续集结果也返回当前集。返回目标只定位，不缩小回查范围；纯回查不重复读长正文和时长。单集也处理独立任务，不把一条链等待扩大为整集停工。临时切集不改变主推进集；只轮转已选范围，共享预算、容量和累计次数。

## 5. 每次生成前的最终校验

每次提交（含独立段、刚解锁后段的优先提交、修复）都执行以下顺序。第1–6项先就绪，才进入第7项选择时长；第1–8项在当前状态下全部满足后才允许点击生成。这里的“全部校验”是当前设置要求的必需项；按规则允许跳过的可选素材或已关闭视觉检查如实记为跳过，不重新启用，也不把必需项待核当作通过。

1. 项目、集号、分镜、范围、总路径和归档目录正确，所需输出目录可写、工具就绪。
2. 当前完整正文去除引用节点和无关排版空白后与有效稿一致；已执行一键引用时，按[一键引用正文核对](references/one-click-reference.md#应用保存与正文核对)恢复被真实节点替换的具体名称后比较，不能全局忽略名称。已执行音色括号替换时，只按记录的具体位置将有效稿中的对应括号片段替换为同一音频引用后再比较，不全局忽略括号文本。实际标签、说话人及逐句映射另行核对，台词／VO／OS及顺序完整；修订已保存。剧情文字按第1节放行。
3. 全部出镜人物及真实引用齐备且正确；其他引用无误，无空标签／遗留搜索词／失效图。本次素材搜索／选择前已确认“全部素材”范围，平台缺项结论不能来自本集筛选。一键引用开启时，已先完成整段人物／道具素材校验，再进入面板清空并按原名称重建；未匹配行已删除，素材绑定完成后已点击“确认并引用”且读回生效、保存无误，未重复叠加手动引用。跳过项有仍有效的本地递归查找记录；音色符合当前开关和准入。
4. 全部直接前置当前版本均按第4节当前校验设置完成检查，或已记录独立依据；关闭时允许“文件与参数通过、全段视觉已跳过”，不要求视觉通过记录。站位图有效或合理记录跳过；计划复用音色仍须等来源视频完成对应检查及音色准入。
5. 模式、模型、分辨率**实际显示**正确，目标秒数已从有效提示词确认；此时仍不操作时长控件。记录档位及已核实画幅／像素映射，“8K”等风格文字不作规格。
6. 无生成中／不明的重复任务；历史覆盖及修复授权明确，修复次数未超限；实际任务容量可提交，用户预算及已花费用、在途预留已核清。已知无容量、超预算或其他阻塞时停在准备阶段，不先设置时长等候。
7. **仅在现在就要提交该段时选择目标时长。** 先完成模式／模型／分辨率设置，再打开时长控件，按提示词选择秒数；输入后失焦、关闭面板，读取生成区实际显示值。已经准确显示目标值时确认即可，不为走流程重设。记录目标与实际值；不能用提示词秒数、时间线旧值、其他分镜或缓存代替当前显示。读回不符先修正并复核，不点击生成。
8. **点击前最终放行。** 确认正文及真实引用已保存、项目／集号／分镜和前置版本未变，第1–7项仍有效，模式／模型／分辨率／时长显示一致；按设置时长后的当前可见费用重算已花费用＋在途预留＋本次费用，核对预算、实际容量及修复上限。未知费用不当零。任何必需项失败、未完成或状态不明均不得点击；修正后重新核验受影响项和最终状态。设置时长后若继续改正文、引用、模型／画幅或切换页面，旧放行失效，下次准备提交时重新执行本节，不在等待期间反复设置时长。

全部满足后简报实际参数、可见费用和已按规则跳过项，点击一次“生成”并核对新增任务；不能先提交再补校验，也不能只因时长正确、按钮可点或部分项目通过就生成。已有授权不重复问是否生成。购买、充值、订阅不在授权内。

## 6. 结果检查、修复与归档

以可见状态及历史判断结果。失败、取消、停止不自动重试；仅“重新校验”不恢复生成。首次下载及恢复归档时读[视频下载与归档](references/video-archive.md)：同一项目、集号、分镜和生成版本在正常流程中只触发一次平台下载，确认下载失败不可续用或文件确实丢失／损坏时按参考处理；先检查已有下载／工作文件，归档使用本地转存，不为素材目录再次下载。默认直接把实际下载文件作为待检工作文件，不额外复制到项目总目录。所需检查通过后按唯一正式路径命名归档，并完成临时副本收尾；仅替换不同的历史版本时保留旧版备份。所有保存自动创建缺失父目录。

### 成片实际参数核对

每段包括独立／链末段均须完整解码、核对实际时长、像素尺寸及显示旋转信息，并确认最终归档的哈希等于所检下载内容。单文件转存核对转存前后的哈希；确有不同路径副本时核对双方哈希，不为对比而新增副本。优先按[本地技术检查](references/performance.md#本地技术检查)一次生成报告和按需联系表；技术与视觉通过分开记录。

- 逐项比较目标与实测；时长仅允许有实际帧率／时间基依据的帧边界舍入，不取整掩盖缺段。尺寸按已核实的平台档位／画幅映射，不凭“480p”臆定宽高。
- 不符、映射未知、无法测定或解码失败均待核，暂停最终验收及依赖后段；核对版本、提交记录及平台规格。不得改目标、补时或缩放伪装合格。参数错误不增加付费重生成权限。

### 穿帮严重程度

开关开启时，读[视觉检查与修复](references/continuity-review.md)并检查全部成片的全段和衔接；关闭时，关联前段、独立分镜及链末段全部跳过主动全段视觉／穿帮检查，也不为此生成联系表或逐镜抽查。用户单独要求检查时按其范围执行。按需取站位帧或核实音色区间仍按对应流程完成，只记录实际查看范围。要求全段检查时，片尾帧不能替代；按设置跳过时不声称全段检查通过。

**前面有实际对应动作，切镜后合理站位变化不算穿帮，允许省略中间走位。** 结合切前动作、切后状态和机位判断，记承接依据并用切后正确站位参考。不影响剧情、关键动作和后续衔接的轻微道具瑕疵记录放行，不重做、不问、不阻塞。重大站位、出入方向、空间关系或关键道具错误须定向修订，未解决不验收、不放行后段；按剧情影响而非道具体积判严重程度。

修复按第2节授权和[校验参考](references/continuity-review.md)的次数规则执行，保留台词、剧情、身份、场景名和时长，每次预检及检查新结果。上游改版导致后段修复与其自身修复共用累计上限，不重置、不借额度；达到上限保留问题与修订，预算／停止指令优先。未做的视觉或听检不宣称通过。

### 下载副本清理

按[归档收尾规则](references/video-archive.md#归档收尾与恢复)处理同一版本的本次下载原件及临时工作副本：最终文件完整、可解码且哈希一致后，精确清理仍存在的冗余文件，并确认最终文件仍在。单文件已移动到最终位置时没有源副本可删；源与目标解析为同一文件时绝不删除。同内容的本次临时副本不当作历史备份永久保留；用户要求保留则记录例外。失败、未完成、对应不明不删，不通配清空、不删真正历史或其他集文件。清理失败记“已归档，副本清理待完成”，下次只重试该收尾，不重新下载。取帧／音色只读已记录的归档版本。末段无衔接可不取站位，但提取开启仍完成音色待办。

## 7. 断点记录与交付

工作目录保存参数、总路径和派生目录、提示词／导演版本、分镜与依赖、素材查找／缓存证据、站位来源、覆盖授权、任务与结果版本、归档、技术报告、视觉证据、修订次数／费用、音色待办和索引。一键引用开启时另记进入面板前的整段素材校验、补齐／跳过结果、清空状态、原名称与素材对应、未匹配行删除、“确认并引用”及实际保存结果，未完成关系不能记成已引用。轮转记录主推进集、返回目标、全部在途／待检／阻塞项、编辑断点和下一单元；按[耗时与恢复](references/performance.md#耗时与恢复)记录耗时，只输出变化／异常，不反复输出长正文。

提交前保存意图、来源及依赖版本、验收依据和预算预留；提交后立即记可见任务标识、时间和状态。状态不明保留预留、查历史对账，不重提探测；平台接受即计修复次数，失败不返还。版本／依赖变化撤销对应放行，复核站位、后段验收和音色资格。

下载另记项目／集号／分镜／生成版本、下载意图与状态、浏览器实际落点、唯一工作文件、正式目标、内容哈希、检查报告、转存及副本清理状态。平台原文件名只作来源记录，不决定正式命名。恢复时以这些记录核对真实文件，不能因原下载路径在成功移动后不存在而重新下载。

恢复先核对页面、记录及缓存有效性，沿用同任务授权／计数，不重复生成或恢复停止任务。交付列实际完成范围、视频／站位／音色位置、检查／清理情况和未完成项，保留结果页或可继续编辑页；技术、参数、视觉、听检分别表述，音色待办未清不得称全部完成。不保存凭据、令牌或隐藏接口数据。
