# 机位与主拍人物的真实变化

近景切中近景等四种有条件切换，以及同景别相邻切点，都先比较前镜实际结束构图与后镜实际开始构图；跨段与回忆按成片顺序比较。两镜都叫过肩不代表同机位，改叫斜侧过肩也不证明换机位。

同段同场、原文或用户具体片段要求支持的时间跳切，可按 [跳切记录](cut-techniques.md#时间跳切的内部记录) 局部放宽下述普通切点限制；例外不证明换机位，实际位置仍如实填写，跨段景别要求不放宽。

## 导演判断

- 对过肩镜头明确主拍谁、越过谁的哪侧肩膀、摄影机在场景哪处、朝哪个方向、什么高度、背景空间参照。前景肩背属于关系参照，不因说话人改变、可见名单排序或前景面积增加就改成主拍人物。
- 同一摄影位置与高度、同一主拍人物，仅裁切、变焦或改变人物在画面中的大小，不能作为任何人物景别组合的普通合法硬切，包括中景→近景；只改机位编号、措辞或背景名单也不能放行。原地转动摄影方向本身不等于移动机位；若因此真实换主拍人物，按换主体判断。
- 真实换机位须在原“运镜／画面内容”落实新摄影位置或高度及随之改变的观察关系、肩背遮挡或背景参照，不用“机位 B”“略换角度”“背景虚化”代替。只让人物移动或让背景变化，不等于摄影机移动。空间、轴线和距离继续按原场景，不为了制造差异让人物无依据换位。
- 切点检查只判断是否允许这样切，不替代 [同场对白的关系构图](shot-selection.md#同场对白的关系构图) 复核。`subject` 只标主拍，不限制其他人出镜；`foreground: []` 也不证明对方不在现场或无需关系位。不得为换主拍删除原本应保留的互动对象。
- 真正从乙肩后拍甲切到甲肩后拍乙，可以按反打执行；一镜内连续推拉也可变化景别，写清运动过程、结束景别和落稳构图，不把硬切标为连续移动。跨段景别不同必须与真实机位／主体条件同时满足，不能为了换景别在同一过肩构图上硬切。
- 缺少换机位或换主体的具体依据时，先按未改变处理：保留当前镜头、选择有剧情任务的真实反打／新机位，或在原时长内连续改变取景；不强制延长镜头，不增加无关特写、空镜或动作当过桥。

## 面对面过肩正反打

两人面对面、站位与朝向未变的常规过肩正反打，先以两人连线建立轴线，两个机位留在轴线同一侧。**人物自己的左／右肩、摄影机的场景方位、肩背在画面的左／右侧是三个不同信息，不能复制成同一套左右。** 换拍另一人时，前景人物变了，其解剖学肩侧也应相反；不能两个机位都写左肩后或都写右肩后，再靠“轴线同侧”一句放行。

以下以甲在南面向北、乙在北面向南，镜头不翻转、不镜像、前景人物未转身为例；实际姓名、方位与参考图按当前场景重算：

| 共同机位侧 | 拍乙 | 反打拍甲 |
| --- | --- | --- |
| 人物轴线西侧 | 南端甲左肩后朝北；甲左肩背占画右前景，乙在画左，视线朝画右的甲 | 北端乙右肩后朝南；乙右肩背占画左前景，甲在画右，视线朝画左的乙 |
| 人物轴线东侧 | 南端甲右肩后朝北；甲右肩背占画左前景，乙在画右，视线朝画左的甲 | 北端乙左肩后朝南；乙左肩背占画右前景，甲在画左，视线朝画右的乙 |

按实际成片顺序连同内部切镜、道具插镜后的反打和跨段接话，核对“共同空间与轴线侧 → 前景人物及自身肩侧 → 肩背画面侧 → 主拍画面侧及视线 → 对应背景／光源”。把正确事实分别落实到 `view.position/direction/foreground`、`relation.placements` 和本镜画面，不增正式字段；运镜写机位，位置句写投影后的画面关系，不重复整段解释。姓名换了或景别变了都不能代替这个核对。

肩背位置相同本身不足以证明所有类型镜头都越轴；本节对应常规、站位不变的面对面过肩反打。人物确有转身、换位、摄影机连续跨轴、镜面视点或其他特殊构图时，按真实过程重新建立轴线与画面关系，不机械左右互换；不能为了修复错误额外添加走位、转头或过桥镜。正反打参考图仍共用真实空间，不能把一张图水平翻转来凑肩侧。普通无依据的同肩反打应改机位和全部相关位置描述，不能只换肩膀字样。

`shoulder_axis_review.py` 使用现有记录，定位能明确读出肩侧、前景侧或相邻反打重复肩侧的疑点，随集中报告提示人工复核；不从自然语言或图片证明真实摄影几何，不自动改左右。未识别、插镜隔开的反打、移动及特殊视点仍按上述完整链检查，无提示不等于轴线已通过。

## 按需记录构图

最终交付时，四种有条件切点、所有同景别相邻切点、同集跨提示词段切点的两侧实际镜头需要 `view`；时间跳切记录在基础及最终检查中也要求两侧有效 `view/end_view`；同一镜已填写则复用。其他镜头可省略，单镜内连续变景别不因本规则被迫拆镜。已有 `start_camera/end_camera` 仍记录实际机位，编号不能单独授权切换。基础草稿检查兼容旧记录；排版及 `--final-prompt` 最终模式必须满足本节，不能用基础模式代替交付。

`view` 表示镜头起始的实际观察构图。全镜摄影位置、方向、主拍、前景、背景等没有变化时不写 `end_view`；改变观察位置、方向或关系时明确填写完整 `end_view`。细微手持可围绕同一构图浮动：起止观察关系确实相同且没有实际移位／转向任务时，可复用 `view`，质感及其变化写在 `camera_text`，不逐次采样微浮。若浮动实际导致构图、遮挡或观察关系变化，仍按真实过程记录；不能借“手持”省略推进、横移、摇向或升降的终点，也不能把微浮当作切镜所需的新机位。即使起止景别不同，固定机位变焦且上述信息不变时仍可复用 `view`。记录原地转向或前景离框也需要 `end_view`，不要从起始构图猜结束；机位编号或主拍标识起止不同而缺失结束构图时会报错。运镜文字已明确摄影机移至／转向新位置或方向时，即使机位编号没变也必须有 `end_view`；程序只识别部分明确表达，其余仍逐镜复核。

```json
"view": {
  "space": "大厅",
  "position": "长桌南端东侧 Elias 右肩后",
  "direction": "长桌北端的 Mara",
  "height": "Mara 眼高",
  "subject": "Mara",
  "foreground": ["Elias"],
  "background": "Mara 身后的北窗"
}
```

- `space` 是场景空间，`position` 是以固定场景参照描述的摄影位置，`height` 是真实摄影高度；同一空间、位置和高度复用相同文字，不加镜号、角色说话状态、焦距、景别或近义改写假造差异。人物会移动时，不能只写“某人肩后”作为位置，要带上固定空间参照。背景移动、明暗或时间变化不产生新机位。
- `direction` 是朝向，`subject` 是实际主拍人物的原姓名；无人或非人物主体才用 `null`。`foreground` 只列仅作关系参照的可见人物，不包括主拍人物；没有则用 `[]`。脸未出现不等于不在画面，肩背仍是可见关系人物。主拍与前景须同时符合最终画面描述，不通过删除前景记录冒充主体变化。
- `background` 是真实空间参照，供内容复核观察关系；改变这项不能单独作为换机位依据。空间事实与场景图、人物眼线、距离和轴线一致，不凭空增加参照物。
- 实际使用同场正反打多图时按 [场景图分视角规则](asset-library.md#同一场景的正反打与多角度参考) 填写：所有角度的 `view.space` 沿用同一个真实空间名称，不把正打／反打文件名填成不同空间；各镜独立填写实际 `position/direction/subject/foreground/background` 及 `relation.placements`。参考图原名与适用区间复用已有素材记录，在 `camera_text` 写明确引用；本镜 `visual_text` 仅写该视角的画面。固定世界站位与各机位中的画面左右分开，不能直接复制或一律镜像；程序不会从图片推导正确位置。镜内观察关系改变仍填 `end_view` 并交代真实过程，不为换图而虚构切点。
- 渲染器从 `view/end_view` 派生缺失的 `start_subject/end_subject`；已经提供却不一致的主拍记录会报错，不静默改正。只变更主拍字段或改编号，无法替代真实构图记录。

## 跨段同主体的可见构图检查

四种模式均执行，按实际成片顺序展开正式分镜内部的所有硬切。只比前段最后一个实际镜头的**结束画面**与后段第一个实际镜头的**开始画面**；不能拿前镜起始画面比较，也不能拿后段几秒后的反打替首镜过检。新段时间重置为0、分镜重新编号、台词换句都不会自动产生新画面。

同一场景、同一人物出镜是正常连续性。重复风险在于主拍、观察方向、人物在画面的分布、前景遮挡和背景空间关系基本不变，只有近景／中近景标签或轻微裁切变化。逐对核对以下事实：

- 实际观察角度是否改变到可辨的正面／三分之二侧面／侧面关系；相机方位文字换了，脸部观察关系仍相同，不算充分依据。
- 前景肩背占位、对主体的遮挡或两人的空间关系是否有清楚变化；不为差异删掉必要关系位，不无依据移动人物。
- 新取景是否展示本段确需看见、前镜未展示的信息。仅脸变大变小、背景更虚、细微表情或台词继续，不构成新的构图任务。
- “向东错开半步”只描述移动量；如实际产生可辨的遮挡或观察关系变化，写清结果再判断。半步并非一律无效，也不设一律转满某角度的机械阈值。轴线、持物、光源与动作阶段仍须连续。

例如22-2末镜为南端伊森东侧肩后、主拍佐伊近景；22-3首镜仍在同一侧肩后、同方向同高度、伊森左前景与佐伊右后方，仅改中近景并删去“错开半步”。这一对应判为**缺少可见构图变化依据**，不能因位置字符串和景别标签不同放行。22-3第7秒才反打伊森，不能补偿0秒首镜重复。

修复时依据原剧情选择真实反打、有新观察关系的机位，或重新安排生成段边界以保留连续镜头；不补无关空镜、道具插镜、重复动作或额外停顿。保留原句、声音连续性和已完成动作，不让换画面重新起句／重新起手。新方案还必须通过原有景别与机位规则，本检查不会放宽它们。

### 内部记录与成稿绑定

同集跨段的两侧实际构图处于同一 `space` 且 `subject` 相同，在后镜记录 `cut_change_before`。两侧 `subject: null` 时同样说明所拍道具／非人物内容的实际区别。真实换主体或换场仍查原有规则，无须为此额外填此记录。同一物理空间复用同一名称，不能更名规避检查。

```json
"cut_change_before": {
  "from_segment_id": "22-2",
  "from_shot_start": 22.5,
  "aspect": "occlusion",
  "before_evidence": "切出时伊森肩背占画左前景，佐伊面部呈近正面，双方之间的空间被肩背遮住。",
  "after_evidence": "切入时伊森肩背仅留画左下角，佐伊呈三分之二侧面，双方之间的空隙清楚可见。",
  "basis": "以原有对峙关系呈现佐伊继续追责时与伊森保持的距离。"
}
```

此例仅示范记录格式，不替当前片段自动设计机位。`aspect` 从 `view_angle`（观察角度）、`occlusion`（遮挡）、`spatial_relation`（空间关系）、`visible_information`（入画信息）中选实际主要变化。两条 `evidence` 分别摘录前镜结束与后镜开始在 `camera_text`／`visual_text` 中已经写出的可见事实；`basis` 说明原剧情的观看任务，不写“为过检换镜”。不得反过来编造依据。

程序核对实际前驱段号／镜头起时、记录完整性、证据区别与两侧原镜文字；渲染不自动补证据。最终检查还要求证据落在对应实际镜头的“运镜／画面内容”区间，放到段首、别镜、后段反打或只改检查摘要都不能替代。记录保留内部，正式模板不增加字段；证据复用已写的具体画面句，避免重复描述。

分批续作先读取上一批已交付末镜及结束状态，联同本批首镜做同样比较。有结构化记录时合并相邻批次的来源、段落及实际播放顺序后校验，再按本次范围交付。没有前批记录时对照已交付文字人工核对；无法取得前镜则明确该边界尚未检查，不能以两批分别通过宣称跨批已验证。程序不会自动读取其他文件或推测缺失的前批。

## 与最终提示词绑定

`render_prompt.py` 用上述记录自动生成自然语言摄影位置、朝向、高度、主拍、关系前景和背景描述，放入原“运镜”字段；`camera_text` 只补自动描述尚未包含的取景边界、清晰重点、稳定性、运动、触发、衔接等必要导演信息，不再重复或与自动描述矛盾。没有新增正式字段，不输出内部 JSON 或机位编号。

手动填写正式文本时，使用 `scripts/camera_views.py` 的 `camera_view_prose(shot)` 取得同一段构图说明，放在本镜对应“运镜”区间。最终检查要求这段说明与记录一致且出现在本镜区间；放在段首或别镜、修改记录后未更新正文，均不能通过。有多个实际镜头时仍各自绑定区间。

无本地 Python／文件工具时，沿用主技能的人工校验路径，在原“运镜”直接说明上述构图事实并逐切点比较；不必输出内部 JSON，也不声称执行了脚本。

脚本比较前镜 `end_view`（可复用不变的 `view`）与后镜 `view` 的真实位置记录，忽略编号、焦距、景别、前景或背景更名；主拍变化按构图中的角色判断，且不能同时是关系前景。无有效时间跳切例外时，相同景别不允许同机位，即使换主拍也不豁免；跨段同景别仍禁止，即使真实换机位也不豁免。

**结构检查不能证明摄影几何正确。** 脚本统一少量明确同义写法（如南边／南侧），其余同义位置、同时虚构构图记录与最终文字，仍需内容复核识别。交付前将切点两侧并排看，核实具体变化在空间中能否成立、与画面主体是否一致；不要把字符串不同或证据字段齐全称为已验证实际换机位，更不能声称验证了生成视频。

## 同义机位与续作边界

同一场景的相同实际机位使用一致的位置、高度与机位标识，不通过“的”、东边／东侧、近义肩后位置或改编号声称换机位。比较实际观察面、前景遮挡和信息变化，不能凭两个字段字符串不同判定有效切镜。程序只做有限规范化及相似候选定位，不能证明真实几何；按 [镜头排列](shot-sequence.md) 复核。

续作读取已交付前段末镜；`episode.segment_start > 1` 时复制 `episode.previous_tail`，格式见 [镜头排列](shot-sequence.md)。缺前段上下文不能标记跨段通过。修改当前首镜后复查前后切点，修改前段末镜后更新快照；旧文本和新机位不混用。
