# 竖屏短剧的拍摄技巧

四模式生成时读取，在镜头骨架阶段共同选择取景与摄影。先确定观众需要看清的信息、感受到的人物关系及关键表演，再按下文和 [构图技巧](composition.md) 选择角度、运动与持机质感；不等所有镜头锁定后才装饰性补运镜。方法服务叙事与情绪，不设轮换次序或使用配额，不因列出技巧就新增动作、走位、人物或场景元素。

## 情绪节点的摄影选择

关键施压、控制失效、反击、保护／获救、被接纳等节点，先沿原文确认关系怎样变化、观众跟随谁，再按 [情绪与景别的模式优先级](shot-selection.md#情绪与景别的模式优先级) 比较摄影如何参与这一变化；两种剧不以普通景别偏好先排除情绪收近，两种推文先比较中近景内的有效表演与注意重点，必要时再收近。固定拍摄与运动都有表达价值；不因没有人物走动、没有新物件或表演已强，就省掉摄影选择。已有关系的情绪变化也是摄影任务，不要求每次运动都揭示新对象。普通信息交流可自然稳拍，不强制每镜写选择理由。

选角度前，分开判断人物既有身份／资源优势、本轮谁在施压或回应、谁的情绪正在失控，以及观众此刻跟随谁。职位高不等于每一轮都占主导，处境弱不等于只能恐惧或退缩；强者可以失控，弱者可以坚定。这些判断只用于已有剧情的摄影选择，不新增输赢、认可或关系反转；不能按“老板／弱者”等身份标签固定仰俯，也不能改成“失控必俯拍、反击必仰拍”的另一公式。对称或居中构图本身不证明人物势均力敌。正式提示词只写所选真实机位、表演与构图，不输出主导权评分或抽象选镜理由。

| 原文支持的节点 | 可比较的摄影方案与落点 |
| --- | --- |
| 施压、受困、被迫回应 | 结合拍谁与双方关系，比较短距离推进、收紧前景空间或俯仰角度；落在实际承受或施压的表演，不为构图新增逼近、围堵或人物高差。稳定构图也可持续施压，须与当前任务相符。 |
| 不安、控制开始失效 | 比较细微手持浮动与稳定观察；选择手持时面部、口型与证据仍可读，不把摄影浮动写成人物发抖、场景晃动或新增撞击。 |
| 反击、夺回主动 | 在原词／动作的实际转折处比较观察高度、角度、接近方式或稳态变化；不必全用，也不把换角度当成角色已获胜。 |
| 获救、被保护、被接纳 | 根据此前摄影状态和当下真实回应，比较由浮动转稳、从压迫性遮挡中释放必要空间、改变观察高度或有分寸地靠近；原先没有手持不补造手持，没有人物移动不添走位。拍救助者可考虑仰角，但需结合温和或坚定的原有表演、距离与被救者反应，不用角度词单独证明救赎。 |

这些是候选方案，不是情绪到镜头的一一映射。仰拍不永久等于强者，俯拍不永久等于弱者；比较拍摄对象、前后关系与表演后选择。强情绪可持续同一摄影状态，不按每句重音重启推进或交替晃动。摄影不能代替必要反应、证据特写或旁白视觉信息；运动本身不豁免长镜复核与自然结束点。

## 角度、主要运动与持机质感

- **观察角度**：平视、俯拍、仰拍与景别分开选择，近景和过肩也可采用俯仰。普通叙事机位可基于有依据的关系与情绪选择高度，不要求人物先存在身高／站坐差，也不改变人物站位；写清实际摄影高度与朝向，核对肩背遮挡、口型、眼神、背景和光源。人物主观视角仍必须符合其真实位置与可见范围；极端俯仰、垂直顶拍须有清楚的观看任务和可读性依据，不为角度牺牲关键表演。
- **主要运动**：按任务选稳定观察、推进、横移、跟随等一个主要摄影行为，写起点、原词／动作触发、可执行路径与实际终点。静止人物也可由摄影机靠近或改变观察位置；不让角色为配合摄影新增动作。切到新高度不必拍完整升降过程，仍满足真实机位与切点条件。
- **持机质感**：稳定支撑、细微手持浮动或已有移动中的跟随起伏分别选择。静止对白可以使用轻微、不规则的上下／侧向浮动，不必先有奔跑或碰撞；幅度须让主体画面侧、必要关系和关键细节可辨，不以持续摇摆、随机滚转或失焦代替手持感。两种3D将其作为虚拟摄影质感，不连带改变角色速度、身体动作或世界状态。

俯仰角度、一个主要运动与细微手持质感可以共存；质感不自动算第二个主要运动，但明显摇移、滚转或升降不能伪装成微浮来叠加。相同区间不能同时要求三脚架锁死／完全无晃与持续手持浮动。写手持时用“位置基本保持”或明确移动路径，避免笼统“固定不动”；“停止推进”只结束位移，“浮动减弱至稳定”才说明质感变化。持续轻微手持不被“落稳”一词自动取消，真有变化才写触发与过程。

例如人物原地追责，可在其关键原词处写“沿既有轴线同侧短距离靠近，由中近景连续收至近景；保留细微不规则上下浮动，面部及前景肩背关系可辨；停止推进后轻微浮动延续”。原声、人物动作与摄影同期，实际位置和终点按本镜填写；这不是每次追责必用的镜头，也不能用它填满本来已完成的信息。

## 由信息确定景别

| 本镜任务 | 优先取景与边界 |
| --- | --- |
| 普通讲话、倾听、上身表演 | 中近景／近景，兼顾必要手势与关系人物；有意义的身体动作确需更宽时再用中景，不先裁紧再删除表演。 |
| 身体行为、人物与道具交互 | 选择能看清发起、接触及结果的范围；不只按“动作”标签固定分配景别。 |
| 路线、人数、空间分布 | 有任务的全景／远景或适当高机位；全景讲话取舍、连续讲话不插中全景等仍按 [中全景与讲话](shot-selection.md#中全景与讲话)，不为铺垫新增空镜或等待。 |
| 重要道具易主、证据变化、关键接触 | 原镜看不清且确有剧情作用时才用动作／手部／道具特写；按 [动作特写](shot-selection.md#剧情动作特写) 承接动作，不重复结果，不逐动词拆镜。 |
| 有指向、施受或注视他人行为的动作 | 按 [关系动作规则](shot-selection.md#有指向与人物关系的动作) 优先呈现谁对谁做什么／谁看着谁做什么，可以不用动作特写；画面要有可辨对象、方向、动作阶段与必要接触，不只写姓名。 |
| 强化人物情绪的主要动作 | 先判断上行的关系动作情境；符合时可用关系构图，其他主要动作在关键阶段安排实际动作／手部特写。按 [主要情绪动作的特写](shot-selection.md#主要情绪动作的特写) 保持发起与落点、原声和时间连续，已有特写不重复。 |
| 关键面部转折或必须辨读的细微变化 | 按 [情绪优先取景](shot-selection.md#情绪与景别的模式优先级) 区分模式后比较中近景是否足够、近景／短特写／有效收近是否更适合；两种剧突出关键情绪，两种推文中近景优先，任务完成后推进，普通讲话不反复贴脸，不用器官级大特写。 |

## 机位、运动与焦点选择

示例中的人物、物件、空间及动作须已有剧情或确认设计依据；姓名、方向与落点按本次素材填写。表格只提供选择入口，复杂条件继续按 [镜头选择库](shot-selection.md) 执行。

| 方法 | 信息任务与具体写法 | 核心控制 |
| --- | --- | --- |
| 稳定拍摄 | 适合当前观看任务的对白、倾听或完整动作。例：“稳定中近景，人物随原句完成胸前手势，摄影位置保持。” | 稳拍不等于平视、人物静止或长时间停留；关键节点先完成上述摄影选择，不以表演有力自动免除。 |
| 短距离推近 | 关键原词或信息出现时集中观察。例：“说到关键原词时，摄影机短距离向人物推进，中近景连续收至近景，随后停稳。” | 写明真实摄影路径与落点，保留必要关系和表演；不每句推、不自动推至面部特写。 |
| 拉远揭示 | 从局部扩展至已有空间或关系。例：“摄影机后退，逐渐露出人物两侧已有队伍，位置清楚后停止。” | 人物与摄影机距离增大，主体通常变小；露出的信息已有依据，不拖成无限拉远或无任务航拍。 |
| 后退跟拍 | 人物已有的向前走动、边走边追问。例：“人物沿走廊向前，摄影机在其前方同步后退，保持中近景和大致相同距离。” | 交代双方路径与相对距离，不能同时要求固定距离和人物持续放大；空间须容纳运动。 |
| 侧向跟拍 | 行走、追赶、搬运等已有移动。例：“摄影机沿人物左侧平行移动，保持上身与手中物品可见，背景连续经过。” | 按实际速度和路径承接，不能穿过陈设、无依据跨房间或令人物突然反向。 |
| 横向移动揭示 | 显露原有遮挡后的对象。例：“摄影机沿桌侧向右平移，越过前景遮挡，露出原本位于桌后的人物后停稳。” | 目标一直处于该位置，实际入场另写入场过程；不默认利用门框、柜门装饰画面。 |
| 水平摇镜 | 从一个已知目标转向另一目标。例：“摄影机位置固定，镜头从林悦向右转至陈默，陈默完整入画后停止转动。” | 改朝向而非摄影位置；按真实目标方位转动，不因摇镜虚构机位变化。 |
| 上下摇镜 | 沿同一对象观察不同高度的信息。例：“摄影机位置固定，从人物手中文件向上转至面部，落稳后保留其看向对方的视线。” | 交代起止对象，必要文字尚未看清时不提前移开；不等同升降或固定仰拍。 |
| 升降拍摄 | 改变观察高度以显露必要空间信息。例：“摄影机沿垂直方向升高，逐渐显露桌面原有物品，到达所需视点后停止。” | 摄影机实际高度改变；明确是否需要同时调整朝向，不默认变成顶拍或新增大幅运动。 |
| 小幅弧形移动 | 通过侧向视角变化看清原有关系。例：“摄影机沿人物斜前方的小幅弧线移动，停在能看清其侧脸与桌面的位置。” | 写起点、路径、终点，保持既有轴线一侧；不自动整圈环绕，不让人物无依据跟镜转身。 |
| 拉焦／焦点转移 | 同一构图内由证据转向反应。例：“前景文件先清晰；后景人物抬眼时，焦点转至其面部，文件自然虚化。” | 两处目标已在画内且有前后距离；不同时要求完全虚化的细节仍可读，不无意义往返跳焦。 |
| 主观视角 | 展示人物实际看见的对象。例：“从林悦当前站位及眼睛高度看向桌面，文件位于视线下方。” | 只写该视点可见内容，不同时写未入画的视点人物表情；POV 不自动变成 VO／OS。 |
| 俯拍或仰拍机位 | 既有高差、关系或情绪支持的观察角度。例：“摄影机低于陈默眼线，向上取景，陈默仍平视原高度的交谈者。” | 按上文区分叙事机位与人物主观视角；人物不因摄影机升降改变眼线或站位。幅度服务表演，不因仰拍自动向上摇或升降。 |
| 手持质感 | 有依据的临场观察、情绪不安或已有移动。例：“摄影位置基本保持，画框有细微不规则上下浮动，人物眼神和口型持续可辨。” | 静止对话也可选；按具体观看任务设计幅度与变化，不因高音量自动剧烈摇晃，不追加奔跑或碰撞。 |

## 区分五组易混指令

- **推近与变焦**：推近改变摄影机与主体的距离，空间透视随之改变；固定位置变焦改变焦距及取景范围，不产生同样的视点变化。不用变焦、裁切或改景别标签冒充真实换机位。
- **横移与摇镜**：横移改变摄影位置，摇镜在原位置改变朝向。转向导致真正换主拍时按主拍变化判断，不把转向本身记为移动机位。
- **升降与俯仰**：升降改变摄影机高度；俯仰描述镜头上下朝向，上下摇是其连续转动过程。固定轻仰／轻俯可以全镜不动；高度标签与真实观察角度另按下节核对。
- **拉焦与变焦**：拉焦改变清晰目标，不自动改变人物大小、景别或摄影机位置；固定机位也能拉焦。
- **后退跟拍与拉远**：人物与摄影机大致等速同向移动、相对距离保持时，取景可基本不变；距离增大才逐渐拉远。同一动作写清实际相对运动，不混写互斥的结果。

### 摄影高度与实际俯仰

离地高度、相对拍摄对象的高度和镜头朝向分别核对。主要拍脸时结合人物当前站／坐／跪／躺姿态与眼线判断；拍手、道具或空间时按实际目标及观察方向判断，不能只凭“低机位／高机位”写成仰拍／俯拍，也不把人物身高或身份直接当角度依据。

例如人物躺在床上，摄影机与其眼睛等高并水平拍脸，即使离地低也可为眼高平视；站立人物眼线下方的摄影机明确向上拍其面部时才写对应仰角。人物起身或摄影升降后，复核相对高度、朝向、取景和遮挡是否仍一致，不只沿用前镜标签。普通叙事机位仍可主动选俯仰，人物主观机位仍取真实眼位；不为匹配摄影指令改变人物眼线、姿态或站位。无需强填厘米和角度数，真实几何关系清楚即可。

### 运镜结束点与切出事件

在现有运镜描述中把已确定的触发、路径和结束构图与具体表演／信息节点联系起来：到达时需要读清什么，之后还有哪段必要变化，在哪个可观察事件切出。只写“缓推至近景、适时切换”而无其他字段提供落点时，补清已有事件；不为凑完整句式新增转头、停顿或反应。不同字段已有的同一动作或原声不再抄写，摄影描述引用对应动作节点即可。

运动结束不自动证明表演已完成，必要变化可在原区间内继续或由后镜承接；信息与必要表演已经完成则推进，不固定追加落稳、呼吸或尾帧停留。也允许在运动尚未停止时切出，此时 `end_view` 和结束景别按真实切出瞬间记录，不虚称已抵达原定终点；不能为了完整停稳拖长动作。固定镜头只保留其观看任务和实际切点，不编造运动触发。

摄影路径、速度和幅度须能在现有声画窗口内执行；放不下时调整路径、幅度或选择有任务的合法切镜，不默认把所有镜头改为固定，也不让人物慢动作等待摄影。例：原剧情已有回应指责、抬眼直视与对方接收时，可写“开始回应时沿交流轴同侧短推，由中近景收至近景；抬眼直视对方时结束推进，目光落定后切向对方的接收反应，原声连续”。实际切入与反应起点分别按信息到达判断，不能凭例句提前反应；若直视和接收并非原有表演则不套用。切镜继续检查原机位／景别条件；运镜与声音动作同期不重复计时，两种推文的已锁预算不追加摄影用时。

## 表演、动作、光影与声音配合

1. **先让表演成立**：沿用原词、视线、姿态和手位，按 [讲话肢体表达](spoken-emotion-camera.md#讲话中的肢体表达) 选择自然细节，再决定是否运镜。普通实际镜头选一个主要摄影行为；运动须有具体信息或情绪任务、起止状态和可执行路径，固定镜头不被强加触发动作。
2. **在关系中拍对白**：站位允许时保留肩背或前后景关系，过肩画面非必要不描述人物侧脸；反打按真实机位重新核对视线、背景与轴线。换主拍不删除交流对象，远距离或异地不硬塞同框。
3. **按动作衔接切镜**：前镜右手伸到中途，后镜承接同一只手、方向及相邻进度；接稳后再松手，不能跳完成或重新伸手。按 [连续动作承接](source-continuity.md#连续动作之间的承接) 将必要过程落实到实际画面；有结构记录时继续使用原动作链。
4. **让反应与原声并行**：听者收到足够信息才开始反应，原句按原区间连续覆盖。前镜声音延续到后镜画面可用 L-cut，下一画面声音先于画面进入可用 J-cut；两者均须遵守 [声画错位边界](output-template.md#声画错位的适用边界) 及 [声音连续性](spoken-emotion-camera.md#反应镜头中的声音连续性)，不改声类、不重复原词、不让听者代说。听者开口默认另起合法分镜，实际声音覆盖仍按一位发声人物规则核对。
5. **同期内容共享时间**：讲话、兼容动作和收到信息后的反应可以重叠；必须先后发生的接触过程仍按因果排列。保留真实停顿，去除摄影造成的额外停声、准备或展示时间；按 [时长规则](timing.md) 计实际区间，不以运镜或景别数量倒推延长镜头。
6. **光源按设计和空间承接**：按 [影视光影](cinematic-lighting.md) 依据剧情氛围选择布光，可调整参考图的照明并使用画外摄影光，保留空间陈设。选定后固定本场的光源方向，换机位或人物转身按空间重算受光侧，不机械复制画面左右；关键动作特写承接这套照明，动态光有真实触发、过程和结束，不为灯光新增出镜灯具或天气。
7. **声音跟随真实来源**：现场讲话、电话传声与内心 OS 区分来源和口型；钥匙接触、脚步等音效按 [时间归属](output-template.md#音效的时间归属) 对应实际触发点；每镜只写当前可听部分，已结束不复制、未来不提前。移开镜头不令仍可听的声源自动停止，跨镜只承接未结束部分并说明来源、持续依据和结束位置。保留必要环境声及原真实沉默，无背景音乐，不添配音解释动作。
8. **按信息推进节奏**：有新信息、有效反应、动作阶段或关系变化时再切，不按句号机械剪。固定镜头可以短；长动作按已有信息节点变景别，普通动作不逐项特写。看清当前信息即推进，不为技巧增加等待、慢动作或重复反应。

真人剧的无台词画面另按 [纯画面内容定时](timing.md#真人剧纯画面按内容定时)：先判断必要动作、信息辨认与情绪接收需要多久，再选择能在该过程内完成的摄影行为。3秒以内也不能默认取最长；不以“推进到位／摇镜落稳”单独增加等待。优先选择能与原声、动作及情绪过程同期完成的运动距离和速度；放不下时简化路径或选择合法切换角度，不把删光运动当成提速默认。提前切出时核对实际结束构图，不能保留原来较长运动的终点却只缩短时间标注。原声覆盖、必要动作和空间连续性仍按原规则处理。

## 提示词写法与原字段

运动镜头可按“起始景别与真实机位 → 原词／动作触发点 → 摄影路径、速度或相对距离 → 人物同期行为 → 结束构图及对应表演／信息落点 → 必要后续变化与切出事件 → 必要声音承接”组织，只写本镜适用项。固定镜头不填虚构运动。用具体可见、可听和可执行的描述，不堆设备名或“震撼运镜”等抽象评价。

例如，剧情已有向前追问并在桌边停下时，可写：“摄影机位于林悦斜前方，以中近景取景。林悦沿原走廊向前追问，摄影机同步后退，保持其面部、肩背与胸前手势可见；她到桌边停下，摄影机随之停稳。原台词连续，不因移动另加停顿。”例子不能用于为静止对白新增走路。

“运镜”填写摄影位置、角度、运动、焦点及结束构图，“画面内容”填写人物同期动作、关系和本镜原声承接，声音原句和区间仍用原声音字段。沿用 [自动填写说明](rendering.md) 的 `view/end_view`、`camera_text`、关系与动作记录，不新增“拍摄技巧”字段、不复制重复描述，也不把内部机位编号输出。

镜头选择库的景别／切点、构图规则、原文事实和时长约束继续有效。连续推拉不是硬切，但切出时仍按真实结束景别核对；变焦、拉焦或技巧名称变化不能豁免 [真实机位校验](camera-continuity.md)、跨段不同景别、连续讲话不插中全景或原声完整性。

## 返回前核对

先沿整轮剧情检查摄影表达是否缺失：关键变化是否只加强了声音／身体而无理由沿用普通交流机位；连续固定平视是否确有表达作用还是默认套用；已选的角度、运动或质感是否在排时、精简和渲染后丢失或被相反指令抵消。按实际节点回修，不把全段固定判为必错，不统计技巧比例，不用补一个手持关键词过检。

再对本次实际使用的技巧检查：是否把身份、当前施压关系和情绪稳定程度混成同一判断；摄影高度与实际俯仰是否一致；起止状态与路径是否明确且在场景中成立；相对距离、画面大小与清晰变化是否相容；人物关系、口型、必要动作和证据是否可读；反打后的视线与受光是否正确；切镜是否接住手位、道具、动作进度及原声；结束构图是否对应实际切出时点，必要表演是否已呈现或由后镜承接；信息完成后是否及时推进且没有新增等待，不强制每镜停稳后才切。

光影部分执行 [逐镜光影校验](cinematic-lighting.md#返回前光影校验)。将关键节点、摄影选择的具体依据及对应成稿表现随空间和光影结论归入已有 `delivery_review.visual_continuity`；同一轮共用判断，不逐镜新增理由字段或复制一套清单。普通无变化交流说明相应范围即可。同期动作／声音和运动耗时归入 `delivery_review.timing`，实际矛盾与修复归入 `conflicts`。修改后同步记录与正文，按 [交付校验](delivery-validation.md) 检查同一版本；结构脚本不能判断真实摄影几何、模型理解或视频效果，不能用脚本通过代替内容复核。
