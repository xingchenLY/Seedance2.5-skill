# 真人剧独立占时记录

仅在真人剧最终成稿仍有无发声覆盖、且定位器找到邻近原声的区间时使用。记录放在 `delivery_review.timing_overlap`，不输出到提示词，不为每个镜头增建表格。两种3D和推文不新增此项必填记录；纯无声且邻近也无原声时继续做原有画面内容定时，不编造比较对象。渲染阶段不要求这份成稿记录，成功渲染不等于可以交付。

先按 [台词窗口优先排时](timing.md#真人剧台词窗口优先排时) 实审并修改排法，再复核最终仍保留的区间。程序的 `timing_overlap` 提示包含每段未覆盖范围、相交镜头起点及邻近 `segment_id / speech_index`（索引从0起）和原声时间。它只是待比较窗口：不证明同场、同一时间层、角色知情或适合同期。跨段候选按实际剪辑顺序，只取直接相邻同集片段中完整包含的声音，不跨集、不跳过无声片段；复杂回忆和转场仍核对本次剧情，不照搬候选。

每个命中区间一条记录，可在一条理由中说明该区间跨镜的完整任务，不按镜头重复建记录：

```json
{
  "timing_overlap": [{
    "segment_id": "S1",
    "start": 4,
    "end": 6,
    "shot_start": 3,
    "task_evidence": "Mara 将钥匙放入锁孔后转动，锁舌弹回",
    "comparisons": [
      {
        "segment_id": "S1",
        "speech_index": 0,
        "constraint": "source_order",
        "basis": "本次原文规定先听清门外口令才开锁，前句末词才提供完整口令，不能在前句中先开锁。"
      },
      {
        "segment_id": "S1",
        "speech_index": 1,
        "constraint": "source_order",
        "basis": "本次原文规定锁舌弹回后才向门外答话，下一句不能前移到开锁过程中；原动作按自然速度连续完成。"
      }
    ]
  }]
}
```

示例依据仅为合成情境，不可套入别的剧本。字段要求：

- `segment_id/start/end` 对应最终未覆盖区间，包含不足3秒的空档；已消除的区间不保留旧记录。范围跨多个镜头仍一条，理由覆盖整个区间。
- `shot_start` 为该区间实际相交的一个镜头起点；`task_evidence` 摘取该镜最终画面中的具体可见任务／状态，不复制台词或抽象评价。内容审阅确认该证据在此无声区间确实发生，不能拿同镜更早已完成的动作充数。
- `comparisons` 覆盖定位到的每个相邻声音索引且不重复；`basis` 写该声音窗口为何不适合这一任务，不能只说“需要完整动作／情绪”。触发过晚要指出关键消息／条件；无法边做边说要指出身体冲突；观看冲突要指出两处必要信息为何不能经合法切镜共同交代。原文没规定的先后不能冒称原文要求。
- `constraint` 选择实际限制：`source_order` 原文因果；`physical` 身体或口部执行限制；`readability` 必要信息无法同期看清；`performance` 有具体阶段依据的失语、消化或沉默；`scene_boundary` 真实时空／揭露边界；`delivery_pause` 自然起声、呼吸或句尾收声。类别不是豁免，仍须本次具体依据；自然气口不自动放大成反应段。
- 若比较后可以同期，先改 `authored.json` 的动作、原声或切点并重渲染，不填“可以合并但保留”。其他约束、短镜例外和整数可行性照常执行，不能压短实测声音或必要动作。

最终校验检查区间完整覆盖、真实相交镜头、成稿证据、全部候选原声引用、类别和非空具体说明；漏项、旧时点、错镜、重复项会失败。原有 `timing` 摘要或反应 `after_basis` 不能代替这份范围绑定。程序不能证明理由真实、自然动作速度或最优节奏：这些必须根据原文及实际成稿判断，不能把字段填齐当成内容通过。没有无声区间也仍检查晚起反应和人为拉长原声。

仅含“需要完整呈现情绪变化”“给反应留时间”等已知纯套话的整条理由也会被拒绝；含具体原因的说明不因出现“完整表演”等词被删除。这是有限的套话检查，不穷举所有改写，仍须核实具体限制是否真实。

修改时间、声音、镜头或最终文本后，重算受影响范围并更新真实复核与摘要；旧制作计划可正常渲染，旧真人剧成稿在下次交付前按命中区间补齐。无工具时人工覆盖同一比较范围并如实说明，不能声称已跑程序。
