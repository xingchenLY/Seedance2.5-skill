# 人物运动过程的剪辑省略

用户已授权四模式：人物移动或身体运动的中间过程拖慢剧情、且不承载必要信息时，可适当删减过程，**保留可见起始动作和结果**。这项条件授权可用于符合条件的片段，无需每次再询问；不等于任意删剧情或略掉全部动作承接。与 [完整动作链](action-continuity.md) 共同执行：保留因果完整，不要求把无信息路程全程拍完。

## 先判断省略是否有收益

- 可选：已建立起点和方向的普通步行、重复往返、已发起的无关键接触姿态调整，或其他没有新信息的中段运动。先检查能否在已有原声时间内自然完成；完整展示已不拖慢节奏时无需强行跳切。
- 必留：起步／起手／转向的可见发起，片段原文要求的结果、新位置和朝向；路线上的发现、遮挡解除、危险、躲避、关系变化、情绪转折及观众必须看见的关键证据；必要接触、接稳、交接、松开、归属改变和作用结果。不能把这些包装成“中间过程”删掉。
- 行走本身若体现迟疑、逼近、伤势、追逐距离或逃生条件，依其实际剧情作用保留必要进程，不能只因距离长就跳。原文要求连续看清或用户锁定某段动作时仍执行该要求。
- 原文只到抬手或走近途中，结果就是该未完成阶段，不能擅自补成按下按钮、到达目的地或完成交接。

## 如何拍与剪

前镜拍清人物从既有位置发起并向已建立的目标移动；后镜用实际切点进入较后时点，呈现落脚停稳或当前结果，给足目的地锚点、朝向和仍在场人物的相对关系。不要复演起步；不靠拉远镜头强行展示整条路线，也不强加额外建立镜头。根据任务取景、自然速度和可读时间估算两端，不固定分配1秒或3秒。

三种情况必须区分：

1. **同一连续镜头**：画内运动服从距离与实际可用时间，不准把未走完的路写成瞬间到达，也不通过加速人物、慢动作、镜头摇移或遮挡声称自动省时。
2. **连续时间的切走再切回**：已起始的非关键运动可在真实经过的画外时间内推进，用 `offscreen_progress`；实际时间必须够，不凭相邻硬切虚构经过几秒。
3. **剪辑省略故事时间**：明确切掉中间无信息过程，后镜进入较后时点，用下述 `motion_ellipsis`。只缩短展示时间，不改故事空间距离、人物运动速度或事件顺序。必要时在运镜写清切法，画面说明省略对象及后镜状态。

声音仍按四模式保留全部原词、类别、顺序和唯一发声记录。旁白可以连续覆盖合适的省略画面；现场对白不能剪掉原词，不能让同一现场时刻的连续口型跨越不成立的时间省略，也不能擅自改成画外旁白。若全长原声仍需展示时间，就用原文有效信息覆盖或采用真实画外推进；不要声称删路程就能使视频短于必要原声，更不要用空等填回刚省掉的秒数。

修改后重算受影响的声画时间并集、后镜起点、音效、段长及剪辑映射；只计保留展示的区间，被省略的故事时间不累计。用户明确锁定的总长／时点不能擅改，先在锁定区间内调整有效内容。3D仍在保留片段中表现重心、启动与停止的自然缓冲、耳尾跟随等适用动画原则，不为补齐被省略的每一步而恢复整段拖沓路程。

## 内部动作链记录

后镜 beat 的 `before` 与前镜 `after` 因省略而不同，在原动作链填写：

```json
{
  "break_before": {
    "kind": "motion_ellipsis",
    "basis": "原文甲从桌边走到门口；中间走廊无新事件，整段跟拍会推迟下一句反击，按用户授权省略",
    "omitted": "甲在桌边与门口之间没有新事件的中段步行",
    "motion_keys": ["甲.position", "甲.motion_phase"],
    "start_evidence": "甲从桌边起步，朝已建立的门口迈出第一步",
    "result_evidence": "甲在门口落脚停稳，转向仍在桌边的乙",
    "resume_text": "切入较后时点，甲已到原场景门口，右手仍握手机，乙仍在桌边"
  }
}
```

`start_evidence` 须原样出现在前一个 beat 的实际 `action_text`，`result_evidence` 须在本 beat 的 `action_text`；两端仍绑定实际镜头，不能只在内部补状态。`motion_keys` 精确列省略区间实际变化的键，限以 `.position/.location/.orientation/.posture/.motion_phase` 或 `.位置/.朝向/.姿态/.动作阶段` 结尾的运动状态；已有键名需调整时全链一致，不另起链重置状态。手别、接触、持物归属等非运动状态须在省略边界保持；发生必要变化就在可见镜头内完成，不能改名为位置来规避。省略的必要性和内容语义仍须真实审阅，程序不理解自由文本。

实际切点才可用本例外；同一镜头中两条 beat 不构成剪辑，也不允许瞬移。渲染器把省略提示、恢复说明和当前动作写入本镜“画面内容”；删掉说明再刷新摘要仍不能通过。同段同场的运动时间省略，无论是否更换机位和景别，均按 [跳切记录](cut-techniques.md#时间跳切的内部记录) 填 `jump_cut_before`，其 `from_shot_start` 指实际紧前镜；动作链的证据仍指本链前一 beat，两者不一定是同一镜。跨段或跨场不套用这个仅限同段同场的切法例外，在本镜 `camera_text` 写清省略与时点，动作链仍核对 `motion_ellipsis`；只给动作例外不豁免切点规则，跨段不同景别要求保持。

## 修后核对

检查省略前后是否仍能看懂谁从哪里、朝哪里、现在到哪里；起始和结果是否真实可见；关键中途信息、接触／归属、其他在场者与原声是否保全；省略是否实际减少无信息占时，是否造成慢放、停顿、重复起手或无依据跨越。将判断落实在实际稿，并交给 [独立成稿审阅](editorial-review.md) 验收。不能为了过检回填一条未经执行的“已省略”说明。
