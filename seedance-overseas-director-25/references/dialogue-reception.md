# 对白排镜、长镜与关键听者反应

四种模式中出现人物现场／电话对白时共用本页。两种推文的叙事旁白仍按 [旁白镜头设计](narration-editing.md)；内心声、非共享 OS 和仅供观众听见的声音不能触发别人当场反应。VO 先判断实际声源与可听对象，不为使用本页把原类别改成对白。3D 的无触发耳尾摆动或循环呼吸不能充当有效接收；已有动物在信息抵达后的耳尾姿态变化可以作为主要可见反应。疯狂动物城标签按 [耳尾表演](animal-performance.md) 判断，实际可见的耳／尾用身体通道记录，不误当脸部可见证据。

## 排镜前必须作出判断

按一轮连续讲话识别：谁能听见、哪段原词足以让其理解、理解后有没有必须让观众看见的变化、当前构图能否读清。关键揭晓、指责落点、拒绝、关系转折、原文明确的反应，不因台词短而跳过；普通说明句不强造反应。原文只给对白时，可依据人物处境补自然且不改剧情的无声表演，不新增知情、决定、接触、道具操作或声音。

先沿原词找出提问／指责、证据落地、态度变化、对手接收与回应准备等实际节点，给每个必要节点选择主看对象和可读机位。关注对象或关键信息改变时主动设计切点，不先把整句装进一条固定镜头再补表情填时。切点写到对应 `shots` 的真实边界及运镜区间；声音整句一次登记，内部换画面不拆句。节点若仍在同一画面内最清楚，保留连续观察并按下文复核，不强造信息转折或逐句轮拍。

- **同框可读**：必要表情或身体变化确实在画内，距离、遮挡和景别足以辨认，可以在同框中完成该节点；这不自动证明后续整轮对白都应留在此构图。只露听者肩背不能证明眉眼／嘴角反应；肩背确实可见的收缩、松落等身体变化可以成立，但不能替代必须看到的脸部变化。
- **需要切反应**：当前画面不能看清听者必要反应，就安排能接住该变化的切点或重新组织关系构图。反应自身必须在足够信息到达后发起；为了看清已有表情前态到变化的过程，可以有任务地先切入听者，但不能提前演出尚未被触发的变化。原说话者继续原句，原声跨切不断；听者未轮到原文接话时不代口型。普通分镜一位发声者不限制摄影主体，内部切镜仍属于同一正式分镜。
- **有依据持续拍讲话者**：保留讲话者正在发展的表演，或剧情／用户明确要求暂不揭示听者反应时，说明具体观看价值与听者反应的处理。完整表演可以跨镜承接，不自动等于长镜；超过6秒的实际镜头另做下文长镜复核。不能只填“台词未说完、保持张力、完整表演、同一说话人、怕断句”。原文必须可见的接收与结果不能用该理由删掉；已安排稍后可见的反应仍按实际节点登记。
- **没有可听见的互动对象**：独处自语、对无接收人的设备讲话等据实说明。不能因为听者没有台词、未列出镜名单或暂在画外，就认定没有听者；电话另一端也可能需要反应。

按 [触发与阶段判断](spoken-emotion-camera.md#反应合并前的触发与阶段判断) 确认足够信息及可共存阶段后，默认与余下台词同期呈现反应，不把整轮话都说完才考虑听者。后置否定、条件或句末揭晓必须等完整语义；原文要求听完、必要沉默或反应可读性确需句后处理时保留依据。反应可以承接原定本人接话，但只合并能自然讲话的阶段，不把必要失语、理解与全部余波一并压短；不重演，也不额外给每句加停顿。一个关键反应后可以继续留在听者，不强制回讲话者，更不轮拍所有在场者。

“声音同期”只处理时间关系，“同框”才是摄影选择；合并时间、同一 `frame_id` 或一位发声者都不要求合并实际镜头。先选能读清关键表演的机位，再满足轴线、景别与真实换机位规则；存在必要反应时，不能以怕过检为由取消切镜。正反打参考图按实际切点选用并分别描述站位，不为凑两张图强切，也不因只引一张图取消剧情需要的反打。

切入听者镜头的时刻、足够信息被听清的时刻、反应开始的时刻分别判断。先切入时只承接已有前态，信息抵达后再变化，不固定额外留一秒前态，也不以无信息等待填长镜。有结构化记录时，`shot.start` 记录切入，`trigger.heard_at` 记录听清，反应节点的 `start` 记录实际发起；镜头可先开始，反应不得早于信息到达，跨段仍按实际播放顺序比较各自的本地时刻。不把整镜起点反填为听清时间或反应开始，不增加字段、不放宽原有时间与长镜检查。

例如一段12秒原台词，可以在0–4秒拍讲话者提出指责，4–7秒在关键意思已被听懂后切听者，7–12秒按新的表演重点留在听者或切回讲话者。全程只有原讲话者的连续台词，听者不代口型；时长与机位须按实际原词和场景调整，此例不是三镜配额。

## 双人画面的任务结束点

双人中近景用于必须同时看见的共同动作、关系变化或同步反应；不能仅因双方都在画内，就让整轮对白留在该构图。确定当前主要观看对象和任务完成点，出现需强调的单方情绪或另一方必要接收时，比较真实反打、单主体过肩或合适单人近景。无需等到6秒才切，也不逐句轮拍。

单主体清晰、另一人仅作肩背前景的过肩镜头不算双人主拍；在场名单、同框人数和焦点同样不能代替观看重点。程序对持续双人对白给出候选，结合 [镜头排列](shot-sequence.md) 修复或说明当前区间仍需同看的具体变化。不得用“关系稳定、双方都可见”单独放行，不强行拉远展示全部动作；原声跨切连续，合并时间不等于合并镜头。

## 讲话者关键表演覆盖

在安排听者反应的同一轮排镜中，也从原文、人物处境和本轮有依据的表演设计核对讲话者是否有必须被看见的变化，例如试探转为决绝、强撑转为失控或原文明示的表情破绽；不能为增加镜头虚构新动机、暴露剧情未揭晓的秘密或给普通说明句强加转折。判断的是具体可见表演，不是“这句由谁说”或谁露过一次脸。只有声音力度变化、可由原声完整传达且无必要视觉变化时，不据此强制切回。

- **需要呈现时**：在变化真实发生的区间安排讲话者可读的镜头，或确认现有同框构图已能读清。只在段首名单、肩背前景或音色括号出现，不能证明需要看清的面部变化已呈现；切回时变化已经全部结束，也不能冒充覆盖了必要过程。镜头要保留相应前态、关键变化和必要落点，不要求从头到尾一直拍讲话者。
- **没有必要切回时**：听者反应仍是主要观看任务、讲话者无新的必要可见变化，或其表演已在同框中有效呈现，可以继续留在听者。不设每句／每轮必拍讲话者、不设开口露脸配额，也不要求每次反应后切回。原文要求隐藏说话者、画外声、VO／OS、内心声与叙事旁白仍守声音分类及揭露边界，不为本检查让其入画开口。
- **双方关键变化接近时**：结合真实发生时点重排切点、角度或有效关系构图；不能为了轮流露脸提前听者反应、延后本已发生的讲话者变化或重演同一动作。必要面部情绪继续优先于强行用远景装下双方；近景、中近景及必要短特写按模式和既有时长规则选择。若当前窗口确实容不下必要内容，回修受影响设计并按该模式预算处理，不擅加声音、停顿或秒数。

最终对照原句和实际镜头检查：需要看见的讲话者表演在哪里发生、是否真正可读、是否为补回讲话者漏掉听者的关键接收。改排后仍按 [相邻切点条件](shot-selection.md#相邻景别切换条件与替代) 核对实际景别、真实机位、轴线与跨段边界，不能只把主拍姓名换回来。复用已有画面、动作与表演记录及 `delivery_review.visual_continuity`；同一原声跨镜连续且只登记一次，画面不复制台词全文。无需新增模板字段或每句表演表，程序通过不替代本项内容判断。

## 结构化记录

生成记录按实际 `playback` 顺序，将同一集、同一人连续的 `dialogue` 合为一轮；换发声者、换声音类别或换集结束该轮。换 `source_id`、实际镜头、正式分镜、生成段或插入无声空隙不自动重置。真实时空变化在依据和节点中区分，不为了避检拆轮。

一轮累计发声区间超过 **6秒**，在该轮第一条 `speech` 填 `dialogue_review`；这是内部复核触发线，**不是六秒必切或镜头时长上限**。短对白有关键接收也填写：在对应 `sources` 添加 `reaction_targets: ["听者姓名"]`，将原文明确／本次内容分析认定必须可见的接收对象锚定到源句，脚本要求对应节点覆盖。原文没有、分析漏标的关键反应无法由脚本自行推断，仍须逐轮内容复核。

关键接收需要指定可见部位时，在对应源句添加 `reaction_channels: {"听者姓名": "face"}` 或 `"body"`；它同时声明该听者必须被覆盖，无需重复填写 `reaction_targets`。必须看清目光、眉眼、嘴角或面部情绪转折时使用 `face`，不能为了保留肩背构图改成 `body`。仅需身体变化／已有动物耳尾且确实可见时可用 `body`；不把所有反应一律规定为脸部。通道依据先从原文任务判断，再排镜，不能从已有构图反推。

最常用的 `covered` 示例（合成示例，时间须按实际语速核定）：

```json
{
  "dialogue_review": {
    "mode": "covered",
    "listeners": ["Elias"],
    "basis": "Elias 在场听见 Mara 的钱款指责；原文要求他避开目光后望回。",
    "reactions": [{
      "listener": "Elias",
      "trigger": {"segment_id": "S1", "speech_index": 0, "quote": "You lied to me about the money.", "heard_at": 3},
      "segment_id": "S1", "shot_start": 3, "start": 3, "end": 5,
      "channel": "face",
      "visibility_evidence": "Elias 正脸与眉眼清楚可见",
      "evidence": "Elias 听清钱款指责后目光短暂避开，再重新看向 Mara；他保持闭口，不替 Mara 对口型"
    }]
  }
}
```

- `speech_index` 从0开始；`heard_at` 是该声音所属生成段的本地时刻，指足够语义已被听见，必须晚于该声音起声且不超出结束。`quote` 必须来自这一条原声音，选择能支撑本次反应并区分重复出现位置的简短完整片段，不能拿未来信息触发当前反应。它定位听见内容，反应自身的消化／克制延迟留在反应区间；不能把延迟后的反应开始时刻反填为听见时间。同一声音中唯一可定位片段的听见顺序不得与原词结束位置顺序相反；这只能发现部分矛盾，不是逐词对齐。具体时间仍须对照目标语种、原句语气、后置条件／否定及已有音频复核，无音频依实际语义估计，不由字数比例自动认证，也不因没有音频停止制作。
- 每个反应节点对应一个实际镜头。`segment_id / shot_start / start / end` 为反应所在段及镜内本地秒数。跨镜发展的同一反应分阶段承接，不重复发起；跨段／回忆按实际播放顺序比较信息到达。若当前节点在整轮对白结束后开始（包括此前已发起反应的延续阶段），复用 `after_basis` 说明是必要的句后初始反应，还是承接哪一已起状态，以及为何可与原定下一句共存或必须独立；不能只填“等说完”。填写此依据不要求重演反应或增加停顿。
- `listeners` 只列本轮需审视的相关听者；`covered` 下每人至少有对应可见节点，不自动覆盖所有群众。不同关键源句分别登记其反应落点，不能用开头一次点头覆盖后面所有揭晓。
- `channel` 为 `face` 或 `body`。`visibility_evidence` 是当前 `camera_text`、`visual_text` 或该听者的 `relation.placements[].placement` 中含姓名的原文摘录；面部通道明确正脸／侧脸等可读条件。背对／肩背构图不能声称清晰脸部反应；身体通道按真实可见部位和变化审阅，不是绕过脸部可见性的开关。
- `evidence` 写带姓名的具体起态、已经听清的关键含义、由此引发的变化及落点；不能只填“听到原句后神情变化”，也不能把原句指责改述成已原谅等另一事件。跨镜／接话只承接仍在继续的阶段。渲染器将实际时段与 `evidence` 写入对应“画面内容”；`trigger.quote` 保留在内部核对原词、来源和听见时点，不再作为引文输出，以免模型再次朗读。手写字段不重复同一段动作或抄入完整台词；分类、内部理由、索引不输出。执行 [同段切镜不重新起句](output-template.md#同段切镜不重新起句)，声音行与实际切点保持原设计。

确有理由持续拍讲话者时用 `mode: "hold_speaker"`，保留 `listeners` 与具体 `basis`，`reactions` 为空或省略，另填：

```json
{
  "hold": {
    "reason": "speaker_performance",
    "why": "连续保留 Mara 从勉强辩解到说出承认的过程，本段没有要求立即展示 Elias 的判断。",
    "segment_id": "S1", "shot_start": 0,
    "evidence": "Mara 尝试维持的笑容消失，话音从急于解释转为低声承认"
  }
}
```

`reason` 为 `speaker_performance / deliberate_withholding / user_requested`；最后一项须有实际用户要求。`evidence` 摘自这轮对白覆盖镜头的 `visual_text`，在成稿同一区间保留。未拍听者的具体价值及原文依据由内容复核确认；不能自动套理由。已标记 `reaction_targets` 的源句不能改用该模式放行。

确无接收人时用 `mode: "no_listener", listeners: [], basis: "具体情境及无听者依据"`，不填写反应或 hold。脚本不凭角色名单猜谁听见，因此该结论必须对原文复核。

## 对白实际长镜复核

上述 `dialogue_review` 判断听者如何接收；它不批准长镜。四模式中，任何承载 `dialogue` 的实际镜头总长超过6秒，默认回到信息节点重新分镜。按整个镜头计算，包括前后无声区间；只缩短发声区间、改编号、换 `source_id`、填写 `covered / hold_speaker / no_listener` 都不豁免。6秒不是必须等待的切点，也不是每6秒强切一次；短于6秒仍需切到当前构图无法呈现的必要反应。

确有不可替代的连续观察价值或实际用户长镜要求时，在该 `shot` 填 `dialogue_visual`。使用下列对白专用阶段和备选切点结构，只保存本次对白的依据；叙事旁白的小于3秒硬限制不使用本项长镜例外，不给剧模式添加 `narration_visual` 或独立旁白。原句、语种、发声时长和声音情绪保持。

- `mode: "progression"`；`basis` 写原词／原情境支持的持续观看任务。
- `beats` 至少两个不同阶段，`start / end` 连续覆盖整个实际镜头。每阶段填写 `change`（`action_progress / reveal / relationship_change / performance_turn`）、`new_information` 和 `visual_evidence`。新增信息摘自本阶段具体可见表演；不能靠换一种说法重复皱眉、注视、耳尾摆动，也不以多加手势造阶段。
- `long_take.reason` 用 `continuous_action / gradual_reveal / relationship_transition / performance_arc / user_requested`；`why_uncut` 明确持续看见什么变化，以及为何值得一直看。
- `long_take.cut_review` 必须比较本镜内部一个有意义的候选切点：`at` 是段内秒数，`next_view` 写具体对象与构图，`loss_if_cut` 写切走会漏掉的必要可见阶段。对照原词或动作说明时点；不能故意选无关空镜来证明不切。若反应可以在另一合法镜头看清、讲话者的必要动作也能承接，就采用切镜方案。无听者时比较有任务的关系、行动或其他合法观察角度，不虚构听者或证据。
- 用户指定长镜时，另在 `cut_review.user_basis` 摘录实际要求；`finish_evidence` 摘录最后阶段的自然结束结果。不得填“台词讲完”作为唯一结束证据。

例如原句从强硬指责转到信任破裂、最后恢复边界，只有必须连续看见这次表演转折时才保留长镜；需写出各阶段姿态／视线的真实变化，以及具体切到听者会漏掉哪个必要瞬间。只有“完整表演、保持张力、声音连续”不放行。已有动物耳尾可承担真实态度转折，不因使用身体通道被否定；无信息循环仍不算阶段。

渲染器把 `beats[].visual_evidence` 连同区间写进本镜“画面内容”，不在 `visual_text` 重复填写同一段。理由、备选方案与内部字段不进入正式提示词。最终校验核对阶段、时段、切点记录和实际成稿证据；记录充分仍需判断长镜是否真比切镜更有价值，不能批量套用同一份理由。

## 成稿验收

反应证据存在后仍按 [情绪与肢体复核](emotion-performance.md#返回前复核) 判断是否接住这条信息的分量：主要姿态／原有动作怎样受影响，关键变化是否可见、是否承接后续原回应。重大揭晓若通篇只写“闭口看着、眉心微动”且无有据的掩饰／受限／静止价值，回修具体表演；不强制听者更大声、更大动作，也不擅造认错、退让或新决定。`covered` 只表示记录覆盖，不能当成表演强度已经合适。

先按 [触发与阶段判断](spoken-emotion-camera.md#反应合并前的触发与阶段判断) 对照原文确认反应含义、关键接收及可合并阶段，再跑结构校验：缺少长轮次判断、关键源句目标漏拍、引用了别轮声音、整句起声瞬间就标为已听清触发、已登记唯一片段听见顺序倒置、反应提前、反应区间落错镜、面部反应仅由肩背构图支撑，均退回设计。成稿删掉／挪错具体语义因果、反应或可见性证据，即使重算摘要也不能通过。不可为通过新检查把零时点一律改为0.1秒；须回到真实信息位置重排。未发现顺序错误不证明具体触发秒数或表演含义正确。

再沿实际镜头序列检查：哪里改变观看任务、哪里切到必要接收、哪里刻意保持；不能以正式分镜标题数代替切镜数，也不能每个短句都机械换人。承载对白的实际长镜缺少 `dialogue_visual`、备选切点、不同阶段或自然落点，源句要求 `face` 却只交付 `body`，均回修；反应有记录不等于镜头设计已合格。生成视频只有在实际查看后才能确认切镜执行，文本校验不代替样片检查。

四种模式的同一正式分镜内有多个实际镜头时，都明确写真实切点；不存在“声音还连续所以画面不切”的例外。优先保留作者写明的切法，未写切法默认补内部硬切；若又要求整段不切、与前镜连续或禁用默认硬切，先解决实际镜头设计冲突，不叠加矛盾指令。原有真人剧景别、机位、轴线及跨段构图检查继续执行。

将源句触发、可见反应／保留长镜依据及实际成稿核对结果并入既有 `delivery_review.visual_continuity`。程序能检查引用、时序、证据绑定与少量明确矛盾；不能证明人物表演自然、每个关键点都被分析出来或生成视频一定切镜。无工具时按同样口径人工核对，不宣称跑过程序。

真人剧的 `after_basis` 只解释该反应节点，不能代替 [独立占时比较](timing-overlap-records.md)。长对白接收检查未触发的短句与普通动作仍按 [窗口优先排时](timing.md#真人剧台词窗口优先排时) 处理。切入听者的时点、反应实际开始和本人随后开口分别判断，不从切点推断已知情，也不以“完整表演”为由默认等整句说完。

## 短对白中的特写检查

不到6秒的对白也按 [特写时长与必要例外](closeup-duration.md) 检查：普通完整句不默认占用一个面部特写。明确特写要读清的变化及其结束点，剩余原声覆盖下一有依据的画面；必要时先用近景／中近景承载讲话，只在关键落点进入特写。任何时长都从原文复核必要听者反应，未登记接收节点不构成无反应证明；不可为了凑切镜提前反应或让听者无信息地露脸。同一声音事件／正式分镜可包含多个实际镜头，切镜不拆声、不重读。
