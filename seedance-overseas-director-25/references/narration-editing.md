# 连续旁白的镜头设计与长镜复核

“3D漫推文／推文”共用本节。先按 [旁白画面信息覆盖](narration-coverage.md) 补全必要信息，再按 [自然结束点](narration-coverage.md#自然结束点与声画时长匹配) 决定各镜时间；约2–4秒是参考，不是待填满的动作预算。本节只处理确有必要的长镜及切点。声音保持一条完整记录，画面独立安排实际镜头；3D的动作连贯、口型约束与风格稳定都不要求旁白一镜到底。

## 先安排观看任务，再决定保留长镜

1. 沿原文确定当下事件、关注对象、证据揭示、关系／态度转折，以及观众何时可以知道这些信息。先为这些节点选择合适的观察对象、范围与落点，不先建一条覆盖整句旁白的镜头再补动作填满。
2. 任务或必要观察对象改变时，优先考虑有动机的实际切镜；同一任务可在一个正式分镜中容纳多个实际镜头。新独立任务按既有规则另起正式分镜，不把所有节点改叫“整体氛围”合并。
3. 原旁白按完整区间连续覆盖这些镜头，起声位置写一次原句，后镜明确承接。画面切点无需等句末，不拆声音记录、不重复起句、不为切镜停顿，也不让画面提前揭露原文尚未允许的信息。
4. 只有持续观察本身有具体价值时，才保留长镜：如连续行进中逐步揭示出口、完整交互的因果过程、关系变化，或有原文依据的完整表演转折。写清未切断观察能让观众看懂什么，以及镜头在哪个可见结果结束。

“一句旁白／一条 speech”“一个生成段”“一个正式分镜”和“一个实际镜头”分开核对。`speech` 记录数量不决定镜头数；`shots` 每条是一个实际镜头；相同 `frame_id` 只是正式分镜分组。一个分镜标题下有多个时间段，也要看运镜是否真的写出切换；画面里的分时动作阶段、变焦或焦点移动仍可能是同一镜。

例如原剧情依次呈现“围观者等待接花 → 伊森递出花束 → 佐伊看向手机”，可以让一条完整旁白连续覆盖三个实际镜头；每个镜头有自己的观察任务与真实机位。此例不规定镜头数、时长或固定组接顺序，仍遵守人物关系、轴线、景别及动作承接规则。

## 长镜必须提供新的可见信息

实际镜头承载任何叙事旁白且总时长超过6秒时，默认回到分镜设计；确需保留才填写 `narration_visual`。计算整个镜头，包括开头／末尾无声或其他声音部分，旁白只占其中几秒也检查。具体长镜依据、阶段新信息、自然结束证据与备选切点评估全部具备才进入内容复核，不增加正式提示词字段。

- `basis`：原文中支持本镜持续任务的具体依据，不用成稿反推剧情。
- `long_take.reason`：`continuous_action`（连续行动）、`gradual_reveal`（逐步揭示）、`relationship_transition`（关系转变）、`performance_arc`（完整表演转折）或 `user_requested`（用户明确要求）。类型标签不能代替下面的理由。
- `long_take.why_uncut`：连续观察的具体价值。仅“旁白还没讲完、避免断句、保持张力、动作连贯、人物闭口”不足以支持长镜；用户明确要求时记录实际要求，仍保留源文与表演事实。
- `long_take.cut_review`：必须具体比较一个本镜内的备选切点。`at` 为本段内、位于本镜开始与结束之间的时刻；`next_view` 写切到哪个对象、关系或细节；`loss_if_cut` 写切开会丢失哪一项必要观察，而非“保持张力、动作连贯、避免断句”。只有真有不能由合法后镜承接的必要损失才保留；找不到则采用分镜方案。`user_requested` 另填 `user_basis` 摘录实际用户长镜要求，不伪造授权。
- `long_take.finish_evidence`：从最后一个阶段的 `visual_evidence` 摘录镜头自然结束时的可见结果，不能仅写“旁白结束”。
- 每个 `beat` 沿用 `start/end/visual_evidence`，另填 `change` 与 `new_information`。`change` 从 `action_progress`、`reveal`、`relationship_change`、`performance_turn` 选择；`new_information` 摘录本阶段画面描述中相较前态新增的可见进展。

```json
{
  "mode": "progression",
  "basis": "本合成示例假定原文要求连续确认出口属于当前通道，并看清人物抵达后试门把的过程",
  "long_take": {
    "reason": "continuous_action",
    "why_uncut": "持续看清人物接近出口的距离变化与到门前试门把的动作衔接",
    "finish_evidence": "右手握住门把下压，门把受阻未转动",
    "cut_review": {
      "at": 4,
      "next_view": "切到门把与右手的接触处",
      "loss_if_cut": "本例需要连续确认出口与原通道的关系，此时切到手部会丢失通道抵达出口的空间揭示"
    }
  },
  "beats": [
    {
      "start": 0, "end": 4,
      "change": "reveal",
      "new_information": "原通道出口逐渐进入画面",
      "visual_evidence": "玛雅沿走廊向门口走，原通道出口逐渐进入画面"
    },
    {
      "start": 4, "end": 8,
      "change": "action_progress",
      "new_information": "右手握住门把下压，门把受阻未转动",
      "visual_evidence": "玛雅在门前停稳，右手握住门把下压，门把受阻未转动"
    }
  ]
}
```

仅在原文支持这些事实时采用，示例不授权新增门锁或受阻事件。摄像机或主体观察关系改变时同步维护 `end_view`；长镜复核不豁免结束构图与下一镜切点检查。

至少两个阶段须有不同的实际进展，时间覆盖整个镜头，不能靠“抬眼、继续注视、眉心收紧、更加紧绷”改写同一状态。3D耳尾轻摆、毛发飘动、随机眨眼、持续呼吸或无信息慢推也不单独构成新的叙事阶段。细微表演本身可以有价值；若承担真实态度转折，应明确原文触发、前后差异和可见落点，而非仅写更强的表情形容词。已有动物的耳尾可成为这一转折的主要通道，不能因不是人类式面部／手势就判无信息；疯狂动物城标签按 [耳尾表演](animal-performance.md) 执行。

6秒是需要例外复核的界线，默认镜头更短；它不是要求等到第6秒才切。4–6秒仍须有充分可读过程，超过6秒默认重分，保留长镜须证明具体备选切点会损失必要信息。不得按秒数机械拆分；不足6秒的空转、多镜重复以及整集每段都机械采用一个长镜仍须内容复核。不要为绕过阈值改编号、把一个实际镜头伪拆成多条记录或拉慢动作；有实际切镜也不能靠无关空镜、重复反应凑数。静态连续展示≤2秒、真人剧摄影库与原句保留规则继续生效。

## 明确实际内部切点

四种模式共用明确切点的渲染规则；本页将它用于两种推文的连续旁白。同一正式分镜的第二个及后续实际镜头要在对应“运镜”区间明确切入方式。渲染器在没有已写切法时补“内部硬切至本镜。”；已写硬切、反打切入、叠化、匹配剪辑等则沿用，不重复添加硬切。已有时间跳切记录继续按其原规则处理，不利用自动标签放宽合法切点。

若作者明确禁用硬切却未指定其他切法，或写“接前镜连续”却另建实际镜头，先修正设计，不能自动覆盖其意图。连续运动应作为一个实际镜头记录；切入后在新镜头中继续推近是合法情况。切镜前后保留同一动作进度，不因增加镜头重新递花、重新起手或重复反应。

## 最终检查

- 先按 [画面信息覆盖](narration-coverage.md) 对照原文检查人物、对象、过程、结果是否完整；再看真实镜头数、各镜观看任务及切点，最后看正式分镜标题和声音行。一个正式分镜内可有多个实际镜头，标题长不等于一镜到底。
- 程序按整个实际镜头时长核对长镜理由、备选切点记录、新信息所属阶段、重复信息、自然结束证据与原有时间覆盖；识别有限的纯表情／空转措辞。阶段信息写在其他阶段、只写在内部记录或修改正文后未同步，都不能用重新计算摘要代替检查。
- 最终“画面内容”必须包含各阶段的实际证据；内部切法必须出现在后镜对应的“运镜”区间，删去、移到前镜或改成否定指令会报错。已经安排多镜时，不能再写“整段一镜到底／本段全程不切镜”。
- 内容复核并入既有 `delivery_review.visual_continuity`，核对原文任务、长镜取舍与实际可拍性。脚本不能证明所有语义变化有效，也不能证明视频模型执行了切镜；没有看过视频时只报告提示词与记录检查结果。

此前的旁白完整连读、逐镜非讲话表演及跨段首尾构图校验继续执行。修复镜头设计不改变实际发声者、音色、原词、原定时间或揭露顺序。
