# 3D导演共同规则

生成或分析3D分镜时读取，并按 [动画十二原则应用](animation-principles.md) 设计和复核具体动作，覆盖通用3D、3D人类及已有动物。这里把原真人导演的摄影和表演逻辑转换为动画制作语言；原剧情、台词、时长与连续性仍由主技能及其专题管理。可选风格只能细化表现，不能更改故事事实。

## 角色、空间与材质基准

先确定实际角色、物种、年龄感、轮廓与相对身高、身体比例、五官辨识点和已有状态；有素材则实际查看。人类参考保留可识别特征，转换为经过形体概括的3D角色。不得把所有年龄做成同一幼态脸，也不因风格标签加耳朵、尾巴或毛皮。明确动物化时保持人物身份关系和已确定物种，并核对抓握、口型、身高差和道具尺度。

将场景转为连续的3D空间：保留门窗、通道、桌椅、固定灯具与可交互表面；角色脚底落在地面，手与道具有真实接触，动作中的重心能支撑身体。允许概括非关键碎细节，但不能重排证据位置或为视觉丰富加布景。

材质以光泽、粗糙度、反射和适度透光区分已有表面；轮廓与表情优先于细节密度。人类使用有体积和柔和明暗过渡的皮肤、分束头发；只有已有动物才使用毛发组织、耳尾和口鼻结构。不要用摄影毛孔、锐化噪点、统一塑料高光或无处不在的毛绒替代3D质感。服装沿素材与原技能边界，不新写服装款式、颜色、材质或图案。

同场固定角色造型、比例和材质基准。改变机位、表情或受光不等于换脸、改变眼睛大小、毛长或骨架。伤病、变身和时间变化只更新剧情要求的部分。

## 姿态与动画表演

按“剧情诉求 → 可读姿态 → 动作主线 → 表情／声音”设计。动作可有预备、发力、弧线路径、接触、跟随与落稳，但这些是同一动作的自然组成，不逐项加镜头或空等。小动作不用强加明显预备；不可提前暴露角色尚未知道的信息。

- 先让身体轮廓、肩胯关系和重心读得清，再放眉眼、嘴部与手势；一轮对白选有目的的姿态变化，不逐词摆姿势。脸部、身体和声音服务同一意图，角色掩饰情绪时允许表层克制与身体压力不同。
- 夸张强度按处境选择：克制可有明确的压住动作与残留张力；外放可扩大姿态开合、躯干转向和手臂弧线，并用起动、制动与跟随形成可读节奏。肩胯、头部和手臂服务同一动作，不全身机械同时启动／停住，也不为补十二原则逐项表演。严肃伤痛、羞辱、威胁不自动变成喜剧，情绪外放不等于所有角色跳跃或瞪眼。
- 对白口型以原音同步为先，嘴角和下颌动作不遮蔽读词；听者只在信息足够后反应，反应可与说话者后半句重叠。原词、类别与声源不变；不能为了动画节拍快读或新增喘息、尖叫。
- 重量通过起动速度、减速、脚底支撑、接触反馈体现。急停后头发或既有耳尾可稍后落稳；物理跟随与交叠体现驱动和惯性，次要动作则补充主要表演，两者不混为一项，均不能破坏握物接触或遮挡线索。耳尾的惯性跟随从属于身体动作，但有剧情触发的耳尾姿态变化可以承担主要情绪表达，与面部、躯干分工，不限定为补充。疯狂动物城标签下的已有动物按 [耳尾表演](animal-performance.md) 主动设计，不能持续机械摆动。
- 有依据的挤压拉伸和夸张服务动作可读性，部位、强度与恢复按已选风格及本次情绪设计，保持总体积感、基础造型和身份稳定；不能把“保持模型一致”变成全身刚硬，也不默认都压成微动。默认不做无依据的橡皮肢体、眼球弹出、骨架拉长、速度线和撞击星星；刚性道具不随表情变软。用户选择的其他风格明确需要时，按其规则和原剧情范围处理。

两种3D共用的是摄影与连续性规则，表演幅度和动作节奏按已选动画风格选择。关键情绪先按 [强弱差异](emotion-performance.md#关键情绪的强弱差异) 设计可读的姿态轮廓与身体主线，再落实表情和原声；普通交流不强造夸张。有结构且可见的动物耳尾可成为主要表达并与躯干协同，不总是尾端轻摆，也不要求耳尾同时动作。对白按 [情绪优先与动作取景](shot-selection.md#对白情绪优先与动作取景) 保留当前主要耳尾／姿态或面部变化，身体过程可跨镜共同交代，不为完整轮廓扩大取景。必要中景须有具体任务，不为动画放宽对白宽景限制或把画外肢体写成可见。

## 虚拟摄影与画面层次

延续原轴线、景别、主拍与声源规则。9:16下优先保住本节点主要表演通道和关系前景：动物耳部承担反应时保住必要耳根／耳尖，尾部承担反应时确认部位归属与动作可见，再兼顾表情、手势；身高差通过相应机位与前后层次处理，不能为同框改变角色比例或让人物漂浮。背景细节在主体附近适度简化，用明度、色块和清晰度区分前中后景，不靠极浅景深遮住必要证据。

虚拟摄影仍需起点、路径、触发和落稳；没有叙事任务时保持稳定。动画形式不授权穿墙、穿人、任意环绕和跨轴。镜头间共享人物状态、物体尺寸、接触位置与动作进度。

## 光色与渲染设计

先确定时段、实际空间光源和情绪任务，再选主色群、辅助色群及有限强调色。背景饱和度和高光面积服务关注点，不给每个表面同等亮度。根据剧情在清亮日常、压迫对峙、亲密或悬念之间调整，但同一场景内不随每句情绪跳光变色。

用主光建立体积，环境反射光保留暗部信息，必要时用有空间依据的轮廓分离；脚底、握持和碰触处有接触阴影。已有透明／半透明材质、毛发或皮肤可有适度透光和反射，但不能把所有材质都做成蜡或玻璃。没有雾、水或粒子条件时不凭空加体积光、焦散或漂浮尘屑。

灯光方向以场景空间锚定，正反打重算受光；材质与角色配色跨镜稳定。色调设计可与参考照片不同，但固定空间和剧情必要日夜保持。8K等词是提示词约定，不声称平台已实现某分辨率、渲染器或物理仿真功能。

面部表现按 [面部色彩与轻微脸红](concrete-language.md#面部色彩与轻微脸红) 处理：符合情境与既有造型的脸颊淡红晕、眼眶微红可以保留，眼眶不做鲜红整圈或发光眼球；受控形变与夸张不授权整脸变色、染红动物毛发或改变斑纹。原文明示的面部视效按其指定部位、程度及过程允许，其他特征稳定；不能以颜色关键词一律删去合法表演或剧情变化。

## 返回前复核

对实际最终提示词完成以下检查，结论并入既有内部内容复核，无须另增正式字段：

1. **风格落地**：每段标签一致，有可执行的造型／表演／光色描述，未同时残留真人实拍或另一风格的互斥要求；未把作品名当全部指令。
2. **身份与资产**：年龄、物种、比例和参考特征稳定，未未经授权动物化；空间与道具尺度对应本段实际角色，未因风格新增事件或素材。
3. **动作与声音**：按 [十二原则内容复核](animation-principles.md#返回前内容复核) 检查相关方法是否落入可见表演、动作物理与角色意图；疯狂动物城标签下已有动物另按 [耳尾表演复核](animal-performance.md#返回前内容复核) 检查采用程度、触发、力度、可见性与跨镜状态，不以“辅助动作”省略。重量、抓握、脚底和必要接触成立，预备、缓入缓出与跟随未拖长时长；受控形变不混同模型跳变，台词及嘴部归属完整，听者不提前反应。
4. **光影与可读性**：口型、手势、证据仍可辨；明暗、光源方向、配色和材质跨镜连续，反打没有直接复制受光侧；没有堆叠高光、雾和景深遮住信息。

提示词语义复核只能判断设计是否自洽，不能证明生成画面无穿模、无闪烁或达到指定质量。只有拿到实际视频并查看后，才可报告对应视频缺陷已修复。

## 两种3D模式的声音差异

3D漫真人剧使用人物台词、VO、OS；3D漫推文另保留中性叙事旁白和内心声。无论角色是人类还是动物，非现场旁白／内心声都不对口型；动物对白按原口鼻结构自然开合，不贴人类嘴。无触发的耳尾循环、毛发细节或随机眨眼不能替代推文长旁白的信息推进；有明确触发、前后态差异与可见落点的耳尾表演可以承担真实态度转折，不一概排除。旁白按原信息节点与画面并行，不让动作重演或慢做来凑满声音。
