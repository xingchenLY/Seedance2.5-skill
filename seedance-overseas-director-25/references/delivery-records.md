# 交付记录的扩展说明

只在对应字段、例外或报错需要时读取相关小节。完整 `scene_characters` 用于派生段首“出镜人物”与核对全部在场者的位置，包含全段画外人员；`relation.characters/placements` 仍只收本镜可见者及当前需承接的画外对象，不每镜重复全场位置。普通生成先使用 [渲染记录表](rendering.md)，最终步骤统一见 [交付检查](delivery-validation.md)。


先从源文建立 `sources`、必要的 `events` 和 [动作链记录](action-continuity.md)，不要从生成结果倒推来源。一次固定译文、声音类别、剧情文字、场景映射和来源定位，先核算不可压缩的发声与关键动作，再设计镜头与时间线。有工具时优先按 [自动填写模板](rendering.md) 共用一份原句、时间与导演描述，生成正式文本及派生记录；复杂记录查 [结构化说明](validation.md) 的对应章节；跨段仅更新有变化的状态，避免重新翻译、重建场景或从成稿倒推记录。

有本地文件与 Python 时，将记录保存为 `plan.json`、最终交付的完整纯文本保存为 UTF-8 `final.txt`，放在本次工作目录。不要把文件写到技能目录。命令名 `python` 不可用时先查找当前环境提供的 Python 运行时，确实没有这些工具时逐项人工核对，不能声称执行了脚本。

最终记录顶层必须有 `action_tracks`，按 [动作链记录与输出校验](action-continuity.md) 覆盖需承接的原文动作及自然表演；没有相关变化才显式填 `[]`。各链前后状态、必要结束状态与本镜动作文字分别检查，不能只核对特写。

交付用的每个 `segment` 在原记录上增加 `cast`，每个实际 `shot` 增加：

```json
{
  "start": 0,
  "end": 2,
  "frame_id": "分镜一",
  "start_scale": "中近景",
  "end_scale": "中近景",
  "start_camera": "对话区机位A",
  "end_camera": "对话区机位A",
  "start_subject": "Mara",
  "end_subject": "Mara",
  "visible_characters": ["Mara", "Elias"],
  "relation": {
    "mode": "same_scene",
    "characters": ["Mara", "Elias"],
    "scene_characters": ["Mara", "Elias"],
    "placements": [
      {"character": "Mara", "visibility": "visible", "placement": "位于右后方桌北端，面向 Elias"},
      {"character": "Elias", "visibility": "visible", "placement": "以肩背留在左前景桌南端，与 Mara 隔桌相对"}
    ],
    "evidence": "Elias 的肩背留在左前景，Mara 位于右侧中近景，目光落向 Elias。"
  }
}
```

- `frame_id` 等于正式分镜标题中括号之前的名称，多个实际镜头可归属同一个分镜，归属必须连续。正式文本仍不增加子镜头标题。
- 景别取主要叙事主体的真实起止取景：远景、全景、中全景、中景、中近景、近景、面部特写、手部特写、动作特写、道具特写。不能改名字掩盖实际禁切；器官级大特写仍禁止。连续推拉的起止景别分别记录。
- `start_camera`／`end_camera` 是可区分实际机位的内部标识，同一物理机位必须用相同标识；只换主体、重编号或改措辞不能伪造机位变化。运动镜头记录真实起止机位，不要求在提示词里输出标识。四种有条件切换及同景别相邻切点还必须按 [真实机位校验](camera-continuity.md) 提供两侧 `view/end_view`，机位编号不同不能单独授权切换。
- `start_subject`／`end_subject` 是镜头起止时实际主拍人物的原姓名；有 `view/end_view` 时由渲染器补全缺失项，已经填写的值必须与相应构图 `subject` 一致。主拍须真实可见且不能同时属于仅作关系前景的 `foreground`；只是换说话人、前景肩背或背景人物不算。无主拍人物时构图 `subject` 为 `null`，省略对应姓名字段，不编造人物。基础草稿仍可用旧姓名字段预检，最终交付以与本镜“运镜”文字绑定的构图为依据，并复核实际视觉重点，不新增正式模板字段。
- `visible_characters` 包括无台词／无独立动作的入画背景人物，以及可辨肩背、侧脸及可明确归属的手、脚等局部所属人物；按 [静默角色保留](output-template.md#出镜人物与静默角色) 核对，不只登记主拍／前景或有表演的人物；`cast` 等于本段各实际场景的在场人物合集，包含全段未入画者；最终“出镜人物”列这些姓名，用顿号分隔，全部场景确实无人时写“无”。段首“人物位置关系”同步保留所有场内位置及必要时点。原文有中文名时，`sources.speaker`、`speech.speaker`、`cast`、可见人物、最终声音行和“出镜人物”均沿用同一中文名，不翻译或拼音化；场内画外人物、入离场与回忆时点仍须对照正文人工核对，合集相等不能证明没有漏人。
- 单个连续镜头及整个原模板分镜只能对应一种声音类别；普通分镜内所有实际声音区间还必须属于同一位人物，同分镜内部切镜不重置人数。一个声音跨镜连续时全文只登记一次，最终声音行放在发声开始所属的分镜，写明完整覆盖区间；后续镜头不重复引号内台词，但实际覆盖到的分镜仍计入该发声者，并在每个承接镜头的“画面内容”明确其原声延续，不能只在第一镜写完整声音区间。多人特殊情境按下节记录，不把声音行放到别处来规避人数检查。
- 相邻切点按成片 `playback` 顺序检查，包括段间及回忆插入／返回，比较前镜结束景别／机位／主要人物与后镜开始状态。除 [有效时间跳切](cut-techniques.md#时间跳切的内部记录) 的局部例外外，四种景别组合只在同机位且没有经记录核实的主要人物变化时判错；换机位或换主要人物任一成立即可放行。同集相邻镜头来自不同 `segment_id` 时，两侧景别仍必须不同；同段无有效时间跳切例外的同景别同机位相邻切镜也仍判错，换人不能豁免这些独立规则。同一生成段的连续剪辑区间不算新的提示词段界；新集重新开始，同集不因分段重置。
- 使用 `playback` 时，在每集提示词之后沿用原模板外说明：`剪辑顺序：第 1 段 0–8 秒 → 第 2 段 0–6 秒 → 第 1 段 8–18 秒；回忆插入第 1 段第 8 秒的镜头切点。` 每个引用区间写全，段号按该集从 1 开始，补充解释放在中文分号之后。脚本将这些区间与内部记录比较。

同段跨实际镜头的原声另按 [一次执行与非声音字段检查](output-template.md#同段切镜不重新起句) 输出：原词和完整区间仅在起点登记，渲染器在声音括号标明只执行一次；后镜只承接未完部分。原文确有的再次发言／重复词句仍保留，切镜本身不新建发声事件。内部精确触发原词保留，最终画面用 `evidence` 的具体语义承接，不复制完整原句。

### 拆句停顿与声音承接校验

先按 [反应镜头中的声音连续性](spoken-emotion-camera.md#反应镜头中的声音连续性) 排声音，再安排反应画面。同一句在同段内优先使用一条 `speech` 及完整发声区间，内部切镜不拆发声记录；这条区间内自然气口已经计入估时，无需逐个登记。原文来源的粒度从剧本确定，不为镜头切换重建 `sources`。

只有同一 `source_id` 确需拆成多条记录，并且两条之间存在真实停声时，在**后条** `speech` 填写可选 `pause_before`：

```json
"pause_before": {
  "reason": "source_pause",
  "basis": "原文 L1 在此处注明迟疑，随后接原句后半部分；按本次语气估时。",
  "seconds": 0.4
}
```

- `reason` 只取 `source_pause`（原文明示停顿／迟疑）、`natural_pause`（具体语义与自然发声所需停顿）、`story_break`（原文打断、跳时或插入剧情后续说）。`basis` 写本次具体位置、语义或剧情依据；切镜、给反应、凑时长不是依据。不要按镜头补造原文停顿，也不要求正常不同原句之间填写此项。
- `seconds` 为后片段成片起声时点减前片段成片收声时点，须与真实间隔一致。使用 `playback` 时包含中间插入区间，跨生成段包含前段尾部及后段开头；默认按各段顺序整段播放。不把时间浮点误差当停顿。
- 无间隔无需填写；首片段、相邻连续片段保留旧停顿记录会报错。同一原句片段不得互相重叠，一般 `overlap_basis` 不豁免同句重念。无依据断声时修正实际设计和时间线，不只填理由过检；脚本不自动压缩时长或改词。
- `speech_continuity.py` 由基础检查和最终检查调用。它核对同源片段的成片间隔与停顿记录，但非空依据不证明停顿合理；不同原句之间、单一记录内部的自然发声与停顿，以及源文拆分是否真实，仍须内容复核。

渲染器按实际声音与镜头的交集，在跨切镜承接、拆句后续片段或声源与画面主体不同的镜头中补充自然的声音承接句，保留原台词／VO／OS 类别、声线与情绪；仅在声源完全不可见时把台词标为画外。承接句不新增声音行或引号内原词，也不为 VO／OS 添加口型，记录中的必要停顿后才恢复发声。不要在 `visual_text` 重复整句自动承接文字。

默认承接句明确“承接该句已写明的声音表演及其变化，原声连续，不因切镜重新起句或重念已完成部分”，不会把声音承接解释成音量／语气恒定。旧版“沿用原音色与语气”简短句及旧完整句仍可做绑定校验；内容复核另查其是否与本句已设声音变化相容，返修稿重新渲染采用新句式，不为兼容旧句而抹平角色演法。

最终检查将这段承接句绑定到**对应实际镜头的“画面内容”区间**，不能只放在段首、原起声分镜、别的反应镜头或“运镜”字段。手工排版且使用脚本校验时，可调用 `speech_context(plan)` 一次，再用 `speech_carry_prose(segment, shot, context)` 取得对应句。无工具时写等价的清楚说明并人工检查。连续发声仍只在起声分镜登记完整原词；切到听者不新增台词、VO／OS，也不改变一分镜一位发声者的计算。

复核时还须排除“听者无声”和“全场静音”的混写、表演说明要求原说话者停下来等矛盾，检查反应不抢在语义抵达之前。将同句断点、实际停顿依据及间隔计入已有 `delivery_review.timing`，将各反应镜头的声源、人物与口型承接计入 `visual_continuity`。脚本只验证计划与提示词，不验证生成视频的实际声音是否连续。

### 单人发声与特殊例外

按 [一分镜一位发声人物](output-template.md#一分镜一位发声人物)，沿原模板每个 `frame_id` 汇总与其时间区间相交的 `speech.speaker`，不是只数该分镜写了几行声音，也不是按可见人物人数判断。普通分镜的不同发声人物最多一位；前人跨镜声音与后人接话即使先后、不重叠，落在同一分镜仍算两位。自然呼吸、无语言动作音与无声反应不作第二位人物的台词、VO 或 OS。

先在实际发声交接处安排合法分镜边界，保留完整原文、连续声音、关系位与原总时长。同一人在同一声音类别下的多句、多人出镜但只有一人发声，以及没有语言的分镜，不需要例外记录。普通分镜之间换人也不需要另建独立提示词段。J-cut／L-cut 另按 [声画错位的适用边界](output-template.md#声画错位的适用边界) 对照实际声音和真实切点，不把同一未切镜画面仅改标题拆开，也不把声画错位本身登记为多人例外。

原文明确要求的多人同期声音或用户已指定的同镜多人设计，才在对应 `segment` 内添加 `frame_speaker_exceptions`，以该段实际 `frame_id` 为键，例如：

```json
{
  "frame_speaker_exceptions": {
    "分镜一": {
      "basis": "原文 L2 明示在 L1 句尾抢话，本分镜保留两人同期现场台词。",
      "source_ids": ["L1", "L2"]
    }
  }
}
```

`basis` 写具体原文位置及声画要求，或用户已明确指定的设计；不能只写“特殊情况”“提速”或“多人同框”。`source_ids` 完整、去重地列出与该分镜时间区间相交的发声来源，包含前镜延续进来的原声。例外仅作用于本段这一分镜；不抄到其他镜头，调整边界或原声后同步更新，无多人情况时删除该例外记录。

确实重叠的声音仍需原有 `overlap_basis`，它与分镜多人例外分别检查；不能仅凭有重叠依据就把整段都放宽为多人分镜。例外不放宽不同声音类别互斥、口型、原声顺序、覆盖与计时要求。脚本在完整镜头记录上检查人数及例外的分镜／来源匹配，最终模式必查；原文依据是否成立仍需内容复核，不能把任意非空理由视为已验证的授权。

### 逐镜关系记录

最终交付时，每个实际 `shot` 必须填写内部 `relation`，同一分镜内的多个实际镜头各填一份；基础草稿模式仍兼容不带此项的记录，不能用基础模式代替最终校验。沿用已读正文中的人物及空间状态，不从成稿漏掉的人物反推“独处”。正式提示词仍使用原字段，不输出这些内部标签。

- `mode`：按下表选择；是该镜的关系情境，不是景别或声音类别。
- `characters`：本镜关系描述涉及的原剧本人物名，至少覆盖本镜全部 `visible_characters`，以及需承接的画外互动对象；允许包含本镜不可见者；本地在场者按 `scene_characters` 进入段首 `cast` 与“人物位置关系”，电话异地等对象不能仅因在此关系表中就当成本地在场。该字段负责逐镜关系，不能代替完整在场表。不必把全场人物每镜抄一遍，不新增未知姓名；原文只有称谓时沿用称谓。
- `scene_characters`：所有模式都填写本镜实际地点、剧情时段中在场的人物名，按正文和已确认空间设计先确定，包括全程画外和中途进出者（实际时点另在站位／画面注明）；异地对端不算本地在场，真实无人场景填 `[]`。可见者必须在此表内，`same_scene.characters` 也须是其子集；`solo` 只在此表恰有一人且与关系人物一致时成立。此表派生段首在场名单，不从可见名单反推；段首位置覆盖全段画外人员，逐镜口型／可见反应仍只查真实可见名单。同步伪改在场表仍需内容复核识别。
- `placements`：`same_scene` 必填，按本镜关系人物各一条 `{character, visibility, placement}`。`visibility` 为 `visible`（镜内任一阶段可见，含肩背等局部）或 `offscreen`（整镜未入画），与 `visible_characters` 一致；`placement` 是紧接姓名的自然短句，写清画面前后／左右、既有空间位置、朝向或视线对象，例如“位于右后方桌北端，面向 Elias”。不能再只写另一人名字或“关系保持”。运动中离框／进入时在同一条内写清起止及变化，与 `view/end_view` 对照，不把暂离框写成离场。覆盖本镜全部实际可见者及必要画外关系人物，不因可见人物无戏份而省略，也不机械抄全体在场者。
- `single_reason`：`same_scene` 只有一人可见时必填本镜具体的距离、遮挡、独立反应或叙事任务依据；只在内部保存，不进入提示词。不能只用“近景”“在讲话”“换景别”充当理由。多人合理同框、异地通话、独处和重要插镜无需此项，不因此扩大双人同框要求。
- 渲染器把 `placements` 写成自然句接入该镜“画面内容”，为全程画外人物自动标明“画框外的”；最终校验将整组位置句绑定该实际镜头区间。手工填写使用 `scripts/relation_layouts.py` 的 `relation_layout_prose(shot)` 取得同一段文字，不移到段首或借其他镜头的关系描述。填写 `visual_text` 时集中写行为与情绪，不重复整组自动位置句。
- `evidence`：未提供时，同场默认复用自动位置句，其他模式默认取 `visual_text`；自行填写则直接摘录本镜最终“运镜”或“画面内容”内的一段连续文字，明确点名上述人物并落实其可见关系、画外方位或特殊情境。与成稿共用文字，不另写一份概括；不能只引用段首人物位置、名单、台词或其他分镜。同一分镜含多个实际镜头时摘取各自时间区间的对应描述；运动镜头的片段应覆盖关系位如何随起止构图变化。不存在相关人物时照实摘取空场描述。

| `mode` | 适用情境与记录要求 |
| --- | --- |
| `same_scene` | 同场互动，至少两名关系人物且至少一人可见；优先合理同框，确需单人取景时有 `single_reason`，双方位置仍由 `placements` 落入画面描述。 |
| `remote` | 异地通话两端的联系，至少记录当前可见者与对端人物；说明各属不同空间，不要求同框。若重点是本地多人互动，用 `same_scene`。 |
| `solo` | 原文状态确为独处，恰有一名关系人物且可见；对方暂在画框外不算独处。 |
| `insert` | 手部、道具或必要局部插镜；记录相关人物及动作／空间归属，可无人形可见，不强行补脸或同框。 |
| `empty` | 当前取景确无可见人物且没有人物关系任务，`characters` 与 `visible_characters` 均为空；不表示整个地点无人，`scene_characters` 与段首名单／位置仍须保留画外在场者，不能用来隐藏仍需承接的互动。 |

脚本检查记录形状、在场／可见／关系名单的一致性、独处条件、同场双方位置条目、单人理由是否存在，以及关系证据与位置句是否实际绑定对应镜头区间。只有人名而缺少位置记录、将已记录多人的同场状态标成独处、把位置句移到段首或其他镜头，即使更新文本摘要也不能通过。**脚本不理解空间语义**：同步伪改在场表、位置句写得空泛、单人理由牵强或距离失真，仍需对照原文和构图复核，非空字段不证明导演判断正确。

内容复核还要沿成片顺序检查整轮同场对白及跨段接话：需要的互动对象是否长期只存在于名字或画外说明中；若反复单人互切，逐个核实独立信息任务及真实空间限制，能合理同框则调整原镜关系构图。关系变化后是否更新，切到听者是否仍能辨明对象位置，分别核对。不要以一镜同框抵消后续遗漏，也不为了过检硬加双人镜头、反复肩背、额外中全景或改变距离。结论归入既有 `delivery_review.visual_continuity`，不设同框比例或新的正式字段。

### 动作特写取舍与连续性复核

先按 [关键信息与特写](shot-selection.md#关键信息的可读性与特写) 从原文确定本时点的必要视觉证据，静态细节同样对应实际段镜。下述关系动作例外允许不用特写，前提是所需证据另已可读；仅人物关系成立不能免除细节检查。复用 `delivery_review.source_coverage` 与 `visual_continuity` 记录来源范围、具体段镜及取舍依据，不添加每镜必填对象。

先对照原文及已设计的自然表演确认动作行为与必要结果保留，区分普通动作、剧情关键动作及主要情绪动作。先按 [关系动作规则](shot-selection.md#有指向与人物关系的动作) 核对指向、施受或注视他人行为的呈现：谁发起、朝谁／对谁做什么，谁在何处看着谁做什么，关键动作与关系是否在实际画面可辨；符合者可以不用动作特写，不判漏项或未解决冲突。其余主要情绪动作按 [特写取舍](shot-selection.md#主要情绪动作的特写) 核对触发、关键身体变化及实际落点；对白中因保护不可替代情绪瞬间而保留原近距离镜头时，必须同时读清该动作与情绪并说明具体冲突，符合者不判漏特写。除此以外，不能仅因未改剧情结果、原文未逐字写手势或普通近景已看见而漏拍；已有特写不再重复。普通动作不逐项特写，必要过程可在连续镜头中共同呈现。对所有特写检查具体剧情／情绪作用及强调细节；只贴“强化情绪”标签而没有具体动作依据、只为凑景别的特写仍应取消，不能把普通动作一律标为主要动作。

再将特写前、特写内、特写后的实际画面按时间顺序连看，核对发起、运动方向、左右手、接触阶段、道具归属、位置距离、轴线、光影和声音。不能突然进入已完成状态、重演或倒退进度、跳过关键接触、打断必须完整观看的运动／施受关系；取消特写也不能删掉原文动作或必要证据。同期讲话与回忆内的特写按各自时间线检查，原文明示隐藏、画外、未发生或仅声音提及的行为不补拍。

重复或非必要特写可移除、合并回原镜头；符合关系动作规则时直接采用能清楚呈现行为关系的构图，不必先尝试特写或另求确认。其他必要的主要情绪动作特写先调整切点、连续取景或原镜构图以保持连贯；符合 [对白情绪取舍](shot-selection.md#对白情绪优先与动作取景) 的同框可读方案可直接保留，不能反向要求补特写切走必看情绪，其他情况不因初稿不顺就删除该要求。确实无法兼容时保留真实过程并说明具体未解决点，不虚称覆盖；不靠拖长、慢动作或多补一个过桥镜头修复。复用既有原文对应记录，在 `delivery_review.visual_continuity` 概述主要情绪动作的特写对应、关系构图或对白情绪同框取舍依据、具体施受／注视关系、重要动作取舍及前后承接与修复，不新增正式模板字段。脚本可核对景别、区间、机位与关系记录，无法判断动作重要性或真实视觉连贯性，须完成内容复核，不能把结构通过写成已验证导演效果或视频画面。
