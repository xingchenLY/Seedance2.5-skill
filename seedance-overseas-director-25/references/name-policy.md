# 所有项目的名称规则

用户已确定的通用要求：**最终提示词任何字段均不出现品牌名或真实地名**，适用于四种制作模式和全部项目。覆盖声音引文、画面文字、人物／场景标识、风格标签、道具、环境、背景招牌与反射中的文字；不在“不要出现某品牌”、括号解释、对照表或否定提示中再次写被排除名称。品牌标识及明确品牌化外观也不从素材带入生成画面。技能内部资料的作品归因、来源链接、真实文件路径和原始正文不属于最终提示词，仍按实际依据保存。

## 如何替换而不丢剧情

- 在分段、估时前识别名称的实际语义：真实公司／产品／平台／连锁名称、商业作品／IP名用通用类别或固定虚构称呼；国家、城市、行政区、街道和真实地标等地名用场景功能／相对位置或固定虚构名称。名称作为人物姓氏或普通词使用时，不因同形就机械删改。英语、西班牙语、葡萄牙语等语种名称可以明确保留，它们在此是语言标识；“某真实国家／城市风格”等地域描述则改为具体建筑、空间、光色和表演特征。
- 不影响身份辨认时优先用“手机、社交平台、豪华轿车、医院、城北”等自然通称；剧情必须区分两个公司、两座城市或同一地点反复出现时，使用可区分且全篇一致的虚构称呼。不能把两家竞争公司都替换成同一个“公司”，不能把异地变同城或抹掉距离、方向、迁移、跨境等剧情作用。不增加新地址、历史或现实背景来补词。
- 原文声音包含名称时，仅替换名称及必要的冠词／介词等语法衔接，保留其余原词、数值、否定、条件、语气、人物归属和事件。目标语种不变，重新核对自然发声、词数、重音词、画面文字和动作所指内容。该项是已授权的有限替换，不允许趁机缩句、删旁白或改变关键事实；名称本身是谜底／字形线索时同步保留其识别关系，确实无法兼容才说明具体冲突，不把禁用名称直接放行。
- 逐个实体固定替换关系及生效范围，原名与别名只在内部任务状态保存。检查所选虚构称呼没有已知品牌／真实地点含义；不要为了换名挑另一个真实名称，也不声称能证明名称在全球从未使用。重名风险不靠空泛保证解决，必要时改用功能与相对位置描述。

## 素材风格与输出名称

实际文件名／文件夹若含被排除名称，选图时仍读取真实文件；输出采用固定中性别名，内部保存真实路径、原文件主名、输出别名、正反视角及适用镜头的对应关系。原图、文件名不擅自修改，路径不进入提示词，不声称外部平台已接受别名。正式场景行、站位、运镜引用及画面统一使用同一输出名，正反视角仍分别描述。只替换名称不改变布局或凭空生成另一场景；参考图已有标识／地名需明确其对应部位使用无标识外观或制作版文字。

3D风格目录 `id` 与 `aliases` 继续支持原来的风格选择，`label` 使用通用输出名称。原参考作品的具体形体、材质、重量与耳尾表达继续按档案执行，最终只写通用标签及本镜适用特征，不附原作品名。新增风格同样遵守；主技能及其他文件的“原名／原标签照抄”与本页冲突时以本页为准。

## 原声替换的内部记录

未替换的 source 不加字段。发生名称替换时，在同一 `sources` 项内加 `name_adaptation`；`sources.text` 是替换后的制作文本，各镜 `speech.text` 仍按其原顺序完整覆盖。原文保存在已有来源记录，两种推文 `narration_sources.original_text` 必须保留真实原文；不要把替换后内容冒充原始清单。

`name_adaptation` 包含：

- `before_text`：同语种为替换前完整原句；需要翻译时为忠实译完、尚未替换名称的完整目标语句，原语正文仍另留在原文记录。
- `replacements`：按原句字符位置排序的替换项，每项 `start/end` 是 `before_text` 的零起点 Unicode 字符索引、左闭右开，`original` 必须等于该范围原文；`replacement` 是非空制作称呼及必要局部语法，`kind` 为 `brand` 或 `real_place`，`basis` 简述该范围对应的名称及语法必要性。各项不重叠；同名重复出现逐处登记，不替换同形人名或普通词。

程序据这些范围重建制作文本并逐字核对，拒绝替换范围外的改词／删句、无效或重叠范围及伪改旁白原始清单；范围内是否只含名称及必要语法仍须内容复核，它不自动改词、不证明名称分类或译文语义正确。修改后重新渲染，重建已有来源／画面／计时复核；不把旧通过摘要带过来。画面与素材名称映射沿用内部任务状态，不增加每镜必填名称表。

## 返回前检查

先从正文、素材和已选风格识别本次名称，再审实际最终提示词的全部字段，包含台词引文、旁白、重音提示、场景名、画面文字和负面描述，核对替换一致、无原名残留、无新增真实名称。逐实体检查仍能区分原有身份、地点关系和证据，特殊道具清单保留，语种与时点一致。结果并入现有 `source_coverage`、`visual_continuity`、`conflicts` 与必要 `timing`，无新增独立审查流程。

程序只检查可确定的替换范围、结构与文本绑定；名称识别仍需内容复核。没有实际生成视频就不宣称画面中标识已消除，也不把此规则写成知识产权合规保证。
