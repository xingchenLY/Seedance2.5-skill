# 推文连续剧情分组与发声预算

用于推文／3D漫推文，优先于原来的声画合计后向下取整。真人剧／3D漫真人剧不采用本项。执行顺序固定为：**连续剧情合理分组 → 每组总发声计时 → 核对4–30秒并锁定 → 安排镜头与生成提示词**。不能先造镜头、先按固定秒数切原文，或逐句锁出大量碎段再拼接；镜头不能反过来决定或扩大预算。

## 先按连续剧情合理分组

固定目标语种、必要名称替换／忠实译文及已授权旁白删减后，先通读本次范围及必要前后承接，按连续事件、因果链、对话来回和自然情绪落点建立候选组。一组可以含多句旁白、对白、内心声和多个实际镜头；原文换行、一句话结束、声源切换或拟切镜，都不自动成为一段提示词的边界。

优先保持同一事件的发起、信息到达、回应与结果在可理解的连续关系中；不把没有独立叙事任务的短句单独建段，也不为凑秒数合并不相关剧情或打乱原顺序。剧情本身连续跨场时可随原文承接，明确空间变化，不凭同场景标签认定所有内容必须塞入一组。候选组此时尚未排镜、尚未锁时。

然后逐组计算下节预算。任何组不合格，先回到相邻连续剧情重新合并／分配，或在自然语义与剧情落点拆组，再重算受影响各组；包括末组和分批边界，不留下1–3秒尾段。组数与镜头数量都不是预设目标，不能仅为接近30秒而不断塞满。分组是否自然须对照原文审阅，脚本不自动判断剧情语义。

## 再计数并锁定

1. 对已经按连续剧情确定的候选组，核对原文范围与顺序；总发声包含保留的叙事旁白、人物对白及内心声，不只数人物对白；标签、画面说明和无人朗读的文字不计。同一句跨镜只计一次，数字按既定真实读法展开。
2. 按原语种计算：中文实际汉字数÷7；英语、西班牙语和葡萄牙语统一按对应原语种实际发声词数÷3.4，不翻译成英文再计词。三种外语沿用相同空格分词口径，标点不单独计词，数字先按实际读法展开；重音符不改变计词。混语各部分分算，只对本段总和取整，不逐句取整。英／西／葡语3.4词／秒是本项统一预算基准，不为迁就已设计画面改慢；已有实际测量音频时，在锁定前用真实时长替代对应估值并保留测量依据。中文必要停顿沿用 `chinese_timing`，不能与实测重复计算。
3. 原文确需的独立声音停顿在生成前登记 `segment.narrative_pauses`，每项 `{start,end,basis}` 使用段内时点；只计没有包含在声音估值／音频中的自然气口或明确停声，不把动作、表情、摄影、读屏、场景转换或任意缓冲伪装成声音停顿。内部停顿已含于中文估时或实测声音时不另填；真实拆句仍保留原声音承接及停顿依据。两种语言声音的重叠须有原文／用户依据，不能为省时自行叠声；本项总发声预算不因切镜或叠声减少计数。
4. `T锁定 = ceil(T全部实际发声 + T未重复计算的必要声音停顿)`。例如中文75字为75÷7≈10.714秒，锁定11秒；英／西／葡语34词均为10秒，锁定10秒；96词均约28.235秒，锁定29秒。不是默认30秒，不另加动作／反应／镜头数量秒数。向上取整的不足1秒余量仅是网格余量，不要求追加定格或固定片尾等待。
5. 每段提示词的最终整数预算必须满足 **4 ≤ T锁定 ≤ 30秒**，另检查96英文词及完整发声可行性。4秒是整段下限，不是单镜下限，也不是把计算值自动抬到4秒：3.2秒向上取整为4秒可用，3秒仍为3秒，必须回到连续剧情分组。低于4秒优先合并／重新分配相邻连续内容；高于30秒在自然语义／剧情边界拆组，所有受影响组重算合格后才锁定。不得用 `max(4, T)` 补静止、慢动作或虚构停顿，也不得用 `min(30, T)` 裁声、改词或加速。既有 `limits` 可进一步收紧范围，不能通过旧的较大上限放行超过30秒的推文。
6. 原文必须保留的停顿、不可压缩过程或短镜下限导致不可行时，在排镜前识别并回修合理分组。纯无声内容优先与相邻连续剧情及原声放入同组，不按零词生成零秒段，也不凭空补台词。孤立短内容、不可拆的超长发声或无声内容无法形成合格组时，明确报告具体冲突与所需补充，不伪造4–30秒合格提示词，不强并无关段落。

## 在锁定时间内制作

只有候选组的发声预算通过4–30秒检查并锁定后，才完成组内声音时序并安排实际镜头。段首预估时长、全部实际镜头时长之和及末镜结束点必须严格等于 `T锁定`；正式分镜与内部镜头不重复相加。动作、反应、证据阅读、摄影和转场均在该窗口内，能同期就共用时间，但不提前知情、弱化关键表演、漏掉接触或必要证据。

先比较合法切点、取景和兼容的同期安排；不能把自然1秒的动作拖到旁白末尾，也不能为赶预算把复杂过程加速。若内容确实放不下，不能把锁定11秒改成13秒后继续生成；只能回到生成前调整原文自然分组，保留原顺序、原词和旧预算记录，对新分组重新锁定并重做受影响镜头；无法解决则报告具体冲突，不能通过反复重组掩盖不可能条件。更改原声、读法、语种、停顿或实测依据同样使旧预算失效。

近景／特写、长镜、静态停留和推文最短镜头规则仍有效。完整一集50秒约定不允许人为扩大各段预算，不足按既有冲突规则说明。分批处理2–3段和上下文软预算不改变本项计时。

## 工具与记录

有工具时，先按连续剧情在同一设计记录的 `segments` 建立候选组，再用 `mode`、`sources` 与各组 `speech` 形成尚无实际镜头的计时输入；多条原声属于同组就放在同一个 `segment.speech`，不逐条调用锁定来制造碎段。无需另建完整分组表，已有原文范围与来源顺序就是核对依据。来源含既有语种、发声原文等字段；声音事件保留准确 `source_id/text` 和必要读法／混语记录。英／西／葡语及混语中这三种片段均按统一词速计算，普通 `estimated_seconds` 不覆盖公式。计时锁定程序不需要摄影描述，不会生成动作、声音或素材。

```text
python scripts/narrative_budget.py speech-input.json --output authored.json
```

输出同一设计稿及 `segment.narrative_budget = {version, speech_sha256, raw_seconds, duration}`，同时设置 `pre_round_duration` 为未取整的发声总时间、`duration` 为向上取整值；之后在该稿补齐声音区间、镜头等内容，不再另写一份完整方案。已存在锁定或实际镜头的输入不直接重锁；确需重组／改词时从新声音输入重算，保留原记录用于核对，不用事后刷新摘要迁就成稿。

公开 `render_prompt.py` 与 `validate_plan.py`（含 `--timing-only`、`--final-prompt`）要求两种推文具有预算记录，并复核发声绑定、公式、4–30秒范围、整数值与实际结束点；计时入口与最终成稿均不得放行过短、过长段。渲染器不能从镜尾反向覆盖预算或自动挪动声画区间；已有旧稿缺少记录时，回到原声预计算并重新核对镜头，不直接填“通过”。直接调用内部函数的无锁旧测试兼容不代表制作入口放宽。`--timing-only` 可用于预先核对已锁声音及已有不可压缩过程，仍不能代替成稿审阅。

不能从普通英文估值、外语估值或“有测量依据”字段推导音频已验证。程序检查数字与内容绑定，无法证明先算后写的真实执行顺序或自然表演；独立成稿审阅需核对连续剧情分组是否合理、完整原声及其顺序、生成前计时记录与画面可行性，不能只凭区间合格就宣称剧情分组正确。没有工具时按同一公式在已有任务状态记录总发声量、停顿依据和锁定秒数并人工比对，不声称自动校验通过。最终正式提示词保留原模板，不额外输出内部预算表或摘要字段。
