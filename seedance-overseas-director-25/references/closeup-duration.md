# 特写时长与必要例外

四模式共用。面部、手部、动作、道具特写在一般非必要情况下，每次连续特写取景不超过2秒；近景、中近景不套此上限。2秒是上限，不是目标镜长；任务读清后推进，不补停留。实际镜头默认至少1秒及原有局部短镜例外仍保留，连续运镜中的短暂特写阶段不是另一个独立短镜。

## 排镜与切出

在镜头骨架里先确定“必须看清什么、何时看清、余声期间下一画面看什么”。先按 [模式优先级](shot-selection.md#情绪与景别的模式优先级) 选景：两种剧先定关键情绪强调，两种推文先考虑有效中近景；特写承担确有需要的关键细节或情绪变化。2秒限制约束持续区间，不取消必要的情绪特写；不为免做特写排时而退回全程中近景。整句可以很长，但台词未完不是让特写等待的理由。

- 已有特写信息在2秒内完成：在完成点切到有信息的下一构图；可以仍拍讲话者的近景／中近景，也可拍此时应发生的听者反应、动作结果或关系变化。需要换机位、轴线和反应触发继续按原规则核对。
- 必要过程仍未完成：先比较用近景承载过程、只在关键节点收近，或在自然动作阶段换镜能否完整表达；不能为限时删除证据、隐藏接触、提前切断情绪落点、拉远削弱表演或把自然动作加速。
- 切镜共用原声时间线，同一声音只执行一次；切镜本身不另加时间，已同期的反应不重复计时，自然未完的必要尾段按原计时规则保留。不暂停／重读原句，也不把一句拆成几个重新起声的片段。没有合适听者反应时，不编造反应来凑切镜。
- 连续推近／拉远按真正进入和离开特写的区间计时。镜头起止都是近景但中间进入特写，也要记录。画面始终是同一特写时，换编号、微裁切、轻微手持、改称“近景”都不重置计时；连续特写阶段必须合并计算。真实换镜后有新的观看任务才按新镜检查，不能用重复特写规避。

例如一段5秒台词：前段用中近景读清发声与身体应对，关键原词处用约1.5秒面部特写呈现表情变化，再将余声覆盖到已受触发的听者反应。具体分配随原文、自然语速和信息到达点确定，不把此结构做成每句必用模板。短句的完整有效特写若只有1.6秒，可以整句保留。

## 超过2秒的必要性

只有具体阅读任务、不可替代的连续动作／表演转折，或用户明确要求，才考虑必要延长。内部说明必须回答：为何该细节在自然速度下需要超过2秒；在2秒以内哪一具体时点可切向什么；换成该画面会损失什么必要信息；本特写在何种可见结果出现时结束。取最短足够时间，不能默认取长镜或段长上限。

“情绪强烈、保持压迫感、完整表演、正在讲话、声音连续、没有听者、参考图适合、摄影机仍在移动”本身均不足。程序检查记录不等于认可理由；要核对源文与实际画面是否支持、近景能否同样读清。理由不成立则回修排镜，不补空泛文字过检。

必要延长只放宽本项2秒上限。连续静态展示≤2秒仍独立检查，阅读需要不能自动豁免静态限制；超过6秒的对白／旁白实际长镜仍执行各自复核。若其他约束与必要阅读、动作或原声确实不能兼容，沿用 [可行性处理](timing.md#排镜前的可行性检查)，不虚构循环动作、加速原声或删除重要信息。

## 结构记录

整个实际镜头≤2秒时无需新增记录，混合景别仍在原运镜文字交代变化。实际镜头超过2秒且含特写时，在 `shot.closeup_spans` 填列表：包括全程特写，以及镜内进入／退出特写（起止景别相同但中间有变化也包含）。每个连续特写阶段是一项，相接阶段合并；间隔必须在实际运镜中明确回到非特写取景。段内秒数与原时间线共用，不新增时间。

每项：

- `start/end`：实际特写区间，有限数值，精确到0.1秒或更粗；与镜头起止景别、真实变化相符。
- `task`：内部记录该阶段必须读清的具体信息。
- `finish_evidence`：该阶段结束时的可见证据，逐字取自本镜最终“画面内容”已有描述，含动作链等自动生成内容；该描述须明确对应时点。不要再次抄写动作以满足绑定。
- `necessity`：仅区间超过2秒填写，含 `reason`（`reading / continuous_action / performance_turn / user_requested`）、`basis`、`cut_at`、`next_view`、`loss_if_cut`；`cut_at` 在本阶段开始后、结束前且不晚于开始后2秒，比较此时切出的具体损失。用户例外另填真实 `user_basis`。其他情形不得冒用用户授权。

例如连续镜头0–5秒从中近景推近，在第3.5秒进入面部特写，至第5秒完成变化，可填：

```json
"closeup_spans": [{
  "start": 3.5, "end": 5,
  "task": "读清原有笑意消失后的回应变化",
  "finish_evidence": "第5秒，笑意已消失，目光停在对方脸上。"
}]
```

运镜还应给出可见构图依据，例如“第3.5秒已收至以完整面部为主的取景，原先胸肩范围退出，必要的对手肩背只留画框边缘”。这只是说明进入时点的例子，不强制裁掉所有肩背或改变关系位；实际画幅仍须与景别一致，不能只改标签。

示例只说明区间记录，不授权新增该表演。其余0–3.5秒仍需真实画面任务，5秒连续镜头还要满足原有声音、景别、表演及运镜规则；不能把标注当作长镜许可。

渲染器在原“运镜”字段补具体特写区间，内部任务与必要性不输出；结束证据绑定同一实际镜头的“画面内容”。最终内容复核另检查该证据确实发生在所标结束点、混合景别阶段与实际取景一致，以及跨编号是否重复画面。结构校验不识别所有自然语言景别与叙事必要性，未生成视频时不得声称实际视频已满足2秒限制。
