# 推文旁白断句校验

仅用于“推文／3D漫推文”的 `narration`。人物对白、内心声、剧模式VO／OS保留原有声音连续性检查，不自动套用这里的叙述声规则。正常同句连续旁白不需要新增记录；以下额外字段只用于实际存在的边界。

## 先固定声音，再安排画面

- 从源文登记完整语义单元及固定译文，确定自然朗读与气口，再排镜头。同一句在同一生成段连续发声时，使用一条完整 `speech`，可以覆盖多个正式分镜；只在起声分镜写一次完整原句及覆盖区间，后续画面明确原声承接。不要为了使声音行位于每个分镜内而拆引号文本。
- 分镜仍按实际叙事任务组织。换机位、切反应、改变画面任务都不自动使旁白停顿；6秒长旁白视觉复核、2秒静态上限及整数段长同样不是停声依据。自然气口可以包含在完整发声区间内，不逐个建立碎片。
- 确需真实打断、独立记录自然停顿或跨生成段时，优先句末或自然分句边界。不同生成段分别生成声音，不能仅凭数值首尾相接声称实际音频连续；优先移动生成边界，后续实际试听接头。

## 自动检查的范围

| 情况 | 处理 |
| --- | --- |
| 同源、同生成段、首尾无间隔的多条旁白 | 报错，合为完整声音记录并重渲染，画面分镜保留 |
| 在 `the｜man`、`Dr.｜Smith` 等高风险词组内部拆分 | 报错，恢复完整原句或移动断点；真正的原文打断按下文记录，不强行连读 |
| 真实逗号、分号等气口，已有合理的自然停顿记录 | 保留；标点只能提示候选边界，实际朗读仍需检查 |
| 无标点但语义上确实可断的从句边界 | 要求具体 `boundary_before`，绑定该处前后文字并说明语义依据 |
| `pause_before` 理由为切镜、等反应、凑时、取整等 | 拦截明确的制作性停声；“不因切镜停顿”等否定要求不按停声指令处理 |
| 相邻同集、同叙述者的两个旁白来源，前项原文未自然结束 | 检查疑似换来源编号拆句；恢复同一来源，或提供真实独立单元依据 |
| 最终旁白声音说明另加“每次切镜停顿” | 即使重新计算复核摘要，也报错；不能仅凭计划通过代替成稿检查 |

高风险词组检查目前覆盖部分英语、西班牙语、葡萄牙语功能词与常见英语称谓缩写；中文及其他未识别的无标点边界要求具体复核记录。它不是完整语法分析器，不能证明所有断点自然。原文若先被错误重建、补标点或伪造依据，程序不能代替对原文的核对。

## 边界记录只在需要时填写

同一来源真实停声仍在后条 `speech.pause_before` 写 `reason`、具体 `basis` 与实际间隔 `seconds`，沿用 [声音连续性](delivery-records.md#拆句停顿与声音承接校验)。不存在间隔时不填pause_before；不同完整原句之间不新增这个要求。停顿秒数必须对应成片顺序中的间隔，跨段包含前段尾部和后段开头，不按镜头添加缓冲。

无标点的合法从句边界，在后条 `speech.boundary_before` 填：

```json
{"kind":"clause","left":"closed the door","right":"before anyone","basis":"主句动作完成，随后进入时间状语从句；按本次自然读法在此换气。"}
```

`left` 必须逐字匹配前片段结尾，`right` 匹配后片段开头，包含足以定位并解释语义关系的文字；示例不是通用通过理由。程序核对锚点与类型，语义合理性由实际原文和朗读复核。不允许用clause记录豁免已识别的冠词／名词等词组内部硬切。跨生成段无停声而确需自然从句分界时也可用此记录；同段无间隔碎片仍应合并。

原文明示迟疑、被打断或插入剧情后续说，`pause_before.reason` 为 `source_pause`／`story_break`；后条speech的boundary_before用 `kind: "source_break"`，写相同的left、right、具体basis，另填 `source_evidence`，摘录实际原文的打断说明或用户要求并注明定位。允许原文在未完成词组处被真实打断，不能只将自然停顿改名为source_break过检。内容未给出该证据时不要编造。

两个无句末标点、但原稿明确独立的口播单元，在后一项 `narration_sources.boundary_before` 用 `kind: "independent_unit"`，left／right对应前后两项的 `original_text`，basis解释独立性，source_evidence记录实际原稿的分段或标注。原文同一句应保留同一来源，不能为换镜生成不同source_id；授权删减仍按既有旁白清单保留依据。完整句末通常不需要此额外记录。

## 成稿复核

先在不看画面分镜标题的情况下连读完整旁白，再对照各段时间：检查冠词／名词、介词短语、主谓、固定搭配及中文词组是否被割开，是否在句中无依据收声、重新起句或变速。核对原标点、真实气口与分段依据，不以“中性平稳”代替连续性。所有明确让旁白等待切镜／反应的画面说明也须消除。

使用 `python scripts/validate_plan.py plan.json --final-prompt final.txt`，计划和最终文本都必须通过。问题应回到设计及authored.json修复、重渲染和复核，不伪填理由；原文支持的自然气口与打断保留，不把校验变成要求全程无停顿。检查结论写入既有delivery_review.timing，不添加正式提示词字段。没有实际音视频时只报告文本与时间记录检查，不能声称已检验真实朗读。
