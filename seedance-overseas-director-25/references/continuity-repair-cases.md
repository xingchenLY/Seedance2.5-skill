# 连续性修复案例

用于局部修订、错误诊断或相同表演难点，按需选读。例中情节只是成立条件，不向其他剧本加入车窗、纸张、群众或固定动作；共用的模式、声音、摄影与计时规则不变。只有文本推导的结论不当成样片验收。

## 增镜改机位与恢复画面

已确认“进门落到桌侧 → 对话近景”，用户要求在对话期间增加文件证据镜，并保持总长。应保留进门与桌侧站位，在原声继续且证据此时允许揭露的位置安排插镜；重分配未锁定的切点，接同一持物进度。不能把进门镜替换掉，也不能先复制一遍文件动作再加秒。若用户连原有每个区间都锁定，先检查是否还有可用窗口；实际放不下就说明冲突及最小调整，不偷偷加速或移动已锁区间。

改为反打或恢复被漏掉的动作，同样先核对哪些已确认条件保留；“换机位”不授权交换人物站位，“恢复画面”不授权延长时长。已有错误依据最新事实修正，不因保留旧稿而维持错误。

## 遮挡与知情边界

| 条件与错误 | 可执行的修复方向 |
| --- | --- |
| 关闭车门的车内机位，却要求穿过实心门板看全车外低处动作 | 保持门闭及车内视点时，只写窗内真实可见的头脸下降至窗沿以下、随后按动作进度重新进入视野；原文必须看清的低处关键接触／结果用实际可见的车外角度交代。不能借被挡住省略关键动作，也不为“拍清楚”开门 |
| 隔桌正面机位，看不到被桌沿挡住的低处交接 | 在不挪人、不改桌子的条件下选择能看清实际交接点的斜侧／局部构图，保持同一只手和原动作进度；若当前镜头只拍脸，就不写桌下细节已可见 |
| 受话者被前景肩背遮住，或人物从背后靠近却已经认出对方 | 分别核摄影机与人物的视线；必要表情用真实可见角度呈现，认出反应等对应脸部／身份线索进入该人物视野后才开始。观众先看见不使角色提前知情 |
| 手机背板朝镜头，却写屏幕内容清楚可读 | 当前镜头只描述背板和人物可见反应；观众必须辨认的文字另安排朝向屏幕的合法角度，保留屏幕归属、持机手与阅读时点，不复制一次操作 |

这些方案不默认增加镜长；改排后重新检查可读时间、同一轴线、实际切点及受影响后镜。

## 双手分工接触解除与可达范围

条件：人物甲左手递纸，右臂抱住乙的腿；原文下一步要求乙蹲下。内部先核对乙接纸的空闲手、双方当前姿态与右臂抓握是否真的限制乙屈膝。

若确受限制，镜内写甲左手把纸递到乙可接位置，乙用空闲手接稳后甲松开左手；到原文允许解除抓握的时点，甲右手松开并将右臂撤出妨碍范围，乙才继续蹲下。若姿态允许一边保持接触一边屈膝，不机械新增松手。交接、解除和屈膝可在已有窗口内连贯完成，不逐步骤停住或加镜。

跪姿／坐姿角色向站立角色递物时，按自然臂长与接收者向下伸手设计接触点，不要求低处人物把手凭空举到对方脸前。两手都被占用时，不另加同手指人，也不为手势无依据丢掉原道具。

## 背景活动与离场

已建立的走廊中，护士沿通道带病人向出口移动。切人物近景时两人可以在画外；再次看到通道时按经过时间接合理位置，不能因换镜消失，也不要求停在原点等主角说完。若已明确走出该空间，再切回不得无依据重新站回背景。

该活动只有来源／已确认设计支持才保留。用原角色称谓追踪，不加名字、人数或新反应；最终描述只写本镜实际需要看见的背景部分，不把完整在场表塞进人物位置关系。

## 段首初态与镜内变化

初态为“甲在乙右侧，右臂抱住乙腿部，左手持纸”；后镜才发生递纸和放手。段首只交代上述初态；逐镜动作文字负责递交、接稳、松手及退出接触，切入后镜用简短当前状态承接。不能在段首同时写“始终抱住”和“手已收回”，也不能将同一过程在段首、位置句和画面内容各完整复制一次。

本段后半才从门口入场的丙，可列入本段出镜合集，但站位注明入场时点；开场在场记录和早期镜头不提前放入丙。道具清单仍保留相关纸张及必要初始归属，不能用精简为由删除。

## 情绪强度与表达方式

| 原有情境 | 声音与身体如何共同表达 |
| --- | --- |
| 身体虚弱却急切求救 | 原句带沉重哭腔，声线发虚、请求词仍尽力咬清；撑起或抓握表现吃力与落点。情绪很强不要求持续高声或突然有力，不新增独立哭喊 |
| 前一句已处在争执高点 | 下一句从已有怒意、音量与作用对象继续，依原词发展；不每句重做低声蓄力，切到听者后原声力度不归零 |
| 绝望中得到一点希望 | 目光或原句声调对新信息有变化，疲惫、哭腔和未退余波按实际过程保留；希望不自动变成微笑、起身或身体恢复 |
| 数清少量钱后低头，轻声呼唤亲人 | 呼唤保持此前低垂、无力与原词可辨；没有新触发就不在句末自动抬头恢复。不是所有悲伤台词都必须低头 |
| 当下仍是温暖交流 | 从当前温柔与可见互动进入，不因后文悲剧预添泪痕、惨白或过早悲伤 |
| 同一轮从威胁对象转为向手下下令 | 在原文命令开始处让目光／必要转头和声音指向实际手下，维持真实站位；不为过肩同时看清两人正脸而挪人 |

这些组合沿用目标语种、完整原词和声音类别；叙事旁白仍中性，3D按已选风格调整形体与耳尾幅度，身体限制和触发顺序不变。
