# 四种模式的成稿检查

四模式均按 [剧本语种](source-continuity.md#剧本语种与台词画面文字) 分析中文、英语、葡萄牙语和西班牙语；实际台词／旁白及必要画面文字使用对应语言。中文项目允许中文入画；逐段检查声音限制与画面限制，没有遗留禁中文或另一语种默认指令。语言选择不改变各模式原声类别和旁白口型规则。中文发声按 [独立7字／秒估时](chinese-timing.md) 核对字数、数字读法、混语分算及实际区间，切镜不重复计时。

四模式都须完成 [独立成稿审阅与优化落实](editorial-review.md)，逐项修复已确认错误及有效优化后验收当前文本。人物运动可按 [运动过程省略](motion-ellipsis.md) 有条件删减无信息中段，保留起始、结果和关键事实；3D保留所展示片段的自然运动与动画表演，两种推文保持完整旁白，两种剧保持现场声音时点和口型。下列模式边界不变。

四模式最终提示词都按 [通用名称规则](name-policy.md) 排除品牌和真实地名，声音引文与画面文字同查。3D保留已选内部 `style_id`，输出使用目录中的通用 `label`；原作品名只作输入别名／内部依据。该限定替换不改变模式声音分类、剧情与连续性，取代相冲突的原名照抄要求。

只按用户已明确选择的 `mode` 执行对应一行。不能根据成稿有无旁白、画风或风格标签反向选模式；没有模式先补选，不生成依赖模式的成稿。同一稿每段都检查，不用首段通过代表后续通过。检查对象是实际交付的最终文本，计划与复核摘要只用于对应版本。

| 3D漫真人剧 | 明确3D电影动画；每段风格标签匹配已选 `style_id`；将人物情绪落实为动画面部与身体表现，保持物种及接触连续 | 保留人物台词、VO、OS及原角色归属，三者均可有剧情情绪；不新增独立叙事旁白；不套推文删减权限 | 不设完整一集最低时长；按共同规则检查有依据的局部短镜；不套推文50秒或中性叙述声要求 |

| 推文 | 明确真人写实；人物与场景保持真人形式；不加载3D风格档案 | 保留原文叙事旁白、人物对白、内心声；只有叙事旁白要求清晰平稳中性、不对口型；对白、内心声按剧情表演 | 旁白清单与保留／授权删减对应；长旁白视觉推进；完整一集默认至少50秒；实际镜头默认至少1秒，用户明确调整才变更 |

声音标签跟随模式：剧模式用“台词参考／VO 参考／OS 参考”；推文模式用“台词参考／旁白参考”，后者行首按“画外叙事｜原身份／内心声｜原人物”区分，并在引号外明确类别与独立声轨。两种推文逐镜按 [旁白口型检查](narration-mouth-isolation.md) 核对无声表演和实际对白区间；两种剧不套用推文声源前缀。现场或电话中的画外人物发声不能仅因不在画面就当作中性叙事旁白。源文确实没有独立旁白时，推文模式可只有人物声音，按模式记录填写空旁白清单与实际依据，不补写旁白。

两种推文另按 [连续旁白的镜头设计](narration-editing.md) 检查实际镜头与内部切点，完整旁白可以覆盖多个镜头。另按 [画面信息覆盖](narration-coverage.md) 核对完整原文与具体画面，默认约2–4秒的观看任务；承载旁白且整个镜头超过6秒默认重分，长镜例外须比较实际备选切点的必要损失，并保留不同阶段新信息与结束证据；3D另排除仅靠耳尾／毛发等循环动画填时。两种剧不增加叙事旁白记录要求，四种模式的原有摄影规则继续保留。

四模式按 [关键情绪取景复核](shot-selection.md#关键情绪取景复核) 区分优先级：真人剧／3D漫真人剧以关键情绪强调为先，推文／3D漫推文以有效中近景为先、必要时收近；3D以实际脸部／身体／耳尾载体选景，推文中性叙述声不压低人物的视觉表演。

两种推文逐镜按 [任务与景别](shot-selection.md#推文旁白与内心声的景别选择) 检查人物态度、身体交互、细节和空间是否得到相应的可读取景，信息完整由镜头组共同承担；旁白可用宽景不等于默认宽景。按 [景别成稿复核](shot-selection.md#推文景别成稿复核) 审阅连续偏宽、全景承诺微表情／小字等问题，处理命令行 `REVIEW` 提示并将具体修订或保留依据并入已有内部复核。提示不是近景配额，连续宽景有真实任务可以保留；仅景别名称交替或程序 `PASS` 不证明景别设计合理。两种剧仍按原对白与VO／OS规则检查，不新增此推文专项。

两种3D模式均执行 [动画十二原则内容复核](animation-principles.md#返回前内容复核)，包括通用3D、3D人类及已有动物。检查具体姿态、必要接触、运动路径、驱动、速度、主次和角色辨识度；不要求每镜使用全部十二项，也不把连续动作法误作长镜、缓入缓出误作慢动作或模型稳定误作禁止受控形变。依据实际内容修正问题，结果进入既有内部复核；两种真人模式不套这项动画检查。

两种3D模式选中疯狂动物城且角色已有动物结构时，另执行 [耳尾表演复核](animal-performance.md#返回前内容复核)：关键节点优先考虑耳／尾表达，检查是否落入可见镜头、力度符合剧情、跨镜承接不复位；缺少采用且无具体依据时回修。该内容复核区分主动情绪表达与无信息循环，不要求每镜同时动耳尾。真人模式、3D人类及其他标签不套用此耳尾专项要求。

风格不是剧情授权：选择“疯狂动物城”不自动把人类改成动物；通用3D不强制电影专属造型。3D分支先按已选档案核对，真人分支不要求填写动画风格。共同情绪规则应用于人物表演，不能把角色的愤怒、哽咽或惊讶强加给推文叙述者。

## 四种模式共同检查

四模式按 [出镜人物与静默角色](output-template.md#出镜人物与静默角色) 核对本段各场景的在场人物：全段画外、没有专门镜头、无台词／动作的背景与旁观人物也写入段首名单和场内位置。先查源文与已确认空间，再核对在场合集、段首位置及逐镜可见范围；带到周围区域时检查应在者是否确实呈现或有真实遮挡。两种推文不把无声人物删掉以避免口型，两种3D不为保留背景角色强加表演；两种剧不按发声者筛选出镜人物。精简措辞不删身份，不强制每镜全员同框。

四模式共同执行 [特写时长检查](closeup-duration.md)：面部、手部、动作、道具特写一般非必要不超过2秒，纯画面、对白、VO／OS及推文叙述声覆盖均适用。3D表演、情绪优先、长镜许可和一条完整声音均不自动豁免；近景／中近景仍按原规则。实际进入／离开特写的区间、必要延长及最终可见落点进入既有复核，不新增正式提示词字段。


四模式按 [同期与新增占时复核](timing.md#同期与新增占时复核) 核对实际排时，不逐镜补秒，不无依据延后可同期的动作／反应。声音覆盖不代替视觉证据与必要情绪；未覆盖区间不自动删除，两种推文旁白不成为听者知情依据。改时后复核原声、切点、动作、音效、跨段承接及各模式时长约束；程序定位与具体保留／修订依据进入既有复核，不新增正式字段。

四模式的现场／电话对白及连续反应按 [情绪优先与动作取景](shot-selection.md#对白情绪优先与动作取景) 核对：不能为把动作全貌装进一镜拉远削弱关键表演，必要过程由连续镜头共同交代；动作特写不固定一秒、不遮断必看情绪，必要中景保留具体依据。两种真人核对实际动作与接触，两种3D兼顾既有耳尾／姿态的主要情绪，不把情绪优先等同只拍脸或动作微缩。两种推文的现场对白同样适用，纯叙述画面仍按旁白任务选择景别；声音类别、反应触发、重要证据及各模式计时边界不变。取舍并入既有画面复核，符合明确条件的无局部特写不判漏项。

四模式均按 [关键信息与特写](shot-selection.md#关键信息的可读性与特写) 从原文检查本时点应展示的具体视觉证据，再对照最终段镜的实际可读取景与时间；无旁白、短镜、静态证据及 `action / result / relationship` 分类均不免检。关系构图可保留，但不能替代必要细节；两种推文不以旁白说到证明画面已展示，两种剧不把动作说明转成配音，两种3D不以夸张表演或高分辨率声明代替证据辨认。既有特写、面部、声音、计时与连续性规则共同成立，不设特写配额或新记录字段。缺失、不可读、提前揭露时修正实际画面，结论并入既有来源覆盖与画面复核。

人物声音单独按 [声音成稿与样片复核](spoken-emotion-camera.md#声音成稿与样片复核) 验收，不能由肢体、运镜或一条重读指令代替。两种剧的对白、VO／OS及两种推文的对白、内心声均可有剧情支持的强声态，只有独立叙事旁白要求中性平稳；动画形式不自动变滑稽声线，真人写实也不自动变低声。检查参考音色与本句演法的区别、起句／关键原词／收尾、跨镜与跨段延续，允许原句有力发声而不新增独立叫喊。没有可用音频时仅完成文本检查，不声称配音已通过。

四模式同轮执行 [情绪与肢体复核](emotion-performance.md#返回前复核)，比较关键节点与前态的可感差异、主要身体驱动、原声变化、接收和余波，防止通篇只用皱眉／绷下颌／小幅前倾。两种真人以可信身体力量和人物条件核对，不把自然等同微动；两种3D允许符合风格的姿态对比、受控形变及适用耳尾表达，不照搬真人微动作上限。两种推文只有叙事旁白保持中性，画内角色仍可有强烈无声身体表演，不能因避免旁白口型而压住整个身体；两种剧的台词、VO／OS继续有剧情情绪并分别守住口型边界。简短表演意图可与具体行为一起保留，不新增正式字段、不要求每段爆发，也不把程序通过当成力度验收。

四模式逐镜执行 [面部色彩与轻微脸红](concrete-language.md#面部色彩与轻微脸红) 的内容复核，允许有情境依据的脸颊淡红晕和不过分明显的眼眶微红，纠正导演自行添加的明显情绪变色；带视效剧本原文明示的面部变化按指定部位、程度与时点允许，不以题材标签单独放行。两种真人核对自然皮肤表现；两种3D兼查固有配色与造型，已有动物不以染红面部毛发或新增贴片红腮代替表演。分别核对已有外观、真实受光、原文明示的身体变化与原声内容，不把它们当成统一禁词；结果进入既有 `visual_continuity`；[面部与眼部校验](appearance-validation.md) 对实际成稿常见颜色指令做有限检测，需保留的命中项逐范围绑定来源，脚本通过不代替真实来源与强度的语义检查。

四模式另共用 [语种与画面文字检查](source-continuity.md#剧本语种与台词画面文字)：西语原稿对应西语发声及画面文字，葡语原稿对应葡语发声及画面文字；用户明确目标优先。两种推文连同旁白／内心声检查，两种剧连同VO／OS检查；屏幕、按钮、评论、标牌和道具逐项核对，语种不改变本模式的声音归属与情绪要求。检查实际文本、原词重音提示和两项限制，不仅检查语言标签；有据外语例外、专名及代码分别核对。

四模式有同场正反打参考图时，均按 [分视角引用](asset-library.md#同一场景的正反打与多角度参考) 检查实际成稿：参考图与镜头／内部区间对应，人物位置关系和画面内容分字段且按各引用视角分别描述；共同空间、角色身份、真实站位、持物与动作阶段连续，不混入另一侧背景或自动调换人物。只用一图无需凑反打，两种3D也不得为动画风格镜像人物或改动空间。

原文声音与剧情覆盖、人物身份、素材、光影、空间关系、动作和声音承接、发声区间、词数与段长、静态展示、无背景音乐及正式模板均保留共同校验。除用户明确修改的制作约定外，每段英文发声≤96词、全部声画≤30秒、整数段长、连续静态≤2秒；完整一集与局部短镜的差异按上表执行，不互相套用。

**四种模式统一采用真人剧运镜规则**，逐镜检查真实机位、景别、切点、轴线、主要摄影行为、关系位及跨段连续性，并按 [摄影表达复核](shooting-techniques.md#返回前核对) 从关键节点回查角度、运动与持机质感。两种3D的手持是虚拟摄影质感，不改变动画表演速度；两种推文的叙述声中性不要求摄影中性或静止，运动仍不代替原文视觉信息与长镜检查。3D画风、推文文体或旁白长度不自动豁免共同摄影规则；现场／电话对白的讲话构图限制只检查对应人物发声，不误套到没有现场口型的叙事旁白。仅预分析时按所选模式检查实际分析内容，不要求生成最终文本或交付JSON。

四种模式都做 [跨段首尾构图检查](camera-continuity.md#跨段同主体的可见构图检查)：比较实际末镜结束／首镜开始，同主体同场景须说明可见构图变化，仅换近景／中近景标签或“错开半步”不能放行。该项不改变上表各模式的声音和画面形式要求。

四种模式的人物对白另按 [对白排镜与听者接收](dialogue-reception.md) 逐轮检查原词节点、主看对象及实际切点，关键短句同样不能漏反应；源句 `reaction_channels` 要求脸部时不能用肩背替代。同框可读只完成当前节点，承载对白且整个实际镜头超过6秒默认重分，例外须有 `dialogue_visual` 的持续变化、备选切点与必要损失；`covered / hold_speaker / no_listener` 不自动批准长镜。内部切点四模式都明确写出，原声不因切镜中断、换人或重置力度。3D用真实可见的动画表演，已有耳尾可承担有依据的身体反应；真人按实际表情和身体核对。推文叙事旁白／内心声不作为他人的当场听觉触发，也不强套对白长镜记录。

仅真人剧另按 [纯画面内容定时](timing.md#真人剧纯画面按内容定时) 复核无台词／VO／OS覆盖的画面：所有镜长包括3秒以内均按内容判断，不能默认给满参考区间或上限。信息已读清、必要动作和情绪完成后推进，不固定追加运镜／落稳等待；复杂动作及有依据的阅读、沉默仍保留。处理命令行的纯画面 `REVIEW` 并并入已有计时与连续性复核，不增加每镜必填表、不自动缩时，也不向其他三模式扩展本项。

两种推文另按 [自然结束点](narration-coverage.md#自然结束点与声画时长匹配) 逐实际镜头检查旁白／内心声与画面所需时间，含3秒以内及混合镜头的前后尾段。真人按动作、接触与情绪真实进程，3D兼顾重心、缓入缓出及既有耳尾，不拉慢这些过程填声轨；内心声保留情绪，旁白保持中性。处理 `narrative_visual_pacing` 提示，检查本镜落点后与相邻镜头的新增信息；不动原声完整、口型、语种、最短镜头及静态限制。两种剧的对应规则与提醒范围不变。

## 直接检查最终文本

四模式同样执行 [复核处理与修复验收](review-closure.md)：自动候选逐项关闭，原文独立反查人员、道具及关键事实；当前计划与成稿分别绑定。已发现的问题修复后再检查，不能用模式标签正确或概括的复核结论替代。程序只确认记录完整及有限规则，实际音视频验收另行说明。

四模式人物反应与原声合并时共用 [触发与阶段检查](spoken-emotion-camera.md#反应合并前的触发与阶段判断)：原词含义、知情与触发时点成立后，只并行兼容阶段，必要理解与未完余波不裁掉。原声定位片段内部保留，反应所在画面用具体语义写已听清的信息和可见变化，不再引用完整台词，换人接话后核对原说话者及开口区间。两种推文旁白、非共享内心声与OS不能变成他人听到的信息；VO按真实声源判断。3D耳尾仍受触发及阶段约束，无音频按目标语种估时并如实标明，不能把结构校验当作语义或样片通过。

四模式共用 [观看任务](episode-design.md)、[完整表演](emotion-performance.md#完整表演过程与情绪落点) 与 [视听转折](audiovisual-turning-points.md)，差异继续按上表：人物情绪不传给推文叙述者，3D强化不改变物种或事实，两种剧不新增叙事旁白。后期补充与正式稿分别核对，生成稿无背景音乐、实际光源连续、声源完整和计时限制继续生效；不能因跨模式采用情绪方法而改变原有授权范围。

1. 核对每段“整体风格、画面规格、声音限制”与已选模式和设计记录一致。“整体风格”由本段明确撰写；后两项可使用所选模式默认值，定制时写入 `presentation`。3D整体风格以“风格标签：目录中已选标签；”开头。不能只改成稿为另一种形式而保留原模式记录。
2. 逐条核对实际发声者、音色参考者、类别、内容和区间。剧模式不接受独立叙事旁白；推文模式不把人物内心声误当叙事旁白，也不无依据删除原文VO／OS，应先按实际语境映射其类别。
3. 只对推文两模式的 `narration` 检查引号外的中性／平稳说明，并按 [旁白断句校验](narration-flow-validation.md) 核对完整声音记录、自然断点、同句间隔和来源粒度。明确禁用情绪的“不带愤怒或哽咽”是合法要求；“中性，但带哭腔”仍冲突。“不平稳”不能当作已要求平稳。成稿另加“每次切镜停顿”等指令仍报错；原文引号内提到“愤怒”“三维动画”或讨论“停顿”，不是导演指令，不据此误判。
4. 人工逐镜核对实际运镜、画面内容、人物表演及声音说明与该模式一致，防止段首写对而镜内混入相反要求。程序能检查字段绑定、声音类别及有限明确矛盾，不能完整理解所有自然语言、判断素材贴合或验证未生成的视频。将实际所选模式、检查范围及处理结果写入既有 `delivery_review.visual_continuity`／`conflicts`，不新增正式提示词字段，也不以“模式检查通过”替代具体核对。

完整命令为 `python scripts/validate_plan.py plan.json --final-prompt final.txt`。它按 `mode` 检查计划，再检查实际文本；修改成稿后即使重新计算摘要，模式字段不一致或实际叙事旁白语气冲突仍应失败。需要变更设计时更新 `authored.json`、重渲染、复核实际文本后重跑。仅 `--timing-only` 或不提供 `--final-prompt` 不代表完成成稿检查。

四模式共同按 [同段切镜不重新起句](output-template.md#同段切镜不重新起句) 检查每次原声的唯一执行与后镜承接：剧模式检查 dialogue／VO／OS，两种推文检查 dialogue／narration／inner。保持各模式声音标签、口型与旁白语气边界；反应画面不再次输出完整台词，切回不重启已完成部分。实际切镜、听者反应、原文自带重复、必要画面文字和目标语种仍保留；不以取消切镜、拉长镜头、合并不同声音任务或删掉线索解决重复朗读。
