# 专业光影术语库

仅在准备使用特殊光效、核对术语或用户要求专业光影时读取；普通稳定窗光无需加载本库。基本连续性与返回检查见 [影视光影](cinematic-lighting.md)。


采用“术语＋必要对象／空间方向＋关键可见结果”的简洁写法，已有上下文足够时不重复补齐全部要素。专业术语可以直接保留，不必改成口语释义；库中的条件用于选择与复核，不整段复制进提示词。中文名优先，英文名仅在消歧时选用，不堆别名。纯技术分析可以讨论未采用的方案，正式提示词只写实际采用效果。灯光可重新设计，图中没有同样光效不构成禁用理由；材质、散射介质和遮挡物的条件仍须成立。

| 术语 | 使用条件与识别重点 | 精简画面示例 |
| --- | --- | --- |
| 柔光／硬光 Soft / Hard Light | 区分阴影边缘过渡柔和或清晰，不把柔光等同于低反差、硬光等同于过曝 | 东侧柔光照亮近窗侧脸，脸上明暗交界过渡柔和 |
| 低调／高调布光 Low-key / High-key Lighting | 低调以暗部为主，高调以明亮调子为主；分别保留所需暗部细节和高光层次，不写成全黑或过曝 | 低调布光，背景亮度低于人物，侧主光保留眼神与口型 |
| 侧光／侧逆光 | 指光从主体侧方或后侧入射；用空间参照定位，反打后按人物朝向重算，不能把两者当同义词叠加 | 东侧后方的侧逆光勾出肩部亮边，正面保留弱补光 |
| 冷暖对比 Warm–Cool Contrast | 不同光源或不同区域的色温关系，写清哪一处冷、哪一处暖；不让灯光随情绪无故换色，不借受光改变人物固有色。脸颊淡红晕、眼眶微红及原文明示的面部视效另按 [面部色彩边界](concrete-language.md#面部色彩与轻微脸红) 判断 | 冷色窗光照亮靠窗侧脸，背景原有壁灯保持暖色 |
| 体积光 Volumetric Lighting | 光在薄雾等介质中散射，使空间中的光路可见；需有光源和介质依据，不能仅因逆光就使用 | 高窗斜射光在既有薄雾中形成可见光束，穿过大厅中部 |
| 丁达尔效应 Tyndall Effect | 指胶体微粒散射使光路可见的物理现象；不泛指所有光晕或逆光。普通影视雾中光束优先写“体积光／雾中光束”，使用此词时补充散射介质和可见光路，不与体积光重复堆写 | 杯内原有胶体液使侧向入射的光路清晰可见 |
| 伦勃朗光 Rembrandt Lighting | 侧上方主光，鼻影与面颊阴影相接，暗侧眼下保留小块三角亮区；单纯半脸亮不等于该光型，转头后不强保三角 | 侧上方窗光使背光侧眼下保留小块三角亮区 |
| 蝴蝶光 Butterfly Lighting | 正前上方主光在鼻下形成较对称的小阴影；只在光源与朝向成立时选用，不为该光型强改日常对白机位 | 正前上方柔光照亮面部，鼻下留下浅小的对称阴影 |
| 负补光 Negative Fill | 通过遮挡或吸收环境反射光压低暗侧亮度，是减光手段；不写成黑色发光或自动新增黑旗道具 | 保留窗侧主光，背窗侧负补光加深面颊阴影，眼神仍清楚 |
| 轮廓光 Rim Light | 后侧光沿主体边缘形成亮边，与背景分离；不是主体全身自行发光，也不是整圈恒定光环 | 后侧窗光沿肩部形成细窄亮边 |
| 镜面高光 Specular Highlight | 光滑表面对光源的反射；按物体、光源及观察角判断，不要求每次移动都改变高光，也不一概冻结 | 杯子倾斜时，杯沿的镜面高光改变位置 |
| 焦散 Caustics | 光经反射或折射汇聚形成亮纹；需匹配实际水体、玻璃或曲面等介质与光路，不把普通影子称为焦散 | 阳光穿过盛水玻璃杯，在桌面形成弯曲亮纹 |
| 水波焦散 Water Caustics | 水面起伏造成反射／折射亮纹变化；区别于水面本身的闪光，注明亮纹落在哪个表面 | 池水反射形成的亮纹在邻近墙面缓慢游移 |
| 图案投影 Gobo Projection | 用图案片投影塑造光形，须有已确认的投影设计；自然窗框投下的影子直接写“窗格光影”，不误称 Gobo，不为术语新增设备或窗户 | 已有投影光在背景墙形成清晰窗格图案 |
| 斑驳光影 Breakup Lighting | 枝叶等遮挡分割亮区形成明暗块；没有风或遮挡物运动时不自动摇曳 | 树叶将阳光分割为地面上大小不一的亮斑 |
| 高光辉光 Bloom／Diffusion Glow | 高亮区域周围柔和扩散的成像效果；不等于失焦、雾中光束或新光源，不一律称为胶片光晕 Halation | 背景灯泡周围轻微辉光，人物眼神与轮廓清晰 |
| 镜头眩光 Lens Flare | 强光进入镜头形成光斑、条纹或局部雾化；需光源与视角关系，不是落在墙面的实体光斑 | 镜头转向低角度阳光时，边缘短暂出现眩光，随取景变化退出 |

例如窗边对峙可选适合人物朝向的伦勃朗光与负补光；有薄雾的大厅可选体积光；已有水杯的关键动作可有焦散。不是所有场景都要加入特殊光效；选一种准确效果即可时，不添加同义术语或无关组合。

## 视频提示词的精简写法

- 稳定照明写状态即可：“低调布光，东侧柔光照亮人物靠光侧脸，暗侧负补光，双眼与口型仍可辨。”不为固定布光附加闪动或变化。
- 有实际运动时写变化及终点：“侧逆光沿肩部形成窄亮边；人物转身走出原亮区时，肩部亮边逐渐减弱。”只有剧情原有转身和移动时使用，不为示范术语新增动作。
- 每段按信息任务选择足够的术语，不设数量下限，不堆同义词；同一对象、同一时点不同时要求清晰硬阴影与完全柔化阴影。不同光源或区域确需不同效果时说明归属。
