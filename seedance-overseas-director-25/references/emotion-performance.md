# 情绪外放与强度选择

设计人物情绪、讲话或无声反应时读取；即使剧本没有情绪标注，也须从剧情内容判断表演。依据用户提供的《Seedream 情绪外放提示词手册》提取表演方法，并改为适用于人物连续视频表演的动作与声音提示。手册中的静态图像构图、道具、天气和画风示例不自动成为本剧剧情或素材事实；主技能的原文、景别、服装、光影连续性与时长规则优先。

人物**实际讲话**的情绪节奏、原词重音、口型与运镜选择，另按 [讲话情绪与运镜](spoken-emotion-camera.md) 执行；此处的通用情绪线索不自动成为发声动作。

## 剧情驱动的情绪放大

- **情绪标注只作参考**：剧本里的“平静、淡淡、微怒、悲伤”等名称、强弱词和一般表演提示用于理解，不直接锁定成片情绪，也不是强度上限。依据本场实际事件、人物诉求、可能失去或得到什么、关系变化及已知信息，主动选择更有表现力的情绪及强度；不等待原文写出“强烈、崩溃、爆发”才强化。情绪未标或标得较轻，但剧情冲突明确时，也要放大关键反应。剧情依据可以支持合理推断出的表演细节，无须逐词明示该神情或语气。
- **区分情绪提示与剧情事实**：可以重设表现强度和情绪侧重，不能借此改变原词、人物动机、关系事实、知情顺序、行为结果或身体条件。剧情确需保密、掩饰、安抚或稳住对方时保留其目的，用更清楚的咬字、目光、肩背或动作收放呈现内在压力；单独一个“平静”标签不能自动成为压低全部表演的理由。用户直接指定的具体表演要求另行遵从。
- **按整场设计层次**：先确定本轮从何种前态开始、压力如何积累、何处因实际信息改变、关键峰值及之后的余波，再落到逐镜表现。关键冲突、求助、揭晓、失去、重逢和告白等节点应比普通信息交代更鲜明；强化既包括愤怒、悲伤、恐惧，也包括喜悦、温柔与释然。不把所有人物、所有台词同时推到最高档，不为每段强造爆发；已有强度可以维持，回落仍有承接。
- **主要情绪动作先看人物关系**：在本轮已设计的动作中，确定承担情绪积累、转折或释放的主要动作；有明确指向、施受或注视他人行为时，按 [关系动作规则](shot-selection.md#有指向与人物关系的动作) 清楚呈现“谁对谁做什么／谁看着谁做什么”，可以不用动作特写。其他主要情绪动作按 [特写取舍](shot-selection.md#主要情绪动作的特写) 安排关键阶段；对白中遇到不可替代情绪瞬间时，按其中的同框可读取舍处理，不只改拍一张脸或漏掉身体变化。自然表演补全也可入选，须有具体剧情和动作变化依据；普通表达手势不逐项特写。
- **用视听行为实现放大**：优先选择能让观众看清人物诉求与受影响程度的原词重音、声线变化、可见神情及自然肢体；普通节点突出一两项，关键峰值可按 [视听转折](audiovisual-turning-points.md) 让多个通道有主次地协同，不将数量偏好当作强度上限。放大不是统一加大音量、每句颤声或增加形容词，也不自动加哭喊、吸气音、接触、道具、走位或慢动作。能与原声同期的过程共用时间，必要接收及未完成余波保留真实占时。

例如，背叛证据当面揭晓而剧本只标“微怒”，可依据被欺骗的事实和追责诉求，让原句在关键指控处由压住音量转为清楚提高音量，重心在原站位内前移带动躯干前倾，问完仍保留前倾姿态等待原有回应；不擅加拍桌或辱骂。若人物必须假装未发现背叛，则改为短暂失守后主动收住，不让对手无依据地识破。不是每次背叛都必须前倾或提高音量，取舍取决于当前人物与场面。

## 关键情绪的强弱差异

在固定取景和秒数前，先依据已提供事实判断人物想从谁那里得到／阻止什么、眼下可能失去什么、哪句信息改变了回应。选择该节点的主要表演，再按 [模式优先级](shot-selection.md#情绪与景别的模式优先级) 安排镜头与时间；不为每句另填评分或全套阶段表。

- **强度有可感差别。** 普通说明、关键交锋和原剧情的失控／释放不能只换情绪形容词而继续同样的皱眉、绷下颌和轻微前倾。结合前态，选择能在当前画幅读清的姿态对比、动作幅度／起动速度／制动方式、原句音量／语速／重音变化及持续状态；不要求每项同时增大，也不把高强度固定成快读、大喊或大动作。有据的低声、静止或掩饰须让观众读到具体控制、压力或其对原有回应的影响。
- **身体与声音作用于同一对象。** 以一个主要意图组织协同：支撑与重心可带动躯干、肩臂和手，脸部及原声配合；这是同一表演，不按身体部位数限制成只能动一处。具体取舍见 [讲话中的肢体表达](spoken-emotion-camera.md#讲话中的肢体表达)。悲伤、欢喜、温柔和释然各有方向，不统一转成逼问或愤怒。
- **落点是回应发生变化。** 对已存在的关键刺激，写清原先怎样应对、听到后怎样继续／收住／改变原有回应、离开本镜时残留什么。已建立的强度可以维持，不为每句造新峰值；对手反应必须基于其实际接收，不能擅造退让、认错、恐惧、决定或事件来证明主角有气势。
- **完整过程由镜头组与真实时间共同承载。** 重要身体驱动、接触和落点须可读，不要求同一镜装下全部身体。对白按 [情绪优先取景](shot-selection.md#对白情绪优先与动作取景) 保住关键表演，必要动作沿同一进度通过合适构图或短特写交代，必要中景须有具体关系／身体任务；普通手势不滥切特写，原声保持完整。自然语气和必要接收／余波参与估时，不把主要表演压成微动、不强塞一秒，也不为动作轮廓完整拉远削弱关键情绪。按已有计时、长镜复核和切点规则调整，不恢复无信息长镜或固定加停顿。

## 完整表演过程与情绪落点

完整指刺激、接收、应对、可见落点与必要余波的因果可读，不要求一直停在同一个人物或机位。对白可在信息节点切到听者并保持原声，在必要时切回承接讲话者的新阶段；不能借“完整表演”取消有任务的反打，或切走原文必须看见的瞬间。实际长镜按 [对白长镜复核](dialogue-reception.md#对白实际长镜复核) 取舍。

重点情绪先确定这次刺激究竟改变了什么，再把必要过程写进当前可见镜头。无需每镜填写固定步骤，也不强迫所有人物藏有算计。

- **诉求与进入状态。** 承接姿势、目光、呼吸、持物、距离及此前余波，明确人物正在争取或保住什么。心理依据取自本段事实；真诚、喜悦或直接拒绝同样成立，不新增秘密关系或创伤解释。
- **刺激、本能与选择。** 指定触发的原词、可见动作或已有声音，先出现什么反应，人物随后压住、放任、利用或未能控制什么。身体和意志可以不同步，例如声音已稳而肩背仍绷紧；不每次都“立即恢复正常”，也不把合理自然动作都解释成情绪反射。独立吸气、哭喊、倒地等声音／事件仍遵守原文边界。
- **对白与对手反馈。** 原句是在命令、试探、求证、安抚还是拒绝，重音与停连如何作用于对方；对方看到了什么、是否误读，原有回应怎样改变局面。需要隐瞒时说明观众为何能察觉、对手为何未同样察觉，不能公开暴露后仍无依据地写对手毫无发现。
- **落点与余波。** 用可见变化落实听懂、强撑失败、接受安慰或改变应对，等关键变化成立再切。大幅表演也要有因果，强压迫要看见原有施压、应对和阻碍，反击要看见原文已有后果；不能把所有重击统一缩成眼神微变或手指收紧。下一镜接残留状态，不重新演同一次发现、失守或起身。

先判断画面能否承载：手部特写不能同时要求看清脸，远处双人关系镜头不能默认读清两张脸的微小变化；需要单独读取时用符合现有切点规则的实际反打，或同镜有效转移注意。只有人物收到足够信息后才反应；声画同期不要求把整个反应挤在原句结束前。详情见 [讲话与反应](spoken-emotion-camera.md#台词与他人反应同步)。

这些心理与观看依据用于导演分析；正式“画面内容”和声音说明保留完整的可执行过程，删除无执行作用的解释，不把完整版压成情绪标签。推文叙事旁白继续中性平稳，人物对白、VO／OS／内心声按各模式表演，不能借强化删原句或改变声源。

## 从情绪词落到可拍变化

面部和生理表现须遵守 [面部色彩与轻微脸红](concrete-language.md#面部色彩与轻微脸红)：可依据实际情境保留脸颊淡红晕和不过分明显的眼眶微红，不扩大到眼白／虹膜或整圈鲜红；不把放大情绪解释为惨白、整脸涨红、发青发紫或改变毛色。原文明示的面部视效、身体状态与已有外观分别核对，允许指定变化，不从情绪名称或视效题材标签推导新的生理事实。

强度比较与长篇心理判断用于内部设计。最终提示词按 [具体视听表达](concrete-language.md) 以可见／可听过程为主体，可用简短、有依据的表演意图区分“压住怒火追责”和“急于解释求理解”等不同演法；必须紧接具体身体与声线变化，不只贴标签，也不在动作后堆叠“破碎、情绪复杂、极具感染力”等评价。没有剧情依据时不新增泪水、颤抖、接触或空间变化；清理冗余不能删掉有效意图或把关键反应压回微动作。

- 先标明剧情实际触发点、谁已经知道信息、角色当前目标与得失、前次表演的余波及本镜可见范围，再主动选择足以强化该节点的程度，不照抄情绪标注。按 [讲话情绪的连续过渡](spoken-emotion-camera.md#讲话情绪的连续过渡) 从前态逐步变化或保持，不逐镜重选档位造成忽高忽低。极强可由剧情中的重大冲击和此前积累支撑，无须原文另写强度词；不能仅凭“悲伤／愤怒”标签安排失控，不将所有角色、所有台词逐级升级。已有高强度不因切镜立即归零。
- 把“悲伤”“愤怒”等抽象词改成可见或可听变化：面部与生理信号（视线、眉眼、下颌、泪膜、呼吸）、身体信号（肩线、重心、步态、可用手势）、原有角色声音（重音、气息、语速、音量）、按剧情设计的场景光影与构图。普通节点选择少量有效信号，不把各层逐项堆满；峰值按具体作用和可读性决定协同范围，不设固定信号数量上限。整轮讲话按 [讲话中的肢体表达](spoken-emotion-camera.md#讲话中的肢体表达) 纳入合适的身体参与，维持情绪也可有自然动作。
- 写清“触发 → 变化开始 → 观众看清 → 动作或视线落点 → 残留状态”，并按段内起止时间安排。将将落未落的泪、伸到一半又停的手等未完成动作只用于原文支持的迟疑或转折；下一镜延续同一状态，不反复从头表演，也不为了静态画面定格人物。
- 面部细节要在实际景别能看清，关键变化还须成为有效观看重点。按 [模式优先级](shot-selection.md#情绪与景别的模式优先级) 选景：两种剧先定关键情绪强调，普通讲话用中近景／近景；两种推文先在中近景内表现，关键变化确需更集中观看时再收近。面部特写不自动对应每个情绪波动，禁止器官级大特写。手势检查持物、左右手和遮挡；口型、VO/OS 声源及原文台词保持正确。
- 根据剧情氛围选择主光方向、色温、光质与反差，可重新设计参考图照明，让受光与取景服务当下表演；方案确定后保持跨镜连续，不把悲伤固定套成蓝光、喜悦固定套成暖光，也不无依据增加雨、花瓣、火光、血迹或新道具。按已选模式保持真人写实或3D动画竖屏，不加入油画、水彩、海报定帧、超宽画幅或未经请求的胶片品牌词。
- 不把手册中的“无声呐喊”“嘴张开发声却听不见”等静态描述当作配音或口型指令；现场说话与人物 VO/OS 严格按原文类型处理。情绪强化不能改词、添台词、增加独立旁白、强制哭喊或用快读挤时长。

## 情绪线索库

以下是可选择的**表演线索**，不是必须复制的句子；情绪标签可作为简短表演方向，必须落实为本镜具体视听过程，比喻和空泛评价不输出。先按剧情内容设计并放大适合该节点的强度，再只取当前人物、镜头和身体状态能执行的细节；三档均不由原文情绪标签锁定，也不是逐句轮换或从低到高爬升的模板。极强表演须有足够剧情支撑，接触、逃离、瘫坐等改变行为结果的事件仍须原剧情已有，不能由情绪放大新增。笑、哭、哽咽等声音线索可用于原句声线或已有发声，不凭本表新增独立笑声、哭喊或吸气音，原词和完整发声保持清楚。

| 情绪 | 克制 | 外放 | 极强（剧情充分支撑时） |
| --- | --- | --- | --- |
| 喜悦 | 眼神亮、嘴角松开 | 笑声与肩背一起舒展 | 喜极而泣，笑与泪同步出现 |
| 悲痛 | 泪膜浮起但压住呼吸 | 眼泪滑落，声音或肩膀发颤 | 崩溃痛哭、身体收缩，保留实际发声关系 |
| 愤怒 | 原句压低音量，已展开的手有意收住，目光仍留在对方 | 重心带动躯干朝实际对象前倾，肩臂随指控原词展开，关键词咬字变硬；不强加步移 | 原句关键处音量明显提高或节奏突然收紧，躯干与已有手势在同一落点明确制动，结束后保留姿态；不新增喊词、独立喊声或冲突动作 |
| 恐惧 | 呼吸一滞、警觉回望 | 身体后缩、手做有依据的防御 | 惊退或失控逃离，路线和结果清楚 |
| 绝望 | 视线失焦、肩线垂下 | 姿态松塌、动作明显迟滞 | 原句说得吃力、肩背明显收拢；瘫坐等动作只在原剧情发生时呈现 |
| 惊艳或震撼 | 眼睛微睁、短暂停息 | 屏息凝望、身体向目标靠近 | 含泪或震住，仍保留知情和动作顺序 |
| 孤独 | 目光避开他人、姿态内收 | 与已有空间或人群形成距离 | 被既有环境压住的孤立感，不编造人群 |
| 温柔或深情 | 视线放软、说话放缓 | 身体朝向对方、已有触碰更轻 | 原句声线可短暂哽咽但保持词句完整；拥抱只在剧情已有时出现 |
| 悲喜交加 | 笑意与泪膜并存 | 笑声发颤、肩膀轻抽 | 哭笑同时爆发，不能混淆实际声音 |
| 释然 | 吐气、眉心松开 | 肩背卸力、声音回稳 | 脱力或坐下须有原文动作依据 |
| 挑衅或桀骜 | 下巴微抬、目光不退 | 斜睨、语调有意挑衅 | 冲突动作只取原文已有的接触或推进 |
| 执念或凝望 | 视线停在既有目标 | 手停在接触前、呼吸收紧 | 真正接触或失控只按原文事件呈现 |

## 返回前复核

把以下判断并入同一轮内容复核，不增加正式字段、固定评分或额外重读全稿的步骤：

- **取景与观看重点**：先按 [关键情绪取景复核](shot-selection.md#关键情绪取景复核) 从重要节点回查实际构图和切点；两种剧检查关键转折是否被中近景带过；两种推文检查中近景是否有效、收近是否必要。写了表情或使用了特写都不等于表演成立，实际取景充分才保留。
- **强弱与意图**：按 [强弱差异](#关键情绪的强弱差异) 比较关键节点与进入状态、普通交流及相邻已给片段。短意图须绑定可辨的原声／姿态／动作过程，不把情绪标签当上限。若重大冲突普遍只有皱眉、绷下颌、小幅前倾和重读关键词，又无控制过程或身体条件依据，回到表演设计；不靠换同义词、全员喊叫或禁用“小幅”过检。持续高强度与有据克制均可成立，不为每句造新峰值。
- **身体与可读性**：核对主要动作的驱动、幅度与速度、姿态对比、收势及对原有互动的影响。同一意图下多部位协同不判堆砌，杂乱无目的的动作才减。主要动作按关系动作规则或必要特写呈现，符合关系规则或对白情绪同框取舍的无特写不判漏项；关键过程被裁掉先调整合法近距离构图及切点，不默认扩大景别。已有特写不重复补拍，有意静止或受限不为过检添动作。
- **接收、落点与承接**：刺激、本能／选择、原有回应和必要余波在可见镜头内成立，反应不提前知情、不因追求紧凑提前切断。观察者、行动者和承受者不混淆；换人、反打、跨段后延续实际姿态和声线，不重演发现或复位耳尾，不无由突升／骤降。整集另按 [观看任务](episode-design.md) 检查兑现与原断点；无需每镜都呈现完整四阶段。
- **事实与模式边界**：保留掩饰目的、身体条件、持物、施受结果与原词。可见信号落在正确机位和时间，光影与素材空间连续，不新增无依据的生理反应、天气、道具或事件。两种真人核对可信力量；两种3D核对姿态与风格，已有动物按耳尾专题。推文叙事旁白中性不压低人物情绪，无口型不等于无表演。按 [面部色彩](concrete-language.md#面部色彩与轻微脸红) 保留合规脸颊淡红晕、眼眶微红及原文明示的面部视效，不添加无依据的明显情绪变色。

听者记录“已覆盖”、原词完整和脚本通过均不证明力度足够。发现问题先改实际表演及受影响动作／反应证据，必要时回修取景与预算；具体结果并入 `delivery_review.visual_continuity`，真实冲突记入 `conflicts`，依原流程重渲染、复核和最终校验。没有实际视频时不声称已验证成片感染力。
