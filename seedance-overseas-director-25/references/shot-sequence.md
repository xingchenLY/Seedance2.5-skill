# 镜头排列、重复画面与续作边界

四模式共用。按既有流程先从原文识别必要信息和表演，排实际镜头骨架，再写正式提示词；本页加强已有复核，不增加景别比例、切镜配额或制作模式。两种推文仍先连续剧情分组、计算发声预算、锁定4–30秒段长，再排镜。

## 真实机位与有效切点

同场同一实际机位复用一致的定位与标识，起点和落幅分别核对。同一主拍人物、同一真实机位，仅改变人物景别、焦距或裁切的普通硬切不通过，包含中景→近景；人脸取景收紧不能冒充不同拍摄任务。人物与物件、手部之间有必要信息任务的插镜不按同一人物裁切处理，但仍查可读性、连续性与无效重复。真实时间跳切仅按原限定范围处理，跨段同景别仍不允许。

机位文字有差异不等于实际画面有差异。小幅位移、略调高度、同义位置、改编号或改主拍名字，均须核对真实观察面、前景遮挡及空间关系；没有可辨认变化，按相似构图回修。合法的连续推近是一镜，不能用推近描述掩盖硬切，也不因禁切一律改成长镜。

先比较服务当前任务的真实反打、斜侧观察、前后景层次、必要细节及有动机的摄影运动，再看整段是否反复使用同一组平视过肩。每个选择必须保持人物站位、视线、轴线、主光与道具接触；不用强行走位、无关空镜、随意俯仰或手持摇晃制造多样性。

## 每镜信息与整段返回

从原文提取本段必要的环境关系、动作发起、关键接触、证据、接收变化和结果，按需求安排；不是每镜七项全写。每镜明确主看对象、可见起态、本镜必要变化及结束状态。不能用重复皱眉、耳尾摆动、慢推或换措辞证明信息变多。

相邻切点通过后，还要按成片顺序检查整段：返回先前构图时，哪些新的原文信息已经到达，人物进入哪个新的动作／情绪阶段，观众需要重新看清什么。正常A/B/A正反打和有新信息的返回允许保留；相同构图、相同状态且无必要进展的返回重排。普通镜头可合并重复，但不能因此超出旁白全镜小于3秒，或吞掉必要反应、证据、真实切点。

程序以有限文字规范化、构图重复与相似机位给出 `shot_sequence` 候选，不证明几何相同或画面必错。复用既有 `delivery_review.findings`，证据覆盖本批所有关联镜头；跨批前镜已由 `previous_tail` 与其最终文字绑定，当前候选仍须对照该快照。保留时写具体的新变化或持续同看的必要阶段。只有“台词未完、双方在场、保持张力、换了机位名”不能放行。修复后重新生成当前候选，旧结论不套用新文本。没有候选也要对照原文检查遗漏的信息。

## 双人对白

双人中近景的结束点由共同观看任务决定，不能把整句台词时长直接当成双人镜长。关注点转为单方关键情绪或另一方接收时，选择能读清变化的真实机位，声音完整跨镜。单主体过肩中的肩背只承担关系参照，不视作两个同等主拍对象。程序对较长／跨发声者的双人画面给出复核候选，3秒仅是此候选的定位条件，不是对白硬上限，也不是3秒前免检。

## 同集续作的前段末镜

每批续作先读取已交付前段最后一个实际镜头及其最终运镜／画面文本。`episode.segment_start > 1` 时填写内部 `previous_tail`，不是正式模板字段：

| 字段 | 内容 |
| --- | --- |
| `episode.segment_start` | 本批起始段序，例如3 |
| `episode.previous_tail.segment_id` | 前段原内部ID |
| `episode.previous_tail.segment_number` | 前段序号，例如2；须为本批起始序号减一 |
| `episode.previous_tail.shot` | 从已交付记录复制末个实际镜头的对象，不能填说明字符串 |
| `episode.previous_tail.final_camera` | 复制该镜最终运镜区间，含原起止秒数、景别与机位 |
| `episode.previous_tail.final_visual` | 复制该镜最终画面区间，含原起止秒数与内容 |

`shot` 必须为真实对象，含起止时间、景别、机位、可见人物、`view/end_view` 与已交付对应的 `camera_text/visual_text`。程序核对段序、实际末镜构图及最终文字绑定，并把该末镜加入本批第一处切点比较。同场同主体时当前首镜仍用原 `cut_change_before` 绑定前后可见变化；前段的证据来自快照，不复制进新段提示词。

快照不参与本批渲染、计词、总时长或重复播放；不要用改回段号1、改集号或虚构快照规避。程序无法证明所填快照确实来自已交付文件，必须实际读取原件。前段末镜被修订后重新载入，不能只更新说明或摘要。缺少可确认的前段时可准备其他内容，但不能声称跨段已通过或交付为完整校验成稿。

## 交付与回修

实际旁白镜长严格小于3秒；普通特写一般不超过2秒；对白按关键表演和接收节点排镜。切镜不拆声、不重读、不重演动作、不追加推文预算。画面信息不够时先补齐原文可见事实及必要表演，不能新增剧情；确实无可行安排时报告具体冲突。

运镜只表达必要摄影事实，画面表达可见行为和变化；段首保留完整在场名单、道具与基本空间。修改源字段后重新渲染，检查相邻边界、整段返回、声音连续与信息可读性。检查描述不进入最终提示词。
