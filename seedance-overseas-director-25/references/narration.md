# 旁白识别、保留与覆盖

生成前先按本节确认原文的发声性质，再排镜头和时间。已有同一文稿、版本与范围的分类可复用。独立叙述者旁白、角色叙述性 VO 和人物内心声都属于应保留的声音，不能仅因为没有人物当场开口而省略；内部类别仍分别使用 `narration` 与 `inner`。以下已获授权的删减只适用于相应叙述片段，不扩大到人物实际台词或内心声。

## 从源文识别

| 原文情况 | 处理 |
| --- | --- |
| 明确标注旁白、解说、叙述者、Narrator，或已确认的旁白口播稿 | 登记为旁白；不因句子同时描写动作、背景、心理或随后有台词改成纯画面 |
| 已确认作为叙事正文输入的小说／故事段落，叙述者连续讲述，而没有逐句标“旁白” | 叙述句默认作为旁白登记；不只提取引号内对白，不因去掉标签就丢失叙述声音 |
| 标准拍摄剧本的场次地点时间、镜头指令、舞台动作说明、括号中的表演提示 | 仅用于画面／表演，不机械配音；明确的旁白标记优先，不能把已标旁白的内容改归舞台说明 |
| 人物 VO／OS、第一人称回顾、当下内心声或现场画外对白 | 按语境和已有定义分类，缩写与第一人称本身不决定类型。角色回顾讲述可为旁白，当下心理为 `inner`，实际在场或电话说话为 `dialogue`；保留原标记及声音归属 |
| 只有剧情构思、梗概或镜头想法，未给需要念出的叙述文本 | 用于设计，不自行编造独立旁白；原文确无旁白时允许零旁白 |

无标签时先查全文文体、相邻段落和用户已确认用途，不单凭“可以拍出来”或“没有引号”判为无声。局部确实无法区分，且会改变是否发声或谁发声时，只澄清该处；已有口播／叙事用途的确认直接沿用，不重复询问。不能把所有非对白都配音，也不能把所有非对白都变成画面。

## 保留与同步

- **原文旁白默认完整保留，话语引导和两人对话中的反应旁白按下文已获授权的例外处理。** 先登记原句、来源及声源，再确定保留／删除片段，最后翻译、分镜和估时；按 [共用语种](source-continuity.md#剧本语种与台词画面文字) 与人物台词、画面文字统一，保留的同语种片段逐字保留；中文／西语／葡语旁白不默认转英文，确需翻译时才固定忠实译文。其他删减／取消旁白仍须有用户明确要求并按其范围处理，逐项留下依据；已有明确要求不再请求确认。
- 快节奏、动作已在画面呈现、动作特写要求、单人声音分镜、字数／时长上限都不授权删旁白。时间不足先减少无信息等待和可选摄影，再自然分段；不将旁白压成摘要或改成角色台词。纯拍摄说明分类为无声，不算删除旁白；已标为旁白的获准引导／对话反应仍先登记，再按相应小节删除，不伪称原文没有旁白。
- 旁白与动作特写可以共享时间：画面呈现原文支持的动作及关系，声音完整连续，画内人物不对旁白做口型。原文叙述尚未揭晓的信息不提前展示；角色不能因为观众听见旁白就提前知情或反应。说话声音与其所配画面是两条时间线，动作完成后可接下一已有镜头，不拖慢动作配满旁白。
- 独立叙述者也是合法发声者，不必是出镜人物。“一个正式分镜一位发声者、一类声音”同时适用于叙述者、角色旁白、内心声及对白；顺序出现的旁白与人物对白另起正式分镜，可在同一生成段连续画面中衔接，不删除声音或增加停顿。原文明示／用户要求不同类别同时发声时按 [跨类别重叠例外](narrative-voice.md#跨类别重叠例外)，分别保留声音行，不为了单类规则错开发声。
- 旁白跨镜全文只登记和发声一次。同一句在同一生成段连续发声时，完整声音行放在起声分镜并写全覆盖区间，后续正式分镜在画面内容承接，不重复引号内原词。只有真实停声或跨生成段才按自然语义分配片段，拼接还原原句，并执行 [断句校验](narration-flow-validation.md)。旁白不默认等于角色 OS，角色也不替叙述者说话。音色借用不改变实际发声者身份；只有声音的叙述者不进入出镜人物或正式站位。

声音标记明确独立画外叙事身份，配合 [画内讲话分离检查](narration-mouth-isolation.md)，例如：

```text
（画外叙事｜叙述者）旁白参考（叙述者）音色：（叙事旁白，独立画外叙述声轨，仅观众听见，清晰平稳，0–3 秒）“He would need the key.”
```

用户已指定借用女主音色时，改为“（画外叙事｜叙述者）旁白参考（女主）音色”；角色有已确认中文名时声音标签按中文名规则填写。“画外叙事”不改变真实叙述身份，不新增人物或模板字段。

## 话语引导的授权删减

用户已明确允许本技能删除“她开口说”“他回答道”“她压低声音回答”等话语引导，后续使用直接按此规则处理，无需再次确认；用户本次另要求逐字朗读或保留引导语时遵从该要求。

- **按作用判断，不按关键词批量删除。** 仅引出、承接或标明相邻实际台词，且发声者已能从上下文与声音标签明确的引导语可以省去，例如“她说道”“他问道”、`she said`、`he replied`。前置、后置或夹在同一句台词中的纯归属语均可处理，人物台词本身不删、不改、不重念；即使引导语原先标为旁白也适用。
- **带说话方式的引导也可删，表演信息转入声音说明。** “她压低声音回答”“他愤怒地说道”“她颤声问”、`she whispered` 等，仅为相邻实际台词附带音量、说话方式、语气或情绪时，可整段删去引导旁白，把“压低音量接话”“声音发紧”“尾音颤抖”等原有表演要求放到该人物台词行的引号外说明；原台词引号内不加字。音量变化与现有声线承接，不另加准备镜头或停顿；不能把这些词又放进发声文本让角色念出。
- **独立剧情信息继续保留。** “他终于打破沉默”“陌生人用父亲的声音说”等承载事件转折或身份线索，不作为整句引导删除；“他没有回答”“他说她会回来”及对过去言行的转述也不按引导语处理。角色实际说出的句子中出现“他说／你说”仍是台词内容，不能套用此例外。
- **混合句只去可分离的引导部分。** 如叙述“她握紧杯子，低声说：”后接人物台词，可去掉“低声说”及仅服务该引导的标点，将低声要求转入人物声音说明，保留“她握紧杯子”的叙述信息、原有动作和后续台词；若该动作同时符合下节两人对话的即时反应例外，可另按该授权省去其口播，动作仍保留。不能因此把其余旁白全改成画面／表演说明；无法安全分离或会损失语义时保留原句。英文同样按原文连续片段分割，保留片段的实词、大小写和内部标点不改，不为润色重写对白。
- **先删减，再计词排时。** 已有草稿或定稿时，必须执行 [删减后时间轴重排](narrative-voice.md#删减后的时间轴重排)，同步词数、整段时长及全部受影响区间并重新校验，不能只删文字。 被删引导不进入发声文本、词数或声音区间，也不单独生成一个无声分镜、不预留停顿，不在最终声音说明里要求再念一次。实际说话人、原有动作、必要气口和真实剧情停顿继续保留；**删除引导旁白不删除画面中的开口动作**：出镜人物实际讲话时按 [开口与口型](narrative-voice.md#开口与口型) 在原画面内容写可见开口／持续讲话，不能误将这类制作说明也清除；其余旁白的完整性、回忆、可见性与镜头规则照常执行。

按下方原始记录保留被删片段及定位，使用现有 `status: "omit"` 与 `omission_basis`；依据写明“用户对本技能已授权删除话语引导（含说话方式／语气）”，并说明本项为何属于引导、实际台词由谁发声；附带的说话方式还需核对已写入该台词声音说明。不要假称用户在本次剧本里逐句指定，也不要把此依据复制给实质叙述。没有本次额外要求也可执行这项既定授权。

## 两人对话中反应旁白的授权删减

用户已允许删除两人对话中描述人物反应的旁白，例如一人说话后，旁白交代另一人惊讶、皱眉或握紧杯子。符合下列条件时可直接省去这部分口播，无需逐句询问；本次明确要求保留／逐字朗读旁白时按本次要求执行。

- **删的是反应旁白的朗读，原有反应仍保留。** 适用于两人当前对话中，由对方话语触发、仅描述即时表情、情绪或身体反应的叙述，包括说完后的反应和听到句中信息时的反应。如“听完他的话，她愣住了”“他皱起眉头”“她听后握紧杯子”及相同作用的英文叙述；已标为旁白也可处理。将必要反应落到原“画面内容”，情绪词改成可见表情／姿态，身体动作保留起始、过程和结果，不以删口播为由取消反应或添加新事件。
- **按信息作用划界。** 身份、隐情、因果解释、回忆、后续决定、时间地点变化、离场及道具交接等独立剧情信息，不因发生在一句对白之后就整段删除；当下内心声、人物 VO 中的实质回顾和实际回答也不属于这项例外。纯写沉默的即时反应可在画面保留，但沉默若构成拒绝回答等关键事实，须保留其叙事信息。普通情绪反应不必为了继续旁白而保留抽象措辞，无法通过反应表达的隐秘想法也不能以一个表情替代后删掉原句。
- **同一句带独立剧情信息，就整句不动。** 用户已进一步明确：如果一句话还交代身份、隐情或后续事件，就保留整句原文，不拆掉其中的反应分句，不概括、不改写，也不先拆句来规避。如“她愣住了，因为来人正是失散的哥哥”完整发声；“他皱起眉，随后把钥匙交给她”涉及后续事件，同样整句保留。真正独立的纯反应句可单独判断，例如“她愣住了。来人正是失散的哥哥。”仅前一句可省去口播，后句完整保留；有语义依赖或不确定时整句保留。只有反应与话语引导、没有独立剧情信息时，才可分别按两项授权处理，如听到对方话语后的“她握紧杯子，低声说”：动作留画面，低声要求留台词声音说明；缺少对话反应依据时不删除一般动作叙述。
- **反应时机由原文决定。** 原文明确“说完／听完后”才反应，就在该句结束后表现；确在听到句中信息时反应，可与剩余台词同步，不能因省去旁白让人物提前获知。台词照原进度连续，反应不自动触发切镜、特写、吸气／惊呼音效或准备停顿；优先在既有关系构图中连贯完成，跨镜承接同一阶段。
- **沿用现有记录，删后重新计时。** 无论全部或部分省去口播，都执行 [时间轴重排与复核](narrative-voice.md#删减后的时间轴重排)，旧时间与通过结果不能直接沿用。 原文片段继续保存在 `narration_sources`，设 `status: "omit"`，`omission_basis` 写明“用户已授权删除两人对话中的反应旁白”，并注明触发台词、为何仅为即时反应及画面落实位置；不假称本次逐句授权。实际身体动作仍进入 `action_tracks` 并覆盖，原文仅情绪时不凭空建立新剧情动作。被删口播不进入 `sources`、`speech`、发声词数或声音区间；必要反应过程仍计入真实画面时间，不保留原旁白留下的空档，也不另给每个反应加固定时长。所有旁白都获准删除时，原清单仍保留 omit 项，最终省略旁白声音行；其他台词、旁白与必要音效照常保留。

## 旁白按叙事任务划分正式分镜

叙事旁白（含角色叙述性 VO）的正式分镜以当前主要叙事任务划分；发声者相同只是声音归属相同，不是合并整段旁白的理由。先按原文确定“这部分告诉观众什么、对应画面要让观众看清什么”，再划分原模板的“分镜一、分镜二……”；无需新增正式字段或固定分镜数量。

- **任务发生实质变化时另起正式分镜。** 原文从一个事件阶段进入新的事件／结果，关注对象转向承担另一信息任务的对象，揭示新线索、身份或关系变化，或实际画面进入另一地点／时点时，在相应自然语义节点分配新分镜。不能把不同画面任务全塞进同一个分镜；但一条连续旁白可以覆盖多个任务对应的正式分镜，声音记录数量不决定画面分镜数量。只换机位、看同一动作的另一细节、旁白提及过去而画面未入回忆，不自动构成新任务；不得为拆分新增场景或事件。
- **同一任务可以容纳多句或多个必要实际镜头。** 如持续跟随人物穿过走廊直到门口显露，或连续观察同一证物对照，可按同一任务组织；微小动作阶段不逐项拆成正式分镜。保留合并须有具体持续任务与自然结束点，不能只以“同一叙述者、原文同一段、句子没说完、没满 30 秒”为依据。多个独立任务不能改叫一个“整体氛围”来合并；已有长镜、静态上限与可见推进仍检查。
- **声音按自然语义组织，画面按任务承接。** 同一句在同一生成段内没有真实停声时，只保留一条完整 `speech`，起声分镜的声音行写全原句和实际覆盖区间，其他分镜明确承接到当前词句，不再复制、拆出另一条引号文本。自然气口已包含在完整发声区间内，不逐个拆记录。确需独立记录真实停顿或跨生成段时，优先完整句或自然分句边界，词语边界本身不证明能停顿；不在冠词与名词等紧密词组中间截断。保留原词及标点，不补省略号或用“同上”代替原句；含身份／隐情的整句仍须完整保留。具体边界记录见 [断句校验](narration-flow-validation.md)。
- **画面与声音按同一任务对齐，但不强制切点完全相等。** 切镜可在原声连续时发生，持续动作按同一阶段与状态承接；确需一镜连续完成时只维护一条实际镜头及其正式分镜归属，不为编号制造硬切、倒拍或重演。当前分镜的画面描述仍只写本时段实际可见内容，听者不提前获知下一片段的信息。音效也按各分镜的实际区间分配，不把原整段音效清单复制到拆出的每镜。
- **分镜细分不增加生成段或时长。** 先在同一段提示词内分配旁白，不因增加“分镜二”就另开“第 2 段”；生成段超限再按既定分段规则处理。不逐句、逐标点或按固定秒数机械拆分，不新增分镜缓冲，整段计词估时与取整规则不变。96 词／30 秒是生成段限制，承载旁白且整个镜头超过 6 秒须作例外复核，都不是允许一个正式分镜容纳多个独立任务的依据，也不形成新的分镜时长上限。

例如原文依次交代“人物进入房间”“发现新的线索”“根据线索做出决定”，应分别匹配这些任务的正式分镜及当时念出的旁白；原文若只讲一个持续过程，则按实际信息推进选择镜头，不为凑数量拆开。交付前对照每个分镜的旁白片段与画面任务：发现一镜包含多个独立任务时重分配；一镜多句仍为同一任务时不按句数强拆。内部沿用 `sources`、`speech`、`frame_id`、`shots` 的同一方案，不另建全文台账。

## 长旁白的画面推进

先保证按既定授权处理后的声音完整，确定原句自然读法与气口，再对应叙事任务安排分镜与画面。长短不只看词数：一句中已有多个信息节点也要检查；多句持续服务同一可见过程则可共用镜头。同一任务可含多个切镜，多个独立画面任务须分镜；同一条旁白仍可连续覆盖这些分镜，由完整发声区间及逐镜承接明确对应关系，不因任务变化强拆声音。

先按 [画面信息覆盖](narration-coverage.md) 将原文必要事实逐项落到人物、动作、物件、关系与结果，再执行 [连续旁白的镜头设计](narration-editing.md)：先设计各节点的观看任务与实际镜头，随后决定是否有必要保留连续长镜；不先建立覆盖整句的长镜再用微表情填满。同一正式分镜的内部实际切点在对应运镜区间明确写出，分时画面描述本身不算切镜。

1. 从原文标出事件阶段、关注对象、空间变化、证据揭示及人物当时可以知道的信息，给每个节点选已有依据的可见内容。当前节点完成后应转入下一任务；切点可在句中，声音照原区间连续，不删句、不重复、不为换画面加停声。
2. 需要改变观看对象或范围时，用有动机的机位／景别转换、关系反应或必要线索镜头。多个节点同属一个持续可见过程，且有具体连续观察价值时，可以通过原有动作推进、焦点转移或有信息的揭示一镜完成；写清各时段新增的可见信息，不用同一表情、重复反应或无新信息的慢推覆盖全部旁白。普通动作仍不自动加特写。
3. 当下行为、人物关系、已出现的关键物件及必要环境可承担画面任务；旁白讲过去不自动生成闪回，抽象信息不强行逐词配图，不为画面丰富新增道具、动作、天气或事件。若确实只有一个有效观察对象，按静态展示最多 2 秒组织观察，超过此范围须有实际动态推进；不能仅靠下述长镜复核放宽，不硬凑空镜或删改原声。
4. 叙事旁白和内心声没有现场口型要求，可按内容使用全景、中景、近景与必要特写。连续讲话的宽景限制针对现场／电话人物对白；同时叠加对白时仍按其规则核对，不改变真实声源类别。画面揭示不早于原叙事允许的节点，角色不因观众听到旁白而提前反应。
5. 保留长镜时，明确它持续提供的动作进展、关系变化、逐步揭示及自然结束点；纯静态阅读／观察每次连续展示最多 2 秒。仅写“旁白还没讲完”“保持张力”“动作连贯”不足以成立；不要把本可及时完成的动作拉慢、加无依据等待或只换 JSON 编号。多次切镜同样需要逐镜有效信息，不能用镜头数代替叙事推进。

例如：原文先交代两块断片在同桌左右，再比较已有断口，最后才允许判断对应关系。可先用中景交代两物位置，再以必要特写依次看断口；旁白跨切点只念一次，特写接特写按 [局部组接规则](cut-techniques.md)。若原文要求人物沿已知走廊前行直到门口逐渐显露，则可一镜连续跟随，按实际行进和揭示阶段分时写画面；不能把全程写成“跟拍人物，旁白继续”。这些是条件示例，不是每段强制套用的镜头顺序。

长旁白中可适当穿插 [人物动作与反应](narrative-voice.md#原声与反应)，按知情和原有行动节点选择，原声不断，不虚构反应理由或批量加特写。

承载叙事旁白的每个实际镜头严格小于3秒，3秒整也不通过，按包括无声与其他声音部分的全镜计时。旧长镜理由不豁免；沿原文有效信息与动作阶段安排真实切点，旁白原句连续跨镜，不机械等分、不重读或慢放。必要信息确实无法兼容时先重排，仍不可行则说明具体冲突；不能擅改已锁定段预算。静态展示与一般特写的2秒规则保留；短镜与整组镜头同样查信息空转及重复返回。

## 先登记、后分配、最后核对

在同一 `plan.json` 顶层保存从源文建立的 `narration_sources`，覆盖独立叙述者及实际类别为 `narration` 的角色讲述；`inner` 和 `dialogue` 仍按原声音清单保留。该记录替代零散的旁白原文／删减备注，不再维护第二套全文。

```json
{
  "id": "N1",
  "episode": "current",
  "source_ref": "本次正文第1段",
  "original_text": "他会用到这把钥匙。",
  "source_language": "zh",
  "status": "keep",
  "source_id": "L1"
}
```

- `source_language` 为原文语言的两字母代码，如 `zh`、`en`，与 `sources.language` 的最终发声语言分开记录。
- 每个 `id` 唯一；`source_ref` 使用真实定位，无行号时注明内部段号。先登记原句，随后固定译文到 `sources[source_id]`，其 `kind` 为 `narration`，再由 `speech` 覆盖。同一原文单元一对一关联一条声音来源，发声可跨镜、跨段拆分，不重复翻译或新增来源编号。
- 原文确无旁白时填 `narration_sources: []`，另写非空 `narration_absence_basis` 说明本次范围属于纯对白／拍摄说明／构思等实际依据。不能从无旁白示例复制空清单，也不能把“画面已经表现”作为无旁白依据。
- 用户明确要求删掉某项，或符合上文话语引导／两人对话反应旁白的既定授权时，该项仍留在原文清单中，`status: "omit"`，以 `omission_basis` 记录对应用户要求和适用范围，不填写 `source_id`。允许局部删减时先按原文真实位置划分保留和删除片段，分别登记，保留项各关联实际发声来源，原文不改写；登记删减后统一按 [删后重排](narrative-voice.md#删减后的时间轴重排) 更新声音与画面时间；反应旁白同一句含独立剧情信息时按上节整句保留，不拆成 keep／omit 片段；原旁白仅含符合条件的引导语／对话反应而全部获准删除时，仍保留这些 omit 项，不能改填空旁白清单；不把“提速、重复、超过上限”冒充用户授权。
- 原文已登记旁白而 `sources` 或 `speech` 漏掉时，统一模式校验 报错；同时检查编号、集号、旁白类别、一对一映射、同语言原句与来源文本一致，以及零旁白异常。经明确要求删去的项目要有依据，不能直接移出原文清单。
- 程序不读取原剧本，不能证明清单齐全、分类正确、译文忠实或删除依据确为用户指令；`--final-prompt` 会核对定稿实际声音行。最后沿“原文 → 旁白原始清单 → 发声来源 → 正式旁白声音行”逐项对照；原文有旁白而成稿没有时必须查明去向，不能以画面覆盖或程序通过结束检查。原文漏读与错误分类仍须由源文审查发现。
