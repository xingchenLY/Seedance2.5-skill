# 跳跃组接与特写接特写

作为按剧情选择的镜头衔接方法，应用于有具体信息任务的切点，不设使用数量、固定轮换或最低比例。原文声音、关键事件、因果关系和真实空间优先；以下是局部制作例外，不取消普通连续性检查。其他动作、视线和声音衔接复用已有主题规则。

## 跳跃组接的两种用途

- **景别跳级**：需要立即读清重要信息时，可以从较宽构图直接切到必要细节，不必逐级经过中景、近景。此时故事时间仍连续，按 [动作承接](source-continuity.md#动作起始与跨镜承接) 接住阶段、手位、接触、道具和声源；只跳过无用的过桥镜头，不跳掉动作发起或关键结果。不因景别跨度大自动构成时间省略。
- **时间跳切**：原文明示跳时、反复过程或概括性行动允许压缩，或用户对具体片段已明确要求时间省略，以及符合 [运动过程省略](motion-ellipsis.md) 的用户通用条件授权时，可跳过不影响剧情的重复／无信息过程，展示有意义的前后时点。一般性“加快节奏”或“使用跳切”不授权随意删除具体事件、原声和关键步骤。说明省略了什么、后镜处于哪个时点与状态；不把跳时伪写为连续完成。

时间跳切可有意使用相同机位、相同景别，或同机位同主体的取景变化；仅在同一提示词段、同一场景内、有有效跳时依据的指定切点放宽普通“同景别同机位”和四种相邻景别组合限制。摄影位置如实记录，不重编号冒充换机位。跨段同景别仍禁止；普通换场、跨集与回忆跳转按各自时空规则，不借这个例外放宽。

可用例子：原文明示人物逐页核对一份无关键文字线索的名单、过程较长，可从检查第一页跳到稍后检查末页，省略中间重复阅读。不可用例子：一次关键钥匙交接，从尚未伸手跳成对方已持有，隐藏接稳与松开的因果过程。若原文要求过程被完整看见，就保留过程；时间跳切不是修补动作缺口的方法。

## 特写可以接特写

同一提示词段内允许有新信息和清楚联系的“动作特写→道具特写”“手部特写→另一方手部特写”“必要面部特写→必要面部特写”。不要求每个特写之间插中景、全景、空镜或关系镜头；信息链结束后按下一任务选择景别，不强制再补一镜。

逐切点判断以下条件：

- **每镜有独立信息**：例如重要接触→接触引起的证据变化，或甲嘴角短暂变化→乙看见后下颌绷紧。后镜不是重复同一证据或同样表情；普通动作仍不逐项特写。
- **归属与位置可辨**：局部镜头写清手、道具属于谁、接触谁、从哪边来；面部连切承接双方视线与既有距离。可以通过已有空间参照和准确画外联系承接，不强塞肩背或多加建立镜头，也不长期退化为没有位置联系的单人肖像互切。
- **进度和声音连续**：同一行为跨特写接相邻阶段，不重演或跳完成；听者须先收到信息才反应，讲话可继续覆盖其无声反应。现场台词不改成 VO／OS，另一人接话仍按一分镜一位发声人物规则处理。
- **面部特写仍有必要性**：每一张脸都须有较宽构图难以读清的具体关键变化，不把普通问答、重要台词或情绪强烈一律作为连切理由。完整面部取景，不使用眼睛、嘴部等器官级大特写。
- **真实切点仍成立**：普通同景别特写连切要真实换机位，换主要人物本身不豁免同景别同机位限制；不同景别按原切点规则。同机位的时间跳切须另满足上节条件，不能仅写“特写接特写”放行。跨段按真实取景继续要求不同景别，不靠将同一取景改称手部／动作特写绕过。

连续特写保留短剧节奏，所需时间按动作和信息可读性估算，不为丰富镜头延长行为、拆每个动词或加慢动作。相关源文、情绪前态、光影、声音和重要动作取舍继续按 [镜头库](shot-selection.md)、[讲话声画连续性](spoken-emotion-camera.md#反应镜头中的声音连续性) 执行。

## 时间跳切的内部记录

景别跳级及普通特写连切无需新例外。同段同场采用时间跳切时，无论换不换机位／景别，在后镜 `shot` 上记录 `jump_cut_before`，包括 [运动过程省略](motion-ellipsis.md)；记录只对应实际成片相邻的前镜，不新增正式模板字段。跨段、跨场不使用这个局部切法例外，按原切点规则在 `camera_text` 写清时点，动作状态按相应 `break_before` 核对：

```json
{
  "jump_cut_before": {
    "from_shot_start": 0,
    "basis": "正文场次明确逐页核对并跳至稍后的末页，中间为可省略的重复过程",
    "omitted": "中间各页的重复阅读与翻页过程",
    "cue": "保持同一摄影位置和取景，画面直接进入稍后的阅读时点"
  }
}
```

- `from_shot_start` 是同段实际前镜的起始秒数，不是被省略的故事时间。只作用于进入本镜的一次切点，第一镜、跨段／跨集、跨场景或成片前镜不匹配均不适用。剪辑顺序改变后重新核对，不复制例外到整段。
- `basis` 写具体原文位置、允许省略的剧情依据，或已有用户对具体片段的要求；符合 [运动省略](motion-ellipsis.md) 通用授权时写清本处中段无新信息且拖慢节奏的具体事实，不必重复索取许可；不能只写“提速、好看、特殊情况”。一般允许跳切不是每处跳时的依据。`omitted` 写确实可省略的过程，`cue` 写后镜时间关系与取景，均为单行文字，不重复完整镜头时间区间。
- 两侧提供真实 `view/end_view`，按 [真实机位记录](camera-continuity.md) 填位置、朝向、高度和主体，不假造变化。脚本核对记录格式、同段同场及成片前镜，再有限放行同机位切点；非空理由不能证明原文支持，须内容复核。
- 渲染器将 `omitted` 和 `cue` 生成自然语言写入后镜对应的“运镜”区间；`basis` 保留内部，不输出 JSON 或来源编号。手工排版可用 `scripts/cut_transitions.py` 的 `jump_cut_prose(shot)` 获得相同文字，最终检查绑定到本镜区间，不能移到段首、另一镜或仅写入画面内容。
- 时间省略导致动作状态不同，仍按 [动作链](action-continuity.md#切走跳时与返回) 在相关后续 beat 按实际依据使用 `break_before.kind: "source_time_jump"` 或 [运动省略](motion-ellipsis.md) 的 `motion_ellipsis`，记录依据与 `resume_text`，说明后镜实际状态。跳切例外只处理切法，不替代动作链例外；同一动作链不改键名或时间层逃避承接检查。
- 声音原句、类别、顺序、词数和实际区间照常核对；不删词压缩对白，不让现场讲话随图像跳时而错口型。用已有声音覆盖省略后的画面必须符合原声来源及叙事时点，不能擅改成 VO。成片时长只计展示的区间，不把被省略的故事时间加成等待或用于凑最低时长；原关键事件仍完整覆盖。

## 返回前检查

对每处跳跃组接先区分景别跳级与时间省略，核实信息、原文依据、切入时点和状态；对每组特写连切核实逐镜必要性、新信息、归属、空间、动作进度、面部取景及声源。与普通切点逐个合看，例外不蔓延到前后无关切点，不覆盖跨段景别要求。

实际依据及原信息保留写入既有 `delivery_review.source_coverage`，时间省略与声画区间写入 `timing`，特写信息链、关系及动作承接写入 `visual_continuity`，局部例外与冲突处理写入 `conflicts`。修改后同步实际提示词和记录，按 [交付校验](delivery-validation.md) 验证；结构通过不证明跳切语义合理或视频效果已验证。
