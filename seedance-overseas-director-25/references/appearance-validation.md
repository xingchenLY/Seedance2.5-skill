# 面部与眼部描述的校验

四模式有面部／眼部颜色或视效变化时读取。表演边界以 [面部色彩与轻微脸红](concrete-language.md#面部色彩与轻微脸红) 为准：有情境依据的脸颊淡红晕、眼眶轻微发红可保留；其他变化逐条核对来源，原文明示的面部视效按指定范围允许，不因本检查删掉剧情。

## 成稿检查与修复

`appearance_review.py` 接入统一 `validate_delivery`，渲染后的实际文本也会检查。覆盖段首导演说明、逐实际镜头的运镜／画面（包括自动加入的位置、动作和静态句）、声音括号及音效／转场说明；场景原名和出镜人物姓名不作为效果指令扫描，实际发声原句不进入扫描。明确承载在屏幕、信件等物体上的引号内显示文字另按画面文字规则实审，不能把加引号的表演指令冒充道具文字。

程序对常见中文面部／眼部颜色表达做有限检测。明确的“脸颊轻微泛红”“眼眶微微发红”等局部低强度表达可通过；是否有情境依据、是否符合角色材质、是否被后文强化仍须实审。眼白、虹膜、瞳孔、眼球不适用眼眶轻微泛红的许可；“眼睛发红”应先明确实际部位。静态“脸色惨白”、动态“脸色骤白”及“脸失去了血色”“面孔毫无血色”等改写都需核对，不因没有“变”字跳过；未被有限检测命中的同义表达仍按实际含义复核。明确禁止变色的指令、原声和必要画面文字分别处理，不能只见颜色词就删改。

命中的其他描述返回 `facial appearance REVIEW` 并阻止渲染／最终通过。无依据的情绪变色改为符合当前剧情、机位的表演；仅想写眼眶微红时直接明确部位与低强度。确有原文身体状态、既有外观、真实受光、明确面部视效或用户具体要求时，保留实际描述并补下节的来源记录。不自动删除词语，不为过检编造原文、改说“视效剧本”或复制笼统通过说明。

## 按范围绑定允许项

只有被检测到且确有依据的描述才在对应 `segment.appearance_reviews` 填记录，无命中时省略或用空数组。记录保留在作者设计中，渲染不会自动生成或认证，正式提示词不新增字段。

```json
"appearance_reviews": [{
  "scope": "shot:0",
  "evidence": "Mara的虹膜随诅咒触发变为血红",
  "subject": "Mara",
  "kind": "source_vfx",
  "source_ref": "本次剧本第4场第2段",
  "source_evidence": "这里逐字摘录实际已读原文明确描述该人物虹膜变化的句子，不填写占位句",
  "basis": "说明本镜部位、范围、强度、触发与持续状态怎样对应这条原文；不添加发光或扩散"
}]
```

此例只说明结构，不能直接当成已核对的真实来源。`subject` 是实际对象，须出现在 `evidence` 中；`evidence` 必须逐字存在于对应实际成稿范围，并覆盖需保留的变化描述。字段须填写具体内容，不能用“已检查／无冲突／通过”等占位。

| `kind` | 需要的来源与适用边界 |
| --- | --- |
| `source_vfx` | `source_ref` 定位实际正文，`source_evidence` 逐字摘录原文明示的面部变化；不限定西幻，科幻、变身、魔法等视效剧情均可。只有题材标签、原文有别处特效、情绪比喻或导演想强化，都不足以放行 |
| `source_state` | 定位并摘录原文明示的伤病、身体状态等；保留原程度，不能用“害怕／愤怒”推导惨白、铁青或血红眼睛 |
| `existing_appearance` | 具体参考图／已确认设定及实际观察证据，保留已有肤色、毛色、眼部配色、妆容等；既有色不当作新变化 |
| `lighting` | 本场已设计的实际光源、被照部位与受光方向，说明这是受光而非固有色改变；不能给情绪变色套一个灯光解释 |
| `user_requested` | 本次用户明确要求这一具体变化的原话及适用范围；概括的“加强情绪”或“有视效”不等于要求具体面部变化 |

范围按实际成稿绑定：段首字段用 `prefix:整体风格`、`prefix:环境光影` 等；逐实际镜头用起始秒数 `shot:0`、`shot:2.5`，包含本镜运镜和画面；声音括号用其发声起始秒数 `voice:0.2`，原句不包含在内；音效／转场用实际分镜标题，如 `frame:分镜1:转场方式`。秒数去掉无意义的末尾0，如 `shot:2`，不能用另一个镜头的依据放行当前镜头。同一效果跨镜延续须分别对应本镜实际描述，来源可复用；原文仅改变虹膜，不放行脸颊、眼白或整张脸一起变化。

程序检查有限命中、记录完整性、对象与文字范围绑定；不会读取原始剧本或图片替你确认记录真实性，也不能完整判断所有同义词、否定、语义强度、颜色效果或翻译。内容复核必须对照实际来源与整句前后文，结果并入原有 `visual_continuity`／`conflicts`。样片未提供时不声称验证了实际红色程度；取得样片后还要检查是否被生成模型放大。
