# 竖屏短剧的构图选择与动态可见性

用于四种模式的 9:16 短剧的取景设计与交付复核。先明确本镜需要看清的主体、人物关系和行为，再选择画面布局；构图技巧是可选方法，不设使用配额、轮换次序或每镜必须使用的名称。

## 选择顺序

1. 按剧本、场景图及前镜确定实际人物、距离、朝向、道具和动作进度，再确定本镜信息重点。
2. 同场互动先按 [关系构图](shot-selection.md#同场对白的关系构图) 判断谁需要以什么方式可见；异地通话、独处、远距离和局部插镜按实际情境，不硬塞肩背或改变距离。
3. 按需要读清的表情、手势、接触与结果确定取景范围，再选择下表适用的布局。先按 [模式优先级](shot-selection.md#情绪与景别的模式优先级) 选景；两种剧关键情绪优先、普通对白用中近景／近景，两种推文对白优先中近景，必要身体动作可用合适中景；面部特写、动作特写的取舍仍按镜头库执行。
4. 检查动作起始、中途、结束的遮挡和画框边界；需要时调整真实机位、构图边界或清晰范围，再按原规则选择必要摄影行为。构图变化不自动要求运镜或切镜，不额外增加时长。

## 十二种可选构图

以下示例仅在本次人物、空间和剧情支持时采用，姓名与方向按实际素材替换。不要照抄示例新增人物、陈设、行为或情绪。

| 方法 | 适用任务与具体写法 | 使用边界 |
| --- | --- | --- |
| 三分构图 | 日常对白、观察、等待回应。例：“林悦位于画面左侧三分之一附近，面向画右，右侧留出视线空间。” | 三分线是参考，不精确卡点；关键动作和人物关系优先，不为三分位置裁掉手或对象。 |
| 中心构图 | 正面表态、关键人物出现、集中呈现行为。例：“人物位于画面中央，双肩与胸前动作完整入画，身后已有通道向远处延伸。” | 居中不意味着直视摄影机；目光仍对应剧情内对象，也不强求背景对称。 |
| 对称构图 | 已有对称空间中的会面、仪式或正面对峙。例：“摄影机对准大厅中轴，两侧已有立柱对应排列，人物保持原中轴站位。” | 只利用真实场景与已有站位，不为对称移动陈设、调换人物或补造建筑。 |
| 过肩关系构图 | 实际站位允许的问答、交涉与倾听。例：“陈默的肩背留在左前景边缘，林悦位于右侧中近景，面向陈默说话。” | 写明肩背归属及摄影位置，按 [过肩画面描述](shot-selection.md#过肩镜头的画面描述) 非必要不加人物侧脸，不遮主拍口型、手势或道具；远距离不强造贴近肩背。 |
| 前后景双人构图 | 一人行为与另一人反应同框。例：“林悦位于左前景，陈默在右后方桌边，两人身体轮廓错开。” | 明确清晰重点；要同时读清双方表情，就不能又要求其中一张脸完全虚化。 |
| 斜侧双人构图 | 实际靠近、并坐或共同查看物品。例：“从两人斜前方取景，林悦在画左、陈默在画右，双方侧脸和中间文件可见。” | 根据实际距离选景别；两人相距较远时不用双人侧面近景压成并排或贴近。 |
| 纵深构图 | 隔桌交流、远距离对峙、前后人物关系。例：“桌沿进入画面下方，林悦在近端，陈默在远端窗旁，中间桌面可见。” | 保留距离参照，远者可只要求位置与身份可辨；需要其微表情时另选合适取景，不同时要求人物很远且面部细节很大。 |
| 三角构图 | 原有三人交涉或第三人介入。例：“林悦与陈默分处左右前景，周宁位于两人之间的后景，三人的脸互不遮挡。” | 用真实前后位置形成层次，不凑人数、不新增走动；当前信息不需要三人都可见时，不强求全员同框。 |
| 留白构图 | 观察画外对象、等待原剧情中的入画、交代空着的位置。例：“人物位于画右，视线朝左，左侧保留已建立的空椅和桌面。” | 留白对应视线、动作路径或既有信息，不长时间留下无任务墙面，不因此延长等待。 |
| 引导线构图 | 引向主体、关键道具或空间终点。例：“已有桌沿从画面左下方延伸至右后方，关键文件位于其延伸方向。” | 利用实际桌沿、楼梯或通道，不新增线条；避免无关背景边缘紧贴人物头部轮廓。 |
| 框中框／遮挡构图 | 剧情已有的窥视、隐藏、信息揭示。例：“前景立柱遮住后方人物一部分；人物沿原路径走出后，面部完整露出。” | 遵守 [门柜视角](shot-selection.md#日常机位与门柜视角) 与遮挡揭示规则；不把门缝当默认视角，不遮关键证据或凭空添观察者。 |
| 动作与道具构图 | 重要物品交接、证据展示、接触结果，以及主要情绪动作的关键身体变化。例：“双方手部从画面两侧进入，钥匙及接触点位于中央偏下，接稳与松手过程可见。” | 写清手部归属、来向与结果；普通手势留在原对白构图；有指向、施受或注视他人行为时按 [关系动作](shot-selection.md#有指向与人物关系的动作) 选择能看清双方或必要多方的构图，可不用动作特写；其他主要情绪动作按 [特写规则](shot-selection.md#主要情绪动作的特写) 安排关键阶段，其他重要细节按需要取舍，不逐动词拆镜。 |

## 竖屏取景检查

- **给表演留位置**：先确定已设计的自然手势或上身动作，再确定构图下沿。需要胸前手势和文件时让两者可见，不先裁成脸部近景再删光肢体语言，也不强把手抬到脸旁。
- **利用真实前后层次**：竖屏横向空间有限，站位允许时可保留肩背或前后错位的身体；过肩非必要不描述侧脸，其他取景按信息需要选择；不为入画靠近、换位或制造本不存在的高低差。
- **头顶与视线空间有任务**：普通对白避免大片无信息头顶区域或无意裁切；抬头、起身、倾身时核对动作后的边界。通常给注视、递物或移动方向留下必要空间；有意挤压取景必须有具体剧情任务，不机械套固定留白比例。
- **背景既能定位又不抢重点**：保留需要的窗、桌沿、墙角等真实空间参照，选择机位减少无关亮点和轮廓重叠；保留参考图陈设，可按剧情重新布光、压低背景亮度以突出人物，并沿用本场选定的光源方向。前景不能挡住关键口型、表情、手势或接触点。
- **清晰要求相容**：两人同框不必同时承担面部细节。只强调一人时明确其清晰；两人的关键反应均需读清时选择能容纳的清晰范围，不同时要求后景完全虚化。需要拉焦时按镜头库写明起止目标与时机，不把焦点变化当成景别或机位变化。
- **动作全过程可读**：起始、中途和结束分别核对谁被挡、哪里被裁、道具在哪里，尤其是抬手、倾身、递物和接稳／松开的过程。动作超出当前边界时先调整原构图或有依据的连续取景，不随意删除原动作、跳到完成状态或另加过桥镜头。

## 写入原字段

组织描述时可按“景别与真实机位 → 主体画面位置 → 关系人物位置 → 朝向与视线 → 必须可见的动作／道具 → 清晰重点”思考，只填写本镜需要的信息。不新增“构图技巧”字段，不将技巧名称列表、抽象审美评价或内部选择过程粘进提示词。

- “运镜”承载景别、机位、取景边界、必要的清晰重点和摄影行为；“画面内容”承载人物位置、视线及动作过程。最终使用具体描述，按 [具体视听表达](concrete-language.md) 清理“高级构图、张力拉满”等无执行内容的词。
- 使用渲染器时，摄影位置等复用 `view/end_view`，人物位置复用 `relation.placements`，动作过程复用 `action_tracks`；`camera_text` 只补自动记录尚未说明的取景边界、清晰重点、稳定性或运动等，`visual_text` 不重复整组自动位置句和动作句。起止构图记录按 [真实机位校验](camera-continuity.md) 更新，不新增一套平行数据。
- 所有布局服从原文、参考图、真实距离、轴线、切点及声音／时长约束。连续讲话不插中全景、跨段首尾不同景别、四种有条件切点等按原规则执行；从“中心”改称“三分”不能证明换机位或授权切镜。若冲突，先调整取景方案，不以构图技巧删声、移走动作或改剧情。

## 连续镜头与返回前复核

逐镜检查起始／中途／结束的主体、关系位、动作和清晰重点，再沿整轮对白或动作链检查相邻镜头：

- 换主拍、反打、收紧景别后，对象的位置是否仍有有效联系；单人镜头是否有具体任务，而非同场连续孤立肖像互切。
- 视线、背景、画面左右及运动方向是否符合实际新机位；主拍变化与前景面积变化分别判断，不机械复制左右位置。
- 切入特写是否承接同一动作归属、方向和进度，切出是否接住结果；切到听者时，原句按既有声区间继续。
- 每次构图或景别变化是否承担已有的新信息，是否无故增加动作、等待、全景或重复反应；不为展示技巧轮换布局。

将本次实际检查的取景边界、遮挡、清晰范围及跨镜关系结论写入既有 `delivery_review.visual_continuity`。构图和镜头记录修改后同步正文，按 [交付校验](delivery-validation.md) 重新渲染和检查。结构脚本只能核对记录与文字绑定，不能证明真实摄影几何、模型理解程度或生成视频已经通过检查。
