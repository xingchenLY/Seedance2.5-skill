# 提示词的具体视听表达

填写最终提示词及返回前复核时使用。导演分析可以用情绪、关系、主题和审美词理解剧情；提交给视频模型的导演说明以可见画面、可听声音或明确拍摄操作为主体。允许简短表演意图帮助选择动作和声线，但必须与本镜具体过程绑定，不把心理解释冒充画面事实。不根据一份词表声称已验证某个模型能否识别，而是逐句检查描述有没有明确的执行对象与视听结果。

## 输出边界

- 不直接写无执行作用的抽象审美评价、心理结论、比喻或程度口号，例如“高级感、宿命感、破碎感、气场强大、张力拉满、情绪有层次、极具感染力、眼神复杂、空气凝固、充满故事感”。这类修饰即使跟着具体动作也删除，不换成另一个近义评价；有依据且能区分表演的短意图按下一条保留。
- **表演意图与行为一起写。** 成稿可简短注明“受辱后的愤怒，压住声音追责”“急于解释，想让对方听完”等原剧情支持的状态／意图，并在同句或紧接的画面、声音说明落实触发、身体驱动、语气变化与落点；通常一个有用短语即可，不机械要求每镜都有。不能只写“很愤怒／保持压力”，也不能清理到只剩没有作用对象的皱眉、绷下颌。长篇心理推理、主题评价及强度数字表留内部，不新增动机、秘密或结果；人物对白的意图不套到中性叙事旁白。
- “低声、放慢语速、重读原词、侧逆光、浅景深、中近景、固定机位”等有明确视听或摄影含义的术语可以使用，说明对象及必要的方向／变化。不是删除所有形容词，也不是把每个技术术语都改成冗长解释。
- 低调布光、侧逆光、伦勃朗光、负补光、体积光、焦散、高光辉光等有明确视觉含义的专业术语可以直接保留，按 [光影用法](cinematic-lighting.md#专业术语与使用条件) 核对条件，按上下文补足必要的对象、方向或可见结果；无需逐词展开定义，不能当抽象词机械删除，也不能仅有名词堆叠。丁达尔效应不泛指所有逆光或光晕。
- 原台词、人物 VO／OS 引号内的原句或已固定译文，以及按画面文字规则已确定语言和写法的剧情必要画面文字，属于剧情内容；其中出现情绪词、抽象词或比喻仍原样保留，不为清理导演说明删改声音或证据。人物名、专名和按参考图对应的场景原名也不做关键词删除；它们用于识别实体，不当成画面效果指令。

## 面部色彩与轻微脸红

以下边界适用于四种模式的导演说明、表演和光影描述；“面部与生理信号”、情绪强化及3D夸张均不另行放宽。

- **允许轻微脸红。** 有害羞、窘迫、亲密互动等实际情境依据时，可保留或合理设计“脸颊轻微泛红／浮起淡淡红晕”，不要求原文逐字写出脸红；限于局部、低强度、自然的变化，保留原肤色和辨识特征。它是可选表演，不是每次害羞的必填动作，不扩大成整脸通红，也不逐镜重演起红或突然恢复。
- **允许眼眶轻微发红。** 有委屈、悲伤、忍泪等实际情境依据时，可设计“眼眶微微泛红／眼眶只有淡淡红意”，不要求原文逐字写出；限于眼眶周围局部、低饱和、不过分明显，保留原皮肤质感，不扩大为鲜红整圈、浓重红肿或大片红色。该许可不改变眼白、虹膜、瞳孔或眼球，不添加红光、发光、血丝；避免含混的“眼睛发红”，也不能用“轻微”掩盖后文的“通红”。不因眼眶微红自动添哭声、落泪或揉眼动作，跨镜承接实际程度。
- **不自行添加其他情绪变色。** 不因愤怒、震惊、恐惧等情绪补写“脸色惨白／骤白／煞白、整脸涨红、脸色铁青／发紫、血色瞬间褪尽”等明显变色。优先用当前可见的目光、眉眼、下颌、姿态和原声变化表达；已有动物可按既有耳尾规则表演，不为替换变色另加事件或声音。没有“变”字的“脸色惨白／眼睛血红”等静态表述也按其实际效果判断，不当成既有状态自动放行。“轻微”修饰词不能掩盖“轻微脸红但整张脸鲜红”等实际效果冲突。
- **保留已有外观。** 原肤色、唇色、毛色、斑纹、痘印、伤痕及已有妆容不因情绪消失或换色。两种3D模式的脸颊淡红晕与眼眶微红须符合已确认造型：人类可作自然局部表现，已有动物不把覆盖面部的毛发染红、不改变斑纹或新增贴片红腮、鲜红眼圈；不能因动画十二原则的夸张而放大颜色变化。两种真人模式按自然皮肤表现核对，不增加卡通色块。
- **照明与固有色分开。** 写清哪个实际光源照到哪一侧、明暗或光色如何变化，不能把冷光受光写成“吓得脸发青”，也不用暖光为整脸通红找借口。合理受光可以保留，人物固有色及辨识特征仍可辨；剧情需要的照明与后期边界继续按光影专题执行。
- **允许原文明示的面部视效变化。** 带视效的剧本中，正文明确写出的脸色、眼部颜色、面部纹理或形态变化可以执行，不限西幻题材，也不限真人／3D模式。先定位原句，明确对象、部位、触发、范围、程度及结束或持续状态，按原文实现并跨镜承接；原文只写虹膜变色时，不扩大到眼白、眼眶、整脸或全身，不自行增加发光、爆裂、伤势或永久变化。其余身份特征保持原设定；原文要求改变的指定特征按剧情变化，不被“造型稳定”误删。仅有视效题材标签、其他部位的特效或“愤怒得像变了一个人”等比喻，不构成新增面部变化的依据。
- **原文事实与声音单独核对。** 原文明示的伤病、妆容变化、变身等身体状态／事件按原文保留并承接，不在其程度上自行加码；情绪比喻不能自动当成生理事实。原台词、旁白、VO／OS、内心声的原句或固定译文照常保留，其中提到“脸红、苍白”等不等于授权新增同样的画面变化，不做全局关键词删除。用户明确的视觉变化要求按其范围执行。

返回前在既有逐镜内容复核中检查所有实际相关字段，包含段首风格／氛围、环境光影、运镜、画面及声音括号里的导演说明；先判断描述的是谁、既有状态还是变化、剧情依据及实际范围／强度，再检查跨镜与跨段承接。保留合规脸颊淡红晕、眼眶微红、外观与受光，以及原文明示的面部视效；无依据的明显情绪变色改成合适的表演，原文事实和声音不删。结果并入 `delivery_review.visual_continuity`，真实冲突记入 `conflicts`，不新增正式字段或独立检查轮次。按 [面部与眼部描述校验](appearance-validation.md) 对实际成稿的常见颜色描述进行有限检测；需保留的命中项绑定具体范围与来源依据，缺少依据时阻止交付。程序不能确认原文真实性或完整判断语义边界，结构通过仍不能代替内容复核，也不保证实际视频不会出现色彩偏差。

## 机位可见性

画面说明先以当前机位、取景边界、遮挡、物体朝向和清晰范围判断可见内容，不能把角色知道或看见的信息全部写成观众看见的画面。屏幕背面、文件背页、口袋内部、人物背面的表情以及画框外动作均不作可见细节描述；必要画外位置关系或声音可按对应规则交代，不扩写不可见行为。

例如正面拍某人举着手机看，手机屏幕朝向人物、背板朝向摄影机，只写持手机、低头看向屏幕、背板可见及人物实际反应，不写屏幕中的照片、文字、来电头像或画面播放。若原文只要求看手机，不为展示内容强加屏幕特写；若观众必须读清关键短信或证据，则在原事件的合适时点选取真实能看见屏幕的角度，并保留持物、方位和动作承接。不以本镜不可见为理由丢掉关键证据，也不让手机同时正反两面朝向摄影机。

角色现场讲话且嘴部可见时，在画面写“开口说出原句／继续开口讲话”，再说明口型同步；“望着对方、神色严肃”或只有声音行不足以交代开口。镜头只见肩背／局部时，不补不可见唇形，不为补开口强切回脸；明确原声在该画面继续即可。听者不代口型，VO／OS 不写开口发声。连续说话切回时用“继续”，不重复一遍开口起声动作。

### 遮挡错误的定位与修复

生成错误先核对实际提交稿的摄影位置、光轴／视野、物体高度与朝向、遮挡边界和必要信息，区分摄影机可见、人物可见与人物已知。车门／桌面／身体／屏幕挡住的内容不能同时被描述为清楚可见；识别反应须等人物确实获得对应信息。先修复矛盾的视点或展示安排，再考虑措辞强度，不反复堆“保持关闭”等否定句。

保留已确认空间与事件，优先用该视点真实可见的阶段表现；关键接触／证据仍看不清时，在原时间线内改用可见角度或必要插镜，按既有切点与计时规则衔接。不可见不等于可删，摄影机看见也不等于人物知道。具体见 [门窗、桌面、人体与屏幕案例](continuity-repair-cases.md#遮挡与知情边界)。只有提示词时给出文本矛盾诊断；有可访问样片才报告实际观察，不把修订写成视频效果已验证。

## 运动朝向与方向

分别写清**谁／什么朝向哪里**和**沿哪条路径向哪里运动**：正面向前走、面向对手向后退、侧身横移等不能混为一类。可用“面向画右的通道口，从画左向画右走近门边”“面朝画左的对方，脚步向画右后退”这样的当前取景与既定目标描述，不凭空改变走位。小幅手势也应有必要方向和落点，如“掌心向下，右手从胸前向下压至腹前”。

摄影机运动另写镜头朝向、移动／转动方向及跟随关系，例如“镜头朝向迎面人物，摄影机沿通道后退，与人物保持原距离”，不把人物前进写成摄影机推进；摇镜、平移、转身的方向分别说明。拐弯或转向写从什么朝向转到什么朝向；反打后依据真实机位更新画面左右，同时保持空间路径和动作进度，不复制上镜左右造成反向。静止对象不需要虚构运动，细节只写执行本动作所需内容。

## 原字段怎样写

| 字段 | 写入什么 |
| --- | --- |
| 整体风格、画面规格 | 风格写实际影像形式及必要造型／摄影特征；规格只写影像形式、画幅和分辨率。具体主体／道具的可读要求落实到对应镜头，不在规格重复泛化保证；删除“高级、精致、震撼、电影级”等评价性填充 |
| 对话氛围 | 该段已确定的对视、距离、说话音量、接话方式或无声互动；不要只填情绪或关系结论，也不为填满字段新增停顿、抢话或肢体动作 |
| 环境光影 | 按剧情选定的光源、来光方向、照亮／落暗的区域、色温或明暗反差，可不同于参考图；把氛围落实为具体布光，不只写“悲伤的蓝光”“神圣的光辉”，不改剧情天气 |
| 运镜 | 景别、真实机位、朝向、移动方向、触发及落稳；把“压迫性推进”落到本段已设计的推进动作，不因一个抽象词强加推镜、晃动或特写 |
| 画面内容、动作句 | 必要时用简短表演意图定方向，再写谁从什么姿态起、怎样作用于实际对象、由哪个部位带动、如何运动／接触、停在什么状态；不把内心判断当成观众已看见的事实 |
| 台词／VO／OS 的音色说明 | 可用简短有依据的讲话意图引导原声线、音量、语速、原词重音、气息或可听停顿及其前后变化；不能只写“坚定、深情、委屈、余怒保持”。引号内原词不变，VO／OS 不因此添加口型，叙事旁白仍中性平稳 |
| 音效、转场 | 已有环境／动作的具体声源、发生时点和实际切法；删除“命运感音效”“强烈情绪转场”等没有执行内容的词 |

普通节点选择少量足以表达意图的变化；关键峰值可按 [视听转折](audiovisual-turning-points.md) 协同表演、构图与声画层次，明确各自作用，不设固定数量上限。已有动作、声音和空间信息能表达时，删除多余抽象词和重复表演，不删本能、控制、落点及必要余波的不同阶段。不能仅凭“悲伤”标签机械添加泪水、倒地、雨景；可依据剧情冲击与人物处境设计更强的神情和身体表现，按 [剧情驱动的情绪放大](emotion-performance.md#剧情驱动的情绪放大) 判断，情绪标注不构成强度上限；不能为了“压迫感”让人物无依据靠近或抓握；可按剧情设计侧光与明暗反差，但应写清可见结果并跨镜承接。必要动作衔接、发声完整性与情绪过渡照常保留，具体化不等于人物统一大喊、握拳或皱眉。

例如在原文确有对应情境时，可这样改写：

| 空泛描述 | 具体表达示例 |
| --- | --- |
| 他眼神复杂，带着强烈压迫感 | 当面追责，要求对方回应：原站位内重心前移带动上身前倾，视线仍停在对方脸上；原问句关键词咬字加重，问完没有立即收回姿态。仅在实际质问情境与身体条件允许时采用 |
| 承接余怒，力度保持 | 延续前句已确定的音量与语速，保持其原词重音及咬字方式；不默认降到低声，也不再无故加码 |
| 她非常震惊，情绪层次丰富 | 听清身份揭晓后，原本朝对方展开的手停在途中，肩背随之收拢；嘴唇微张而未说话，原句接话时承接这一姿态。仅用于原文支持该反应、起手已成立且本镜可见的情况，不新增未写出的台词 |
| 高级、精致的电影光影 | 右侧窗光照亮人物右脸，左脸落在阴影中；须与本场选定的主光方向和人物朝向一致，不必复刻参考图照明 |

## 提示词冗余校验

每次返回前，对**实际最终提示词**逐镜阅读，并对照各字段和相邻镜头；有渲染器时检查拼接后的 `final.txt`，不能只检查单独的设计字段。以“删掉这句话，是否损失本镜必须执行或承接的信息”为取舍依据，不设压缩比例或字数目标。

### 人物与句子的入稿条件

- **在场身份与逐镜可见分层保留。** 按 [同场人物保留](output-template.md#出镜人物与静默角色)，段首“出镜人物／人物位置关系”列本段各场景全部在场者及真实位置，包含全段画外、无台词／动作或独立镜头的人员；这些空间锚点不是冗余。逐镜只写实际可见者、当前变化与必要画外承接，不重复全段站位，也不补不可见行为。运镜带到某人所在区域时按真实边界和遮挡恢复其应有画面，不能因上镜未见而清空背景；不为保留名字新增动作、反应、声音、镜头或时长。

- **每句须改变可执行结果。** 指明对象及可见行为、可听表现、必要状态或摄影操作；纯粹评价“张力拉满、气场强大、充满故事感”等直接删除。心理解释、导演选镜理由、校验结论、为什么没拍某人、未来剧情和制作规则留内部。短表演意图仅在确实区分演法且紧接具体过程时保留；不把一长串抽象形容词挂在动作后面，也不为替换它们新增手势、眼泪、转头或声音。
- **以实际来源字段去重。** 同一机位事实由 `view` 写一次，同一空间关系由必要的 `placements` 写一次，动作、反应和声轨承接由各自已有记录写一次；手写字段只补尚缺的可见／可听变化。不要再加“主体和关系清楚、设备归属不变、保持原有空间”等泛化保证；确需辨认归属、手位或动作阶段时直接写具体事实。绑定句须修正源记录再渲染，不能只删最终文本。
- **全字段按同一标准过滤。** 段首“对话氛围”只留实际对视、距离和发声／接话方式，不复述整段剧情；“整体风格”不夹人物心理分析；音色说明保留真实的力度、节奏和变化，不堆审美评价。最终稿不附“已检查／为避免越轴”等过程说明。每段独立使用所需的模式、规格、限制及必要空间锚点仍保留，不把精简变成省字段或丢信息。

例如本镜只拍甲乙对话，丙丁确实都在画框外且没有当前声音、视线或动作归属关系时，删去“丙丁在画外保持原位，未参与对话”，但段首仍保留丙丁的在场名单与具体位置，内部状态不改；若丙实际站在后景，即使全程不说话也保留丙及简洁位置句，不能照前例删人。“乙气场强大，眼神复杂，张力拉满，抬眼直视甲”只留有依据的“乙抬眼直视甲”，原声另保留已设计的音量与节奏。若需要表现具体情绪变化，则根据现有触发和表演过程填写，不能用删除抽象词为理由把强情绪改成平淡表演。

- **删无信息重复**：同一时点、同一对象、同一状态／指令的近义复述合为一句；删掉“固定机位，镜头保持固定”等重复强调。已自动生成的机位、位置、动作、静态区间或原声承接句，不在手写字段重复一份。重复描述有冲突时按原文和真实设计修正，不能随意保留一个版本。
- **道具清单不按跨字段重复删除**：按 [特殊道具清单](output-template.md#特殊道具清单) 保留本段相关物品及必要归属；段首清单和镜内动作分别承担身份与行为任务。可以删重复措辞，不能因镜内已写手机、花束等就删清单，不能将“普通物品／没有专用图／当前镜头未拍到”当成整段无道具。
- **各字段各有任务**：运镜写摄影机行为，画面写当前可见行为与必要关系，音色写实际发声表现，音效写本镜实际可听的声源和时点。删除没有新增任务的跨字段复述，不将台词全文复制到画面／音效中；必要的同一时点、对象标识及声画同步说明可以保留。
- **排除错位内容**：按本文件的可见性与方向规则复核，不写本镜看不到的细节、只在别镜发生的行为或只属于别镜的声音，不用否定句回顾或预告它们。声效范围依 [音效的时间归属](output-template.md#音效的时间归属)，实际延续到本镜的声音仍需交代当前可听部分。
- **保留必要承接**：动作起始、阶段、接触、结果，左右手与持物、人物关系位、朝向及路径、开口／继续讲话、回忆入口的视觉转场，以及跨镜原声／持续声说明不作机械去重。前镜结果作为后镜起点可以简洁重述，不能只剩两个不相接的结果，也不能改成“同上／保持关系”。
- **保护原文与独立使用**：不删改台词／VO／OS 原句及其有意重复，不删关键事件、剧情必要的目标语种画面文字、人物原名、场景图原名；模板的双姓名声音标签、规定字段、每段独立复制所需的规格／限制与空间说明照常保留。不同时间真实再次发生的动作／声音不是文字冗余，依据剧情保留，不把它们合并成一次。

例如同镜 `visual_text` 写“将杯子放到桌上”，而动作链已完整写出持杯下移、杯底触桌和松手，只保留动作链中的过程，其他可见反应按需留下；下一镜若需要“手指已离杯沿，随即收手”作为新动作起点则保留。不能为去重删掉关键接触、让落杯重演或使动作突然跳到完成状态。

将清理落实到对应设计字段；受绑定的动作句、位置句和声音承接不能只在最终文本里直接删除。有工具时同步源记录、重新渲染，再核对受影响的原文覆盖、相邻镜头及声画区间，之后才更新摘要并运行最终校验。无工具时同样复读修订后的完整文本。无需为删重复措辞重算未改变的时间线；若改变了实际动作或切点，则按原流程重估。校验过程与“已去重”等说明不进入正式提示词。

## 返回前逐句检查

检查所有最终字段，以及渲染器会写出的 `presentation`、`camera_text`、`visual_text`、`action_text`、`resume_text`、人物位置句、`performance` 和音效／转场文字。每句明确“谁／什么对象、哪里、做什么或听到什么”，并核对本机位是否确实看得到、朝向与运动方向是否相容、现场开口是否可见且与声源一致；无法对应具体视听结果的评价、隐喻和心理结论删除或按当前剧情改写。保留确实帮助区分表演且绑定具体行为的简短意图，不按情绪关键词一律删除。不要只检查画面正文而漏掉段首“整体风格／对话氛围”和音色括号。

同步更新与正文绑定的动作句、关系证据等受影响记录，然后按原流程重新渲染、复核和校验。完成上述冗余校验，将抽象词清理、重复／错位内容处理及必要剧情与承接信息保留的实际结果记入已有 `delivery_review.visual_continuity`，发现矛盾及处理依据记入 `conflicts`；不新增正式字段或额外报告。现有脚本检查结构、区间及文字绑定，不能判断所有形容词上下文或语义冗余，不能用自动关键词删除、机械去重或“脚本通过”替代这项内容复核，也不能声称已验证实际视频效果。
